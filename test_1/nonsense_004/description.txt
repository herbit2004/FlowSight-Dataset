## Edges, Branches & Convergence
- `User Request --> Database`: The user request triggers a database write.
- `Database -- Yes --> Is Data Available?`: Checks if data is available after the database write.
- `Is Data Available? -- No --> API Gateway`: If data is not available, the API gateway is called.
- `Is Data Available? -- Yes --> Payment Service`: If data is available, the payment service is called.
- `API Gateway --> Database`: The API Gateway triggers a database write.
- `Payment Service --> Cache`: The payment service updates the cache.
- `Cache -- Success --> User Request`: On successful caching, the flow returns to the user request.
- `Cache -- Failure --> Message Queue`: On caching failure, a message is sent to the message queue.
- `Message Queue --> Authentication?`: The message queue triggers authentication.
- `Authentication? -- No --> Authorization`: If authentication fails, authorization is performed.
- `Authentication? -- Yes --> Logging`: If authentication succeeds, logging is performed.
- `Authorization --> Logging`: Authorization triggers logging.
- `Logging --> Rate Limiter`: Logging triggers the rate limiter.
- `Rate Limiter --> User Profile`: The rate limiter updates the user profile.
- `User Profile --> Logout`: User profile update triggers logout (but actually updates user profile).
- `Logout --> Fraud Detection`: Logout triggers fraud detection.
- `Fraud Detection --> Charge User?`: Fraud detection triggers a check to charge the user.
- `Charge User? -- No --> User Interface`: If the user is not charged, the user interface is displayed.
- `Charge User? -- Yes --> Cache`: If the user is charged, the cache is updated.
- `User Interface --> User Request`: The user interface redirects to the user request.
