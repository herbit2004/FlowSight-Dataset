## Repository Context & Terminology
- **Traces**: A set of spans representing a single request or transaction through the system.
- **Metrics**: Numerical measurements collected at intervals to monitor the performance and health of the system.
- **Logs**: Textual records of events that occur within the system.
- **Spans**: A unit of work within a trace, representing a single operation or function call.
- **Observability**: The ability to understand the internal state of a system by examining its outputs.
