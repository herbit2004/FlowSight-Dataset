## Edges, Branches & Convergence
`User Request --> Cache Hit?`: The user request is passed to the cache check.
`Cache Hit? -- Yes --> Database Write`: If there is a cache hit, data is written to the database.
`Cache Hit? -- No --> Authz`: If there is a cache miss, the request proceeds to authorization.
`Authz --> Login`: After authorization, the user needs to login.
`Login --> API Gateway`: After login, the request is routed through the API Gateway.
`API Gateway --> Payment Required?`: The API Gateway checks if payment is required.
`Payment Required? -- Yes --> Process Payment`: If payment is required, the payment is processed.
`Payment Required? -- No --> Message Queue`: If payment is not required, the request is sent to a message queue.
`Process Payment --> Cache Write`: After payment is processed, data is written to the cache.
`Cache Write --> API Gateway`: After writing to the cache, the flow loops back to the API Gateway.
`Message Queue --> Search Index`: The message queue triggers an update to the search index.
`Search Index --> Logout`: After updating the search index, the user is logged out.
`Logout --> User Response`: After logout, the user response is generated.
`Database Write --> User Request`: After writing to the database, the flow loops back to the user request.
