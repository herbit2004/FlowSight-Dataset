# Pilot V3 实验有效性分析

本文档基于「四类数据 × 多模型」的小规模 pilot 设计，讨论：**运行结果能否作为实验论文的有效证明**、**能得出什么结论**、**可能不符合预期的地方**，以及**建议的改进方向**。实际跑完 pilot_v3 后，可将 report.txt 中的数值代入下文做具体解读。

---

## 一、结果能否作为论文的有效证明？

### 可以支撑的用途（有限但有用）

1. **方法可行性**  
   - 证明「按数据来源分层 + 多模型评测」的 pipeline 可跑通，全量实验（如 1000 条 × N 模型）在工程上可行。  
   - 证明四类数据（real / meaningful / chaos / misleading）在现有数据集与 metadata 下可明确划分、可复现抽样。

2. **趋势与假设检验**  
   - 若在 40 条上观察到「real ≈ meaningful > misleading > chaos」或「无意义类准确率明显下降」，可作为**初步证据**支持假设：模型在「看图」而非纯凭常识；真实/拟真数据更有评测价值。  
   - 若不同模型在 chaos / misleading 上排序与在 real 上不一致，可支撑「常识强的模型在反常识/误导题上更易翻车」的讨论。

3. **为审稿/答辩提供“预实验”**  
   - 论文中可写：在 40 条 pilot 上观察到……，全量实验设计见 4.2 节。审稿人若质疑设计，可指向 pilot 结果与设计文档。

### 不足以单独作为“结论”的部分

1. **样本量小**  
   - 每类仅 10 条、共 40 条，统计波动大，**不能**仅凭 pilot 下「模型 A 显著优于模型 B」的结论；只能说「趋势与假设一致，有待全量验证」。

2. **未控制混淆因素**  
   - QA 由 LLM 按图生成，题目难度/风格未在四类间平衡；同一模型在不同类型上的差异可能来自「题目难度」而非「数据来源」本身。  
   - 若要更强因果性，需在全量中控制题目类型（factual/reasoning/negation）与难度，或做分层分析。

3. **单次运行、单一种子**  
   - 当前仅固定种子 42 抽样一次；未做多次抽样/多次运行以报告方差或置信区间，因此 pilot 更适合作为「探索性证据」而非「显著性结论」。

**综合**：Pilot V3 结果**适合**作为「实验设计合理、假设初步成立、值得做全量」的**证据**；**不适合**作为「模型排序已定、数据来源效应已证实」的**最终结论**。论文中应明确标注为 pilot/预实验，并与全量实验区分。

## 二、能得出什么结论？

在 pilot 跑出合理结果的前提下，可以谨慎得出或讨论的结论包括：

1. **数据来源效应（若趋势明显）**  
   - 「在 pilot 上，真实与 LLM 有意义数据上的准确率高于无意义数据（chaos/misleading），与“流程图理解应依赖图示而非常识”的假设一致。」  
   - 「在误导类(misleading)上，部分模型准确率下降更明显，与“常识会误导”的设定相符。」

2. **模型差异（描述性）**  
   - 「不同参数量/形态（8B/30B/235B、instruct/thinking）在四类数据上的准确率排序存在差异，可作为全量实验模型选的参考。」

3. **无意义子类型的区分度**  
   - 「chaos 与 misleading 在准确率或错题模式上是否可区分；若可区分，可支撑“完全混乱 vs 误导”在评测上的不同价值。」

4. **题目类型与难度**  
   - 「在 pilot 上，reasoning/negation 与 easy/medium/hard 的分布是否在四类间均衡；若否，可提示全量需分层或平衡题目。」

上述结论均需在文中限定为「pilot 上观察到」「有待全量验证」。

---

## 三、可能不符合预期的地方

1. **无意义类准确率未必低**  
   - 若 chaos 题过难（读不懂图），模型可能乱猜，准确率约 25%；若题目偏简单（如仅问图中某节点名），准确率可能不低。  
   - Misleading 若题目未踩中「错误点」，模型按常识答对，会显得「误导性」不足。  
   - **应对**：检查 chaos/misleading 的题目是否真正考察「按图作答」；必要时对无意义类加大 negation/反常识题比例。

2. **四类准确率曲线扁平**  
   - 若 real ≈ meaningful ≈ chaos ≈ misleading，则「数据来源」分层没有区分度，可能原因：题目过易、模型过强、或抽样偶然。  
   - **应对**：全量加大样本；引入更难题目或更细的题目类型分层。

3. **模型预检失败过多**  
   - 若多个模型在 probe 上无法稳定返回 A/B/C/D，实际参与评测的模型变少，表格稀疏。  
   - **应对**：换用支持视觉的模型或调整 prompt；在文中说明「部分模型未通过预检，未纳入下表」。

4. **QA 生成失败或质量差**  
   - 对 chaos 图，LLM 可能生成不出「仅凭图可答」的题，或题目与图不对应。  
   - **应对**：对生成失败的样本做人工补题或排除，并在报告中注明。

5. **误导类“错误点”与题目不匹配**  
   - metadata 中的 `introduced_errors` 与题目未对齐时，难以分析「错在常识还是错在看图」。  
   - **应对**：全量可考虑基于 `introduced_errors` 定向出题（如针对某条错误设计 negation 题）。

---

## 四、建议的改进方向

1. **全量实验**  
   - 将 40 条扩展为 1000 条（500 real + 200 meaningful + 300 nonsense），统一风格、固定题目类型/难度比例，报告按数据来源与模型分层的准确率及（若可行）置信区间。

2. **题目与数据来源对齐**  
   - 对 misleading 样本，利用 `introduced_errors` 生成「针对该错误」的题目，使「按图答对 / 按常识答错」可被直接观测。  
   - 对 chaos，明确题目均为「图中可见」的事实/推理，避免依赖常识。

3. **多次抽样/多次运行**  
   - 若资源允许，对 pilot 做 2–3 次不同种子抽样或 2 次独立运行，报告均值与范围，增强「趋势稳定」的说服力。

4. **错题分析**  
   - 对 1–2 个模型，在 real 与 misleading 上做小规模错题标注（误读图 / 推理错 / 被常识带偏），用于论文的定性讨论与案例展示。

5. **与 pilot_v2 的衔接**  
   - 若 pilot_v2 已得到「题目类型/难度有区分度」的结论，pilot_v3 可沿用相同 QA 设计，仅将「样本来源」从「前 10 条真实」改为「四类各 10 条」，便于对比「数据来源」与「题目类型」两个维度。

---

## 五、小结

| 维度 | 说明 |
|------|------|
| **有效性** | 可作为「设计可行、假设初步成立」的预实验证据；不宜作为最终统计结论的唯一依据。 |
| **可得出结论** | 数据来源效应趋势、模型在四类上的描述性差异、无意义子类型区分度、题目均衡性提示。 |
| **不符合预期时** | 无意义类准确率不低、四类曲线扁平、预检失败多、QA 质量差、误导与题目不对齐。 |
| **改进方向** | 全量 1000 条、题目与 introduced_errors 对齐、多次抽样/运行、错题分析、与 pilot_v2 衔接。 |

跑完 `python pilot_v3/run.py` 后，将 `pilot_v3/out/report.txt` 中的「按数据来源类型」「按模型×数据来源」表格与上文对照，即可写出一段简短的 pilot 结论与局限，放入论文或实验计划文档。
