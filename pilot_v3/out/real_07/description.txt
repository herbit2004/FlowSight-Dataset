## 图类型与用途
这是一个流程图，描述了 `markdown-preview.nvim` 插件的工作流程，该插件用于在 Neovim 中实时预览 Markdown 文件，并支持 Mermaid 图表。该图概括了 Markdown 预览的主流程，展示了从 Neovim 编辑器到浏览器预览的整个过程。

## 图的整体布局
图采用从左到右的布局。从左侧的 Neovim Buffer 开始，经过一系列处理，最终在右侧的 Rendered Preview 中呈现。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为三个阶段：编辑与文件写入、服务器推送、浏览器渲染。

## 节点逐项说明
- **A[Neovim Buffer]**: Neovim 编辑器中的 Markdown 缓冲区，用户在此编辑 Markdown 文件。
- **B[content.md]**: 实际的 Markdown 文件，存储了缓冲区中的内容。该文件位于工作区目录中，根据 `lua/markdown_preview/init.lua` 中的配置，默认文件名为 "content.md"。
- **C[live-server.nvim]**: 一个纯 Lua HTTP 服务器，负责监听 `content.md` 的变化并向浏览器推送更新。根据 README，该服务器由 `live-server.nvim` 提供。
- **D[Browser]**: 用户的浏览器，用于显示 Markdown 预览。
- **E[markdown-it]**: 一个 Markdown 解析器，用于将 Markdown 文本转换为 HTML。根据 README，该解析器用于 Markdown 语法解析。
- **F[mermaid.js]**: 一个 JavaScript 库，用于渲染 Mermaid 图表。根据 README，该库用于将 Mermaid 语法渲染成 SVG 图形。
- **G[highlight.js]**: 一个 JavaScript 库，用于代码块的语法高亮。根据 README，该库用于对 Markdown 中的代码块进行语法高亮显示。
- **H[Rendered Preview]**: 浏览器中最终渲染的 Markdown 预览，包括 HTML 内容、Mermaid 图表和语法高亮的代码块。

## 连线、分支与汇聚关系
- `A -> B`：Neovim Buffer 中的内容被写入到 content.md 文件中。
- `A -.-> B`：可选的，Neovim Buffer 可以使用 `mmdr` (mermaid-rs-renderer) 来加速 Mermaid 图表的渲染，并将渲染结果写入 content.md。
- `B -> C`：live-server.nvim 通过文件系统监听 content.md 的变化。
- `C -> D`：live-server.nvim 通过 Server-Sent Events (SSE) 将更新推送到 Browser。
- `D -> E`：Browser 使用 markdown-it 解析 Markdown 文本。
- `D -> F`：Browser 使用 mermaid.js 渲染 Mermaid 图表。
- `D -> G`：Browser 使用 highlight.js 对代码块进行语法高亮。
- `E -> H`：markdown-it 的输出最终组合成 Rendered Preview。
- `F -> H`：mermaid.js 的输出最终组合成 Rendered Preview，形成汇聚关系。
- `G -> H`：highlight.js 的输出最终组合成 Rendered Preview，形成汇聚关系。

## 仓库语境与术语解释
- **Neovim Buffer**: Neovim 编辑器中用于编辑 Markdown 文件的缓冲区。
- **content.md**: 默认情况下，插件会将 Markdown 内容写入到名为 `content.md` 的文件中，该文件名可在 `lua/markdown_preview/init.lua` 中配置。
- **live-server.nvim**: 一个纯 Lua HTTP 服务器，用于监听文件变化并向浏览器推送更新。该服务器由仓库 `selimacerbas/live-server.nvim` 提供。
- **SSE (Server-Sent Events)**: 一种服务器推送技术，用于将更新实时推送到浏览器。
- **markdown-it**: 一个 Markdown 解析器，用于将 Markdown 文本转换为 HTML。
- **mermaid.js**: 一个 JavaScript 库，用于渲染 Mermaid 图表。
- **highlight.js**: 一个 JavaScript 库，用于代码块的语法高亮。
- **mmdr (mermaid-rs-renderer)**: 一个可选的 Rust 渲染器，用于加速 Mermaid 图表的渲染。可以在 `lua/markdown_preview/init.lua` 中配置使用。

## 可作为 QA Ground Truth 的高信息密度摘要
该图描述了 `markdown-preview.nvim` 插件的工作流程。从 Neovim Buffer 开始，Markdown 内容被写入 `content.md` 文件，`live-server.nvim` 监听该文件变化并通过 SSE 推送到 Browser。Browser 使用 `markdown-it`、`mermaid.js` 和 `highlight.js` 分别进行 Markdown 解析、Mermaid 图表渲染和代码高亮，最终组合成 Rendered Preview。可选的 `mmdr` 可以加速 Mermaid 图表的渲染。`content.md` 文件和 `live-server.nvim` 是该流程中的关键中间环节。
