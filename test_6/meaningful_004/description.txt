## Edges, Branches & Convergence
- `Producer Application --> Order Validation Logic`: The producer application sends an order to the order validation logic.
- `Order Validation Logic -- Valid Order --> Order Type?`: Validated order is sent to determine the order type.
- `Order Type? -- Express --> Express Queue`: Express orders are routed to the express queue.
- `Order Type? -- Standard --> Standard Queue`: Standard orders are routed to the standard queue.
- `Express Queue --> Queue Manager`: Express queue sends messages to the queue manager.
- `Standard Queue --> Queue Manager`: Standard queue sends messages to the queue manager.
- `Queue Manager --> Consumer Group A: Order Processing`: The queue manager routes messages to consumer group A for order processing.
- `Queue Manager --> Consumer Group B: Analytics Ingestion`: The queue manager routes messages to consumer group B for analytics ingestion.
- `Consumer Group A: Order Processing --> Inventory Check?`: Consumer group A checks the inventory.
- `Inventory Check? -- Available --> Create Order Record`: If inventory is available, an order record is created.
- `Inventory Check? -- Unavailable --> Order Backlog Queue`: If inventory is unavailable, the order is sent to the order backlog queue.
- `Create Order Record --> Transaction Manager / DB Commit`: An order record is sent to the transaction manager for database commit.
- `Transaction Manager / DB Commit --> Order Fulfillment System`: The committed order is sent to the order fulfillment system.
- `Order Fulfillment System --> Delivery Service Integration`: The order fulfillment system integrates with the delivery service.
- `Delivery Service Integration --> Delivery Confirmation`: The delivery service confirms the delivery.
- `Order Backlog Queue --> Retry Logic`: Backlogged orders are sent to retry logic.
- `Retry Logic -- Retry Enabled --> Standard Queue`: If retry is enabled, the order is sent back to the standard queue.
- `Retry Logic -- Retry Exhausted --> Exception Handling / Alerting`: If retry is exhausted, an exception is handled and an alert is generated.
- `Exception Handling / Alerting --> Error Reporting System`: Exceptions are reported to the error reporting system.
- `Consumer Group B: Analytics Ingestion --> Data Transformation & Enrichment`: Consumer group B sends data to data transformation and enrichment.
- `Data Transformation & Enrichment --> Data Lake Ingestion`: Transformed data is ingested into the data lake.

## Repository Context & Terminology
- **Message Queue**: A software component that allows applications to communicate asynchronously by sending and receiving messages.
- **Producer**: An application that sends messages to a message queue.
- **Consumer**: An application that receives messages from a message queue.
- **Queue Manager**: A component that manages the routing of messages between queues and consumers.
- **Consumer Group**: A group of consumers that process messages from a queue.
- **Data Lake**: A centralized repository for storing structured and unstructured data.
- **Transaction Manager**: A component that manages database transactions.
