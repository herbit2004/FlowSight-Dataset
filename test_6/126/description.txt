## Repository Context & Terminology
- **Formatting Context**: A formatting context is a part of the CSS visual rendering model. It is a space where the boxes are laid out. Different formatting contexts have different rules for layout.
- **Block Formatting Context (BFC)**: A BFC is a formatting context for block-level boxes. It is responsible for the layout of block-level elements and their content.
- **Inline Formatting Context (IFC)**: An IFC is a formatting context for inline-level boxes. It is responsible for the layout of inline-level elements and their content.
- **Flex Formatting Context**: A formatting context created by a flex container. It governs the layout of flex items.
- **Grid Formatting Context**: A formatting context created by a grid container. It governs the layout of grid items.
- **Table Formatting Context**: A formatting context created by a table element. It governs the layout of table cells, rows, and columns.
- **Multi-column Formatting Context**: A formatting context created by a multi-column element. It governs the layout of content across multiple columns.
- **Fragmentainers**: A fragmentainer is a box that contains a fragment of a larger element. In multi-column layouts, content is fragmented into fragmentainers to fit within columns.
