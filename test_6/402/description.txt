## Repository Context & Terminology
- **GitHub Issues**: A feature of GitHub for tracking tasks, bugs, and feature requests.
- **Git Worktree**: A Git feature that allows having multiple working directories attached to the same repository.
- **Riverpod**: A reactive caching and data-binding framework.
- **Go Router**: A declarative navigation solution for Flutter based on routes.
- **Slang**: A Flutter package for managing internationalization (i18n).
- **GitHub Actions**: A CI/CD platform that automates software workflows.
- **Quality Gates**: Checks performed at various stages of the software development lifecycle to ensure that the software meets certain quality criteria.
