## Repository Context & Terminology
- **NestJS Monorepo**: A repository structure where multiple applications and libraries are managed within a single repository.
- **Apps Directory**: Contains independent services like `api-server`, `worker`, `websocket-service`, and `admin`.
- **Libs Directory**: Contains shared libraries used across multiple applications.
- **Swagger Docs**: API documentation generated using Swagger/OpenAPI.
- **Environment Variables (ENV)**: Used to configure the application, including database selection.
- **REST API**: An architectural style for building web services.
- **Socket.IO**: A library that enables real-time, bidirectional communication between web clients and servers.
