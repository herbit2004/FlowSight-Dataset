## Repository Context & Terminology
- **Integration**: The process of combining code changes from multiple developers into a single repository.
- **Build**: The process of compiling source code into executable code.
- **Unit Testing**: A software testing method where individual units or components of the software are tested.
- **Artifact Store**: A repository for storing build artifacts, such as compiled code, libraries, and other dependencies.
- **Deploy**: The process of releasing software to a target environment.
- **Automated Function Testing**: A software testing method where functional tests are executed automatically.
- **Staging Environment**: An environment that closely resembles the production environment and is used for final testing before deployment to production.
- **Production Environment**: The live environment where the software is deployed and used by end-users.
