## 图类型与用途
这是一个架构图，展示了 Bionic-GPT 系统的整体架构和数据流，以及用户请求如何被处理和路由。Bionic-GPT 旨在提供本地化部署的 ChatGPT 替代方案，强调数据保密性。

## 图的整体布局
图采用从左到右的布局。用户作为起点位于最左侧，请求依次经过 Nginx 路由器、OAuth2 代理，然后到达 Kubernetes 集群中的 Rust Web 服务器。

## 分组/子图/阶段说明
图中包含一个显式的 Kubernetes 子图，表示 Bionic-GPT 系统在 Kubernetes 集群中部署和运行。该子图内部署了 Nginx 路由器、OAuth2 代理、Rust Web 服务器、RAG 引擎、文档引擎和 Postgres 数据库等组件。

## 节点逐项说明
- **User**：系统的最终用户，通过客户端与系统交互。
- **Nginx Router**：作为入口点，负责路由用户请求到相应的服务。
- **OAuth2 Proxy**：负责处理用户身份验证和授权，与外部身份提供商交互。
- **High Performance Rust Web Server**：Bionic-GPT 的核心 API 服务，使用 Rust 编写，提供高性能的 Web 接口。
- **High Performance RAG Engine**：Retrieval-Augmented Generation (RAG) 引擎，用于从数据库和文档中检索相关信息，增强 LLM 的生成能力。
- **Rust Document Engine**：用于处理和索引文档的引擎，使用 Rust 编写。
- **Postgres**：PostgreSQL 数据库，用于存储关系数据和向量数据，支持 PgVector 扩展。
- **External Identity Provider**：外部的身份验证服务，例如 OAuth 提供商，用于验证用户身份。
- **LLM Provider**：大语言模型提供商，例如 Ollama、OpenAI 或 Anthropic，提供生成式 AI 能力。
- **S3-Compatible Object Storage**：用于存储文档和其他数据的对象存储服务，兼容 AWS S3 接口。

## 连线、分支与汇聚关系
- `User -> Nginx Router`：用户请求首先到达 Nginx 路由器。
- `Nginx Router -> OAuth2 Proxy`：Nginx 路由器将请求转发给 OAuth2 代理。
- `OAuth2 Proxy -> RustServer`：OAuth2 代理将验证后的请求转发给 Rust Web 服务器。
- `OAuth2 Proxy -> IdP`：OAuth2 代理与外部身份提供商进行交互，验证用户身份。
- `IdP -> OAuth2 Proxy`：身份提供商验证成功后，将信息返回给 OAuth2 代理。
- `RustServer -> RAG`：Rust Web 服务器将请求传递给 RAG 引擎进行检索增强生成。
- `RustServer -> LLM`：Rust Web 服务器与 LLM 提供商交互，获取生成式 AI 的结果。
- `RustServer -> Postgres`：Rust Web 服务器与 Postgres 数据库进行交互，存储和检索数据。
- `RAG -> Postgres`：RAG 引擎与 Postgres 数据库交互，从数据库中检索相关信息。
- `RAG -> DocEngine`：RAG 引擎与文档引擎交互，从文档中检索相关信息。
- `RustServer -> S3`：Rust Web 服务器可以直接访问 S3 兼容的对象存储，用于存储和检索文档等数据。

## 仓库语境与术语解释
- **Bionic-GPT**：一个旨在提供本地化部署的 ChatGPT 替代方案，强调数据保密性。README 描述 Bionic 为 "an on-premise replacement for ChatGPT, offering the advantages of Generative AI while maintaining strict data confidentiality"。
- **Kubernetes (K8s)**：一个容器编排平台，用于自动化部署、扩展和管理容器化应用程序。
- **RAG (Retrieval-Augmented Generation)**：一种通过从外部知识源检索信息来增强语言模型生成能力的技术。
- **PgVector**：PostgreSQL 的一个扩展，用于存储和查询向量数据，常用于 RAG 场景中的语义搜索。
- **Rust Web Server**：Bionic-GPT 的核心 API 服务，使用 Rust 编写，提供高性能的 Web 接口。
- **S3-Compatible Object Storage**：一种兼容 AWS S3 接口的对象存储服务，用于存储非结构化数据，例如文档和图像。
- **Ollama / OpenAI / Anthropic**：图中可见，是可能使用的 LLM 提供商，但仓库上下文未进一步说明。
