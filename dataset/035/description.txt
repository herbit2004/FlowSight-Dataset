## Repository Context & Terminology
- **Presentation Package**: This package typically contains the UI layer of the application, responsible for displaying data and handling user interactions.
- **Data Package**: This package is responsible for data access, persistence, and networking. It interacts with databases, APIs, and other external data sources.
- **Domain Package**: This package contains the core business logic of the application, defining use cases and interacting with data through repository protocols.
- **Models Package**: This package defines the data structures used throughout the application.
- **Shared Modules**: This package contains common utilities and helper functions used across different modules.
- **Repository Protocols**: These define the interfaces for data access, allowing the domain layer to interact with data without being tied to specific implementations.
- **Use Cases / Interactors**: These represent specific business operations or workflows within the application.
