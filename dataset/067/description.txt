## 图类型与用途
这是一个架构图，展示了 Forward Deployment Engineering (FDE) 中，客户端本地环境的数据如何通过 Google Cloud Platform (GCP) 的服务进行处理，并提供基于 AI 的搜索和查询能力。该图在仓库中用于说明如何利用 Vertex AI Search 和 Google ADK Agent Engine 构建智能化的查询和搜索能力，并强调安全性。

## 图的整体布局
图整体采用从左到右的布局。左侧是客户端环境，中间是 GCP Landing Zone，下方是安全层，用户作为请求发起方位于最左下方。

## 分组/子图/阶段说明
- **Client Environment (On-Prem)**：客户端本地环境，包含 DB (Legacy SQL) 和 Cloud Storage / GCS。
- **GCP Landing Zone**：部署在 Google Cloud Platform 上的区域，包含 Cloud Storage / GCS, Vertex AI Search, Google ADK Agent Engine 和 Multi-Agent Swarm。
- **Multi-Agent Swarm**：ADK Agent Engine 内部的多智能体集群，包含 Planner Agent, SQL Coder Agent 和 Reviewer Agent。
- **Security Layer**：安全层，包含 VPC Service Controls 和 Identity-Aware Proxy。

## 节点逐项说明
- **DB (Legacy SQL)**：客户端的传统 SQL 数据库，存储着需要被访问和利用的数据。
- **Cloud Storage / GCS**：Google Cloud Storage，用于存储数据。从客户端数据库迁移过来的数据可能先存储在这里。
- **Vertex AI Search**：Google Cloud 的 Vertex AI Search 服务，用于构建基于 AI 的搜索应用。
- **Google ADK Agent Engine**：Google 的 Agent Development Kit (ADK) Agent Engine，用于构建和管理多智能体系统。
- **Planner Agent**：规划智能体，负责制定查询和搜索的计划。
- **SQL Coder Agent**：SQL 代码生成智能体，负责根据 Planner Agent 的计划生成 SQL 查询语句。
- **Reviewer Agent**：审核智能体，负责审核 SQL Coder Agent 生成的 SQL 查询语句。
- **BigQuery**：Google Cloud 的数据仓库服务，用于存储和分析大规模数据集。
- **VPC Service Controls**：VPC 服务控制，用于限制对 GCP 服务的访问，增强安全性。
- **Identity-Aware Proxy**：身份识别代理，用于验证用户身份，确保只有授权用户才能访问应用。
- **User**：最终用户，通过身份验证后可以访问系统。

## 连线、分支与汇聚关系
- `DB (Legacy SQL) -- Cloud Interconnect --> Cloud Storage / GCS`：客户端的本地数据库通过 Cloud Interconnect 连接到 GCP，数据被迁移到 Cloud Storage。
- `Cloud Storage / GCS -> Vertex AI Search`：Cloud Storage 中的数据被 Vertex AI Search 索引，用于构建搜索能力。
- `Vertex AI Search -> Google ADK Agent Engine`：Vertex AI Search 将搜索请求传递给 Google ADK Agent Engine 进行处理。
- `Google ADK Agent Engine -> Planner Agent`：ADK Agent Engine 将搜索请求分发给 Planner Agent。
- `Google ADK Agent Engine -> SQL Coder Agent`：ADK Agent Engine 将搜索请求分发给 SQL Coder Agent。
- `Google ADK Agent Engine -> Reviewer Agent`：ADK Agent Engine 将搜索请求分发给 Reviewer Agent。
- `SQL Coder Agent -- Query --> BigQuery`：SQL Coder Agent 生成的 SQL 查询语句用于查询 BigQuery。
- `Planner Agent -- Grounding --> Vertex AI Search`：Planner Agent 通过 Grounding 连接到 Vertex AI Search。
- `User -> Identity-Aware Proxy`：用户通过 Identity-Aware Proxy 进行身份验证。
- `Identity-Aware Proxy -> Google ADK Agent Engine`：身份验证后的用户可以访问 Google ADK Agent Engine。

## 仓库语境与术语解释
- **Forward Deployment Engineering (FDE)**：根据 README，FDE 是在最重要的地方交付复杂软件的艺术，是软件工程师、AI/数据架构师和战略顾问的混合角色。
- **GCP Landing Zone**：根据 README，FDE 需要掌握如何在客户端的 GCP 项目中安全地部署和扩展。
- **Cloud Interconnect**：根据 README，用于桥接客户端的本地数据中心到 GCP 的安全连接方式。
- **Vertex AI Search**：GCP 提供的 AI 搜索服务。
- **Google ADK Agent Engine**：Google 的 Agent Development Kit (ADK) Agent Engine，用于构建和管理多智能体系统。
- **BigQuery**：根据 README，用于处理 petabyte 级别分析的数据仓库服务。
- **Identity-Aware Proxy (IAP)**：根据 README，用于在没有 VPN 的情况下授予对内部应用的访问权限。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了从客户端本地的 Legacy SQL 数据库开始，通过 Cloud Interconnect 将数据迁移到 GCP 的 Cloud Storage。数据在 Vertex AI Search 中被索引，并通过 Google ADK Agent Engine 进行处理，该引擎包含 Planner Agent, SQL Coder Agent 和 Reviewer Agent。SQL Coder Agent 生成的查询用于查询 BigQuery。用户通过 Identity-Aware Proxy 访问系统，VPC Service Controls 用于增强安全性。该架构利用 GCP 服务为客户端提供基于 AI 的搜索和查询能力。
