## Edges, Branches & Convergence
- `Neovim Buffer --> content.md`: The Markdown content is written to the content.md file.
- `Neovim Buffer -.-> content.md`: Optional mmdr.
- `content.md --> live-server.nvim`: The live server watches the content.md file for changes.
- `live-server.nvim --> Browser`: The live server sends updates to the browser via Server-Sent Events (SSE).
- `Browser --> markdown-it`: The browser sends the Markdown content to markdown-it for parsing.
- `Browser --> mermaid.js`: The browser sends the Markdown content to mermaid.js for diagram rendering.
- `Browser --> highlight.js`: The browser sends the Markdown content to highlight.js for syntax highlighting.
- `markdown-it --> Rendered Preview`: The output from markdown-it is sent to the rendered preview.
- `mermaid.js --> Rendered Preview`: The output from mermaid.js is sent to the rendered preview.
- `highlight.js --> Rendered Preview`: The output from highlight.js is sent to the rendered preview.
The outputs of markdown-it, mermaid.js, and highlight.js converge at the Rendered Preview node.

## High-Density QA Ground Truth Summary
The diagram begins with the "Neovim Buffer," where a user writes Markdown content, which is then saved as "content.md." Optionally, the Neovim Buffer can use mmdr. The "live-server.nvim" monitors "content.md" for changes using file system watching. Upon detecting a change, "live-server.nvim" sends updates to the "Browser" via Server-Sent Events (SSE). The "Browser" then distributes the Markdown content to three separate processors: "markdown-it" for general Markdown parsing, "mermaid.js" for rendering any embedded diagrams, and "highlight.js" for syntax highlighting code blocks. The outputs from "markdown-it," "mermaid.js," and "highlight.js" are then combined and displayed in the "Rendered Preview" within the browser, providing a live, updated view of the Markdown document. The diagram illustrates a common workflow for live Markdown preview, leveraging tools like Neovim, live-server, and JavaScript libraries for rendering and highlighting.
