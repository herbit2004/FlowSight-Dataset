## Repository Context & Terminology
- **ExternalSecret**: A Kubernetes Custom Resource Definition (CRD) that allows referencing secrets stored in external secret management systems like AWS Secrets Manager or HashiCorp Vault.
- **SealedSecret**: A Kubernetes controller and CRD that allows encrypting secrets so they can be safely stored in public repositories.
- **ConfigMap**: A Kubernetes API object used to store non-confidential configuration data in key-value pairs. Pods can consume ConfigMaps as environment variables, command-line arguments, or as configuration files in a volume.
- **Secret**: A Kubernetes API object used to store sensitive information, such as passwords, OAuth tokens, and SSH keys. Secrets are stored encrypted in the Kubernetes API server.
- **Deployment**: A Kubernetes API object that manages a replicated application. Deployments declare a desired state and the Deployment controller gradually updates the actual state to match the desired state.
- **DeploymentConfig**: An OpenShift resource similar to a Kubernetes Deployment, but with additional features like triggers for image changes and configuration updates.
- **DaemonSet**: A Kubernetes API object that ensures that all (or some) nodes run a copy of a pod. As nodes are added to the cluster, pods are added to them. As nodes are removed from the cluster, those pods are garbage collected. Deleting a DaemonSet will clean up the pods it created.
- **StatefulSet**: A Kubernetes API object used to manage the deployment and scaling of stateful applications. Unlike Deployments, StatefulSets maintain a sticky identity for each of their Pods. These pods are created from the same spec, but are not interchangeable: each has a persistent identifier that it maintains across any rescheduling.
- **Argo Rollout**: A Kubernetes controller that provides advanced deployment strategies such as canary and blue/green deployments.
- **CronJob**: A Kubernetes API object that creates Jobs on a schedule.
