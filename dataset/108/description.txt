## Repository Context & Terminology
- **Episodic Memory**: A memory system that stores specific events and experiences.
- **Working Memory**: A memory system that temporarily holds and manipulates information.
- **Long-term Memory**: A memory system that stores information for extended periods.
- **Vector Embeddings**: Numerical representations of data points in a high-dimensional space, used for similarity search and other machine learning tasks.
- **Knowledge Base**: A structured collection of information and knowledge about a specific domain.
- **Domain Expertise**: Specialized knowledge and skills in a particular field.
- **System State**: The current condition of the system, including its resources, configuration, and status.
