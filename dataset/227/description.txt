## Repository Context & Terminology
- **LLM (Large Language Model)**: A deep learning model trained on a massive amount of text data, capable of generating human-quality text, translating languages, and answering questions.
- **API (Application Programming Interface)**: A set of rules and specifications that software programs can follow to communicate with each other.
- **WebSocket**: A communication protocol that provides full-duplex communication channels over a single TCP connection.
- **Polling**: A technique where the client repeatedly requests new data from the server.
- **Gateway**: A server that acts as an intermediary between a client and a server.
