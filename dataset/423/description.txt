## Repository Context & Terminology
- **Number Base Conversion**: The process of converting a number from one base (e.g., binary, octal, decimal, hexadecimal) to another.
- **Binary (Base 2)**: A number system using only two digits: 0 and 1.
- **Octal (Base 8)**: A number system using eight digits: 0 to 7.
- **Decimal (Base 10)**: The standard number system using ten digits: 0 to 9.
- **Hexadecimal (Base 16)**: A number system using sixteen symbols: 0 to 9 and A to F.
- **Parse**: The process of analyzing and converting the user input into a specific number base format.
- **Convert**: The process of transforming a number from one base to another.
- **Result**: The converted number in a specific base format.
