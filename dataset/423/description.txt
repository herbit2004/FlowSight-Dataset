## 图类型与用途
这是一个流程图，描述了程序员计算器应用中，用户输入任意进制数值后，如何被转换成二进制、八进制、十进制和十六进制，并最终将所有格式的结果显示给用户。该图在 README.md 中被用作展示实时的数字系统转换流程。

## 图的整体布局
图整体采用从左到右的布局。左侧是输入节点，中间是转换中心，右侧是输出节点。

## 分组/子图/阶段说明
图中包含三个子图：
- **INPUT**：表示用户输入阶段。
- **CONVERSION HUB**：表示进制转换中心，包含二进制、八进制、十进制和十六进制四个节点。
- **OUTPUT**：表示最终结果输出阶段。

## 节点逐项说明
- **A (User Input Any Base)**：表示用户输入的任意进制数值，是整个流程的起点。
- **B (Binary 2️⃣)**：表示二进制数值。
- **C (Octal 8️⃣)**：表示八进制数值。
- **D (Decimal 🔟)**：表示十进制数值。
- **E (Hex 1️⃣6️⃣)**：表示十六进制数值。
- **F (All Formats Displayed)**：表示将所有进制的数值显示给用户，是整个流程的终点。

## 连线、分支与汇聚关系
- `A --> B`：用户输入被解析并传递到二进制组件。
- `A --> C`：用户输入被解析并传递到八进制组件。
- `A --> D`：用户输入被解析并传递到十进制组件。
- `A --> E`：用户输入被解析并传递到十六进制组件。
- `B <--> C`：二进制和八进制之间可以互相转换。
- `B <--> D`：二进制和十进制之间可以互相转换。
- `B <--> E`：二进制和十六进制之间可以互相转换。
- `C <--> D`：八进制和十进制之间可以互相转换。
- `C <--> E`：八进制和十六进制之间可以互相转换。
- `D <--> E`：十进制和十六进制之间可以互相转换。
- `B --> F`：二进制结果传递到输出组件。
- `C --> F`：八进制结果传递到输出组件。
- `D --> F`：十进制结果传递到输出组件。
- `E --> F`：十六进制结果传递到输出组件。
- 节点 B、C、D、E 汇聚到节点 F，形成汇聚关系。

## 仓库语境与术语解释
- **Binary / Octal / Decimal / Hex**：分别代表二进制、八进制、十进制和十六进制，是程序员计算器支持的主要数字系统。
- **Parse**：将用户输入的字符串解析为对应的数值类型，以便进行后续的进制转换。
- **Convert**：将数值从一种进制转换为另一种进制。
- **Result**：转换后的结果，准备输出显示。
- **GUI**：README 中提到 GUI 组件，该图展示了数据在不同进制组件间的流转，最终在 GUI 上显示。

## 可作为 QA Ground Truth 的高信息密度摘要
该图描述了程序员计算器的核心进制转换流程。用户输入任意进制的数值后，该数值会被解析并同时传递到二进制、八进制、十进制和十六进制组件。这些组件之间可以互相转换。最终，所有进制的数值都会传递到输出组件并显示给用户。核心流程是“用户输入 -> 解析 -> 进制转换 -> 结果输出”，展示了计算器支持二进制、八进制、十进制和十六进制之间互相转换的功能。
