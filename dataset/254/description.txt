## Diagram Type & Purpose

The diagram outlines the steps taken by two agents, the Triage Agent and the CodeFix Agent, to automate vulnerability remediation.

## Overall Layout
The diagram flows from left to right. It is divided into two subgraphs, "Triage Agent" and "CodeFix Agent," representing distinct stages in the remediation process. The start node is "Neo4j Attack Surface," and the end node is "Commit + Push GitHub PR."

## Repository Context & Terminology

- **LLM (Large Language Model)**: A type of AI model used for natural language processing and analysis.
- **ReAct Loop**: An iterative process where an agent reasons (Re) and acts (Act) to solve a task.
- **Diff Blocks**: The visual representation of code changes between two versions of a file.
- **GitHub PR (Pull Request)**: A request to merge code changes into a main branch on GitHub.
