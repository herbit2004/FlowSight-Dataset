## Diagram Type & Purpose
This is a flowchart diagram depicting the order processing workflow of an e-commerce system. It outlines the steps involved from receiving an order to updating inventory and handling customer feedback. The diagram serves as a visual representation of the order lifecycle, including inventory checks, payment processing, shipping, and customer satisfaction.

## Overall Layout
The diagram's primary direction is top-down (TD). It starts with the "Receive Order" node at the top and progresses downwards through various stages of order processing. The diagram contains an illogical loop where "Order Delivered" leads back to "Receive Order". The end node is "Update Inventory".

- `B -- Yes --> C`: If inventory is available, prepare the shipment.
- `B -- No --> H`: If inventory is not available, notify the customer of the delay.
- `C --> D`: After preparing shipment, check if payment is received.
- `D -- Yes --> F`: If payment is received, ship the order.

If inventory is available ("Yes" branch), the process moves to "Prepare Shipment" (C), then to "Payment Received?" (D). If payment is received ("Yes" branch), the order is "Ship Order" (F), and then "Order Delivered" (G), which illogically loops back to "Receive Order" (A).
