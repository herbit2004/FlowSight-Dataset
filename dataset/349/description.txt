## Repository Context & Terminology
- **Policy Network**: A neural network that outputs a probability distribution over possible actions given an observation.
- **Value Network**: A neural network that estimates the expected cumulative reward (value) of being in a particular state.
- **Rollout Collection**: The process of gathering experiences (state, action, reward, next state) by running the policy in the environment.
- **Advantage Calculation**: Estimating how much better an action is compared to the average action in a given state, often using Generalized Advantage Estimation (GAE).
- **PPO Clipping**: A technique used in Proximal Policy Optimization (PPO) to constrain policy updates, preventing large changes that could destabilize training.
- **PyBullet**: A physics engine used for simulating the robot's environment.
- **Adam Optimizer**: An adaptive learning rate optimization algorithm used to update the neural network weights.
- **Multi-objective Reward Function**: A reward function that considers multiple objectives or criteria when evaluating the agent's performance.
