## Repository Context & Terminology
- **glTF (GL Transmission Format)**: A royalty-free standard for 3D asset delivery.
- **PBR (Physically Based Rendering)**: A rendering technique that simulates the interaction of light with surfaces in a physically plausible way.
- **Shader**: A program that runs on the GPU and determines how a surface is rendered.
- **Surface Shader**: A type of shader that calculates the final color of a surface.
- **MaterialX**: A framework for describing material appearance. The `mtlx` prefix suggests that some nodes are MaterialX standard nodes.
- **Vector2**: A 2D vector, typically used for texture coordinates (UVs).
- **Color3**: A color represented by three components (RGB).
