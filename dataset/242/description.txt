## Diagram Type & Purpose
This is a flowchart diagram illustrating the context building process for a Large Language Model (LLM) request. It depicts the flow of information from various context sources, through a context builder, and finally into the LLM request. The diagram serves to visualize the steps involved in preparing the input for an LLM, ensuring it has sufficient context for generating relevant and coherent responses.

## Overall Layout
The diagram's layout is top-down (TD). It is hierarchically structured into three main stages: Context Sources, Context Builder, and LLM Request. The flow starts with multiple context sources at the top and ends with the user message within the LLM Request stage at the bottom.

## Subgraphs / Stages
The diagram contains three explicit subgraphs:
- **Context Sources**: This subgraph represents the various sources of information used to build the context for the LLM.
- **Context Builder**: This subgraph represents the process of merging and prioritizing the context information.
- **LLM Request**: This subgraph represents the final structure of the request sent to the LLM, including system messages, conversation history, and the user message.

## Repository Context & Terminology
- **LLM (Large Language Model)**: A deep learning model trained on a massive dataset of text and code, capable of generating human-like text.
- **Context Sources**: Various sources of information used to provide context to the LLM, enabling it to generate more relevant and coherent responses.
- **System Prompt**: A set of instructions or guidelines provided to the LLM to shape its behavior and responses.
- **Task Slots**: Placeholders for specific information related to the task at hand, such as weather or news.
- **User Preferences**: Information about the user's likes, dislikes, and other preferences, used to personalize the LLM's responses.
- **Constitutional Modifiers**: Rules or constraints that guide the LLM's behavior, ensuring it adheres to ethical and safety guidelines.
- **MCP Resources**: Resources provided by the Model Control Program, which manages and controls the LLM.
- **Vision State**: Information about the current state of the vision system, used to provide visual context to the LLM.
