## Repository Context & Terminology
- **Endpoints (Exposers)**: The entry points of the system, responsible for receiving external requests and mapping them to internal services.
- **HTTP Mapping**: The process of translating HTTP requests to internal service calls.
- **Processing Services**: Services that perform computationally intensive tasks, often involving AI/ML algorithms.
- **Orchestration Services**: Services that coordinate the execution of multiple foundation services to fulfill a request.
- **Foundation Services**: Services that provide basic data access and validation functionalities.
- **Brokers**: Components that abstract access to external systems, providing a simplified interface for internal services.
- **CRUD**: An acronym for Create, Read, Update, and Delete operations, representing basic data manipulation functions.
