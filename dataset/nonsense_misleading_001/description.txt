## High-Density QA Ground Truth Summary
The flowchart begins with "User Submits Order," which leads to the "Payment Received?" decision. If payment is not received, a "Send Payment Reminder" is triggered, followed by "Order Cancelled," and then "Order Processing Complete." If payment is received, the flow proceeds to "Order Placed" and then "Inventory Available?". If inventory is unavailable, the user is notified ("Notify User of Delay"), and a "Fulfill Backorder" process is initiated, followed by "Shipping Label Created." If inventory is available, "Shipping Label Created" is triggered directly. After the shipping label is created, the diagram checks "Package Delivered?". If not delivered, the "Mark Order as Complete" step is triggered, followed by "Send Shipping Confirmation." If the package is delivered, the "Order Shipped" step is triggered, leading to "Review Requested?". If a review is requested, a "Request Review" action is initiated, followed by "Order Processing Complete." If no review is requested, "Send Shipping Confirmation" is triggered. The "Send Shipping Confirmation" step incorrectly merges into "Order Processing Complete." The "Order Processing Complete" step then loops back to "User Submits Order," creating an illogical cycle. The "Package Delivered?" decision has a reversed outcome; a 'No' leads to marking the order as complete and sending shipping confirmation, while a 'Yes' leads to order shipment.
