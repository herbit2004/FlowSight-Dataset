## 图类型与用途
这是一个流程图，描述了 Machine Learning Zoomcamp 课程参与者在选择学习方式时需要考虑的因素。它旨在帮助学员根据自身需求选择加入直播课程或选择自学模式。

## 图的整体布局
图采用从上到下的布局。顶部是流程的起点，中间是决策节点，底部是两种学习模式及其特点。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可分为三个阶段：初始状态、决策阶段、学习模式选择。

## 节点逐项说明
- **A ("Want to learn Machine Learning Zoomcamp")**：流程的起点，表示学员想要学习 Machine Learning Zoomcamp 课程。
- **B {"Do you want deadlines & a certificate?"}**：一个决策节点，询问学员是否需要有截止日期和证书。
- **C ["Join Live Cohort"]**：表示加入直播课程，该课程有固定的时间表和截止日期。根据 README，直播课程在特定时间段（如 2025 年的 9 月至 12 月）进行。
- **D ["Self-Paced Learning"]**：表示选择自学模式，可以随时开始，按照自己的节奏学习。
- **C1 ["Fixed schedule (Sept-Dec)"]**：直播课程的特点：固定时间表（9月到12月）。
- **C2 ["Scored homework + leaderboard"]**：直播课程的特点：作业有评分，并有排行榜。根据 README，直播课程的作业会自动评分。
- **C3 ["2 projects + peer review"]**：直播课程的特点：需要完成两个项目，并进行同行评审。根据 README，直播课程需要完成项目并进行同行评审。
- **C4 ["Eligible for certificate"]**：直播课程的特点：完成课程后有资格获得证书。根据 README，完成直播课程后有资格获得证书。
- **D1 ["Start anytime, go at your own pace"]**：自学模式的特点：可以随时开始，按照自己的节奏学习。
- **D2 ["Unscored homework & optional projects"]**：自学模式的特点：作业没有评分，项目是可选的。
- **D3 ["No certificate"]**：自学模式的特点：完成课程后没有证书。

## 连线、分支与汇聚关系
- `A -> B`：学员从想要学习 Machine Learning Zoomcamp 课程开始，进入决策阶段。
- `B -- Yes --> C`：如果学员需要截止日期和证书，则选择加入直播课程。
- `B -- No / Not sure --> D`：如果学员不需要截止日期和证书，或者不确定，则选择自学模式。
- `C -> C1`：加入直播课程后，会遵循固定的时间表。
- `C -> C2`：直播课程的作业有评分，并有排行榜。
- `C -> C3`：直播课程需要完成两个项目，并进行同行评审。
- `C -> C4`：完成直播课程后有资格获得证书。
- `D -> D1`：选择自学模式后，可以随时开始，按照自己的节奏学习。
- `D -> D2`：自学模式的作业没有评分，项目是可选的。
- `D -> D3`：完成自学模式后没有证书。

## 仓库语境与术语解释
- **Machine Learning Zoomcamp**：一个免费的机器学习工程课程，旨在教授从模型构建到部署的完整流程。
- **Live Cohort**：直播课程，有固定的时间表、作业评分、项目实践和证书。
- **Self-Paced Learning**：自学模式，可以随时开始，按照自己的节奏学习，但没有评分和证书。
- **Certificate**：完成直播课程后有资格获得的证书。
- **Projects**：直播课程需要完成的项目，包括中期项目和最终项目，具体信息可以在 `projects.md` 文件中找到。
- **Leaderboard**：直播课程中，作业评分会出现在排行榜上，可以在课程管理平台或 `leaderboard.md` 文件中找到。
- **cohorts 目录**：仓库中包含多个 cohorts 目录，例如 `cohorts/2025`，其中包含特定年份直播课程的作业和截止日期。

## 可作为 QA Ground Truth 的高信息密度摘要
该流程图描述了 Machine Learning Zoomcamp 课程的学习方式选择。学员从“想要学习”开始，需要决定是否需要截止日期和证书。如果需要，则加入直播课程，享受固定时间表、作业评分、项目实践和证书；如果不需要，则选择自学模式，可以随时开始，但没有评分和证书。直播课程的具体信息可以在 `cohorts` 目录和 `projects.md` 文件中找到。
