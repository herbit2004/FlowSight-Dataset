## 图类型与用途
这是一个流程图，用于展示 CDK Express Pipeline 的部署架构，特别是部署流程的组织方式。它描述了一个分层、分阶段的部署流水线，其中包含了基础设施（Infra）和应用程序（Application）两大部分，并跨越了多个 AWS 区域。该图旨在可视化 CDK Express Pipeline 的部署结构，展示如何将部署任务组织成波次（Wave）和阶段（Stage），以及它们之间的依赖关系。

## 图的整体布局
图整体采用从上到下的布局。顶部是基础设施波次（Infra），底部是应用程序波次（Application）。每个波次内部包含多个并行部署的阶段（Stage），代表不同的 AWS 区域。

- **Wave0 (🌊 Infra)**：代表基础设施波次，包含 Iam 和 Networking 栈的部署。
- **Wave0Stage0 (🏗 us-east-1)**：代表基础设施波次中，美国东部 1 区的部署阶段，包含 Iam 和 Networking 栈。
- **Wave0Stage1 (🏗 eu-west-1)**：代表基础设施波次中，欧洲西部 1 区的部署阶段，包含 Networking 栈。
- **Wave1 (🌊 Application)**：代表应用程序波次，包含 AppA 和 AppB 栈的部署。
- **Wave1Stage0 (🏗 us-east-1)**：代表应用程序波次中，美国东部 1 区的部署阶段，包含 AppA 和 AppB 栈。
- **Wave1Stage1 (🏗 eu-west-1)**：代表应用程序波次中，欧洲西部 1 区的部署阶段，包含 AppA 和 AppB 栈。

## 仓库语境与术语解释
- **CDK Express Pipeline**：一个基于 AWS CDK 的库，允许以 CDK 原生的方式定义 pipelines。它利用 CDK CLI 计算和部署 Waves、Stages 和 Stacks 之间的依赖关系。
- **Wave**：代表一个部署的逻辑分组，例如基础设施（Infra）和应用程序（Application）。
- **Stage**：代表在一个波次内的并行部署单元，通常对应于不同的 AWS 区域，例如 us-east-1 和 eu-west-1。
- **Stack**：代表一个 CDK 栈，是实际部署的 AWS 资源集合。例如，Iam、Networking、AppA 和 AppB 都是 CDK 栈。
- **addDependency**：CDK Express Pipeline 使用 `.addDependency` 方法来定义 Waves、Stages 和 Stacks 之间的依赖关系，确保按照正确的顺序部署。
- **synth()**：`CdkExpressPipeline` 类的 `synth()` 方法用于合成 pipeline，创建 stacks 之间的依赖关系。
- **ExpressStack**：继承自 `cdk.Stack` 的类，用于定义 pipeline 中的 stack。
