## 图类型与用途
这是一个架构图，用于展示 Prisma Zod Generator (PZG) 的核心功能和 Pro 功能。它在仓库中的作用是概括 PZG 的功能，区分免费和付费功能。

## 图的整体布局
图整体采用左右布局，左侧是 Pro 功能，右侧是核心功能。每个功能模块都从 PZG 或 PZG Pro 出发，向下延伸展示具体特性。

## 分组/子图/阶段说明
图中包含两个主要子图：
- **🎯 CORE FEATURES (Free Forever)**：展示 PZG 的核心功能，包括 Schema Generation、Customization、Type Safety 和 Performance。
- **💎 PRO FEATURES (Paid Plans)**：展示 PZG Pro 的付费功能，包括 Security & Governance、Developer Experience 和 Platform & Scale。

## 节点逐项说明
- **PZG (Prisma Zod Generator)**：整个系统的核心，也是核心功能流程的起点。根据 README，PZG 用于统一 Prisma 验证、策略守卫和开发者工作流。
- **Schema Generation**：PZG 的一个核心功能，负责生成 Schema。
    - **⚡ Minimal Mode**：Schema 生成的一种模式，提供基本的 CRUD 功能。
    - **🌟 Full Mode**：Schema 生成的一种模式，提供完整的生态系统支持。
    - **🎛️ Custom Mode**：Schema 生成的一种模式，允许用户自定义。
    - **📦 Schema Variants**：支持不同的 Schema 变体，例如 Input, result, pure models。
    - **🔢 Decimal Handling**：处理 Decimal 类型的数据，支持 BigInt & Decimal。
    - **📅 DateTime Support**：支持 DateTime 类型的数据，支持 ISO formats & Zod v4。
- **Customization**：PZG 的另一个核心功能，允许用户进行自定义设置。
    - **🎨 Naming Patterns**：自定义命名规则。
    - **📂 File Organization**：自定义文件结构。
    - **🎯 Selective Generation**：选择性地生成部分 Schema。
    - **🔧 Config Options**：提供各种配置选项。
    - **🧰 Multi-Provider Helpers**：帮助处理多个数据提供商。
- **Type Safety**：PZG 提供的类型安全保障。
    - **✅ Zod v4 Formats**：兼容 Zod v4 格式，支持 ISO string methods。
    - **🛡️ Strict Mode**：提供更严格的类型检查。
    - **🔒 Type Checking**：进行类型检查。
    - **📋 Validation Suites**：提供验证套件。
- **Performance**：PZG 的性能优化特性。
    - **⚡ Fast Output**：快速生成输出。
    - **📦 Tree Shaking**：移除未使用的代码。
    - **🎯 Selective Imports**：选择性地导入需要的模块。
    - **📁 Granular Emit Control**：对输出进行细粒度的控制。
- **PRO (PZG Pro)**：PZG 的付费版本，提供更多高级功能。
- **Security & Governance**：Pro 版本提供的安全和治理功能。
    - **🛡️ Policies & Redaction**：提供策略和数据编辑功能。
        - **Role-Based Policies**：基于用户角色的策略。
        - **Conditional Access**：基于条件的访问控制。
        - **PII Redaction**：编辑个人身份信息。
    - **🚨 Drift Guard**：防止 Schema 漂移，提供 CI 集成。
- **Developer Experience**：Pro 版本提供的开发者体验功能。
    - **⚡ Server Actions Pack**：Next.js typed server actions。
- **Platform & Scale**：Pro 版本提供的平台和扩展功能。
    - **📦 SDK Publisher**：Generate typed client SDKs。

## 仓库语境与术语解释
- **Prisma**：一个 ORM (Object-Relational Mapper)，用于简化数据库访问。
- **Zod**：一个 TypeScript 优先的 Schema 声明和验证库。
- **Prisma Zod Generator (PZG)**：一个根据 Prisma Schema 自动生成 Zod Schema 的工具。
- **Schema Generation**：根据 Prisma Schema 生成 Zod Schema 的过程。
- **Minimal Mode**：PZG 的一种模式，只生成基本的 CRUD Schema。
- **Full Mode**：PZG 的一种模式，生成完整的 Schema，包括所有模型和关系。
- **Custom Mode**：PZG 的一种模式，允许用户自定义 Schema 生成过程。
- **Drift Guard**：PZG Pro 的一个功能，用于检测 Prisma Schema 的变更，防止 Schema 漂移。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 Prisma Zod Generator 的核心功能和 Pro 功能。核心功能（免费）包括 Schema Generation、Customization、Type Safety 和 Performance，Pro 功能（付费）包括 Security & Governance、Developer Experience 和 Platform & Scale。PZG 作为核心，通过 Schema Generation 提供多种模式（Minimal, Full, Custom）和 Schema 变体，并支持 Decimal 和 DateTime 类型处理。PZG Pro 则在安全、开发体验和平台扩展方面提供增强功能，例如 Drift Guard、Server Actions Pack 和 SDK Publisher。该图区分了免费和付费功能，并展示了 PZG 在 Prisma 和 Zod 之间建立桥梁的作用。
