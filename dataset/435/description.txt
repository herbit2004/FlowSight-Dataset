## 图类型与用途
这是一个架构图，展示了 `Knowledge-Assistant` 系统的整体架构和数据流向。该系统是一个轻量级的、基于文件的聊天机器人，能够根据用户提供的知识文件回答问题。该图在 README.md 中被用作架构说明。

## 图的整体布局
图整体采用从左到右的布局。从左侧的 `Knowledge System` 和顶部的 `Frontend` 开始，数据流向中间的 `API Layer` 和底部的 `External`，最终回到 `Frontend`。

## 分组/子图/阶段说明
图中包含四个子图：
- **Frontend**：表示用户界面部分，包含 React 聊天界面和用于渲染 Markdown、Mermaid 图表和代码块的组件。
- **API Layer**：表示 API 层，包含流式 API 接口和聊天 API 接口。
- **Knowledge System**：表示知识系统，包含文件加载器和知识文件。
- **External**：表示外部服务，这里是 OpenRouter API。

## 节点逐项说明
- **UI (React Chat UI)**：用户交互界面，使用 React 构建的聊天界面。
- **MD (Markdown Renderer)**：Markdown 渲染器，用于将 Markdown 格式的内容渲染成可读的格式。
- **MM (Mermaid Component)**：Mermaid 组件，用于渲染 Mermaid 格式的图表。该组件在 `components/mermaid.tsx` 中被使用。
- **CB (Code Block Component)**：代码块组件，用于显示代码片段。
- **STREAM (Stream Endpoint)**：流式 API 接口，用于实时传输数据。对应 `app/api/chat/stream/route.ts` 文件。
- **CHAT (Chat Endpoint)**：聊天 API 接口，用于处理用户的聊天请求。对应 `app/api/chat/route.ts` 文件。
- **LOADER (File Loader)**：文件加载器，负责从文件系统中加载知识文件。
- **CONTENT (Content Files)**：知识文件，存储着系统用于回答问题的 Markdown 或文本文件，位于 `content/` 目录下。
- **OR (OpenRouter API)**：OpenRouter API，用于访问大型语言模型 (LLM)。

## 连线、分支与汇聚关系
- `UI -> STREAM`：用户在 UI 发送的请求被发送到流式 API 接口。
- `STREAM -> LOADER`：流式 API 接口触发文件加载器。
- `LOADER -> CONTENT`：文件加载器从知识文件中加载内容。
- `STREAM -> OR`：流式 API 接口将加载的知识文件和用户请求发送到 OpenRouter API。
- `OR -> UI`：OpenRouter API 将 LLM 的响应返回给 UI。
- `UI -> MD`：UI 将内容发送到 Markdown 渲染器。
- `MD -> MM`：Markdown 渲染器使用 Mermaid 组件渲染 Mermaid 图表。
- `MD -> CB`：Markdown 渲染器使用代码块组件渲染代码块。

## 仓库语境与术语解释
- **OpenRouter API**：用于访问多个 LLM 的统一 API，该项目使用 OpenRouter 的免费模型。
- **content/ 目录**：用于存放知识文件的目录，系统会读取该目录下的 `.md` 和 `.txt` 文件作为知识库。
- **Stream Endpoint (app/api/chat/stream/route.ts)**：处理流式聊天请求的 API 接口，负责从文件加载知识，并与 OpenRouter API 交互。
- **Markdown Rendering**：系统支持 Markdown 渲染，包括语法高亮、Mermaid 图表和代码块。
- **React Chat UI (components/chat-interface.tsx)**：使用 React 构建的聊天界面，负责用户交互和消息展示。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 `Knowledge-Assistant` 系统的架构，用户通过 React Chat UI 与系统交互，消息传递到 Stream Endpoint，触发 File Loader 从 content/ 目录加载知识文件，然后 Stream Endpoint 将知识和用户消息发送到 OpenRouter API，OpenRouter API 返回的响应最终在 UI 中通过 Markdown Renderer 进行渲染，支持 Mermaid 图表和代码块的展示。其中，OpenRouter API 和 content/ 目录是系统的两个关键组成部分。
