## Repository Context & Terminology
- **Block box**: A fundamental box type in CSS, representing a block-level element that takes up the full width available.
- **Inline box**: A fundamental box type in CSS, representing an inline-level element that only takes up the width of its content.
- **Flex container**: A box that uses the Flexbox layout model for arranging its children.
- **Grid container**: A box that uses the CSS Grid layout model for arranging its children.
- **Table wrapper**: A box that wraps a table element to handle its layout.
- **Pseudo-elements**: CSS constructs that allow styling specific parts of an element, such as ::before, ::after, and ::marker.
- **::before**: A pseudo-element that inserts content before the content of an element.
- **::after**: A pseudo-element that inserts content after the content of an element.
- **::marker**: A pseudo-element that styles the marker box of a list item.
