## 图类型与用途
这是一个流程图，描述了 `fastrender` 渲染引擎中盒模型生成的流程。该图展示了如何根据 HTML 元素的 CSS `display` 属性值，生成不同类型的盒模型，最终形成用于布局和渲染的盒树。

## 图的整体布局
图整体采用从上到下的布局。顶部是起始节点 `Styled element`，中间是根据 `display` 属性值判断和生成不同盒模型的阶段，底部是最终生成的盒模型类型。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可以分为三个阶段：
1.  **元素样式化**：流程的起点，表示一个已经应用了 CSS 样式的 HTML 元素。
2.  **盒模型类型判断与生成**：根据元素的 `display` 属性值，确定生成何种类型的盒模型。
3.  **匿名盒模型处理与伪元素生成**：处理需要匿名盒模型包装的情况，以及生成伪元素。

## 节点逐项说明
- **Element (Styled element)**：代表一个已经应用了 CSS 样式的 HTML 元素，是流程的起点。
- **Display{display value?}**：这是一个判断节点，根据元素的 `display` 属性值进行分支。
- **Block[Block box]**：代表一个块级盒模型。
- **Inline[Inline box]**：代表一个行内盒模型。
- **Flex[Flex container]**：代表一个 Flex 容器，用于使用 Flexbox 布局。
- **Grid[Grid container]**：代表一个 Grid 容器，用于使用 Grid 布局。
- **Table[Table wrapper]**：代表一个表格包装器，用于处理表格布局。
- **None[Skip subtree]**：表示跳过该元素的子树，不生成盒模型。
- **Contents[Unwrap children]**：表示移除该元素的盒模型，但保留其子元素。根据 README，`display: contents` 移除了元素的 box，但保留了其 children。
- **Anon{needs wrapper?}**：这是一个判断节点，判断是否需要匿名盒模型包装。
- **AnonBlock[Anonymous block]**：代表一个匿名块级盒模型，通常用于处理混合内容（例如，块级元素和行内元素混合）。根据 README，混合的块级/行内 children 会触发匿名 block box 的创建。
- **AnonTable[Anonymous table parts]**：代表匿名表格部件，用于处理表格的行和单元格。根据 README，Tables 会根据 CSS 2.1 §17.2 生成匿名的 row/cell wrappers。
- **Pseudo{pseudo-elements?}**：这是一个判断节点，判断是否存在伪元素。
- **Before[::before]**：代表 `::before` 伪元素。
- **After[::after]**：代表 `::after` 伪元素。
- **Marker[::marker]**：代表 `::marker` 伪元素。

## 连线、分支与汇聚关系
- `Element -> Display`：流程从已样式化的 HTML 元素开始，根据其 display 属性值进行判断。
- `Display -- block --> Block`：如果 `display` 值为 `block`，则生成块级盒模型。
- `Display -- inline --> Inline`：如果 `display` 值为 `inline`，则生成行内盒模型。
- `Display -- flex --> Flex`：如果 `display` 值为 `flex`，则生成 Flex 容器。
- `Display -- grid --> Grid`：如果 `display` 值为 `grid`，则生成 Grid 容器。
- `Display -- table --> Table`：如果 `display` 值为 `table`，则生成表格包装器。
- `Display -- none --> Skip`：如果 `display` 值为 `none`，则跳过该元素的子树。
- `Display -- contents --> Contents`：如果 `display` 值为 `contents`，则移除该元素的盒模型，但保留其子元素。
- `Block -> Anon`：块级盒模型生成后，判断是否需要匿名盒模型包装。
- `Anon -- mixed content --> AnonBlock`：如果需要，且内容是混合内容，则生成匿名块级盒模型。
- `Anon -- table child --> AnonTable`：如果需要，且是表格子元素，则生成匿名表格部件。
- `Element -> Pseudo`：判断是否存在伪元素。
- `Pseudo -> Before`：如果存在 `::before` 伪元素，则生成。
- `Pseudo -> After`：如果存在 `::after` 伪元素，则生成。
- `Pseudo -> Marker`：如果存在 `::marker` 伪元素，则生成。

## 仓库语境与术语解释
- **Box Generation**：根据 README，`box_generation.rs` 文件负责 styled 元素到 box 的映射。
- **Box Tree**：根据 README，盒树不是与 DOM 一一对应的。
- **display: contents**：根据 README，该属性会移除元素的 box，但保留其 children。
- **Anonymous Block Box**：根据 README，混合的块级/行内 children 会触发匿名 block box 的创建。
- **Anonymous Table Parts**：根据 README，Tables 会根据 CSS 2.1 §17.2 生成匿名的 row/cell wrappers。
- **Flexbox/Grid Layout**: 根据 README，Flexbox 和 Grid 布局委托给 vendored layout library (Taffy)。
- **DOM**: DOM 指的是文档对象模型，是 HTML 和 XML 文档的编程接口。

## 可作为 QA Ground Truth 的高信息密度摘要
该图描述了 `fastrender` 引擎中盒模型生成的流程。流程从 `Styled element` 开始，根据元素的 `display` 属性值，流程会分支到不同的盒模型类型，如 `Block`、`Inline`、`Flex`、`Grid`、`Table`、`None` 或 `Contents`。对于 `Block` 类型的盒模型，会进一步判断是否需要匿名盒模型包装，生成 `AnonBlock` 或 `AnonTable`。此外，还会判断是否存在伪元素，如 `::before`、`::after` 和 `::marker`。其中，`display: contents` 会移除元素的 box，但保留其 children，混合的块级/行内 children 会触发匿名 block box 的创建。该流程与 `box_generation.rs` 文件的功能相关。
