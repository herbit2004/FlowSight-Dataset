## 图类型与用途
这是一个流程图，描述了 VulnX 安全扫描器的核心端口扫描流程。它展示了扫描器如何初始化扫描、管理端口队列、利用多线程进行端口连接、抓取 Banner 信息、分析服务和严重性，并将结果汇总并实时更新。该图在 README.md 中被提及，用于解释 "Complete Scanning Workflow" 和 "Detailed Port Scanning Process"。

## 图的整体布局
图整体采用从左到右的布局。从左上角的“Scan Initialization”子图开始，经过中间的端口队列管理、线程池处理和端口连接过程，最终到达右侧的结果聚合和实时更新阶段。

## 分组/子图/阶段说明
- **Scan Initialization**：负责接收用户输入的目标 IP 地址和扫描模式，验证 IP 格式，并检测地址族（IPv4 或 IPv6）。
- **Port Queue Management**：根据扫描模式创建待扫描的端口队列。如果进行深度扫描，则扫描 1-1024 端口；否则，扫描 23 个常用端口。
- **Thread Pool - 100 Workers**：使用 100 个并发执行扫描任务的工作线程。根据 README.md，VulnX 扫描器使用多线程端口扫描，拥有 100 个并发线程。
- **Port Connection Process**：每个工作线程尝试连接目标 IP 的端口，如果端口打开，则抓取 Banner 信息，并分析端口运行的服务并映射相应的严重性。
- **Result Aggregation**：将所有扫描结果汇总到结果列表中，按端口号排序，并返回最终的扫描数据。
- **Real-time Updates**：当发现开放端口时，通过 WebSocket 发送 'port_found' 事件，实时通知前端；定期通过 WebSocket 发送 'scan_progress' 事件，实时更新扫描进度。

## 节点逐项说明
- **Input**：用户提供的目标 IP 地址和扫描模式。
- **Validate**：验证输入的 IP 地址格式是否正确。
- **Family**：检测 IP 地址是 IPv4 还是 IPv6。
- **AF_INET**：IPv4 地址族，对应 `socket.AF_INET`。
- **AF_INET6**：IPv6 地址族，对应 `socket.AF_INET6`。
- **PortQueue**：根据扫描模式创建待扫描的端口队列。
- **DeepScan?**：判断是否进行深度扫描（扫描所有端口）。
- **Ports1024**：如果进行深度扫描，则将 1-1024 端口加入队列。
- **CommonPorts**：如果不进行深度扫描，则将 23 个常用端口加入队列。`src/core/scanner.py` 中定义了 `common_ports` 列表，包含了常用的端口。
- **Worker1, Worker2, Worker3, WorkerN**：100 个并发执行扫描任务的工作线程。
- **Connect1, Connect2, ConnectN**：每个工作线程尝试连接目标 IP 的端口，即 Socket 连接。
- **Open1, Open2, OpenN**：判断端口是否打开。
- **Banner1, Banner2, BannerN**：如果端口打开，则尝试抓取 Banner 信息。
- **Analyze1, Analyze2, AnalyzeN**：根据 Banner 信息分析端口运行的服务并映射相应的严重性。
- **Results**：将所有扫描结果汇总到结果列表中。
- **Sort**：将结果列表按端口号排序。
- **Return**：返回最终的扫描数据。
- **WebSocket1, WebSocket2**：当发现开放端口时，通过 WebSocket 发送 'port_found' 事件，实时通知前端。
- **Progress**：定期通过 WebSocket 发送 'scan_progress' 事件，实时更新扫描进度。

## 连线、分支与汇聚关系
- `Input -> Validate`：用户输入后，系统验证 IP 格式。
- `Validate -> Family`：验证通过后，检测地址族。
- `Family -- IPv4 --> AF_INET`：如果检测到 IPv4 地址，则使用 `socket.AF_INET`。
- `Family -- IPv6 --> AF_INET6`：如果检测到 IPv6 地址，则使用 `socket.AF_INET6`。
- `AF_INET -> PortQueue`：确定地址族后，创建端口队列。
- `AF_INET6 -> PortQueue`：确定地址族后，创建端口队列。
- `DeepScan? -- Yes --> Ports1024`：如果进行深度扫描，则选择扫描 1-1024 端口。
- `DeepScan? -- No --> CommonPorts`：如果不进行深度扫描，则选择扫描 23 个常用端口。
- `Ports1024 -> PortQueue`：将 1-1024 端口加入队列。
- `CommonPorts -> PortQueue`：将 23 个常用端口加入队列。
- `PortQueue -> Worker1`：端口队列中的任务分配给工作线程 1。
- `PortQueue -> Worker2`：端口队列中的任务分配给工作线程 2。
- `PortQueue -> WorkerN`：端口队列中的任务分配给工作线程 N (100)。
- `Worker1 -> Connect1`：工作线程 1 尝试 Socket 连接。
- `Worker2 -> Connect2`：工作线程 2 尝试 Socket 连接。
- `WorkerN -> ConnectN`：工作线程 N 尝试 Socket 连接。
- `Connect1 -> Open1`：Socket 连接后，判断端口是否打开。
- `Connect2 -> Open2`：Socket 连接后，判断端口是否打开。
- `ConnectN -> OpenN`：Socket 连接后，判断端口是否打开。
- `Open1 -- Yes --> Banner1`：如果端口打开，则抓取 Banner 信息。
- `Open2 -- Yes --> Banner2`：如果端口打开，则抓取 Banner 信息。
- `OpenN -- Yes --> BannerN`：如果端口打开，则抓取 Banner 信息。
- `Banner1 -> Analyze1`：抓取 Banner 信息后，分析服务和严重性。
- `Banner2 -> Analyze2`：抓取 Banner 信息后，分析服务和严重性。
- `BannerN -> AnalyzeN`：抓取 Banner 信息后，分析服务和严重性。
- `Analyze1 -> Results`：分析服务和严重性后，将结果添加到结果列表。
- `Analyze2 -> Results`：分析服务和严重性后，将结果添加到结果列表。
- `AnalyzeN -> Results`：分析服务和严重性后，将结果添加到结果列表。
- `Open1 -- Callback --> WebSocket1`：如果端口打开，通过 WebSocket 发送 'port_found' 事件。
- `Open2 -- Callback --> WebSocket2`：如果端口打开，通过 WebSocket 发送 'port_found' 事件。
- `Analyze1 -- Progress --> Progress`：分析服务和严重性后，通过 WebSocket 发送 'scan_progress' 事件。
- `Results -> Sort`：将结果列表按端口号排序。
- `Sort -> Return`：返回扫描数据。

## 仓库语境与术语解释
- **VulnX Scanner**：一个 Python + Flask 编写的安全扫描器，用于实时端口扫描、Banner 抓取、严重性评分、威胁映射和子域名枚举。
- **Socket**：用于网络通信的 API。`src/core/scanner.py` 中使用了 `socket` 模块进行端口连接。
- **Banner Grabbing**：一种用于获取目标系统上运行服务信息的安全技术。
- **WebSocket**：一种在客户端和服务器之间提供全双工通信通道的协议，用于实时更新扫描进度。`src/app.py` 中使用了 `Flask-SocketIO` 库来实现 WebSocket 通信。
- **IPv4/IPv6**：互联网协议的两个版本，用于标识网络上的设备。`src/core/scanner.py` 中包含了 IPv4 和 IPv6 地址的检测逻辑。
- **Thread Pool**：一种并发编程模式，用于管理和复用线程，提高扫描效率。根据 README.md，VulnX 扫描器使用多线程端口扫描，拥有 100 个并发线程。
- **Flask**：一个轻量级的 Python Web 框架，用于构建 VulnX 扫描器的 Web 界面。`src/app.py` 是 Flask 应用的入口点。
- **Deep Scan/Common Ports**：两种扫描模式。Deep Scan 扫描 1-1024 端口，Common Ports 扫描 23 个常用端口。`src/core/scanner.py` 中定义了 `common_ports` 列表。

## 可作为 QA Ground Truth 的高信息密度摘要
这张图描述了 VulnX 扫描器的核心端口扫描流程。从用户输入目标 IP 和扫描模式开始，系统验证 IP 格式并检测地址族，然后根据扫描模式创建端口队列。通过 100 个并发线程进行端口连接，抓取 Banner 信息，分析服务和严重性。扫描结果汇总后按端口号排序并返回，同时通过 WebSocket 实时更新扫描进度。该流程的关键环节包括 IP 地址验证、端口队列管理、多线程连接、Banner 抓取和服务分析，最终结果通过 WebSocket 实时反馈给用户。`src/core/scanner.py` 定义了常用端口和端口对应的服务信息，`src/app.py` 使用 Flask-SocketIO 实现实时更新。
