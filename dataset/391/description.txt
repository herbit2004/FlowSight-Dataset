## Repository Context & Terminology
- **socket.AF_INET**: Address family for IPv4. This constant is used in socket programming to specify the Internet Protocol version 4 address family.
- **socket.AF_INET6**: Address family for IPv6. This constant is used in socket programming to specify the Internet Protocol version 6 address family.
- **Port Scanning**: A process of sending packets to specific ports on a host and analyzing the responses to identify open ports and running services.
- **Banner Grabbing**: A technique used to gather information about a remote system by capturing the banner or welcome message that a service sends when a connection is established.
- **Thread Pool**: A collection of worker threads that are used to execute tasks concurrently, improving performance by reducing the overhead of creating and destroying threads for each task.
- **Emit**: In the context of real-time updates, "emit" refers to sending out an event or message to subscribers or listeners, typically using a technology like WebSockets or Server-Sent Events.
- **Callback**: A function that is passed as an argument to another function and is executed after the completion of that function.

## High-Density QA Ground Truth Summary
The port scan begins with the "Target IP + Scan Mode" node, where the user provides the target IP address and selects a scan mode. The IP format is then validated, and the address family (IPv4 or IPv6) is detected. Based on whether a deep scan is selected at the "Deep Scan?" decision node, either ports 1-1024 or 23 common ports are added to the port queue. The "Create Port Queue" node consolidates the ports to be scanned. A thread pool of 100 workers then processes the queue. Each "Worker Thread" attempts a "Socket Connect" to a port, and the "Port Open?" node determines if the connection was successful. If a port is open, the "Grab Banner" node retrieves the service banner, and the "Map Service & Severity" node identifies the service and its severity. Real-time updates are emitted via "Emit 'port_found'" and "Emit 'scan_progress'." All results are aggregated in the "Results List," sorted by port number, and finally returned via the "Return Scan Data" node. The use of `socket.AF_INET` and `socket.AF_INET6` indicates the program uses socket programming to establish network connections based on the detected IP address family.
