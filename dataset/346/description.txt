## 图类型与用途
这是一个架构图，用于展示 Claude Code 系统的核心架构和组件，以及它们之间的关系。该图在仓库中用于概括 Claude Code 的整体设计，展示其核心组件、子代理、技能、自定义命令以及基础设施之间的关系。

## 图的整体布局
图整体采用从上到下的布局。顶部是基础设施组件，中间是 Claude Code Core，周围连接着原生工具、技能、子代理和自定义命令。

## 分组/子图/阶段说明
图中包含多个子图，分别代表不同的组件类别：
- **Native Tools**：包含 Claude Code 提供的原生工具。
- **Skills**：包含领域特定的工具包，可以通过 `/skill-name` 调用。
- **Agents (Sub-Agents)**：包含运行在独立上下文窗口中的专业代理，用于深度分析。
- **Commands (Custom Commands)**：包含自定义命令，用于执行特定任务。
- **Infra (Infrastructure)**：包含基础设施组件。

## 节点逐项说明
- **Main (Claude Code Core)**：系统的核心，是所有其他组件的中心枢纽。
- **TaskCreate/Update/List**：用于创建、更新和列出任务的工具。
- **Read/Write/Edit**：用于读取、写入和编辑文件的工具。
- **Bash/Grep/Glob**：常见的命令行工具，用于执行 shell 命令、搜索文本和匹配文件路径。
- **lnd**：Lightning Network Daemon，用于管理 Lightning Network 节点。
- **eclair**：ACINQ 的 Eclair，也是一个 Lightning Network 节点实现。
- **substrate**：代理邮件系统，用于代理之间的消息传递。
- **nano-banana**：通过 Gemini/Imagen 3 生成 AI 图像的工具。
- **mutation-testing**：通过变异分析验证测试质量的工具。
- **frontend-design**：用于生成高质量 UI 组件的工具。
- **Arch Archaeologist**：使用 Mermaid 图进行全面的代码库分析。
- **Code Scout**：快速目标分析（2-3 分钟），最多 10 个文件。
- **Code Reviewer**：使用模式分析进行 PR 和代码更改审查。
- **Security Auditor**：识别漏洞并加强安全性的代理。
- **Test Engineer**：测试工程师。
- **Doc Checker**：文档检查器。
- **Go Debugger**：Go 调试器。
- **Debug Chronicler**：调试记录器。
- **Mutation Tester**：变异测试器。
- **Presentation Builder**：演示文稿构建器。
- **Incremental Commit**：增量提交。
- **Pre-PR Review**：预 PR 审查。
- **Test Forge**：测试工厂。
- **Quick Dive**：快速深入了解。
- **Ideate**：构思。
- **Subtrate Messaging**：Subtrate 消息传递系统。
- **Session System**：会话管理系统，用于保持上下文连贯性。
- **Hook System**：钩子系统，用于在特定事件发生时执行脚本。

## 连线、分支与汇聚关系
- `Main --> NativeTools`：Claude Code Core 连接到原生工具。
- `Main ==> Skills`：Claude Code Core 连接到技能。
- `Main ==> Agents`：Claude Code Core 连接到子代理。
- `Main ==> Commands`：Claude Code Core 连接到自定义命令。
- `Infra -.-> Main`：基础设施通过 lifecycle 关系连接到 Claude Code Core。

## 仓库语境与术语解释
- **Claude Code Core**：系统的核心，负责协调各个组件。
- **Skills**：领域特定的工具包，可以通过 `/skill-name` 调用，例如 `lnd`、`eclair` 和 `substrate`，详见 README.md。
- **Sub-Agents**：运行在独立上下文窗口中的专业代理，用于深度分析，例如 `Arch Archaeologist` 和 `Code Scout`，详见 README.md。
- **Custom Commands**：可重用的工作流程，可以通过名称调用，例如 `/quick-dive` 和 `/incremental-commit`，详见 README.md。
- **Subtrate Messaging**：一个用于协调多个 Claude Code 代理的命令中心，解决了代理之间的隔离和短暂性问题，详见 README.md 和 skills/substrate/SKILL.md。
- **Session System**：提供跨上下文压缩的执行连续性，详见 SESSIONS.md。
- **Hook System**：允许在 Claude Code 生命周期事件中执行 shell 脚本，详见 hooks/README.md。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 Claude Code 系统的架构，核心是 Claude Code Core，它与 Native Tools、Skills、Agents 和 Commands 交互。Infrastructure 组件通过 lifecycle 关系影响 Claude Code Core。Sub-Agents 提供深度分析，Skills 提供领域特定工具，Commands 提供可重用的工作流程。Subtrate Messaging 用于代理间的通信，Session System 保持上下文连贯性，Hook System 允许在特定事件发生时执行脚本。
