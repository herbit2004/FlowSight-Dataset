- **SSE (Server-Sent Events)**: A server push technology enabling real-time data streaming from the server to the client.
- **Blocking**: A synchronous output mode where the process waits for the operation to complete.
- **Polling**: An asynchronous output mode where the client periodically checks for updates from the server.
