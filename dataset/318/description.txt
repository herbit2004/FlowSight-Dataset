## Repository Context & Terminology
- **Argo CD**: A declarative, GitOps continuous delivery tool for Kubernetes. It allows defining desired application states in Git repositories and automatically deploys and manages applications in Kubernetes clusters.
- **Ops Cluster**: A Kubernetes cluster dedicated to running operational tools like Argo CD and observability components.
- **Env Cluster**: A Kubernetes cluster dedicated to running application environments like Development, Staging, and Production.
- **Observability**: The capability to monitor and understand the state of a system through metrics, logs, and traces.
- **GitOps**: A declarative way of implementing continuous deployment for cloud-native applications.
