## Repository Context & Terminology
- **Route 53 DNS**: A scalable and highly available Domain Name System (DNS) web service provided by AWS. It's used to route end-user requests to internet resources.
- **EKS Cluster**: Elastic Kubernetes Service, a managed Kubernetes service that makes it easy to run, scale, and manage containerized applications on AWS.
- **Aurora Global DB**: A distributed, fault-tolerant, self-healing database system compatible with MySQL and PostgreSQL. It allows for low-latency global reads and disaster recovery.
- **ElastiCache Global**: A fully managed, in-memory data store service by AWS, compatible with Redis and Memcached. It provides caching to improve application performance.
- **Availability Zones (AZs)**: Distinct locations within an AWS region that are engineered to be isolated from failures in other Availability Zones.
- **Write Forwarding**: A database configuration where writes are forwarded from a secondary region to the primary region for consistency.
- **Replication Latency**: The time it takes for data changes to be replicated from one database instance to another.
