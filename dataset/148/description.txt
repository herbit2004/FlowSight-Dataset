## Edges, Branches & Convergence
- `Request --> Is it requesting Schemas?`: The initial request is passed to the schema check.
- `Is it requesting Schemas? -- Yes --> Fetch from GitHub`: If the request is for schemas, fetch them from GitHub.
- `Is it requesting Schemas? -- No --> Let the original request go through`: If the request is not for schemas, process the original request.
- `Fetch from GitHub --> Was requesting a .json file?`: After fetching from GitHub, check if the request was for a .json file.
- `Was requesting a .json file? -- Yes --> Response Status?`: If the request was for a .json file, check the response status.
- `Was requesting a .json file? -- No --> Response`: If the request was not for a .json file, return the response.
- `Response Status? -- 2xx --> OK`: If the response status is 2xx, it's an OK response.
- `Response Status? -- 304 --> Not Modified`: If the response status is 304, it's a Not Modified response.
- `Response Status? -- Any other --> response_ko`: If the response status is anything else, it's an error response.
- `OK --> Set Response Content-Type header to application/schema+json`: Set the content type header for a successful response.
- `Set Response Content-Type header to application/schema+json --> Send success metric`: Send a success metric after setting the header.
- `Not Modified -- cached:true --> Send success metric`: Send a success metric for a cached response.
- `response_ko --> Send error metric`: Send an error metric for an error response.
- `Send success metric --> Response`: The success metric leads to the final response.
- `Send error metric --> Response`: The error metric leads to the final response.
- `Let the original request go through --> Response`: The original request leads to the final response.

## Repository Context & Terminology
- **Schemas**: Refers to data schemas, likely in JSON format, used for validation or data structure definition.
- **GitHub**: An online repository hosting service, used here as the source for fetching schemas.
- **.json file**: A file containing data in JSON (JavaScript Object Notation) format.
- **2xx**: HTTP status codes indicating success.
- **304 Not Modified**: HTTP status code indicating that the requested resource has not been modified since the last time it was accessed.
- **application/schema+json**: A MIME type used to indicate that the content is a JSON schema.
- **cached:true**: Indicates that the response was served from a cache.
