## Repository Context & Terminology
- **ArchSpec (YAML)**: A YAML file that defines the architecture. It serves as the central configuration for the system.
- **Terraform (TF)**: An infrastructure-as-code tool.
- **CloudFormation (CFN)**: AWS's infrastructure-as-code service.
- **SBOM (Software Bill of Materials)**: A list of components in a piece of software.
- **AIBOM (AI Bill of Materials)**: A list of components in an AI system.
- **Mermaid**: A markdown-like syntax for generating diagrams.
- **D2**: A modern diagram scripting language that turns text to diagrams.
