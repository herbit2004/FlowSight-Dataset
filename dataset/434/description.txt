- **Next.js**: A React framework for building web applications. The Next.js API likely handles routing and server-side logic.
- **API**: Application Programming Interface; a set of defined rules that enable different applications to communicate with each other.
- **SSE Stream**: Server-Sent Events; a server push technology enabling real-time data streaming from the server to the client.
- **Markdown (.md)**: A lightweight markup language used for formatting text. The knowledge base is stored in markdown files.
- **Knowledge Loader**: A module responsible for reading and parsing the markdown files in the `content/` directory to make the information available for the OpenRouter API.
- **OpenRouter API**: An external API used to generate responses based on the provided context and message.

## High-Density QA Ground Truth Summary
The diagram illustrates a chat application's architecture, beginning with the user interacting with the Chat Interface. A User Message is sent to the Next.js API on the server. The Next.js API then triggers the Knowledge Loader, which reads relevant files from the Knowledge base (specifically, `content/*.md`). The Knowledge Loader then sends the combined Context and the original Message to the OpenRouter API. The OpenRouter API processes this information and sends a Streaming Response back to the Next.js API. Finally, the Next.js API streams the response back to the Chat Interface via an SSE Stream, providing real-time updates to the user. The Knowledge Loader's role is crucial as it bridges the gap between the static knowledge base (markdown files) and the dynamic response generation by the OpenRouter API, ensuring the chat responses are context-aware. The use of Next.js suggests a modern web application framework, and SSE Stream indicates a real-time communication pattern for delivering responses.
