## 图类型与用途
该图是一个流程图，描述了用户请求资源时，在可信环境和不可信环境中进行鉴权、水印处理和验证的完整流程。该流程旨在保护资源安全，防止未经授权的访问。

## 图的整体布局
该图采用从上到下的布局，分为“可信环境”和“不可信环境”两个子图。流程从“用户请求”开始，最终到达“资源访问完成”。

## 分组/子图/阶段说明
图中包含两个子图：
- **可信环境**：处理用户请求的鉴权和水印添加。
- **不可信环境**：处理资源访问的水印检测和验证。

## 节点逐项说明
- **用户请求**：用户发起资源访问请求。
- **鉴权服务**：验证用户的身份。
- **权限校验**：检查用户是否具有访问资源的权限。
- **水印服务**：为资源添加水印。
- **生成水印**：生成用于追踪和验证的水印数据。
- **保存水印元数据**：将水印的元数据存储起来，以便后续验证。
- **返回带水印资源**：将带有水印的资源返回给用户。
- **资源访问**：用户尝试访问资源。
- **水印检测**：检测资源中是否包含水印。
- **提取水印元数据**：从资源中提取水印的元数据。
- **验证水印元数据**：验证提取的水印元数据是否有效。
- **允许访问**：如果水印验证成功，则允许用户访问资源。
- **可疑行为**：如果水印验证失败或未检测到水印，则标记为可疑行为。
- **记录日志/报警**：记录可疑行为并发出警报。
- **返回错误**：权限校验失败，返回错误信息。
- **资源访问完成**：资源访问流程结束。

## 连线、分支与汇聚关系
- 用户请求 -> 鉴权服务：发起鉴权请求。
- 鉴权服务 -> 权限校验：进行权限校验。
- 权限校验 -- 允许 --> 水印服务：权限校验通过，进入水印服务。
- 权限校验 -- 拒绝 --> 返回错误：权限校验失败，返回错误。
- 水印服务 -> 生成水印：生成水印。
- 生成水印 -- 水印成功 --> 保存水印元数据：水印生成成功，保存元数据。
- 保存水印元数据 -> 返回带水印资源：返回带水印的资源。
- 返回带水印资源 -> 资源访问：用户访问资源。
- 资源访问 -> 水印检测：进行水印检测。
- 水印检测 -- 检测到水印 --> 提取水印元数据：检测到水印，提取元数据。
- 水印检测 -- 未检测到水印 --> 可疑行为：未检测到水印，标记为可疑行为。
- 提取水印元数据 -> 验证水印元数据：验证水印元数据。
- 验证水印元数据 -- 验证成功 --> 允许访问：验证成功，允许访问。
- 验证水印元数据 -- 验证失败 --> 可疑行为：验证失败，标记为可疑行为。
- 可疑行为 -> 记录日志/报警：记录日志并报警。
- 可疑行为 -> 资源访问完成：流程结束。
- 允许访问 -> 资源访问完成：流程结束。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **鉴权**：验证用户身份的过程，确认用户是否是其声称的身份。
- **权限校验**：检查用户是否具有执行特定操作或访问特定资源的权利。
- **水印**：嵌入到资源中的一种标识，用于追踪和验证资源的来源和完整性。
- **元数据**：描述数据的数据，例如水印的创建时间、所有者等信息。
- **可信环境**：指安全可靠的运行环境，通常具有较高的安全保障措施。
- **不可信环境**：指安全性较低的运行环境，可能存在安全风险。
- **资源访问**：用户尝试获取或使用特定资源的行为。

## 可作为 QA Ground Truth 的高信息密度摘要
用户发起资源请求，首先经过可信环境中的鉴权服务和权限校验。如果权限校验通过，则进入水印服务，生成水印并保存水印元数据，然后返回带水印的资源。在不可信环境中，用户访问资源时，系统会进行水印检测。如果检测到水印，则提取水印元数据并进行验证。验证成功则允许访问，验证失败或未检测到水印则标记为可疑行为，并记录日志/报警，最终流程结束。
