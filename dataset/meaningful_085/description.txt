## 图类型与用途
该图是一个流程图，描述了包裹从揽收到最终签收的完整物流过程。它展示了包裹在不同阶段的流转和状态变化，以及可能出现的异常情况处理。该流程图清晰地呈现了物流运作的各个环节。

## 图的整体布局
该图采用从上到下的布局，将整个物流过程分为揽收流程、干线运输和末端配送三个主要阶段。流程从揽收点接收包裹开始，到更新包裹状态为“已签收”结束。

## 分组/子图/阶段说明
图中包含三个子图，分别代表物流过程的三个主要阶段：
- **揽收流程**：描述包裹从揽收点到分拣中心接收任务的过程。
- **干线运输**：描述包裹从一个分拣中心运输到下一个分拣中心的过程。
- **末端配送**：描述包裹从末端配送站点到客户签收的过程。

## 节点逐项说明
- **A 揽收点接收包裹**：物流过程的起点，表示揽收点收到需要运输的包裹。
- **B 扫描包裹条码**：扫描包裹上的条码，用于识别包裹信息。
- **BA 包裹信息异常**：当包裹条码无效时，表示包裹信息存在异常。
- **C 上传揽收信息**：将揽收到的包裹信息上传到系统。
- **D 更新包裹状态为“已揽收”**：在系统中更新包裹的状态为已揽收。
- **E 生成揽收任务**：生成揽收任务，通知分拣中心接收包裹。
- **F 分拣中心接收任务**：分拣中心接收到揽收任务。
- **G 计算最优路线**：计算包裹从当前分拣中心到下一个分拣中心的最优运输路线。
- **GA 延迟运输**：如果没有可用的运输路线，则延迟运输。
- **H 分配运输车辆**：根据计算出的最优路线，分配运输车辆。
- **I 车辆装载包裹**：将包裹装载到运输车辆上。
- **J 干线运输至下一分拣中心**：将包裹通过干线运输到下一个分拣中心。
- **K 更新包裹状态为“运输中”**：在系统中更新包裹的状态为运输中。
- **L 到达末端配送站点**：包裹到达末端配送站点。
- **M 智能调度派送员**：通过智能系统调度派送员进行派送。
- **MA 人工分配派送员**：如果智能系统无法分配派送员，则进行人工分配。
- **N 派送员接收任务**：派送员接收到派送任务。
- **O 派送员开始派送**：派送员开始进行包裹派送。
- **P 客户签收**：客户收到包裹并进行签收。
- **PA 重新派送**：如果客户签收失败，则重新派送包裹。
- **Q 上传签收凭证**：上传客户的签收凭证。
- **R 更新包裹状态为“已签收”**：在系统中更新包裹的状态为已签收。
- **S 结束**：物流过程的终点，表示包裹已成功送达并签收。

## 连线、分支与汇聚关系
- **A -> B**：揽收点接收包裹后，扫描包裹条码。
- **B -- 条码有效 --> C**：如果条码有效，则上传揽收信息。
- **B -- 条码无效 --> BA**：如果条码无效，则包裹信息异常。
- **C -> D**：上传揽收信息后，更新包裹状态为“已揽收”。
- **D -> E**：更新包裹状态后，生成揽收任务。
- **E -> F**：生成揽收任务后，分拣中心接收任务。
- **F -> G**：分拣中心接收任务后，计算最优路线。
- **G -- 有可用路线 --> H**：如果有可用路线，则分配运输车辆。
- **G -- 无可用路线 --> GA**：如果没有可用路线，则延迟运输。
- **H -> I**：分配运输车辆后，车辆装载包裹。
- **I -> J**：车辆装载包裹后，进行干线运输至下一分拣中心。
- **J -> K**：干线运输至下一分拣中心后，更新包裹状态为“运输中”。
- **K -> L**：更新包裹状态后，到达末端配送站点。
- **L -> M**：到达末端配送站点后，智能调度派送员。
- **M -- 派送员已分配 --> N**：如果派送员已分配，则派送员接收任务。
- **M -- 派送员未分配 --> MA**：如果派送员未分配，则人工分配派送员。
- **N -> O**：派送员接收任务后，开始派送。
- **O -> P**：派送员开始派送后，客户签收。
- **P -- 签收成功 --> Q**：如果签收成功，则上传签收凭证。
- **P -- 签收失败 --> PA**：如果签收失败，则重新派送。
- **Q -> R**：上传签收凭证后，更新包裹状态为“已签收”。
- **R -> S**：更新包裹状态后，流程结束。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **揽收点**：接收包裹的起始地点，例如快递员上门取件的地点。
- **分拣中心**：对包裹进行分拣、中转的场所，根据目的地将包裹分发到不同的运输线路。
- **干线运输**：长距离的运输过程，通常使用大型货车或火车等交通工具。
- **末端配送站点**：负责将包裹派送到最终客户手中的站点。
- **派送员**：负责将包裹从末端配送站点送到客户手中的人员。
- **签收凭证**：客户收到包裹后，用于确认收到的凭证，例如电子签名或纸质签收单。
- **包裹状态**：包裹在物流过程中所处的阶段，例如“已揽收”、“运输中”、“已签收”等。

## 可作为 QA Ground Truth 的高信息密度摘要
包裹从揽收点开始，扫描条码，若条码有效则上传揽收信息并更新包裹状态为“已揽收”，生成揽收任务后到达分拣中心。分拣中心计算最优路线，若有可用路线则分配车辆并装载包裹，进行干线运输。到达末端配送站点后，更新包裹状态为“运输中”，智能调度派送员，派送员开始派送，客户签收，若签收成功则上传签收凭证并更新包裹状态为“已签收”，流程结束。若条码无效，则包裹信息异常；若无可用路线，则延迟运输；若派送员未分配，则人工分配派送员；若签收失败，则重新派送。
