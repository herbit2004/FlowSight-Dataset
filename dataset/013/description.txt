## Edges, Branches & Convergence
- `watchAllElements --> AllMediaElementsController`: When new media elements are detected on the page, they are passed to the `AllMediaElementsController`.
- `AllMediaElementsController --> chooseController`: The `AllMediaElementsController` passes the original HTMLMediaElement to the `chooseController` for processing.
- `AllMediaElementsController --> Popup`: The `AllMediaElementsController` sends telemetry data to the `Popup` component.
- `chooseController --> ElementPlaybackControllerCloning`: If the cloning controller is appropriate, the original HTMLMediaElement is passed to it.
- `chooseController --> ElementPlaybackControllerStretching`: If the stretching controller is appropriate, the original HTMLMediaElement is passed to it.
- `ElementPlaybackControllerCloning --> Lookahead`: The cloning controller passes a reference to the original HTMLMediaElement to the `Lookahead` component.
- `Lookahead --> ElementPlaybackControllerCloning`: The `Lookahead` component sends silence ranges back to the cloning controller.
- `createCloneElementWithSameSrc --> Lookahead`: A cloned HTMLMediaElement is passed to the `Lookahead` component.
- `Lookahead --> createCloneElementWithSameSrc`: The `Lookahead` component sends a reference to the original HTMLMediaElement to the `createCloneElementWithSameSrc` component.
- `cloneMediaSources --> Lookahead`: A cloned HTMLMediaElement is passed to the `Lookahead` component.
- `Lookahead --> cloneMediaSources`: The `Lookahead` component requests the `getMediaSourceCloneElement` from `cloneMediaSources`.
- `Lookahead --> SilenceDetector1`: The `Lookahead` component sends a clone HTMLMediaElement audio to the `SilenceDetector1`.
- `SilenceDetector1 --> Lookahead`: The `SilenceDetector1` sends `SILENCE_END` & `SILENCE_START` events with timestamps back to the `Lookahead` component.
- `ElementPlaybackControllerStretching --> SilenceDetector2`: The stretching controller sends the original HTMLMediaElement audio to the `SilenceDetector2`.
- `SilenceDetector2 --> ElementPlaybackControllerStretching`: The `SilenceDetector2` sends `SILENCE_END` & `SILENCE_START` events with timestamps back to the stretching controller.

## High-Density QA Ground Truth Summary
The process begins with `watchAllElements`, which scans the webpage for media elements using DOM observation, as implemented in `src/entry-points/content/watchAllElements.ts`. Upon detecting a new media element, it passes control to `AllMediaElementsController`, the orchestrator (`src/entry-points/content/AllMediaElementsController.ts`). The controller then sends the original `HTMLMediaElement` to the `chooseController` decision node. Based on criteria not explicitly defined in the diagram, the process branches to either `ElementPlaybackControllerCloning` or `ElementPlaybackControllerStretching`. If the cloning controller is selected (`src/entry-points/content/ElementPlaybackControllerCloning/ElementPlaybackControllerCloning.ts`), the `Lookahead` component (`src/entry-points/content/ElementPlaybackControllerCloning/Lookahead.ts`) plays back a cloned element (created by `createCloneElementWithSameSrc.ts`) to detect silence ranges. `cloneMediaSources/lib.ts` intercepts media sources and holds clones. The `SilenceDetector` (`src/entry-points/content/SilenceDetector/SilenceDetectorProcessor.ts`) utilizes the Web Audio API to detect silence, sending `SILENCE_END` and `SILENCE_START` events back to `Lookahead`. Alternatively, if the stretching controller is chosen (`src/entry-points/content/ElementPlaybackControllerStretching/ElementPlaybackControllerStretching.ts`), the `SilenceDetector` directly analyzes the original audio, sending silence events back to the stretching controller. The `AllMediaElementsController` also sends telemetry data to the `Popup` component (`src/entry-points/popup/App.svelte`).
