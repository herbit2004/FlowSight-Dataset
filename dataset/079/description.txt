## 图类型与用途
这是一个流程图，展示了 `CI-Report-Converter` 工具如何将各种代码质量检测工具的报告转换为不同的目标格式。该图在仓库中用于概括工具的主要功能和支持的输入输出格式。

## 图的整体布局
图采用左右布局（LR）。左侧是各种代码质量检测工具的报告输入格式，中间是 `CI-Report-Converter` 工具，右侧是转换后的目标格式。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为三个阶段：输入报告格式、`CI-Report-Converter` 工具处理、输出目标格式。

## 节点逐项说明
- **CheckStyle.xml**：CheckStyle 工具生成的 XML 格式报告，用于代码风格检查。根据 README，该格式也被 Phan 和 PHPcs 等工具支持。
- **JUnit.xml**：JUnit 工具生成的 XML 格式报告，用于单元测试结果。
- **PHPmd.json**：PHP Mess Detector (PHPMD) 工具生成的 JSON 格式报告，用于检测代码中的潜在问题。
- **PHPmnd.xml**：PHP Magic Numbers Detector (PHPMND) 工具生成的 XML 格式报告，用于检测代码中的魔术数字。
- **PmdCpd.xml**：PMD Copy/Paste Detector (CPD) 工具生成的 XML 格式报告，用于检测代码中的重复代码。
- **Psalm.json**：Psalm 工具生成的 JSON 格式报告，用于静态代码分析。
- **CI-Report-Converter**：核心组件，代表 `CI-Report-Converter` 工具本身，负责接收不同格式的报告并将其转换为其他格式。
- **GitHub Actions - CLI**：GitHub Actions 平台的命令行界面，`CI-Report-Converter` 可以将报告转换为此格式，以便在 GitHub Actions 中使用。
- **GitLab - JSON**：GitLab 平台，`CI-Report-Converter` 可以将报告转换为 JSON 格式，以便在 GitLab CI 中使用。
- **JUnit.xml (Target)**：`CI-Report-Converter` 可以将报告转换为 JUnit XML 格式。
- **Plain Text**：`CI-Report-Converter` 可以将报告转换为纯文本格式。
- **TeamCity - Inspections**：JetBrains TeamCity 平台的 Inspections 功能，`CI-Report-Converter` 可以将报告转换为此格式，以便在 TeamCity 中显示代码检查结果。
- **TeamCity - Tests**：JetBrains TeamCity 平台的 Tests 功能，`CI-Report-Converter` 可以将报告转换为此格式，以便在 TeamCity 中显示测试结果。

## 仓库语境与术语解释
- **CI-Report-Converter**：该工具的核心功能是将各种代码质量检测工具的报告格式转换为多种目标格式，以便于在不同的持续集成（CI）环境中使用。
- **CheckStyle.xml**：一种通用的代码风格检查报告格式，被多个静态分析工具支持，例如 Phan 和 PHP_CodeSniffer。
- **JUnit.xml**：一种用于表示单元测试结果的通用 XML 格式。
- **PHPmd.json**：PHP Mess Detector (PHPMD) 工具的 JSON 格式报告，用于检测代码中的潜在问题，例如违反编码规范、过度复杂等。
- **PHPmnd.xml**：PHP Magic Numbers Detector (PHPMND) 工具的 XML 格式报告，用于检测代码中的魔术数字，提高代码可维护性。
- **PmdCpd.xml**：PMD Copy/Paste Detector (CPD) 工具的 XML 格式报告，用于检测代码中的重复代码，减少代码冗余。
- **Psalm.json**：Psalm 工具的 JSON 格式报告，用于静态代码分析，发现潜在的类型错误和代码缺陷。
- **GitHub Actions**：GitHub 提供的 CI/CD 服务，`CI-Report-Converter` 可以将报告转换为 GitHub Actions Annotations 格式，方便在 workflow 中展示代码质量问题。
- **GitLab CI**：GitLab 提供的 CI/CD 服务，`CI-Report-Converter` 可以将报告转换为 GitLab Custom Report 格式，方便在 merge request 中展示代码质量报告。
- **TeamCity**：JetBrains 提供的 CI/CD 服务，`CI-Report-Converter` 可以将报告转换为 TeamCity Inspections 和 Tests 格式，方便在 TeamCity 中展示代码检查和测试结果。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 `CI-Report-Converter` 工具的核心功能：将各种代码质量检测工具（如 CheckStyle, JUnit, PHPmd, PHPmnd, PmdCpd, Psalm）生成的报告作为输入，转换为多种目标格式，包括 GitHub Actions CLI, GitLab JSON, JUnit XML, Plain Text, TeamCity Inspections 和 TeamCity Tests。该工具充当一个转换器的角色，使得代码质量报告可以在不同的 CI/CD 平台和 IDE 中更好地集成和展示。其中，CheckStyle 和 JUnit 是两种常见的报告格式，而 GitHub Actions 和 TeamCity 是两种常用的 CI/CD 平台。
