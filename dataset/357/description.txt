## 图类型与用途
这是一个流程图，描述了 GABBE (Generative Architectural Brain Base Engine) 系统的架构，特别是其 Agentic Software R&D Engineering Kit 的工作流程。它展示了用户、智能体、项目上下文、能力层和记忆系统之间的交互关系，用于概括 GABBE 系统的核心组件和它们之间的关系。

## 图的整体布局
图整体采用从左到右的布局。左侧是 Memory System，中间是 Human 和 Agent/Brain，右侧是 Project Context 和 Capability Layer。信息流从 Strategy & Goals 开始，经过 Agent/Brain 的处理，最终影响 Capability Layer，并通过 Review & Approval 环节反馈回 Agent/Brain。

## 分组/子图/阶段说明
图中包含五个显式子图：
- **Human ("User (Steering Wheel)")**：代表用户，作为系统的“方向盘”，负责提供战略和目标，并进行审查和批准。
- **Agent / Brain ("Engine")**：代表智能体，作为系统的“引擎”，负责执行任务和进行决策。
- **Context ("Project Context")**：代表项目上下文，为智能体提供必要的背景信息。
- **Tools ("Capability Layer")**：代表能力层，包含各种工具和资源，供智能体使用。
- **Memory ("Memory System")**：代表记忆系统，用于存储和检索信息。

## 节点逐项说明
- **Strategy & Goals (H1)**：用户输入的战略和目标，是整个流程的起点。
- **Review & Approval (H2)**：用户对智能体生成的结果进行审查和批准。
- **Active Inference Loop (B1)**：智能体的核心循环，基于主动推理，用于规划、路由和优化工作。README 提到该系统使用 Active Inference 来计划、路由和优化工作。
- **Task Router (B2)**：任务路由器，负责将任务分配给合适的能力层工具。
- **AGENTS.md (C1)**：包含关于智能体的信息，例如角色和职责。根据 README 和 `agents/AGENTS.md`，该文件是所有 AI 编码代理的单一事实来源，包含项目标识和操作命令。
- **CONSTITUTION.md (C2)**：包含项目的宪法或规则，指导智能体的行为。根据 README 和 `agents/CONSTITUTION.md`，该文件包含项目的不可变规则，智能体不得违反这些规则。
- **120+ Skills (S)**：超过120个技能，代表智能体可以执行的各种操作。README 指出 GABBE 包含 140+ Skills (specialized capabilities)。
- **60+ Templates (T)**：超过60个模板，用于生成代码或其他内容。README 指出 GABBE 包含 70+ Templates (standardized documents)。
- **30+ Guides (G)**：超过30个指南，为智能体提供指导。README 指出 GABBE 包含 40+ Guides (language & domain expertise)。
- **Working Memory (M1)**：工作记忆，用于存储当前正在处理的信息。
- **Episodic (Logs) (M2)**：情景记忆，存储事件日志，用于项目历史审计和检查点。
- **Semantic (Facts) (M3)**：语义记忆，存储事实和知识，为智能体提供背景信息。

## 连线、分支与汇聚关系
- `H1 -> B1`：用户通过 Strategy & Goals 向 Active Inference Loop 提供战略和目标。
- `C1 -> B1`：AGENTS.md 向 Active Inference Loop 提供上下文信息。
- `M3 -> B1`：Semantic (Facts) 向 Active Inference Loop 提供上下文信息。
- `B1 -> B2`：Active Inference Loop 将任务传递给 Task Router。
- `B2 -> S`：Task Router 根据任务类型选择合适的 Skills。
- `S -> T`：Skills 可以使用 Templates 生成代码或其他内容。
- `S -> M2`：Skills 的结果存储到 Episodic (Logs) 中。
- `S -> H2`：Skills 的结果传递给 Review & Approval。
- `H2 -- Feedback --> B1`：Review & Approval 的反馈信息传递回 Active Inference Loop。

## 仓库语境与术语解释
- **GABBE (Generative Architectural Brain Base Engine)**：是一个用于软件和 AI 编码代理的通用工具包，可以将任何 AI 编码代理转变为受管理的工程团队。
- **Agentic Software R&D Engineering Kit**：GABBE 的一个组件，用于辅助软件研发过程。
- **Active Inference**：一种认知模型，智能体通过最小化预测误差来学习和行动。`agents/skills/brain/active-inference.skill.md` 描述了如何应用 Active Inference 来最小化预测误差。
- **Skills**：代表智能体可以执行的各种操作，例如编码、测试、部署等。
- **Templates**：用于生成代码、文档或其他内容的标准化文档。
- **Guides**：为智能体提供语言、领域等方面的专业知识。
- **AGENTS.md**：是所有 AI 编码代理的单一事实来源，包含项目标识和操作命令。
- **CONSTITUTION.md**：包含项目的不可变规则，智能体不得违反这些规则。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 GABBE 系统的核心架构，用户通过 Strategy & Goals 向 Agent/Brain 的 Active Inference Loop 提供目标，同时 AGENTS.md 和 Semantic (Facts) 提供上下文。Active Inference Loop 将任务传递给 Task Router，Task Router 选择合适的 Skills，Skills 可以使用 Templates 并将结果存储到 Episodic (Logs)，最终结果传递给用户进行 Review & Approval，形成反馈环路。其中，AGENTS.md 和 CONSTITUTION.md 提供了项目上下文，而 Active Inference Loop 是智能体的核心决策机制。
