## Diagram Type & Purpose
This is a flowchart diagram depicting the dependencies between various Go packages and external libraries within the itch.io ecosystem. It illustrates how the `butler` command-line tool relies on other packages for tasks such as archive extraction, compression, and platform-specific operations. The diagram serves as a high-level overview of the architectural relationships between these components.

## Overall Layout
The diagram has a left-to-right orientation. The `butler` node acts as the central starting point, with arrows indicating dependencies on other packages. The diagram fans out from `butler` to various leaf nodes representing individual packages and external libraries.

No explicit subgraphs; logically divided into six stages:

## Repository Context & Terminology
- **butler**: The itch.io command-line tool, used for installing, updating, and managing games and other content from itch.io.
- **hush**: Used for managing installation receipts and manifests, allowing butler to track installed files and their origins.
- **wharf**: Enables delta patching and binary diffing, reducing the size of updates by only transferring the changes between versions.
- **boar**: Provides multi-format archive extraction capabilities, allowing butler to extract files from various archive types such as 7z, RAR, and ZIP.
- **go-itchio**: The itch.io API client library, used for interacting with the itch.io API to retrieve information about games, downloads, and user accounts.
- **kompress**: An abstraction layer for compression algorithms, allowing butler to support multiple compression formats through a unified interface.
