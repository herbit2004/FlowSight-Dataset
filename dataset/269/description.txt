## 图类型与用途
这是一个流程图/架构图，用于展示 `butler` 工具的内部架构和依赖关系。它在仓库中的作用是帮助开发者理解 `butler` 的组成部分以及它们之间的交互，正如 README 中“Butler architecture”章节所述。

## 图的整体布局
图整体采用从左到右的布局。核心组件 `butler` 位于左侧，其余组件根据其功能和依赖关系分布在右侧。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为以下几个阶段：
- 核心组件：`butler` 作为整个架构的中心。
- 高级包：`hush`、`wharf`、`boar`、`go-itchio`，提供高级功能。
- 中级包：`savior`、`httpkit`，提供中间层服务。
- 叶子包：`headway`、`arkive`、`dash` 等，提供基础功能。
- 压缩包：`kompress`、`dskompress`、`go-brotli`、`lzma`，提供压缩和解压缩功能。
- 归档提取包：`sevenzip-go`、`dmcunrar-go`，提供归档文件提取功能。
- 外部原生库：`libc7zip`，提供底层支持。

## 节点逐项说明
- **butler**：核心组件，代表 `butler` 命令行工具本身。README 描述 `butler` 是 itch.io 的命令行工具。
- **hush**：用于处理安装收据和清单。README 描述 `hush` 用于 Installation receipts and manifests。
- **wharf**：用于增量补丁、二进制差异比较和 pwr 格式处理。README 描述 `wharf` 用于 Delta patching, binary diffing, pwr format。
- **boar**：用于多格式归档文件提取（7z、RAR、ZIP）。README 描述 `boar` 用于 Multi-format archive extraction (7z, RAR, ZIP)。
- **go-itchio**：itch.io API 客户端库。README 描述 `go-itchio` 是 itch.io API client library。
- **savior**：用于归档文件提取和查找。README 描述 `savior` 用于 Archive extraction and seeking。
- **httpkit**：HTTP 实用工具和流处理。README 描述 `httpkit` 用于 HTTP utilities and streaming。
- **headway**：进度跟踪和单位格式化。README 描述 `headway` 用于 Progress tracking and unit formatting。
- **arkive**：ZIP/归档格式支持。README 描述 `arkive` 用于 ZIP/archive format support。
- **dash**：游戏配置和元数据。README 描述 `dash` 用于 Game configuration and metadata。
- **elefant**：ELF 二进制解析器（Linux）。README 描述 `elefant` 用于 ELF binary parser (Linux)。
- **hades**：SQLite 模式和查询。README 描述 `hades` 用于 SQLite schema and queries。
- **intact**：文件完整性验证。README 描述 `intact` 用于 File integrity verification。
- **lake**：二进制存储池，文件结构跟踪。README 描述 `lake` 用于 Binary storage pools, file structure tracking。
- **mitch**：测试固件（仅开发）。README 描述 `mitch` 用于 Test fixtures (dev only)。
- **ox**：操作系统抽象（注册表、系统调用）。README 描述 `ox` 用于 OS abstractions (registry, system calls)。
- **pelican**：PE 二进制解析器（Windows）。README 描述 `pelican` 用于 PE binary parser (Windows)。
- **screw**：游戏清单实用工具。README 描述 `screw` 用于 Game manifest utilities。
- **smaug**：Windows 安装程序/运行时检测。README 描述 `smaug` 用于 Windows installer/runtime detection。
- **spellbook**：文件魔数检测。README 描述 `spellbook` 用于 File magic number detection。
- **wizardry**：二进制文件实用工具。README 描述 `wizardry` 用于 Binary file utilities。
- **kompress**：压缩抽象层。README 描述 `kompress` 用于 Compression abstraction layer。
- **dskompress**：解压缩实用工具。README 描述 `dskompress` 用于 Decompression utilities。
- **go-brotli**：Brotli 压缩支持。README 描述 `go-brotli` 用于 Brotli compression support。
- **lzma**：LZMA 压缩支持。README 描述 `lzma` 用于 LZMA compression support。
- **randsource**：随机源实用工具。README 描述 `randsource` 用于 Random source utilities。
- **sevenzip-go**：7-zip 库绑定。README 描述 `sevenzip-go` 用于 7-zip library bindings。
- **dmcunrar-go**：RAR 解压缩支持。README 描述 `dmcunrar-go` 用于 RAR decompression support。
- **libc7zip**：7-zip 的 C 包装器。README 描述 `sevenzip-go` 动态链接到 `libc7zip`。
