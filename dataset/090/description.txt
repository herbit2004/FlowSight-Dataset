- **A (README.md)**：代表包含 Mermaid 图表的 Markdown 文件，是整个流程的输入起点。根据 README，`render-md-mermaid` 脚本可以处理任何包含 Mermaid 图表的 Markdown 文件。
- **B (Find mermaid graphs and image paths)**：表示脚本中查找 Mermaid 图表代码块和对应的图片路径的步骤。该步骤从 Markdown 文件中提取图表定义和目标图片路径。
- **C (docker mermaid-cli)**：代表使用 Docker 容器运行 `mermaid-cli` 工具来渲染第一个 Mermaid 图表，并生成 PNG 格式的图片。根据 `render-md-mermaid.sh` 脚本，实际执行的命令是 `docker run`，并挂载当前目录到容器中。
- **D (docker mermaid-cli)**：代表使用 Docker 容器运行 `mermaid-cli` 工具来渲染第二个 Mermaid 图表，并生成 SVG 格式的图片。
- **E (Graph 1 png image)**：代表第一个 Mermaid 图表渲染后生成的 PNG 图片，是流程的输出结果之一。
- **F (Graph 2 svg image)**：代表第二个 Mermaid 图表渲染后生成的 SVG 图片，是流程的输出结果之一。

## 仓库语境与术语解释
- **Mermaid**：一种使用类似 Markdown 语法的文本描述来生成图表的工具。README 中提到，该工具旨在简化在 Markdown 文档中使用 Mermaid 图表的过程。
- **mermaid-cli**：一个命令行工具，用于将 Mermaid 文本描述渲染成图片（SVG 或 PNG 格式）。`render-md-mermaid.sh` 脚本使用 Docker 容器来运行该工具。
- **render-md-mermaid.sh**：一个 Bash 脚本，用于自动查找 Markdown 文件中的 Mermaid 图表，并使用 `mermaid-cli` 将其渲染成图片。该脚本是该仓库的核心组件。
- **Docker**：一个容器化平台，用于打包、分发和运行应用程序。`render-md-mermaid.sh` 脚本使用 Docker 容器来运行 `mermaid-cli`，以确保环境一致性。
- **action.yml**：定义了 GitHub Action 的元数据，包括输入、输出和运行方式。该文件指定了使用 Docker 镜像来运行该 Action。
- **Makefile**：一个用于自动化构建过程的文件。该仓库提供了一个 `render-md-mermaid.mk` 文件，可以包含到 Makefile 中，以便使用 `make render-md-mermaid` 命令来渲染 Markdown 文件中的 Mermaid 图表。
- **details 标签**：README 中提到，使用 `<details>` 标签可以隐藏 Mermaid 图表的源代码，只显示渲染后的图片。
