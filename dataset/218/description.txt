## Diagram Type & Purpose
This is a flowchart diagram depicting a decision-making process for selecting appropriate analysis methods based on the type of data being analyzed. It guides users through a series of questions about their data (spatial coordinates, multi-modality, etc.) to suggest relevant computational methods available in the `liana-py` package. The diagram serves as a visual guide for researchers to choose the most suitable analysis technique for their specific dataset.

## Overall Layout
The flowchart has a top-down (TD) layout. It starts with a "What type of data?" node at the top and branches out based on the answers to subsequent questions. The end nodes represent specific analysis methods or tutorials.

## Subgraphs / Stages
No explicit subgraphs; logically divided into three stages:
1. **Data Type Identification**: Determining the fundamental characteristics of the data (spatial coordinates, multi-modality).
2. **Comparative Analysis**: Assessing the data's structure and suitability for comparative methods (across samples, specific contrasts).
3. **Method Selection**: Recommending specific analysis techniques based on the data's properties.

## High-Density QA Ground Truth Summary
The flowchart begins with the "What type of data?" node, branching into two primary paths based on whether the data has spatial coordinates or is multi-modal. If spatial coordinates are present, the flow proceeds to "Resolution?" to determine if the data is single-cell or spot-based. Single-cell data leads to the "Inflow Score" method, while spot-based data prompts a question about the "Analysis type?" (bivariate or unsupervised). Bivariate analysis further branches based on "Local interactions?" leading to either "Local Bivariate Metrics" or "Global Bivariate Metrics." Unsupervised analysis leads to "Multi-view Learning." If the initial data type is not spatial, the flow asks "Compare across samples?" If yes, it asks "Specific contrast?" leading to "Differential Contrasts," "MOFA+," or "Tensor-cell2cell," with the latter connecting to "Extended Tutorials" for cell-cell communication protocols. If "Compare across samples?" is no, the flow leads to "Steady-state LR Inference." Alternatively, if the initial data type is multi-modal, it branches into "Multi-Modal Spatial" if spatial, or "Multi-Modal Single-Cell" if non-spatial, with the latter leading to "Metabolite-mediated CCC" for analyzing cell-cell communication from transcriptomics data. The `liana-py` package provides implementations for many of these analysis methods.
