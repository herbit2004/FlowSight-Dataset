## 图类型与用途
这是一个流程图，描述了 `vibe-log-cli` 工具如何处理 Claude Code 会话数据，并最终生成生产力报告。该图概括了从本地数据到云端分析再到仪表盘展示的整体流程，在仓库中起着架构概览的作用。

## 图的整体布局
图采用从上到下的布局，分为三个主要部分：本地环境（Your Machine）、Vibe-Log 云端（Vibe-Log Cloud）和仪表盘功能（Dashboard Features）。流程从本地环境开始，经过云端处理，最终在仪表盘上展示。

## 分组/子图/阶段说明
图中包含三个显式子图：
- **Local ("🏠 Your Machine")**：代表用户的本地机器环境，是整个流程的起点。
- **Cloud ("☁️ Vibe-Log Cloud")**：代表 Vibe-Log 的云端服务，负责数据处理和分析。
- **Features ("Dashboard Features")**：代表 Web 仪表盘提供的各种功能，是流程的终点。

## 节点逐项说明
- **Sessions (Claude Code Sessions)**：代表用户本地存储的 Claude Code 会话数据。
- **Select (Select sessions)**：代表用户选择需要分析的会话数据的步骤。
- **Privacy (🔒 Privacy Layer)**：代表隐私处理层，负责移除代码和敏感信息，只保留模式（patterns）。隐私层的描述文字表明，该步骤旨在保护用户隐私。
- **Upload (Upload patterns)**：代表将经过隐私处理的模式上传到 Vibe-Log 云端的步骤。
- **Verify (Server verification)**：代表云端服务器对上传的数据进行验证的步骤。
- **Analysis (AI analysis)**：代表云端使用 AI 对数据进行分析的步骤。
- **Dashboard (📊 Web Dashboard)**：代表最终展示分析结果的 Web 仪表盘。
- **Track (📈 Track prompt improvement over time)**：仪表盘提供的功能，用于跟踪提示词随时间推移的改进情况。
- **Metrics (⚡ Deeper productivity insights)**：仪表盘提供的功能，提供更深入的生产力洞察。
- **Streaks (🔥 Peak times/Low times)**：仪表盘提供的功能，显示高峰时间和低谷时间。
- **Prompt (💬 User Prompt Analysis)**：仪表盘提供的功能，用于用户提示词分析。

## 连线、分支与汇聚关系
- `Sessions -> Select`：从本地会话数据开始，首先需要选择要分析的会话。
- `Select -> Privacy`：选择会话后，进入隐私处理层。
- `Privacy -> Upload`：经过隐私处理的模式被上传到云端。
- `Upload -> Verify`：云端服务器对上传的模式进行验证。
- `Verify -> Analysis`：验证通过的数据进入 AI 分析阶段。
- `Analysis -> Dashboard`：分析结果最终在 Web 仪表盘上展示。
- `Dashboard -> Track`：仪表盘提供跟踪提示词改进的功能。
- `Dashboard -> Metrics`：仪表盘提供生产力洞察功能。
- `Dashboard -> Streaks`：仪表盘提供显示高峰/低谷时间的功能。
- `Dashboard -> Prompt`：仪表盘提供用户提示词分析功能。
- `Dashboard -> Track, Metrics, Streaks, Prompt`：Web Dashboard 分别连接到 Track, Metrics, Streaks, Prompt，形成分支关系，表明仪表盘提供多种分析功能。

## 仓库语境与术语解释
- **vibe-log-cli**：一个开源命令行工具，用于分析 Claude Code 会话并生成生产力报告，如 README 所述。
- **Claude Code Sessions**：指在 Claude Code 编辑器中产生的会话数据。
- **Privacy Layer**：负责移除代码和敏感信息，只保留模式（patterns），保证用户隐私。相关代码可能在 `src/lib/privacy.ts` 中。
- **Web Dashboard**：最终展示分析结果的 Web 界面，可能与 `src/lib/ui` 目录下的文件有关。
- **AI analysis**：云端使用 AI 对数据进行分析，具体的 AI 模型和分析方法在图中未明确说明，但可能与 `src/lib/sub-agents` 相关。
- **Patterns**：经过隐私处理后保留的模式，用于后续的 AI 分析。
- **报告生成**: `vibe-log-cli` 可以生成生产力报告，相关代码可能在 `src/lib/report-generator.ts` 中。
