## 图类型与用途
这是一个架构图，展示了 ICL 如何与不同类型的客户端以及底层的 Lisp 镜像进行交互。该图用于说明 ICL 的整体架构，以及各种客户端如何连接到 ICL 和 Lisp 环境。

## 图的整体布局
图采用从左到右的布局，分为三个主要部分：客户端、ICL 核心组件和 Lisp 镜像。客户端位于左侧，ICL 组件位于中间，Lisp 镜像位于右侧。

## 分组/子图/阶段说明
图中包含三个子图，分别代表不同的组件类别：
- **Clients**：包含各种客户端类型，如终端、浏览器、Emacs 和 AI 命令行工具。
- **ICL**：包含 ICL 的核心组件，如 Web Server、MCP Server 和 Slynk Client。
- **Lisp Image**：包含 Lisp 镜像中的 Slynk Server。

## 节点逐项说明
- **Terminal**：传统的命令行终端，通过标准输入/输出与 ICL 交互。
- **Browser**：Web 浏览器，通过 HTTP/WS 协议与 ICL 中的 Web Server 交互。
- **Emacs**：Emacs 编辑器，通过 SLY/SLIME 集成 ICL，使用 Slynk 协议。
- **AI CLIs**：AI 命令行工具，通过 HTTP 协议与 ICL 中的 MCP Server 交互。
- **Web Server**：ICL 中的 Web 服务器，处理来自浏览器的 HTTP/WS 请求。
- **MCP Server**：ICL 中的 MCP 服务器，处理来自 AI 命令行工具的 HTTP 请求。根据 `src/mcp-server.lisp`，MCP (Model Context Protocol) server 允许 AI 助手查询 Lisp 环境。
- **Slynk Client**：ICL 中的 Slynk 客户端，用于与 Lisp 镜像中的 Slynk 服务器通信。
- **Slynk Server**：运行在 Lisp 镜像中，负责处理来自 Slynk 客户端的请求。

## 连线、分支与汇聚关系
- `Terminal ---|stdin/stdout| ICL`：终端通过标准输入/输出直接与 ICL 交互。
- `Browser ---|HTTP/WS| Web`：浏览器通过 HTTP/WS 协议与 ICL 的 Web Server 交互。
- `AI ---|HTTP| MCP`：AI 命令行工具通过 HTTP 协议与 ICL 的 MCP Server 交互。
- `Client & Emacs ---|Slynk| Server`：Emacs 和 ICL 中的 Slynk Client 通过 Slynk 协议与 Lisp Image 中的 Slynk Server 交互，形成汇聚关系。

## 仓库语境与术语解释
- **ICL (Interactive Common Lisp)**：一个增强的 Common Lisp REPL，提供现代交互体验，如 README 所述。
- **REPL (Read-Eval-Print Loop)**：一种交互式编程环境，用户可以输入表达式并立即获得结果。
- **Slynk/SLIME**：用于 Common Lisp 的 Emacs 集成工具，允许在 Emacs 中开发和调试 Lisp 代码。`emacs/icl.el` 提供了 ICL 与 SLY/SLIME 的集成。
- **Web Server**：ICL 提供的 Web 界面，允许通过浏览器进行交互，提供包浏览和数据可视化等功能。
- **MCP (Model Context Protocol)**：一种协议，允许 AI 助手查询 Lisp 环境。`src/mcp-server.lisp` 实现了 MCP 服务器。
- **Slynk Client/Server**：Slynk 客户端运行在 ICL 中，Slynk 服务器运行在 Lisp 镜像中，两者通过 Slynk 协议通信。`src/slynk-client.lisp` 实现了 Slynk 客户端。
- **Lisp Image**：Lisp 程序的运行时环境，包含编译后的代码和数据。

## 可作为 QA Ground Truth 的高信息密度摘要
该架构图展示了 ICL 如何作为一个中间层，连接不同的客户端（包括终端、浏览器、Emacs 和 AI 命令行工具）和底层的 Lisp 镜像。终端通过标准输入/输出直接与 ICL 交互，浏览器通过 HTTP/WS 协议与 ICL 的 Web Server 交互，AI 命令行工具通过 HTTP 协议与 ICL 的 MCP Server 交互，Emacs 和 ICL 中的 Slynk Client 通过 Slynk 协议与 Lisp Image 中的 Slynk Server 交互。ICL 作为一个增强的 REPL，通过多种方式与客户端和 Lisp 镜像进行连接，提供统一和增强的 Common Lisp 开发环境。其中，MCP Server 允许 AI 助手查询 Lisp 环境，Slynk Client/Server 用于 Emacs 集成。
