## Edges, Branches & Convergence
- `SQL Query String --> Lexer & Parser`: The SQL query string is passed to the lexer and parser.
- `Lexer & Parser --> Abstract Syntax Tree`: The lexer and parser generate an abstract syntax tree.
- `Abstract Syntax Tree --> AST Visitors & Rewriters`: The abstract syntax tree is passed to AST visitors and rewriters.
- `AST Visitors & Rewriters --> Type Inference & Semantic Analysis`: The modified AST is passed to the type inference and semantic analysis stage.
- `Plugin / Schema Registry -.-> Type Inference & Semantic Analysis`: The plugin/schema registry injects types and methods into the type inference and semantic analysis stage.
- `Type Inference & Semantic Analysis --> C# Code Generator & Compiler`: The semantically analyzed AST is passed to the C# code generator and compiler.
- `C# Code Generator & Compiler --> Execution Runtime VM`: The compiled C# code is passed to the execution runtime VM.
- `Execution Runtime VM <--> Data Source Plugin`: The execution runtime VM streams data row-by-row from the data source plugin.
- `Execution Runtime VM ===> Tabular Result Set`: The execution runtime VM produces the tabular result set.

## Repository Context & Terminology
- **SQL Query String**: A string containing a query written in the SQL language.
- **Lexer**: A lexical analyzer that breaks down the SQL query string into tokens.
- **Parser**: A component that constructs a parse tree or abstract syntax tree (AST) from the tokens produced by the lexer.
- **Abstract Syntax Tree (AST)**: A tree representation of the syntactic structure of the SQL query.
- **Semantic Analysis**: The process of checking the AST for semantic errors, such as type mismatches and undefined variables.
- **C# Code Generator**: A component that generates C# code from the AST.
- **Compiler**: A tool that translates the generated C# code into executable code.
- **Execution Runtime VM**: A virtual machine that executes the compiled code.
- **Plugin / Schema Registry**: A repository of available plugins and schema information.
- **Data Source Plugin**: A plugin that provides access to a specific data source.
- **Tabular Result Set**: The final output of the query execution, presented in a tabular format.
