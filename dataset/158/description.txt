## 图类型与用途
这是一个流程图，描述了 Musoq 核心引擎内部管道如何处理 SQL 查询。该图展示了从接收 SQL 查询字符串开始，经过解析、语义分析、编译和运行时执行，最终生成表格结果集的完整流程。

## 图的整体布局
图采用从上到下的布局，展示了数据处理的各个阶段。流程从顶部的 SQL 查询字符串开始，经过引擎内部处理，最终输出表格结果集。

## 分组/子图/阶段说明
图中包含一个名为 "Core Engine Internal Pipeline" 的子图，它包含了词法分析、语法分析、抽象语法树处理、语义分析、代码生成和运行时执行等阶段。

## 节点逐项说明
- **SQL[/SQL Query String/]**：用户输入的 SQL 查询字符串，作为整个流程的起点。
- **Parser[Lexer & Parser]**：词法分析器和语法分析器，负责将 SQL 查询字符串解析成抽象语法树（AST）。
- **AST[Abstract Syntax Tree]**：抽象语法树，是 SQL 查询的树形表示，方便后续处理。
- **Visitors[AST Visitors & Rewriters]**：抽象语法树访问者和重写器，用于遍历和修改抽象语法树，进行优化和转换。
- **Semantic[Type Inference & Semantic Analysis]**：类型推断和语义分析器，负责检查 SQL 查询的语义正确性，并推断表达式的类型。
- **Compiler[C# Code Generator & Compiler]**：C# 代码生成器和编译器，将抽象语法树转换成可执行的 C# 代码。
- **Runtime[Execution Runtime VM]**：执行运行时虚拟机，负责执行编译后的 C# 代码。
- **Registry[(Plugin / Schema Registry)]**：插件/模式注册表，用于注册和管理数据源插件和自定义函数。
- **DataSource[(Data Source Plugin)]**：数据源插件，负责从各种数据源（如文件、日志、进程等）读取数据。
- **Results[/Tabular Result Set/]**：表格结果集，是 SQL 查询的最终输出结果。

## 连线、分支与汇聚关系
- `SQL -> Parser`：SQL 查询字符串被传递给 Parser 进行解析。
- `Parser -> AST`：Parser 生成抽象语法树（AST）。
- `AST -> Visitors`：AST 经过 Visitors 的处理和优化。
- `Visitors -> Semantic`：AST 传递给 Semantic 进行语义分析和类型推断。
- `Registry -.-> Semantic`：Registry 向 Semantic 提供类型和方法信息，用于语义分析。
- `Semantic -> Compiler`：Semantic 将 AST 编译成 C# 代码。
- `Compiler -> Runtime`：Compiler 将 C# 代码传递给 Runtime 执行。
- `Runtime <--> DataSource`：Runtime 通过 DataSource 插件从数据源读取数据，并逐行处理。
- `Runtime ===> Results`：Runtime 将处理后的数据以表格形式输出为 Results。

## 仓库语境与术语解释
- **SQL**: Musoq 允许使用 SQL 查询非传统数据库的数据源，例如文件、日志和进程。
- **Parser**: 负责将 SQL 查询字符串转换为抽象语法树，以便后续处理。
- **AST Visitors & Rewriters**: 用于优化和转换抽象语法树，提高查询效率。
- **Schema Registry**: 用于注册和管理数据源插件和自定义函数，扩展 Musoq 的功能。
- **Data Source Plugin**: 允许 Musoq 从各种数据源读取数据，例如文件、API 和数据库。
- **Runtime**: 负责执行编译后的 C# 代码，并与数据源插件交互。
- **Tabular Result Set**: SQL 查询的最终输出结果，以表格形式呈现。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 Musoq 核心引擎处理 SQL 查询的流程，从接收 SQL 查询字符串开始，经过 Parser 解析生成 AST，然后通过 Visitors 进行优化，Semantic 进行语义分析和类型推断，Compiler 编译成 C# 代码，最后由 Runtime 执行并从 DataSource 读取数据，最终生成 Tabular Result Set。Registry 允许注入自定义的类型和方法，DataSource 插件负责与不同的数据源进行交互。
