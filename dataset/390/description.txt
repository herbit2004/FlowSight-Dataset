## 图类型与用途
这是一个流程图，描述了 VulnX Scanner 如何处理用户输入的目标地址，并将其转换为可用于端口扫描的 IP 地址类型（IPv4 或 IPv6）。该图在仓库中的作用是展示目标地址解析和处理的流程，确保输入的有效性。

## 图的整体布局
图整体采用从上到下的布局。流程从用户输入开始，经过一系列检查和验证步骤，最终确定使用 IPv4 或 IPv6 套接字进行端口扫描，或者返回错误信息。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可分为三个阶段：输入清理与类型判断、IP 地址验证或域名解析、地址类型返回与端口扫描准备。

## 节点逐项说明
- **Start (User Input: Target)**：流程的起点，表示用户输入的目标地址（域名或 IP 地址）。
- **Clean (Clean Input)**：清理用户输入，移除 "http://" 前缀和括号等不必要的字符。
- **CheckIP (Is it already an IP?)**：检查清理后的输入是否已经是 IP 地址。
- **ValidateIP (Validate IP Format)**：如果输入是 IP 地址，则验证其格式是否正确。
- **CheckIPv4 (is_ipv4?)**：检查是否为 IPv4 地址。
- **CheckIPv6 (is_ipv6?)**：检查是否为 IPv6 地址。
- **IPv4Valid (Validate 4 octets)**：验证 IPv4 地址的四个八位字节是否在 0-255 的范围内。
- **IPv6Valid (Validate IPv6 format)**：验证 IPv6 地址的格式是否符合标准，使用了 `socket.inet_pton` 函数。
- **ResolveDNS (Resolve as Hostname)**：如果输入不是 IP 地址，则尝试将其解析为域名。
- **TryIPv4 (Try IPv4 Resolution)**：尝试使用 IPv4 解析域名，使用了 `socket.gethostbyname` 函数。
- **TryIPv6 (Try IPv6 Resolution)**：尝试使用 IPv6 解析域名，使用了 `socket.getaddrinfo` 函数。
- **ReturnIPv4 (Return AF_INET)**：返回 IPv4 地址类型，准备使用 IPv4 套接字，使用了 `socket.AF_INET`。
- **ReturnIPv6 (Return AF_INET6)**：返回 IPv6 地址类型，准备使用 IPv6 套接字，使用了 `socket.AF_INET6`。
- **UseIPv4 (Use AF_INET Socket)**：使用 IPv4 套接字进行端口扫描。
- **UseIPv6 (Use AF_INET6 Socket)**：使用 IPv6 套接字进行端口扫描。
- **Scan (Perform Port Scan)**：执行端口扫描。
- **Error (Return None)**：表示发生错误，无法解析或验证目标地址。
- **FailMsg (Display Error Message)**：显示错误信息给用户。

## 连线、分支与汇聚关系
- `Start -> Clean`：用户输入的目标地址首先被清理。
- `Clean -> CheckIP`：清理后的输入进入 IP 地址检查环节。
- `CheckIP -- Yes --> ValidateIP`：如果输入是 IP 地址，则验证其格式。
- `CheckIP -- No --> ResolveDNS`：如果输入不是 IP 地址，则尝试将其解析为域名。
- `ValidateIP -> CheckIPv4`：验证 IP 地址后，检查是否为 IPv4 地址。
- `ValidateIP -> CheckIPv6`：验证 IP 地址后，检查是否为 IPv6 地址。
- `CheckIPv4 -- Yes --> IPv4Valid`：如果是 IPv4 地址，则验证其四个八位字节。
- `CheckIPv6 -- Yes --> IPv6Valid`：如果是 IPv6 地址，则验证其格式。
- `IPv4Valid -- Valid --> ReturnIPv4`：IPv4 地址验证通过后，返回 IPv4 地址类型。
- `IPv4Valid -- Invalid --> Error`：IPv4 地址验证失败后，返回错误。
- `IPv6Valid -- Valid --> ReturnIPv6`：IPv6 地址验证通过后，返回 IPv6 地址类型。
- `IPv6Valid -- Invalid --> Error`：IPv6 地址验证失败后，返回错误。
- `ResolveDNS -> TryIPv4`：尝试将域名解析为 IPv4 地址。
- `TryIPv4 -- Success --> ReturnIPv4`：IPv4 解析成功后，返回 IPv4 地址类型。
- `TryIPv4 -- Fail --> TryIPv6`：IPv4 解析失败后，尝试 IPv6 解析。
- `TryIPv6 -- Success --> ReturnIPv6`：IPv6 解析成功后，返回 IPv6 地址类型。
- `TryIPv6 -- Fail --> Error`：IPv6 解析失败后，返回错误。
- `ReturnIPv4 -> UseIPv4`：返回 IPv4 地址类型后，使用 IPv4 套接字。
- `ReturnIPv6 -> UseIPv6`：返回 IPv6 地址类型后，使用 IPv6 套接字。
- `UseIPv4 -> Scan`：使用 IPv4 套接字进行端口扫描。
- `UseIPv6 -> Scan`：使用 IPv6 套接字进行端口扫描。
- `ReturnIPv4 -> UseIPv4` 和 `ReturnIPv6 -> UseIPv6`，最终汇聚到 `Scan` 节点，形成汇聚关系。
- `Error -> FailMsg`：发生错误后，显示错误信息。

## 仓库语境与术语解释
- **AF_INET**：`socket.AF_INET`，表示 IPv4 地址族，用于创建 IPv4 套接字。
- **AF_INET6**：`socket.AF_INET6`，表示 IPv6 地址族，用于创建 IPv6 套接字。
- **socket.gethostbyname**：Python 的 socket 库中的函数，用于将主机名解析为 IPv4 地址。
- **socket.getaddrinfo**：Python 的 socket 库中的函数，用于将主机名解析为 IPv6 地址。
- **socket.inet_pton**：Python 的 socket 库中的函数，用于将 IPv6 地址字符串转换为二进制格式，进行格式验证。
- **端口扫描 (Port Scan)**：VulnX Scanner 的核心功能，用于发现目标主机上开放的网络端口。README 提到支持 IPv4 和 IPv6 地址的扫描。
- **src/core/scanner.py**：该文件包含了 `is_ipv4` 和 `is_ipv6` 函数，用于验证 IP 地址格式。
- **src/app.py**：该文件是 Flask 应用的主文件，负责处理用户请求和调用扫描功能。

## 可作为 QA Ground Truth 的高信息密度摘要
该图描述了 VulnX Scanner 如何从用户输入的目标地址开始，经过清理、IP 地址格式验证或域名解析，最终确定使用 IPv4 或 IPv6 套接字进行端口扫描。流程首先检查输入是否为 IP 地址，如果是，则验证其格式；如果不是，则尝试将其解析为域名。解析或验证成功后，返回相应的地址类型，并用于后续的端口扫描。如果解析或验证失败，则返回错误信息。`socket.gethostbyname` 和 `socket.getaddrinfo` 用于域名解析，`socket.AF_INET` 和 `socket.AF_INET6` 用于指定地址族。
