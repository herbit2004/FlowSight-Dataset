## Repository Context & Terminology
- **VPC (Virtual Private Cloud)**: A logically isolated virtual network in the AWS cloud, enabling you to launch AWS resources in a defined virtual network.
- **Public Subnets**: Subnets within a VPC that have a route to the internet via an Internet Gateway.
- **Security Groups**: Virtual firewalls that control inbound and outbound traffic for AWS resources.
- **ECS (Elastic Container Service)**: A fully managed container orchestration service that makes it easy to run, stop, and manage Docker containers on a cluster.
- **ECS Cluster**: A logical grouping of tasks or services.
- **ECS Task Definitions**: A blueprint for your application that specifies the Docker image, CPU, memory, and other resources required to run a container.
- **ECS Service**: Manages the deployment and scaling of tasks within an ECS cluster.
- **Docker Containers**: Standardized units of software that package up code and all its dependencies so the application runs quickly and reliably from one computing environment to another.
- **CloudWatch Log Group**: A container for log streams that share the same retention, monitoring, and access control settings.
- **Internet Gateway**: A VPC component that allows communication between instances in your VPC and the internet.
