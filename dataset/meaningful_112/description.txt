## 图类型与用途
该图是一个流程图，描述了单点登录（SSO）的完整流程。它展示了用户如何通过身份验证服务登录，并无缝访问多个应用程序，简化了用户的登录体验。该图涵盖了会话初始化、单点登录流程和应用接入三个主要阶段。

## 图的整体布局
该图采用从上到下的布局，逻辑上分为三个主要阶段。流程从用户请求登录开始，最终根据票据验证结果，建立本地会话或拒绝访问。

## 分组/子图/阶段说明
图中包含三个子图，分别代表单点登录流程的不同阶段：
- **会话初始化**：描述用户发起登录请求到身份验证的过程。
- **单点登录流程**：描述身份验证成功后，生成会话标识、颁发票据并重定向到目标应用的过程。
- **应用接入**：描述目标应用接收票据、验证票据并建立本地会话的过程。

## 节点逐项说明
- **A[用户请求登录]**: 用户发起登录请求的起始节点。
- **B[身份验证服务]**: 负责验证用户身份的服务。
- **C{验证成功?}**: 判断用户身份验证是否成功的决策节点。
- **D[生成会话标识（Session ID）]**: 身份验证成功后，生成唯一会话标识。
- **E[颁发认证票据（Ticket）]**: 颁发用于后续应用验证的票据。
- **F[存储会话信息]**: 存储用户的会话信息，例如登录状态和权限。
- **G[重定向到目标应用]**: 将用户重定向到目标应用。
- **H[目标应用接收票据]**: 目标应用接收到认证服务颁发的票据。
- **I[向认证服务验证票据]**: 目标应用向认证服务验证票据的有效性。
- **J{票据有效?}**: 判断票据是否有效的决策节点。
- **K[建立本地会话]**: 票据验证通过后，目标应用建立本地会话。
- **L[返回错误]**: 身份验证失败时，返回错误信息。
- **M[拒绝访问]**: 票据验证失败时，拒绝用户访问。

## 连线、分支与汇聚关系
- A -> B：用户请求登录发送到身份验证服务。
- B -> C：身份验证服务进行身份验证。
- C -- 是 --> D：身份验证成功，生成会话标识。
- C -- 否 --> L：身份验证失败，返回错误。
- D -> E：生成会话标识后，颁发认证票据。
- E -> F：颁发认证票据后，存储会话信息。
- F -> G：存储会话信息后，重定向到目标应用。
- G -> H：重定向后，目标应用接收票据。
- H -> I：目标应用接收票据后，向认证服务验证票据。
- I -> J：认证服务验证票据。
- J -- 是 --> K：票据有效，建立本地会话。
- J -- 否 --> M：票据无效，拒绝访问。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **单点登录（SSO）**: 一种身份验证方法，允许用户使用一组凭据访问多个应用程序。
- **会话标识（Session ID）**: 用于唯一标识用户会话的字符串。
- **认证票据（Ticket）**: 由认证服务颁发，用于验证用户身份的凭据。
- **身份验证服务**: 负责验证用户身份的服务。
- **目标应用**: 用户希望访问的应用程序。

## 可作为 QA Ground Truth 的高信息密度摘要
用户发起登录请求，身份验证服务验证用户身份，若验证成功，则生成会话标识并颁发认证票据，存储会话信息后重定向到目标应用；目标应用接收票据并向认证服务验证，若票据有效，则建立本地会话，否则拒绝访问。若身份验证失败，则返回错误。
