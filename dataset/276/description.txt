## 图类型与用途
这是一个流程图，描述了使用多智能体进行深度研究的架构，特别是 `DeepResearcher` 的流程。该图展示了如何通过多个智能体协同工作，从用户输入开始，最终生成一份完整的深度研究报告。

## 图的整体布局
图采用从左到右的布局。流程从左侧的用户输入开始，经过规划、并行研究和校对，最终在右侧输出最终研究报告。

## 分组/子图/阶段说明
- **Parallel Section Research**：这是一个子图，表示并行章节研究阶段。其中包含多个 `IterativeResearcher` 智能体，每个智能体负责研究报告中的一个章节。

## 节点逐项说明
- **User Input**：用户输入，包括查询内容（query）、最大迭代次数（max\_iterations）和最大运行时间（max\_time）。这是整个流程的起点。
- **Planner Agent**：规划智能体，负责根据用户输入制定研究计划，包括报告的章节划分以及每个章节的背景信息。
- **IterativeResearcher (Section 1)**：迭代研究智能体，负责研究报告中的第一个章节。根据 README，`IterativeResearcher` 运行一个持续循环，对主题或子主题进行研究并起草报告。
- **IterativeResearcher (Section 2)**：迭代研究智能体，负责研究报告中的第二个章节。
- **IterativeResearcher (Section 3)**：迭代研究智能体，负责研究报告中的第三个章节。
- **Proofreader Agent**：校对智能体，负责接收来自各个 `IterativeResearcher` 的章节草稿，进行校对、编辑和整合。
- **Final Research Report**：最终研究报告，是整个流程的输出结果，包含经过校对和整合的各个章节内容。

## 连线、分支与汇聚关系
- `User Input -> Planner Agent`：用户输入被传递给规划智能体。
- `Planner Agent -> IterativeResearcher (Section 2)`：规划智能体将报告计划传递给各个迭代研究智能体。
- `IterativeResearcher (Section 1) -> Proofreader Agent`：第一个迭代研究智能体生成章节草稿并传递给校对智能体。
- `IterativeResearcher (Section 2) -> Proofreader Agent`：第二个迭代研究智能体生成章节草稿并传递给校对智能体。
- `IterativeResearcher (Section 3) -> Proofreader Agent`：第三个迭代研究智能体生成章节草稿并传递给校对智能体。多个章节草稿汇聚到校对智能体，形成汇聚关系。
- `Proofreader Agent -> Final Research Report`：校对智能体输出最终的研究报告。

## 仓库语境与术语解释
- **DeepResearcher**：根据 README，`DeepResearcher` 运行一个更彻底和结构化的过程，首先形成报告大纲，然后为报告的每个部分运行并发的 `IterativeResearcher` 实例。
- **IterativeResearcher**：根据 README，`IterativeResearcher` 运行一个持续循环，对主题或子主题进行研究并起草报告。
- **Planner Agent**：负责根据用户输入制定研究计划，包括报告的章节划分以及每个章节的背景信息。
- **Proofreader Agent**：负责接收来自各个 `IterativeResearcher` 的章节草稿，进行校对、编辑和整合。
- **OpenAI Agents SDK**：该项目是使用 OpenAI Agents SDK 构建的。
- **Agent**：该架构使用多个智能体协同工作，提高研究效率并确保报告的质量和一致性。

## 可作为 QA Ground Truth 的高信息密度摘要
该图描述了 `DeepResearcher` 的流程，从用户输入开始，规划智能体根据输入生成报告计划，然后多个 `IterativeResearcher` 智能体并行地研究报告的不同章节，生成章节草稿。这些草稿被传递给校对智能体进行校对、编辑和整合，最终输出最终研究报告。该流程体现了自动化深度研究的流程，其中 `IterativeResearcher` 和 `Proofreader Agent` 是关键组件。
