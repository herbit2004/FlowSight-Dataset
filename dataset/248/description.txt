## Repository Context & Terminology
- **RESTful API**: An architectural style for designing networked applications. It relies on a stateless, client-server communication protocol, typically HTTP.
- **FastAPI**: A modern, fast (high-performance), web framework for building APIs with Python 3.7+ based on standard Python type hints.
- **MQ (Message Queue)**: A form of asynchronous service-to-service communication used in serverless and microservices architectures. Messages are stored on the queue until they are processed and deleted. RabbitMQ is a message broker.
- **PostgreSQL**: A powerful, open source object-relational database system.
- **S3 (Simple Storage Service)**: An object storage service offered by Amazon Web Services (AWS).
- **Redis**: An open source (BSD licensed), in-memory data structure store, used as a database, cache and message broker.
- **RabbitMQ**: A message-broker: it accepts and forwards messages.
