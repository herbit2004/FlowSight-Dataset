## 仓库语境与术语解释
- **Claude Code Skills 合集**：一个精选的 AI skill 描述文件库，为 Claude Code 提供专业化的工作助手。
- **Skills**：指的是项目中的各个功能模块，每个 Skill 以独立目录存放，包含 `SKILL.md` 文件，用于描述 Skill 的功能和触发关键词。
- **SKILL.md**：每个 Skill 的描述文件，包含 Skill 的名称、描述（触发关键词）等信息。
- **deploy-windows.bat / deploy-macos.sh**：用于将 Skills 部署到本地 Claude Code 环境的部署脚本。
- **Fork AI Commit**：与 AI Commit 相关的脚本，用于生成 Commit 信息。
- **generate-commit-msg.sh**：用于生成 Commit 信息的脚本，位于 `.fork/` 目录下。
- **Codex CLI**: 根据 README 的部署工具部分，Codex CLI 是 skills 的部署目标环境之一。
