## 图类型与用途
这是一个流程图，描述了 Aimmy 软件如何通过 AI 技术实现自动瞄准对齐。它展示了从游戏画面捕获到最终调整鼠标光标的完整流程，用于解释 Aimmy 的核心工作原理。

## 图的整体布局
图采用从左到右的布局。流程从“Playing Game System”开始，经过一系列处理步骤，最终到达“Mouse Cursor”。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可分为三个阶段：触发与画面捕获、AI 识别与决策、光标调整。

## 节点逐项说明
- **Playing Game System**：玩家正在运行的游戏系统，是整个流程的起点。
- **Triggering Functionality**：触发自动瞄准功能，可能通过按下某个按键实现。根据 README，按下触发键后，Aimmy 开始捕捉屏幕。
- **Screen Grabbing Functionality**：屏幕抓取功能，负责从游戏画面中捕获图像数据。`Aimmy2/AILogic/CaptureManager.cs` 文件可能包含该功能的具体实现。
- **YOLOv8 (DirectML + ONNX) Recognition**：使用 YOLOv8 模型进行目标识别，该模型基于 DirectML 和 ONNX 框架，用于检测游戏画面中的玩家或其他目标。README 提到 Aimmy 使用 YOLOv8 模型，并强调其在 AMD GPU 上的性能优势。
- **Making Decision**：决策环节，根据 YOLOv8 的识别结果、X+Y 轴的调整以及视野范围（FOV），决定如何调整鼠标光标。
- **X+Y Adjustment**：X 和 Y 轴的调整，用于确定鼠标光标需要移动的距离和方向。
- **FOV**：视野范围（Field of View），影响目标检测的范围和精度，也是决策的输入参数。`Aimmy2/Visuality/FOV.xaml.cs` 文件可能与 FOV 的显示和调整有关。
- **Mouse Cursor**：鼠标光标，是流程的最终输出，通过调整鼠标光标的位置来实现自动瞄准。`Aimmy2/InputLogic/MouseManager.cs` 文件可能包含鼠标光标控制的具体实现。

## 连线、分支与汇聚关系
- `Playing Game System -> Triggering Functionality`：游戏系统触发自动瞄准功能。
- `Triggering Functionality -> Screen Grabbing Functionality`：触发功能后，开始抓取屏幕。
- `Screen Grabbing Functionality -> YOLOv8 (DirectML + ONNX) Recognition`：屏幕抓取的数据被送入 YOLOv8 模型进行识别。
- `YOLOv8 (DirectML + ONNX) Recognition -> Making Decision`：YOLOv8 的识别结果被用于决策。
- `X+Y Adjustment -> Making Decision`：X 和 Y 轴的调整信息作为决策的输入。
- `FOV -> Making Decision`：视野范围作为决策的输入。
- `Making Decision -> Mouse Cursor`：决策的结果最终作用于鼠标光标，调整其位置。

## 仓库语境与术语解释
- **Aimmy**：一个基于 AI 的自动瞄准对齐机制，旨在帮助有瞄准困难的玩家。
- **YOLOv8**：一种目标检测模型，用于识别游戏画面中的目标。
- **DirectML & ONNX**：用于加速 AI 推理的框架，Aimmy 利用它们来实现更高的性能，尤其是在 AMD GPU 上。
- **FOV (Field of View)**：视野范围，影响目标检测的范围和精度。
- **Trigger Binding**：用于激活自动瞄准功能的按键或鼠标按键，`Aimmy2/InputLogic/InputBindingManager.cs` 文件可能包含相关实现。
- **Screen Grabbing**：从游戏画面捕获图像数据的过程，`Aimmy2/AILogic/CaptureManager.cs` 文件可能包含相关实现。
- **Mouse Movement Method**：Aimmy 允许用户选择不同的鼠标移动方法，以适应不同的鼠标类型和游戏。`Aimmy2/InputLogic/MouseManager.cs` 文件可能包含相关实现。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 Aimmy 软件的核心流程：从“Playing Game System”开始，通过“Triggering Functionality”激活，然后利用“Screen Grabbing Functionality”捕获游戏画面，并使用“YOLOv8 (DirectML + ONNX) Recognition”进行目标识别。识别结果与“X+Y Adjustment”和“FOV”共同输入到“Making Decision”环节，最终调整“Mouse Cursor”实现自动瞄准。其中，YOLOv8 模型和触发机制是关键环节，体现了 Aimmy 基于 AI 的自动瞄准特性。
