## Repository Context & Terminology
- **Client users**: Users who are trying to access the Web App.

- **Web App scripts**: The scripts that make up the Web App.
- **Scopes**: Permissions that the Web App requests to access user data.
- **Access token**: A token that allows the Web App to access user data on behalf of the user.
- **Authorization**: The process of granting the Web App permission to access user data.
