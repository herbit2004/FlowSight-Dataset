## Repository Context & Terminology
- **XLSX**: A file extension for an open XML spreadsheet file format used by Microsoft Excel.
- **OpenXML**: A family of XML markup languages used to represent electronic documents, spreadsheets, charts, and presentations.
- **POCO (Plain Old CLR Object)**: A simple .NET class that does not depend on any specific framework.
- **Dynamic**: A type in .NET that bypasses static type checking at compile time.
- **Stream**: A sequence of bytes that can be read from or written to.
- **Deferred execution**: An execution model where the evaluation of an expression is delayed until its value is actually needed.
