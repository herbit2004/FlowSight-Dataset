## 图类型与用途
这是一个流程图，描述了参与 MasterFabric 的 100 天软件开发学习计划时，根据选择的参与方式（正式实习或开放培训）所对应的不同流程。该图旨在为开发者提供清晰的行动指南。

## 图的整体布局
图整体采用从左到右的布局。流程从左侧的“Start”节点开始，经过一个判断节点后，根据选择的参与方式，分为上下两条不同的路径。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可分为三个阶段：开始阶段、选择阶段、以及根据选择进入的不同学习路径阶段。

## 节点逐项说明
- **Start**：流程的起点，表示开始参与 MasterFabric 的 100 天软件开发学习计划。
- **Which program?**：一个判断节点，询问参与者选择的是“Formal Internship”（正式实习）还是“Open Trainee”（开放培训）。
- **Complete interns/approved_intern+template.md**：如果选择“Formal Internship”，则需要完成 `interns/approved_intern+template.md` 文件中的内容。该文件是正式实习生的入职模板，需要填写个人信息和 100 天目标。
- **Read trainee/README.md**：如果选择“Open Trainee”，则需要阅读 `trainee/README.md` 文件。该文件是开放培训项目的起始指南，介绍了 MasterFabric Academy 的使命和学习方式。
- **Follow interns/intern_checklist.md**：在“Formal Internship”路径下，需要遵循 `interns/intern_checklist.md` 文件中的检查清单。该清单列出了实习生入职和持续学习期间需要完成的任务。
- **Use interns/pr_and_commit_guide.md**：在“Formal Internship”路径下，需要使用 `interns/pr_and_commit_guide.md` 文件中的 PR 和提交指南。该指南描述了如何编写清晰的 Pull Request 和 Commit Message。
- **Follow trainee/CONTRIBUTING.md**：在“Open Trainee”路径下，需要遵循 `trainee/CONTRIBUTING.md` 文件中的贡献指南。该指南描述了如何为 MasterFabric Academy 贡献代码和文档。
- **Pick a track in days/**：在“Open Trainee”路径下，需要在 `days/` 目录下选择一个学习方向。`days/` 目录下包含了 Flutter, Expo, DevOps, NestJS, Next.js, Git, AI Agents 等多个学习方向的 Roadmap。
- **Build in trainee/projects/**：在“Open Trainee”路径下，需要在 `trainee/projects/` 目录下进行项目构建。`trainee/projects/` 目录下包含了一些示例项目，例如 FinderDev 和 Sub Serve。

## 连线、分支与汇聚关系
- `Start -> Which program?`：流程从开始节点进入选择项目类型的判断节点。
- `Which program? -- Formal Internship --> Complete interns/approved_intern+template.md`：如果选择“Formal Internship”，流程进入完成实习生入职模板的节点。
- `Which program? -- Open Trainee --> Read trainee/README.md`：如果选择“Open Trainee”，流程进入阅读开放培训项目指南的节点。
- `Complete interns/approved_intern+template.md -> Follow interns/intern_checklist.md`：完成实习生入职模板后，需要遵循实习生检查清单。
- `Complete interns/approved_intern+template.md -> Use interns/pr_and_commit_guide.md`：完成实习生入职模板后，需要使用 PR 和提交指南。
- `Read trainee/README.md -> Follow trainee/CONTRIBUTING.md`：阅读开放培训项目指南后，需要遵循贡献指南。
- `Read trainee/README.md -> Pick a track in days/`：阅读开放培训项目指南后，需要在 `days/` 目录下选择一个学习方向。
- `Read trainee/README.md -> Build in trainee/projects/`：阅读开放培训项目指南后，需要在 `trainee/projects/` 目录下进行项目构建。

## 仓库语境与术语解释
- **Formal Internship**：MasterFabric 的正式实习项目，需要完成入职模板并遵循实习生检查清单。
- **Open Trainee (MasterFabric Academy)**：MasterFabric 的开放培训项目，是一个非营利性的开源教育计划。
- **interns/approved_intern+template.md**：正式实习生的入职模板，需要填写个人信息和 100 天目标。
- **trainee/README.md**：开放培训项目的起始指南，介绍了 MasterFabric Academy 的使命和学习方式。
- **days/**：包含多个学习方向的 Roadmap，例如 Flutter, Expo, DevOps, NestJS, Next.js, Git, AI Agents。
- **trainee/projects/**：包含一些示例项目，例如 FinderDev 和 Sub Serve，供开放培训学员参考和学习。
