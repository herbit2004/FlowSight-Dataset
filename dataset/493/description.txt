## Edges, Branches & Convergence
  `Start --> Check`: The model response is passed to the tool call check.
  `Check -- Yes --> Skip`: If the model response has tool calls, skip processing.
  `Check -- No --> Extract`: If the model response does not have tool calls, extract the JSON pattern.
  `Extract --> Match`: The extracted JSON pattern is passed to the JSON match check.
  `Match -- No --> Return`: If the JSON does not match, return None.
  `Match -- Yes --> Parse`: If the JSON matches, parse the tool name and arguments.
  `Parse --> Validate`: The parsed tool name and arguments are passed to the tool validation check.
  `Validate -- No --> Return`: If the tool is not valid, return None.
  `Validate -- Yes --> Convert`: If the tool is valid, convert it to an AIMessage.
  `Convert --> Replace`: The AIMessage is used to replace the last message.
  `Replace --> Log`: Log the success.

- **JSON Pattern**: A predefined structure that the tool call information is expected to adhere to, facilitating extraction and parsing.
- **AIMessage**: A structured message format used within the system to represent interactions with the AI model, including tool calls and their results.
