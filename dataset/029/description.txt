## Edges, Branches & Convergence
- `A --> B`: User input is passed to initialize the intelligent agent.
- `B --> C`: The intelligent agent initialization leads to the creation of a dedicated session directory.
- `C --> D`: The session directory creation leads to the LLM understanding the requirements and generating code.
- `D --> E`: The generated code is passed to the safe code executor for execution.
- `E --> F`: The safe code executor executes the code, and the result is checked for success.
- `F -- 失败 (Failure) --> G`: If the code execution fails, the process goes to error analysis and repair.
- `G --> D`: After error analysis and repair, the process loops back to the LLM to generate code again.
- `F -- 成功 (Success) --> H`: If the code execution is successful, the results are formatted and stored.
- `H --> I`: The formatted and stored results are checked to see if more analysis is needed.
- `I -- 是 (Yes) --> J`: If more analysis is needed, the process continues analysis based on the current results.
- `J --> D`: After further analysis, the process loops back to the LLM to generate code again.
- `I -- 否 (No) --> K`: If no more analysis is needed, all charts are collected.
- `K --> L`: The collected charts are used to generate the final analysis report.
- `L --> M`: The final analysis report is output in Markdown and Word formats.
- `M --> N`: The output of the reports signifies the completion of the analysis.

## Repository Context & Terminology
- **LLM (Large Language Model)**: A deep learning model trained on a massive dataset of text and code, capable of understanding and generating human-like text. In this context, it is used to interpret user requirements and generate code.
- **Safe Code Executor**: A secure environment or tool used to execute the generated code, preventing potential security vulnerabilities or malicious code from harming the system.
- **Markdown**: A lightweight markup language with plain text formatting syntax. It is often used for writing documentation, notes, and reports.
- **Word**: A word processing software developed by Microsoft. It is commonly used for creating and editing documents.
- **Session Directory**: A dedicated directory created for each user session to store temporary files, logs, and other data related to the session.
- **Intelligent Agent**: A software entity that can perceive its environment, make decisions, and take actions to achieve specific goals. In this context, it is responsible for handling the user's request and coordinating the various stages of the analysis process.
