## 图类型与用途
这是一个流程图/架构图，用于展示 FreeChat 平台中“Character”（角色/人物）的核心组成部分和配置关系。它描述了创建一个 AI 角色时涉及的各个方面，以及它们之间的依赖关系，用于指导用户如何配置和定制 AI 角色。

## 图的整体布局
图整体采用从上到下的布局。顶部是核心节点“Character”，下方是其相关的配置和功能模块，呈现一种树状结构。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可分为角色定义、知识配置、后端服务配置和提示工程四个阶段。

## 节点逐项说明
- **Character**：代表 AI 角色本身，是整个架构的核心。
- **Profile**：角色的个人资料，例如姓名、头像、简介等。
- **Knowledge/RAG**：角色的知识库或检索增强生成 (RAG) 设置，用于让角色拥有特定的知识背景。README 提到支持设置 RAG (Retrieval Augmented Generation) for characters。
- **Album**：角色的相册，可能用于存储与角色相关的图片或视觉内容。
- **Backend-1**：第一个后端服务，负责处理角色的对话逻辑和生成回复。
- **Backend-n...**：表示可以配置多个后端服务，用于支持更复杂的角色行为和对话策略。README 提到支持 configuring multiple backends for each character。
- **Message Window**：消息窗口设置，可能用于控制角色回复的格式、风格等。
- **Long Term Memory Settings**：长期记忆设置，用于让角色记住之前的对话内容和用户偏好。README 提到支持 long-term memory, preset memory for characters。
- **Quota Limit**：额度限制，用于控制角色使用的资源，例如 API 调用次数。README 提到支持 setting quota limits for characters。
- **Chat/Greeting Prompt Tasks**：聊天/问候提示任务，用于定义角色在不同场景下的行为和回复。
- **Album/TTS Tools**：相册/TTS 工具，可能用于角色生成图像内容或语音回复。README 提到支持 character voices。
- **Moderation Settings**：审核设置，用于过滤角色生成的不当内容（虚线框表示这是一个可选或辅助功能）。
- **Model & Parameters**：模型和参数，用于指定角色使用的 AI 模型和相关参数。
- **API Keys**：API 密钥，用于访问外部服务或模型。
- **Prompt Reference**：提示参考，用于定义角色使用的提示词模板和变量。
- **Template**：提示词模板，用于定义角色回复的结构和格式。
- **Variables**：变量，用于在提示词模板中插入动态内容。
- **Version**：版本，用于管理提示词模板的版本。
- **...**：省略号，表示提示参考可能包含更多未列出的配置项。

## 连线、分支与汇聚关系
- `Character -> Profile`：角色拥有个人资料。
- `Character -> Knowledge/RAG`：角色拥有知识库或 RAG 设置。
- `Character -> Album`：角色拥有相册。
- `Character -> Backend-1`：角色使用第一个后端服务。
- `Character -> Backend-n...`：角色可以使用多个后端服务。
- `Backend-1 -> Message Window`：后端服务配置消息窗口。
- `Backend-1 -> Long Term Memory Settings`：后端服务配置长期记忆。
- `Backend-1 -> Quota Limit`：后端服务配置额度限制。
- `Backend-1 -> Chat/Greeting Prompt Tasks`：后端服务配置聊天/问候提示任务。
- `Backend-1 -> Album/TTS Tools`：后端服务配置相册/TTS 工具。
- `Backend-1 -> Moderation Settings`：后端服务配置审核设置。
- `Chat/Greeting Prompt Tasks -> Model & Parameters`：提示任务指定模型和参数。
- `Chat/Greeting Prompt Tasks -> API Keys`：提示任务使用 API 密钥。
- `Chat/Greeting Prompt Tasks -> Prompt Reference`：提示任务引用提示参考。
- `Prompt Reference -> Template`：提示参考包含提示词模板。
- `Prompt Reference -> Variables`：提示参考包含变量。
- `Prompt Reference -> Version`：提示参考包含版本信息。

## 仓库语境与术语解释
- **Character**：在 FreeChat 平台中，Character 指的是 AI 角色，是平台的核心概念。
- **RAG (Retrieval Augmented Generation)**：检索增强生成，一种通过检索外部知识来增强生成模型效果的技术。
- **Backend**：后端服务，负责处理 AI 角色的对话逻辑和生成回复。一个角色可以配置多个后端。
- **Prompt**：提示词，用于引导 AI 模型生成特定内容的文本。
- **API Keys**：用于访问外部 AI 模型或服务的密钥。
- **Moderation**：审核，用于过滤 AI 角色生成的不当内容。
- **TTS (Text-to-Speech)**：文本转语音技术，用于让 AI 角色能够发出语音回复。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 FreeChat 平台中 AI 角色的核心组成部分和配置关系。一个角色 (Character) 包含 Profile、Knowledge/RAG、Album 等基本信息，并可配置多个 Backend 服务。Backend 服务进一步关联 Message Window、Long Term Memory、Quota Limit、Prompt Tasks 等设置，其中 Prompt Tasks 决定了 Model & Parameters 和 API Keys。整体结构呈现出“角色定义 -> 知识配置 -> 后端服务配置 -> 提示工程”的流程，其中 RAG 和 Prompt Tasks 是关键环节。
