## 图类型与用途
这是一个流程图，展示了 CIA Compliance Manager 项目中 Product Task Agent 如何驱动其他 Agent 之间的协作和数据流动。它概括了以产品任务为中心的自动化流程，涉及开发、测试、质量安全和文档等环节。

## 图的整体布局
图采用从上到下的布局。顶部是 Product Coordination 分组，包含流程的起点 Product Task Agent。下方是 Development Agents、Quality & Security 和 Documentation 三个分组，分别包含不同的 Agent 节点。

## 分组/子图/阶段说明
- **Product Coordination**：包含 `🎯 Product Task Agent`，负责接收和分配产品任务，是整个流程的起点。
- **Development Agents**：包含 `⚛️ TypeScript React Agent` 和 `🧪 Testing Agent`，负责前端代码开发和自动化测试。
- **Quality & Security**：包含 `🔍 Code Review Agent` 和 `🔐 Security Compliance Agent`，负责代码评审和安全合规检查。
- **Documentation**：包含 `📝 Documentation Agent`，负责生成或更新相关文档。

## 节点逐项说明
- **🎯 Product Task Agent**：产品任务代理，负责接收和分配产品任务。根据 `.github/agents/product-task-agent.md`，该 Agent 负责创建 GitHub issues，并将任务分配给其他 Agent，确保代码、UX、安全和 ISMS 维度上的质量。
- **⚛️ TypeScript React Agent**：TypeScript React 开发代理，负责根据产品任务进行前端代码的开发。根据 `.github/agents/typescript-react-agent.md`，该 Agent 专注于 React 和 TypeScript 开发，构建安全且类型安全的组件。
- **🧪 Testing Agent**：测试代理，负责对开发完成的代码进行自动化测试，确保代码质量。根据 `.github/agents/testing-agent.md`，该 Agent 使用 Vitest 和 Cypress 进行单元测试、集成测试和端到端测试。
- **🔍 Code Review Agent**：代码审查代理，负责对代码进行评审，确保代码符合规范和最佳实践。根据 `.github/agents/code-review-agent.md`，该 Agent 专注于代码质量、安全性和可维护性，并检查代码是否可重用。
- **🔐 Security Compliance Agent**：安全合规代理，负责检查代码和系统是否符合安全合规要求。根据 `.github/agents/security-compliance-agent.md`，该 Agent 专注于安全最佳实践和合规框架，例如 NIST 和 ISO 27001。
- **📝 Documentation Agent**：文档代理，负责根据产品任务和代码生成或更新相关文档。根据 `.github/agents/documentation-agent.md`，该 Agent 负责技术文档、API 文档和架构文档的编写。

## 连线、分支与汇聚关系
- `🎯 Product Task Agent -> ⚛️ TypeScript React Agent`：产品任务代理将任务分配给 TypeScript React 开发代理，启动前端开发。
- `🎯 Product Task Agent -> 🧪 Testing Agent`：产品任务代理将任务分配给测试代理，启动自动化测试。
- `🎯 Product Task Agent -> 🔍 Code Review Agent`：产品任务代理将任务分配给代码审查代理，启动代码评审。
- `🎯 Product Task Agent -> 🔐 Security Compliance Agent`：产品任务代理将任务分配给安全合规代理，启动安全合规检查。
- `🎯 Product Task Agent -> 📝 Documentation Agent`：产品任务代理将任务分配给文档代理，启动文档生成或更新。

## 仓库语境与术语解释
- **CIA Compliance Manager**：一个全面的应用程序，旨在帮助组织评估、实施和管理 CIA 三元组（保密性、完整性和可用性）的安全控制。
- **Agent**：在此上下文中，指 GitHub Copilot 自定义代理，每个代理专注于特定的领域（产品、开发、测试、文档或安全），以提供跨代码库的上下文感知帮助。
- **ISMS (Information Security Management System)**：信息安全管理体系，Hack23 AB 确保所有任务都符合其 ISMS 策略。
- **TypeScript React Agent**：一个专门负责 TypeScript 和 React 开发的 Agent，确保代码的类型安全和可重用性。
- **Testing Agent**：一个专门负责测试的 Agent，使用 Vitest 和 Cypress 等工具来确保代码质量。
- **Code Review Agent**：一个专门负责代码审查的 Agent，确保代码符合规范和最佳实践。
- **Security Compliance Agent**：一个专门负责安全合规的 Agent，确保代码和系统符合安全合规要求。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 CIA Compliance Manager 项目中以产品任务为中心的自动化流程。流程从 Product Task Agent 开始，该 Agent 将任务分配给 TypeScript React Agent、Testing Agent、Code Review Agent、Security Compliance Agent 和 Documentation Agent。这些 Agent 分别负责前端开发、自动化测试、代码评审、安全合规检查和文档生成。该流程旨在提高开发效率，确保代码质量和安全，并保持文档的及时更新，体现了一种以任务驱动的、自动化程度较高的软件开发流程。Product Task Agent 作为流程的起点和核心协调者，确保各个环节的协同工作。
