## Repository Context & Terminology
- **入口路由器 (Entry Router)**: The initial point of contact for all incoming requests, responsible for directing traffic to the appropriate handler based on the request's URL.
- **路径判断 (Path Judgement)**: The process of analyzing the URL path of an incoming request to determine the correct service or component to handle it.
- **/v1/models**: An API endpoint that provides a list of available models.
- **/v1/chat/completions**: An API endpoint for generating chat completions.
- **SSE (Server-Sent Events)**: A server push technology enabling real-time data streaming from the server to the client.
- **JSON (JavaScript Object Notation)**: A lightweight data-interchange format.
- **TransformStream**: A WHATWG Streams API that allows transforming data as it flows through a pipeline.
- **CONFIG 对象 (CONFIG Object)**: A centralized repository for configuration settings, potentially loaded from environment variables or configuration files.
