## 图类型与用途
这是一个流程图，描述了 Solana 复制交易机器人如何处理接收到的交易，并决定是否执行购买操作。该图展示了交易类型检测、关注列表判断、购买信号监控等关键步骤，旨在实现快速复制交易，尤其针对新发行的代币，如 PumpFun 或 PumpSwap 上的代币。

## 图的整体布局
图采用从上到下的布局。顶部是交易接收节点，中间是交易类型判断和关注决策阶段，底部是购买信号监控和执行购买阶段。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可分为三个阶段：交易接收与类型判断、关注决策、购买信号监控与执行。

## 节点逐项说明
- **A (Transaction Received)**：接收到的 Solana 交易，是整个流程的起点。
- **B (detect_transaction_type)**：检测交易类型，分析交易内容，判断其属于哪种类型。
- **C (Transaction Type?)**：交易类型判断节点，根据`detect_transaction_type`的结果，判断交易类型。
- **D (Migration Detected)**：检测到迁移交易，可能指代币合约的迁移。
- **E (Token Mint + Dev Buy Check)**：检测到代币发行和开发者购买。
- **F (Buy/Sell Transaction)**：检测到买入或卖出交易，通常指 PumpFun/PumpSwap 上的交易。
- **G (Skip Transaction)**：跳过交易，对于无法识别或不感兴趣的交易类型，直接跳过。
- **H (should_focus = true, focus_reason = Migration)**：标记为需要关注的交易，原因是检测到迁移。
- **I (Dev Buy >= Threshold?)**：开发者购买量是否超过阈值？判断开发者购买量是否足够大，以表明项目方有信心。
- **J (should_focus = true, focus_reason = DevBuyAboveThreshold)**：标记为需要关注的交易，原因是开发者购买量超过阈值。
- **K (should_focus = true, New token detected)**：标记为需要关注的交易，原因是检测到新的代币。
- **L (Already in Focus List?)**：是否已经在关注列表中？判断该代币是否已经被机器人关注。
- **M (should_focus = true, Continue monitoring)**：标记为需要关注的交易，并继续监控。
- **N (Large Buy >= Threshold?)**：大额购买量是否超过阈值？判断是否有大户买入，可能预示着价格上涨。
- **O (should_focus = true, focus_reason = DevBuyAboveThreshold)**：标记为需要关注的交易，原因是开发者购买量超过阈值（图中可见，但仓库上下文未进一步说明，可能是一个笔误，应该指的是大额购买）。
- **P (should_focus = false, Skip transaction)**：标记为不需要关注的交易，并跳过。
- **Q (handle_enhanced_transaction)**：处理增强型交易，对标记为需要关注的交易进行进一步处理。
- **R (should_focus = true?)**：是否应该关注？根据之前的判断，决定是否将该代币加入关注列表。
- **S (Add to FOCUS_TOKEN_LIST, Initialize price tracking)**：将代币添加到关注列表，并初始化价格跟踪。
- **U (Monitor for Buy Signals)**：监控购买信号。
- **V (Buy Signal Detected?)**：是否检测到购买信号？
- **W (Execute Buy: buy_amount_rising SOL)**：执行购买，购买量随着 SOL 价格上涨而增加。
- **X (Execute Buy: buy_amount_recovery SOL)**：执行购买，购买量随着 SOL 价格恢复而增加。
- **Y (Execute Buy: buy_amount_recovery SOL)**：执行购买，购买量随着 SOL 价格时间序列反转而增加。
- **Z (Continue Monitoring)**：继续监控。

## 连线、分支与汇聚关系
- `A -> B`：接收到交易后，进行交易类型检测。
- `B -> C`：交易类型检测后，进入交易类型判断。
- `C -- Migration --> D`：如果交易类型是迁移，则检测到迁移。
- `C -- TokenMint --> E`：如果交易类型是代币发行，则检测代币发行和开发者购买。
- `C -- PumpFun/PumpSwap Buy/Sell --> F`：如果交易类型是 PumpFun/PumpSwap 的买入/卖出，则进行买/卖交易处理。
- `C -- Unknown --> G`：如果交易类型未知，则跳过交易。
- `D -> H`：检测到迁移后，标记为需要关注的交易。
- `E -> I`：检测到代币发行后，判断开发者购买量是否超过阈值。
- `I -- Yes --> J`：如果开发者购买量超过阈值，则标记为需要关注的交易。
- `I -- No --> K`：如果开发者购买量未超过阈值，则标记为新的代币。
- `F -> L`：如果是 PumpFun/PumpSwap 的买/卖交易，则判断是否已经在关注列表中。
- `L -- Yes --> M`：如果已经在关注列表中，则继续监控。
- `L -- No --> N`：如果不在关注列表中，则判断大额购买量是否超过阈值。
- `N -- Yes --> O`：如果大额购买量超过阈值，则标记为需要关注的交易。
- `N -- No --> P`：如果大额购买量未超过阈值，则跳过交易。
- `H -> Q`：标记为需要关注的迁移交易，进入增强型交易处理。
- `J -> Q`：标记为需要关注的开发者购买交易，进入增强型交易处理。
- `K -> Q`：标记为需要关注的新代币交易，进入增强型交易处理。
- `M -> Q`：标记为需要继续监控的交易，进入增强型交易处理。
- `O -> Q`：标记为需要关注的大额购买交易，进入增强型交易处理。
- `Q -> R`：增强型交易处理后，判断是否应该关注。
- `R -- Yes --> S`：如果应该关注，则添加到关注列表，并初始化价格跟踪。
- `R -- No --> T`：如果不应该关注，则跳过处理。
- `S -> U`：添加到关注列表后，监控购买信号。
- `U -> V`：监控购买信号后，判断是否检测到购买信号。
- `V -- DramaticRise --> W`：如果检测到价格急剧上涨，则执行购买。
- `V -- DropStableRise --> X`：如果检测到价格下跌后稳定上涨，则执行购买。
- `V -- TimeSeriesReversal --> Y`：如果检测到价格时间序列反转，则执行购买。
- `V -- No Signal --> Z`：如果没有检测到购买信号，则继续监控。

## 仓库语境与术语解释
- **Solana Copy Trading Bot**：一个 Solana 链上的复制交易机器人，旨在复制其他交易者的交易策略，尤其是在新发行的代币上。
- **PumpFun/PumpSwap**：Solana 链上的去中心化交易所 (DEX)，通常用于新发行代币的交易。README 中提到已更新对 PumpFun 和 Pump Amm Swap 的指令，以适应最近的智能合约升级。
- **FOCUS_TOKEN_LIST**：机器人关注的代币列表，用于监控这些代币的交易活动和价格变化。
- **handle_enhanced_transaction**：一个处理增强型交易的函数或模块，用于对标记为需要关注的交易进行进一步分析和处理。
- **Jito**：一个交易确认服务，用于加速交易确认。README 中提到 "Racing Transaction Confirm" 功能，即同时向多个交易确认提供商（如 Jito, nextBlock, BloxRoute, Temporal）发送交易，并只确认最快的那个。`src/services/jito.rs` 文件中包含与 Jito 相关的代码。
- **Migration Detected**：检测到代币合约的迁移，这可能是一个需要关注的信号，因为迁移可能意味着新的机会或风险。
- **Dev Buy >= Threshold?**：开发者购买量是否超过阈值，用于判断项目方对项目的信心。
- **Buy Signal Detected?**：是否检测到购买信号，例如价格急剧上涨、价格下跌后稳定上涨、价格时间序列反转等。

## 可作为 QA Ground Truth 的高信息密度摘要
该流程图描述了 Solana 复制交易机器人处理交易的流程。从接收交易开始，机器人首先检测交易类型，然后根据交易类型、开发者购买量、是否已在关注列表、大额购买量等因素，决定是否将该代币加入关注列表。如果加入关注列表，则监控购买信号，并在检测到特定信号（如价格急剧上涨、价格下跌后稳定上涨、价格时间序列反转）时执行购买。该流程的关键环节包括交易类型检测、关注决策和购买信号监控，最终目的是实现对 PumpFun/PumpSwap 等 DEX 上新发行代币的快速复制交易。
