## Edges, Branches & Convergence
- `mic --> vad`: Audio input flows from the microphone to the voice activity detection module.
- `vad --> asr`: Voice activity detection output flows to the automatic speech recognition module.
- `cam --> vlm`: Video input flows from the camera to the video language model.
- `text --> llm`: Text input is fed into the LLM with priority.
- `tick --> llm`: Timer input provides autonomy signals to the LLM.
- `asr --> llm`: ASR output is fed into the LLM with priority.
- `vlm --> ctx`: Video language model output is written to the context.
- `Minds --> ctx`: Subagents write contextual information to the context.
- `ctx --> llm`: The LLM reads contextual information from the context.
- `llm --> tts`: The LLM generates text output, which is fed to the text-to-speech module.
- `tts --> speaker`: The text-to-speech module generates audio output, which is played through the speaker.
- `llm --> logs`: The LLM generates logs.
- `llm <--> tools`: The LLM interacts with external tools via the MCP (Model Control Protocol).
- `tools --> images`: Tools generate images.
- `tools --> motors`: Tools control animatronics.

## Repository Context & Terminology
- **VAD (Voice Activity Detection)**: A technique used to detect the presence or absence of human speech in an audio signal.
- **VLM (Video Language Model)**: A model that processes video input and extracts relevant information.
- **ASR (Automatic Speech Recognition)**: A technology that converts spoken audio into written text.
- **LLM (Large Language Model)**: A deep learning model trained on a massive dataset of text and code, capable of generating human-quality text, translating languages, and answering questions in an informative way.
- **TTS (Text-to-Speech)**: A technology that converts written text into spoken audio.
- **MCP (Model Control Protocol)**: A protocol for controlling and interacting with external tools.
- **Subagents**: Independent modules providing contextual information to the main agent.

## High-Density QA Ground Truth Summary
The system begins with various input sources: a microphone capturing audio, a camera capturing video, a text input field, and a timer. The audio from the microphone is processed by Voice Activity Detection (VAD) and then Automatic Speech Recognition (ASR) to convert it into text. The video from the camera is processed by a Video Language Model (VLM). The ASR output and direct text input are fed into the Large Language Model (LLM) with priority. The timer provides autonomy signals to the LLM. The VLM output and the outputs from various subagents (Sensors, Weather, Emotion, News, Memory) are written to a Context store. The LLM reads from this Context to inform its responses. The LLM then generates text, which is converted to speech by Text-to-Speech (TTS) and outputted through a speaker. The LLM also generates logs. The LLM interacts with external Tools via the Model Control Protocol (MCP), which in turn generates images and controls animatronics. The final outputs are audio through the speaker, logs, images, and animatronics actions. The LLM acts as the central processing unit, orchestrating the flow of information and generating appropriate responses based on the input and context.
