## Repository Context & Terminology
- **Convolutional Layer**: A layer in a CNN that performs convolution operations on the input data using a set of learnable filters.
- **ReLU (Rectified Linear Unit)**: An activation function that outputs the input directly if it is positive, otherwise, it outputs zero.
- **Max Pooling**: A pooling operation that selects the maximum value from each patch of the input data.
- **Global Pooling**: A pooling operation that reduces the spatial dimensions of the input data to a single value per channel.
- **Fully Connected Layer**: A layer in a neural network where each neuron is connected to all neurons in the previous layer.
- **Image Classification**: The task of assigning a label to an image based on its content.
