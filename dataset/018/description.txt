## 图类型与用途
这是一个流程图，描述了一个典型的卷积神经网络 (CNN) 的图像分类流程。它在仓库中的作用是展示如何将一张输入图像通过一系列的卷积、激活、池化和全连接层，最终得到分类结果。该图在`Deep learning/计算机视觉.md`中被引用，用于解释CNN的工作原理。

## 图的整体布局
图整体采用从上到下的布局。顶部是输入节点，底部是输出节点，中间是卷积、激活和池化等处理层。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为三个阶段：特征提取（卷积层和ReLU激活、最大池化），全局特征提取（全局池化），以及分类（全连接层）。

## 节点逐项说明
- **A[输入图像 224x224x3]**：网络的输入层，表示一张尺寸为 224x224 像素，具有 3 个颜色通道 (RGB) 的图像。
- **B[卷积层1]**：这是一个卷积层，用于提取输入图像的特征。卷积操作通过使用一组可学习的滤波器（或卷积核）在图像上滑动，并计算滤波器与图像局部区域的点积，从而生成特征图。
- **C[ReLU激活]**：ReLU (Rectified Linear Unit) 是一种常用的激活函数，它将负值置为零，保留正值。激活函数的作用是引入非线性，使得网络能够学习更复杂的模式。
- **D[最大池化]**：最大池化层用于降低特征图的空间维度，减少计算量，并提高网络的鲁棒性。它将特征图划分为若干个区域，并选择每个区域中的最大值作为输出。
- **E[卷积层2]**：这是第二个卷积层，进一步提取特征。
- **F[ReLU激活]**：再次使用 ReLU 激活函数。
- **G[全局池化]**：全局池化层将每个特征图缩减为一个单一的值，通常是特征图的平均值或最大值。这有助于减少参数数量，并使网络对输入图像的大小不敏感。
- **H[全连接层]**：全连接层将全局池化层的输出连接到每个类别，并使用 softmax 函数输出每个类别的概率。
- **I[分类输出]**：这是网络的输出层，表示图像属于每个类别的概率。

## 连线、分支与汇聚关系
- `A -> B`：输入图像进入第一个卷积层。
- `B -> C`：卷积层1的输出经过ReLU激活函数。
- `C -> D`：ReLU激活的输出经过最大池化层。
- `D -> E`：最大池化层的输出进入第二个卷积层。
- `E -> F`：卷积层2的输出经过ReLU激活函数。
- `F -> G`：ReLU激活的输出经过全局池化层。
- `G -> H`：全局池化层的输出进入全连接层。
- `H -> I`：全连接层的输出是最终的分类结果。

## 仓库语境与术语解释
- **CNN (Convolutional Neural Network)**：卷积神经网络，一种专门用于处理具有类似网格结构的数据（例如图像）的深度学习模型。
- **卷积层 (Convolutional Layer)**：使用卷积核对输入图像进行卷积操作，提取图像的局部特征。
- **ReLU (Rectified Linear Unit)**：一种常用的激活函数，用于引入非线性。
- **池化层 (Pooling Layer)**：用于降低特征图的空间维度，减少计算量，并提高网络的鲁棒性。
- **全连接层 (Fully Connected Layer)**：将前面各层的特征进行整合，输出最终的分类结果。
- **`Project/Phase2/dog_cat_classifier/train_dog_cat.py`**：该文件包含使用ResNet18模型进行猫狗图像分类的训练代码，展示了CNN在图像分类任务中的应用。
- **`Project/ai-image-search/models/resnet_model.py`**：该文件定义了一个ResNet50模型，用于提取图像特征，应用于图像搜索任务。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了一个典型的 CNN 图像分类流程，从输入图像开始，依次经过卷积层、ReLU 激活、最大池化、卷积层、ReLU 激活、全局池化和全连接层，最终输出分类结果。其中，卷积层和池化层用于提取图像的局部特征并降低维度，全连接层用于整合特征并进行分类。该流程在`Deep learning/计算机视觉.md`中被引用，用于解释CNN的工作原理，并且在`Project/Phase2/dog_cat_classifier/train_dog_cat.py`和`Project/ai-image-search/models/resnet_model.py`等文件中有所应用。
