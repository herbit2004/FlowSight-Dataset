## 图类型与用途
这是一个流程图，展示了 Cyber-AutoAgent 的整体架构和工作流程。它描述了用户输入如何驱动 Cyber-AutoAgent，以及它如何利用各种组件来实现其目标，并最终生成报告。该图在 README.md 中作为架构说明的一部分。

## 图的整体布局
图采用从左到右的布局。流程从用户输入开始，经过 Cyber-AutoAgent 的处理，最终生成报告和性能指标。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可分为以下阶段：
1.  **输入阶段**：接收用户输入的目标和目的。
2.  **核心处理阶段**：Cyber-AutoAgent 利用 AI 模型和代理工具执行任务。
3.  **存储与报告阶段**：存储证据并生成最终报告。
4.  **监控阶段**：通过可观测性组件监控性能。

## 节点逐项说明
- **A [User Input Target & Objective]**：流程的起点，代表用户提供的关于攻击目标和攻击目的的信息。
- **B [Cyber-AutoAgent]**：系统的核心组件，负责协调和控制其他组件，以实现用户指定的目标。根据 README，Cyber-AutoAgent 是一个主动安全评估工具，自主进行智能渗透测试。
- **C [AI Models Remote/Local]**：代表 Cyber-AutoAgent 使用的 AI 模型，可以部署在远程服务器或本地机器上。这些模型可能用于漏洞识别、攻击策略生成等任务。README 提到可以使用 AWS Bedrock, Litellm 或 local Ollama models。
- **D [Agent Tools shell, swarm, editor, etc.]**：代表 Cyber-AutoAgent 使用的各种工具，例如 shell 命令行工具、swarm 集群管理工具、文本编辑器等。这些工具用于执行实际的攻击和渗透测试任务。根据 `docs/architecture.md`，安全工具通过 shell 访问，而不是直接作为工具。
- **E [Evidence Storage Memory System]**：代表 Cyber-AutoAgent 用于存储攻击过程中收集到的证据和信息的系统。根据 `docs/memory.md`，该系统使用 Mem0，并支持多种后端配置，包括 Mem0 Platform、OpenSearch 和 FAISS。
- **O [Observability Langfuse + Ragas]**：代表用于监控和评估 Cyber-AutoAgent 性能的组件。Langfuse 和 Ragas 是两个可观测性工具，可能用于跟踪 agent 的行为、评估其性能指标等。根据 `docs/observability-evaluation.md`，Langfuse 用于 tracing，Ragas 用于评估指标。
- **F [Final Report AI Generated]**：代表 Cyber-AutoAgent 生成的最终报告，该报告总结了攻击的结果和发现。该报告由 AI 模型生成。
- **G [Performance Metrics]**：代表通过可观测性组件收集的性能指标，用于评估 Cyber-AutoAgent 的效率和效果。

## 连线、分支与汇聚关系
- `A -> B`：用户输入作为 Cyber-AutoAgent 的启动信号，提供了目标和目的。
- `B -> C`：Cyber-AutoAgent 利用 AI 模型来执行任务。
- `B -> D`：Cyber-AutoAgent 利用代理工具来执行任务。
- `B -> E`：Cyber-AutoAgent 将收集到的证据存储到证据存储系统。
- `B -> O`：Cyber-AutoAgent 的行为被可观测性组件监控。
- `C -> B`：AI 模型可以从 Cyber-AutoAgent 获取信息，并反过来影响 Cyber-AutoAgent 的行为。
- `D -> E`：代理工具将收集到的证据存储到证据存储系统。
- `E -> F`：证据存储系统将数据提供给最终报告生成器，生成最终报告。
- `O -> G`：可观测性组件生成性能指标。

## 仓库语境与术语解释
- **Cyber-AutoAgent**：一个自主的网络安全评估工具，使用 Strands 框架进行智能渗透测试。
- **AI Models**：用于漏洞识别、攻击策略生成等的 AI 模型，支持远程和本地部署，例如 AWS Bedrock, Litellm 或 local Ollama models。
- **Agent Tools**：用于执行实际攻击和渗透测试任务的工具，包括 shell、swarm 和 editor 等。
- **Evidence Storage Memory System**：用于存储攻击过程中收集到的证据和信息的系统，使用 Mem0，并支持多种后端配置。
- **Langfuse & Ragas**：用于监控和评估 Cyber-AutoAgent 性能的可观测性工具。Langfuse 用于 tracing，Ragas 用于评估指标。
- **Strands framework**: Cyber-AutoAgent 使用的核心框架，用于编排和管理 agent 的行为。
- **Mem0**: Cyber-AutoAgent 使用的内存系统，用于存储和检索证据。

## 可作为 QA Ground Truth 的高信息密度摘要
Cyber-AutoAgent 的流程从接收用户输入的目标和目的开始，然后 Cyber-AutoAgent 利用 AI 模型和代理工具执行攻击和渗透测试任务。在攻击过程中，它会收集证据并存储到证据存储系统中。AI 模型可以从 Cyber-AutoAgent 获取信息并影响其行为。可观测性组件（Langfuse + Ragas）监控 Cyber-AutoAgent 的行为并生成性能指标。最终，系统生成一份 AI 生成的报告，总结攻击结果和发现。该流程的关键组件包括 AI 模型、代理工具和证据存储系统，其中证据存储系统使用 Mem0 内存系统。
