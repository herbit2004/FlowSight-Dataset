## Repository Context & Terminology
- **FastAPI**: A modern, fast (high-performance), web framework for building APIs with Python 3.7+ based on standard Python type hints.
- **Middleware**: Functions that run before or after each request. They can modify the request or response, perform authentication, logging, etc.
- **Routing**: The process of determining which handler function should be called based on the incoming request's URL and HTTP method.
- **Dependency Injection**: A design pattern where dependencies are provided to a component instead of the component creating them itself. FastAPI has a built-in dependency injection system.
- **Pydantic**: A data validation and settings management library used by FastAPI for request and response validation.
- **OpenAPI**: A standard for describing APIs, used by FastAPI to automatically generate API documentation.
- **APIRouter**: A class in FastAPI used to create modular and reusable route definitions.
