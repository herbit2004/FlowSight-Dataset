## Repository Context & Terminology
- **Amazon EKS (Elastic Kubernetes Service)**: A managed Kubernetes service that makes it easy to run Kubernetes on AWS without needing to install, operate, and maintain your own Kubernetes control plane.
- **AWS Lambda**: A serverless compute service that lets you run code without provisioning or managing servers.
- **Amazon DynamoDB**: A fully managed NoSQL database service that provides fast and predictable performance with seamless scalability.
- **Amazon EventBridge**: A serverless event bus that makes it easy to connect applications together using data from your own applications, integrated Software-as-a-Service (SaaS) applications, and AWS services.
- **Amazon API Gateway**: A fully managed service that makes it easy for developers to create, publish, maintain, monitor, and secure APIs at any scale.
- **Amazon CloudWatch**: A monitoring and observability service that provides data and actionable insights to monitor your applications, respond to system-wide performance changes, and optimize resource utilization.
- **Amazon SNS (Simple Notification Service)**: A fully managed messaging service for both application-to-application (A2A) and application-to-person (A2P) communication.
- **Spring Boot**: An open-source Java-based framework used to create stand-alone, production-grade Spring-based Applications.
