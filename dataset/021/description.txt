## Repository Context & Terminology
- **kernel**: The core of the operating system, responsible for managing system resources and providing services to user-level applications.
- **userland**: The user space, where applications run, as opposed to the kernel space.
- **async**: Refers to asynchronous operations, which allow the system to perform multiple tasks concurrently without blocking.
- **lib**: A library, which is a collection of pre-written code that can be used by other programs.
- **drivers**: Software components that enable the operating system to interact with hardware devices.
- **aarch64**: A 64-bit ARM architecture.
- **sync**: Refers to synchronization mechanisms used to coordinate access to shared resources in a concurrent environment.
