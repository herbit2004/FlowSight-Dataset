The diagram outlines two primary modes: one using an API and another leveraging Claude AI for HTML generation. The diagram serves as a visual representation of the article creation and publishing process, highlighting the decision points and steps involved.

## Edges, Branches & Convergence
- `A --> B`: The user proceeds from writing the Markdown article to selecting the mode.
- `B --> C`: If the user selects the API mode, the workflow proceeds to calling the `md2wechat.cn` API.
- `B --> E`: If the user selects the AI mode, the workflow proceeds to using Claude AI to generate HTML.
- `C --> D`: The API call results in obtaining HTML.
- `E --> F`: Claude AI generated HTML is then refined.
- `D --> G`: The HTML generated by the API is previewed.
- `F --> G`: The refined HTML is previewed.
- `G --> H`: The user proceeds from previewing the HTML to deciding whether they are satisfied.
- `H -- 不满意 --> B`: If the user is not satisfied, the workflow returns to the mode selection step.
- `H -- 满意 --> I`: If the user is satisfied, the workflow proceeds to uploading images.
- `I --> J`: The images are uploaded.
- `J --> K`: The article is sent to the WeChat draft box, completing the process.
- Nodes D and F converge at node G.

## Repository Context & Terminology

- **Claude AI**: An AI assistant developed by Anthropic.
- **md2wechat.cn**: An external API for converting Markdown to WeChat-compatible HTML.
- **微信 (WeChat)**: A Chinese multi-purpose messaging, social media, and mobile payment app developed by Tencent.

## High-Density QA Ground Truth Summary
The workflow begins with writing an article in Markdown (Node A). The user then selects a mode (Node B): either API mode or AI mode. If API mode is chosen, the `md2wechat.cn` API is called (Node C) to generate HTML (Node D). If AI mode is selected, Claude AI generates HTML (Node E), which is then refined (Node F). The HTML from either path is then previewed (Node G). The user then decides whether they are satisfied with the preview (Node H). If not satisfied, the workflow loops back to mode selection (Node B). If satisfied, images are uploaded (Node I), and the article is sent to the WeChat draft box (Node J), completing the process (Node K). The `md2wechat.cn` API is used in the API mode to convert Markdown to HTML suitable for WeChat, while Claude AI is used as an alternative for HTML generation in the AI mode. The decision point at Node H determines whether the user iterates on the HTML generation and refinement or proceeds to the final publishing steps.
