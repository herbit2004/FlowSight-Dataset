## 图类型与用途
这是一个流程图，描述了 Agentic Coding Pipeline（代理式编码流水线）的架构和流程。该流水线旨在自动化软件开发任务，接收开发者任务，并最终输出可提交的补丁，是整个 Agentic-AI-Pipeline 项目的一部分，具体可参考 README 中关于 "Bonus: Agentic Coding Pipeline" 的描述。

## 图的整体布局
图整体采用从上到下的布局。顶部是输入节点，中间是核心流程节点，底部是各个代理和工具节点以及最终输出节点。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可以分成四个阶段：任务接收、代码生成、代码测试与审查、结果输出。

## 节点逐项说明
- **Developer Task**：流程的起点，代表需要完成的软件开发任务。
- **AgenticCodingPipeline**：整个流程的核心，负责协调和管理各个代理（Agent）的工作，并控制整个流水线的执行流程。
- **GPT Coding Agent**：使用 GPT 模型生成代码的编码代理。根据 `Agentic-Coding-Pipeline/agents/coding.py`，该 Agent 负责根据任务生成或改进 Python 代码。
- **Claude Coding Agent**：使用 Claude 模型生成代码的编码代理。
- **Ruff Formatter**：使用 Ruff 工具对生成的代码进行格式化，使其符合代码规范。根据 `Agentic-Coding-Pipeline/agents/formatting.py`，该 Agent 使用 Ruff 自动修复代码格式问题。
- **Claude Test Author + Pytest Runner**：使用 Claude 模型编写测试用例，并使用 Pytest 运行这些测试用例。根据 `Agentic-Coding-Pipeline/agents/testing.py`，该 Agent 负责生成 pytest 测试并运行。
- **Gemini QA Reviewer**：使用 Gemini 模型对生成的代码进行质量审查，判断代码是否通过质量标准。根据 `Agentic-Coding-Pipeline/agents/qa.py`，该 Agent 负责审查代码质量，判断是否通过。
- **Ready-to-commit Patch**：流程的终点，代表经过所有阶段处理后，可以提交的代码补丁。

## 连线、分支与汇聚关系
- `Developer Task -> AgenticCodingPipeline`：开发者提交的任务被送入代理式编码流水线。
- `AgenticCodingPipeline -> GPT Coding Agent`：流水线将任务分发给 GPT 编码代理，让其生成代码。
- `AgenticCodingPipeline -> Claude Coding Agent`：流水线将任务分发给 Claude 编码代理，让其生成代码。
- `GPT Coding Agent -> AgenticCodingPipeline`：编码代理将生成的代码返回给流水线，形成汇聚关系。
- `Claude Coding Agent -> AgenticCodingPipeline`：编码代理将生成的代码返回给流水线，形成汇聚关系。
- `AgenticCodingPipeline -> Ruff Formatter`：流水线将代码送入 Ruff 格式化器进行格式化。
- `Ruff Formatter -> AgenticCodingPipeline`：格式化后的代码返回给流水线。
- `AgenticCodingPipeline -> Claude Test Author + Pytest Runner`：流水线将代码送入测试编写器和运行器，进行测试。
- `Claude Test Author + Pytest Runner -> AgenticCodingPipeline`：测试结果返回给流水线。
- `AgenticCodingPipeline -> Gemini QA Reviewer`：流水线将代码送入 QA 审查器进行质量审查。
- `Gemini QA Reviewer -- PASS? --> AgenticCodingPipeline`：QA 审查器判断代码是否通过质量标准，如果通过，则返回给流水线。
- `AgenticCodingPipeline -> Ready-to-commit Patch`：如果代码通过了所有阶段的检查，流水线将输出可提交的补丁。
- `AgenticCodingPipeline -. feedback .-> GPT Coding Agent`：流水线将反馈信息发送给 GPT Coding Agent。
- `AgenticCodingPipeline -. feedback .-> Claude Coding Agent`：流水线将反馈信息发送给 Claude Coding Agent。

## 仓库语境与术语解释
- **Agentic Coding Pipeline**：一个自动化代码生成、格式化、测试和审查的流程，旨在减少人工干预，提高开发效率。
- **GPT Coding Agent**：使用 OpenAI 的 GPT 模型生成代码的代理。
- **Claude Coding Agent**：使用 Anthropic 的 Claude 模型生成代码的代理。
- **Ruff Formatter**：一个用于格式化 Python 代码的工具，可以自动修复代码风格问题。
- **Claude Test Author + Pytest Runner**：使用 Claude 模型生成测试用例，并使用 Pytest 运行这些测试用例的组合。
- **Gemini QA Reviewer**：使用 Google 的 Gemini 模型进行代码质量审查的代理。
- **MCP (Multi-LLM Pair Programming)**：根据 `Agentic-Coding-Pipeline/README.md`，该流水线使用多 LLM 进行结对编程，保持 GPT 和 Claude 编码器通过共享状态同步。
- **Iteration**：根据 `Agentic-Coding-Pipeline/pipeline.py`，流水线会进行多次迭代，直到代码通过所有质量检查或达到最大迭代次数。

## 可作为 QA Ground Truth 的高信息密度摘要
该图描述了一个 Agentic Coding Pipeline，从接收开发者任务开始，通过 GPT 和 Claude 编码代理并行生成代码，然后使用 Ruff 进行格式化，并使用 Claude Test Author + Pytest Runner 进行测试。接着，Gemini QA Reviewer 对代码进行质量审查，如果通过所有检查，则输出可提交的补丁。其中，AgenticCodingPipeline 负责协调各个代理，并根据测试和审查结果进行迭代，最终生成高质量的代码补丁。这个流水线集成了多种 LLM 和工具，旨在实现代码开发的自动化。
