## 图类型与用途
该图是一个流程图，描述了系统初始化和周期性密钥轮换的流程。它展示了密钥管理过程中涉及的各个步骤，包括密钥的生成、加密、存储和使用。该图有助于理解系统如何保障密钥的安全性和可用性。

## 图的整体布局
该图采用从上到下的布局。整体上分为两个主要阶段：系统初始化和周期性密钥轮换。流程从“启动服务”开始，最终到“通知各模块更新密钥”结束。

## 分组/子图/阶段说明
图中包含两个子图：
- **系统初始化**：描述了系统启动时密钥的加载和生成过程。
- **周期性密钥轮换**：描述了系统运行过程中定期更换密钥的流程。

## 节点逐项说明
- **启动服务**：系统启动的起始节点。
- **加载密钥库**：从存储介质中读取密钥库。
- **主密钥是否可用?**：判断主密钥是否存在的条件判断节点。
- **使用主密钥解密应用密钥**：使用主密钥解密应用密钥。
- **生成新主密钥**：生成新的主密钥。
- **加密应用密钥**：使用主密钥加密应用密钥。
- **持久化新主密钥和加密的应用密钥**：将新的主密钥和加密后的应用密钥保存到存储介质中。
- **应用启动完成**：应用成功启动的标志。
- **定时任务触发**：周期性密钥轮换的触发条件。
- **生成新的应用密钥**：生成新的应用密钥。
- **使用主密钥加密新应用密钥**：使用主密钥加密新的应用密钥。
- **更新密钥库中加密后的应用密钥**：将新的加密后的应用密钥更新到密钥库中。
- **通知各模块更新密钥**：通知系统中的各个模块使用新的密钥。

## 连线、分支与汇聚关系
- A -> B：启动服务后加载密钥库。
- B -> C：加载密钥库后判断主密钥是否可用。
- C -- 是 --> D：如果主密钥可用，则使用主密钥解密应用密钥。
- C -- 否 --> E：如果主密钥不可用，则生成新主密钥。
- E -> F：生成新主密钥后，加密应用密钥。
- F -> G：加密应用密钥后，持久化新主密钥和加密的应用密钥。
- G -> D：持久化密钥后，使用主密钥解密应用密钥。
- D -> H：解密应用密钥后，应用启动完成。
- H -- 定时任务触发 --> I：定时任务触发后，生成新的应用密钥。
- I -> J：生成新的应用密钥后，使用主密钥加密新应用密钥。
- J -> K：加密新的应用密钥后，更新密钥库中加密后的应用密钥。
- K -> L：更新密钥库后，通知各模块更新密钥。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **主密钥**：用于加密和解密应用密钥的密钥，通常由系统管理员管理。
- **应用密钥**：应用程序使用的密钥，用于加密和解密敏感数据。
- **密钥库**：用于存储密钥的安全容器，通常采用加密方式保护。
- **持久化**：将数据保存到持久性存储介质（如硬盘）的过程。
- **定时任务**：按照预定时间间隔自动执行的任务。
- **密钥轮换**：定期更换密钥以提高安全性的过程。

## 可作为 QA Ground Truth 的高信息密度摘要
系统启动时，首先启动服务并加载密钥库。然后判断主密钥是否可用，如果可用则使用主密钥解密应用密钥，否则生成新主密钥，加密应用密钥并持久化。之后使用主密钥解密应用密钥，应用启动完成。应用启动完成后，定时任务会触发密钥轮换，生成新的应用密钥，使用主密钥加密新应用密钥，更新密钥库中加密后的应用密钥，并通知各模块更新密钥。
