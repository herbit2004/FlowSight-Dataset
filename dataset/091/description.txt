## 图类型与用途
这是一个流程图，描述了 EstateWise 项目中，用户查询如何通过嵌入、向量搜索、图增强、合并去重等步骤，最终生成增强提示（Augmented Prompt）。该流程是混合检索增强生成（Hybrid RAG）架构的核心，旨在结合向量搜索和图数据库的优势，为 LLM 提供更丰富的信息，从而生成更准确、个性化的房产推荐，如 README 和 RAG_SYSTEM.md 所述。

## 图的整体布局
图采用从左到右的布局。起点是用户查询，经过一系列处理步骤，终点是增强提示。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为三个阶段：查询处理、数据检索与增强、提示生成。

## 节点逐项说明
- **Q[User Query]**：用户查询，代表用户输入的关于房产需求的自然语言查询。
- **E[Embed Query]**：嵌入查询，将用户查询转换为向量表示，以便在向量数据库中进行相似性搜索。
- **V[Pinecone Vector Search]**：Pinecone 向量搜索，使用嵌入后的查询向量在 Pinecone 向量数据库中进行相似性搜索，找到与查询最相关的房产向量。backend/src/pineconeClient.ts 文件定义了 Pinecone 客户端。
- **K[Top-K Results]**：Top-K 结果，从向量搜索中返回最相关的 K 个房产结果。
- **G[Neo4j Graph Enrichment]**：Neo4j 图增强，利用 Neo4j 图数据库，基于 Top-K 结果中的房产，查找与其相关的其他房产、社区信息、周边设施等，对结果进行丰富。backend/src/graph/neo4j.client.ts 文件定义了 Neo4j 客户端。
- **M[Merge + Dedupe]**：合并 + 去重，将向量搜索和图增强的结果合并，并去除重复的房产信息。agentic-ai/src/agents/DedupeRankingAgent.ts 文件实现了去重和排序逻辑。
- **LLM[Augmented Prompt]**：增强提示，将合并去重后的信息整合到提示词中，用于输入到大型语言模型 (LLM)，以便 LLM 生成最终的房产推荐。

## 连线、分支与汇聚关系
- `Q -> E`：用户查询被嵌入成向量表示。
- `E -> V`：嵌入后的查询向量被用于在 Pinecone 向量数据库中进行搜索。
- `V -> K`：向量搜索返回 Top-K 个最相关的结果。
- `K -> G`：这些结果被用于在 Neo4j 图数据库中进行图增强，获取更多相关信息。
- `G -> M`：向量搜索和图增强的结果被合并并去重。
- `M -> LLM`：最终，合并去重后的信息被用于构建增强提示，为后续的大型语言模型生成房产推荐提供输入。

## 仓库语境与术语解释
- **Hybrid RAG (Vector + Graph)**：如 README 和 RAG_SYSTEM.md 所述，EstateWise 采用混合检索增强生成架构，结合了向量数据库（Pinecone）和知识图谱（Neo4j）的优势。
- **Pinecone**：向量数据库，用于存储房产信息的向量表示，支持快速相似性搜索。backend/src/pineconeClient.ts 文件定义了 Pinecone 客户端。
- **Neo4j**：图数据库，用于存储房产之间的关联关系，如同一社区、同一邮编等。backend/src/graph/neo4j.client.ts 文件定义了 Neo4j 客户端。
- **Embeddings**：将文本或查询转换为向量表示的过程，用于在向量空间中进行相似性搜索。
- **Augmented Prompt**：增强提示，包含从向量搜索和图数据库检索到的相关信息，用于引导 LLM 生成更准确的房产推荐。
- **LLM (Large Language Model)**：大型语言模型，用于生成最终的房产推荐。
- **ZPID**：Zillow Property ID，房产在 Zillow 上的唯一标识符。agentic-ai/src/agents/DedupeRankingAgent.ts 文件中对 ZPID 进行了去重和排序。

## 可作为 QA Ground Truth 的高信息密度摘要
该图描述了 EstateWise 项目中的混合 RAG 流程，从用户查询开始，首先将查询嵌入成向量，然后在 Pinecone 向量数据库中进行搜索，获取 Top-K 结果。接着，利用 Neo4j 图数据库对结果进行图增强，合并去重后生成增强提示，最终输入到 LLM 中生成房产推荐。其中，Pinecone 向量搜索和 Neo4j 图增强是两个关键步骤，共同为 LLM 提供更全面、更准确的房产信息。agentic-ai/src/agents/DedupeRankingAgent.ts 文件实现了 ZPID 的去重和排序，backend/src/pineconeClient.ts 和 backend/src/graph/neo4j.client.ts 分别定义了 Pinecone 和 Neo4j 客户端。
