## Repository Context & Terminology
- **FastAPI**: A modern, fast (high-performance), web framework for building APIs with Python 3.7+ based on standard Python type hints.
- **Middleware**: Software that acts as a bridge between an operating system or database and applications, especially on a network.
- **LangChain**: A framework for developing applications powered by language models.
- **ContextVars**: A Python feature for managing context-local variables.
- **Event Bus**: A software pattern that allows components to communicate without direct dependencies.
- **Data Masking**: The process of obscuring specific data within a database table or cell to ensure that sensitive information is not exposed to unauthorized personnel.
- **Async I/O**: A programming paradigm that allows for non-blocking input/output operations.
- **Server-Sent Events (SSE)**: A server push technology enabling a server to automatically send data updates to a client's web browser.
- **Mermaid.js**: A JavaScript-based diagramming and charting tool that uses Markdown-inspired text definitions to create diagrams dynamically.
- **PanZoom**: A JavaScript library for adding pan and zoom functionality to web elements.
