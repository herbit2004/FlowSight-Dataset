## 图类型与用途
这是一个流程图/架构图，展示了 `MermaidTrace` 工具的内部架构和数据流。该工具通过装饰器、中间件和回调函数等方式，将 Python 代码的执行过程转化为 Mermaid 序列图，用于可视化代码逻辑。

## 图的整体布局
图整体采用从上到下的布局。顶部是用户集成层，中间是核心引擎和异步 I/O 层，底部是存储和可视化层。数据从用户集成层流向核心引擎，再经过异步 I/O 层写入存储，最后通过可视化层展示。

## 分组/子图/阶段说明
图中包含四个显式子图，分别代表不同的层级：
- **User Integration (用户集成)**：包含用户与代码交互的入口，如装饰器、中间件和回调函数。
- **Core Engine (核心引擎)**：包含处理追踪上下文、事件和数据脱敏的核心组件。
- **Async I/O Layer (异步 I/O 层)**：包含异步队列和文件处理器，用于非阻塞地处理追踪数据。
- **Visualization (可视化)**：包含文件监控器、服务器和浏览器，用于展示生成的 Mermaid 图。

## 节点逐项说明
- **@trace / @trace_class**：Python 装饰器，用于标记需要追踪的函数或类。根据 README，将此装饰器添加到代码入口点，可以生成完整的执行路径图。
- **FastAPI Middleware**：FastAPI 中间件，用于在 FastAPI 应用中追踪请求处理流程。根据 `src/mermaid_trace/integrations/fastapi.py`，该中间件拦截所有传入的 HTTP 请求，并自动提取追踪头。
- **LangChain Callback**：LangChain 回调函数，用于在 LangChain 应用中追踪 LLM 调用链。根据 `src/mermaid_trace/integrations/langchain.py`，该回调函数拦截 LangChain 事件，并将其记录为 FlowEvent。
- **ContextVars (Trace Context)**：使用 ContextVars 管理追踪上下文信息。根据 `src/mermaid_trace/core/context.py`，ContextVars 用于确保线程安全和异步环境下的上下文传播。
- **Event Bus (LogContext)**：事件总线，用于传递追踪事件和日志上下文。
- **Data Masking (Sanitizer)**：数据脱敏模块，用于保护敏感信息。根据 `src/mermaid_trace/core/sanitizer.py`，该模块自动对敏感字段进行数据脱敏。
- **Async Queue (Non-blocking)**：异步队列，用于非阻塞地处理追踪数据。根据 `src/mermaid_trace/handlers/async_handler.py`，该队列使用生产者-消费者模式，确保主应用程序线程不会因为 I/O 延迟而阻塞。
- **File Handler (Rotating/Timed)**：文件处理器，用于将追踪数据写入文件，支持轮转和定时。
- **(.mmd File)**：存储 Mermaid 格式流程图的文件。
- **Watchdog (File Monitor)**：文件监控器，用于监控 `.mmd` 文件的变化。
- **FastAPI Server (SSE Support)**：FastAPI 服务器，支持 Server-Sent Events (SSE) 推送。
- **Web Browser (Mermaid.js + PanZoom)**：Web 浏览器，使用 Mermaid.js 渲染流程图，并支持平移和缩放。

## 连线、分支与汇聚关系
- `Decorator --> Context`：装饰器将追踪信息传递给 Context。
- `Middleware --> Context`：中间件将追踪信息传递给 Context。
- `Callback --> Context`：回调函数将追踪信息传递给 Context。
- `Context --> EventBus`：Context 将追踪上下文信息传递给 EventBus。
- `EventBus --> Masker`：EventBus 将追踪事件传递给 Masker 进行数据脱敏。
- `Masker --> Queue`：Masker 将脱敏后的数据放入 Queue 中。
- `Queue --> Writer`：Queue 将数据传递给 Writer 写入 `.mmd` 文件。
- `Writer -.-> Storage`：Writer 将数据写入 Storage（.mmd 文件）。
- `Storage -.-> Watcher`：Watcher 监控 Storage（.mmd 文件）的变化。
- `Watcher --> Server`：Watcher 将文件变化通知给 Server。
- `Server == "SSE Push" ==> Browser`：Server 通过 SSE 将更新推送到 Browser。

## 仓库语境与术语解释
- **@trace / @trace_class**：根据 `src/mermaid_trace/core/decorators.py`，`@trace` 装饰器是用户的主要接口，用于拦截函数调用并捕获执行细节。
- **FastAPI Middleware**：根据 `src/mermaid_trace/integrations/fastapi.py`，该中间件用于在 FastAPI 应用中追踪 HTTP 请求，并自动提取追踪头。
- **LangChain Callback**：根据 `src/mermaid_trace/integrations/langchain.py`，该回调函数用于在 LangChain 应用中追踪 LLM 调用链，并将其记录为 FlowEvent。
- **ContextVars**：根据 `src/mermaid_trace/core/context.py`，ContextVars 用于管理全局上下文信息，确保线程安全和异步环境下的上下文传播。
- **EventBus**：图中可见，但仓库上下文未进一步说明。
- **Data Masking**：根据 README 和 `src/mermaid_trace/core/sanitizer.py`，该模块用于自动对敏感字段进行数据脱敏，保护数据隐私。
- **Async Queue**：根据 `src/mermaid_trace/handlers/async_handler.py`，该队列使用生产者-消费者模式，确保主应用程序线程不会因为 I/O 延迟而阻塞。
- **SSE (Server-Sent Events)**：一种服务器推送技术，允许服务器主动向客户端发送更新。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 `MermaidTrace` 工具的整体架构。用户通过 `@trace` 装饰器、FastAPI 中间件或 LangChain 回调函数集成追踪功能，这些入口将追踪信息传递给核心引擎的 ContextVars，再经过 EventBus 和 Data Masking 处理后，通过 Async Queue 和 File Handler 写入 `.mmd` 文件。最后，Watchdog 监控文件变化，FastAPI Server 通过 SSE 将更新推送到 Web Browser 进行可视化展示。其中，ContextVars 用于管理追踪上下文，Data Masking 用于保护敏感信息，Async Queue 用于非阻塞地处理追踪数据。
