## Repository Context & Terminology
- **ESP32**: A low-cost, low-power system on a chip (SoC) series with Wi-Fi and Bluetooth capabilities.
- **UDP**: User Datagram Protocol, a connectionless protocol used for transmitting data over IP networks.
- **JSON**: JavaScript Object Notation, a lightweight data-interchange format.
- **Nexmon**: A framework for reverse-engineering and modifying Broadcom Wi-Fi chips.
- **tcpdump**: A command-line packet analyzer.
- **pcap**: Packet capture file format.
- **Radiotap**: A header format for 802.11 frame injection and monitoring.
- **RSSI**: Received Signal Strength Indicator, a measure of the power of a received radio signal.
- **Open3D**: An open-source library for 3D data processing.
