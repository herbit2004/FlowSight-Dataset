## Diagram Type & Purpose
This is a flowchart diagram illustrating the process of creating a React root. It outlines the steps involved in initializing a React application, from the initial `createRoot` call to marking the container as the root. This diagram serves as a visual guide to understanding the internal workings of React's root creation process.

## Overall Layout
The diagram has a top-to-bottom (TD) layout. It starts with the `createRoot called` node and flows downwards through a series of steps, eventually leading to the `Mark Container as Root` node. The `Create FiberRoot` node branches into a subgraph detailing the FiberRoot creation process and a separate sequence of steps involving HostRoot Fiber creation and event delegation.

## Repository Context & Terminology
- **FiberRoot**: The root of the Fiber tree, which is a data structure used by React to represent the component tree.
- **HostRoot Fiber**: The Fiber node that represents the root of the rendered output (e.g., the DOM).
- **ReactDOMRoot**: The public root object returned from `ReactDOM.createRoot`.
- **Update Queue**: A queue that holds updates to be applied to the component.
- **Event Delegation**: A technique where event listeners are attached to a parent element instead of individual child elements.
