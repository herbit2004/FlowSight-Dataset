## Repository Context & Terminology
- **User Story**: A high-level, informal description of a software feature from the end-user perspective.
- **BDD (Behavior-Driven Development)**: A software development process that focuses on defining the expected behavior of the system in a human-readable format.
- **Gherkin**: A domain-specific language used to write BDD specifications.
- **Epic**: A large user story that is broken down into smaller, more manageable sub-issues.
- **Sub-Issue**: A smaller task that contributes to the completion of a larger epic.
- **Agent Orchestration**: The automated coordination and execution of tasks by software agents.
- **Pull Request**: A request to merge code changes from a branch into the main codebase.
