## Edges, Branches & Convergence
- `User Input --> Knowledge Gap Agent`: The user input is passed to the Knowledge Gap Agent.
- `Knowledge Gap Agent --> Tool Selector Agent`: The current gaps and objective are passed to the Tool Selector Agent.
- `Tool Selector Agent --> Tool Agents`: Tool queries are sent to the Tool Agents for parallel execution.
- `Tool Agents --> Observations Agent`: New findings are passed from the Tool Agents to the Observations Agent.
- `Observations Agent --> Writer Agent`: The Observations Agent sends its processed observations to the Writer Agent.
- `Observations Agent --> Knowledge Gap Agent`: Thoughts on findings and research strategy are fed back to the Knowledge Gap Agent, closing the research loop.
