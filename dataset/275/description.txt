## 图类型与用途
这是一个流程图，描述了 `IterativeResearcher` 的工作流程，该流程通过多智能体协同工作，迭代地进行深度研究，并最终生成包含参考文献的报告。该图在仓库中的作用是展示 `IterativeResearcher` 的核心流程。

## 图的整体布局
图整体采用从左到右的布局。流程从用户输入开始，经过一个循环迭代的研究过程，最终输出报告。

## 分组/子图/阶段说明
图中包含一个名为 "Deep Research Loop" 的子图，该子图代表了迭代研究的核心循环过程。

## 节点逐项说明
- **User Input**：用户输入，包括查询内容（query）、最大迭代次数（max\_iterations）、最大运行时间（max\_time）和输出指令（output\_instructions）。这是整个流程的起点，定义了研究的目标和约束。
- **Knowledge Gap Agent**：知识差距智能体，负责识别当前研究中的知识空白点，并根据用户输入的目标，制定下一步的研究目标。它接收来自观察智能体的反馈，并不断更新知识差距和研究目标。
- **Tool Selector Agent**：工具选择智能体，根据知识差距智能体提供的当前知识差距和目标，选择合适的工具来获取信息。
- **Tool Agents**：工具智能体，包含各种用于信息收集的工具，包括 Web Search、Crawler 和 Custom tools。这些工具并行运行，根据工具选择智能体生成的查询，从各种来源收集信息。
- **Observations Agent**：观察智能体，负责分析从工具智能体收集到的新发现，提取关键信息，并思考这些发现对研究策略的影响。它将思考结果和研究策略反馈给知识差距智能体。
- **Writer Agent**：写作智能体，负责根据整个研究过程的积累和最终的发现，撰写最终的报告，并包含参考文献。

## 连线、分支与汇聚关系
- `User Input -> Knowledge Gap Agent`：用户输入启动整个流程，并将信息传递给知识差距智能体。
- `Knowledge Gap Agent -> Tool Selector Agent`：知识差距智能体将当前知识差距和目标传递给工具选择智能体。
- `Tool Selector Agent -> Tool Agents`：工具选择智能体选择合适的工具，并生成工具查询，发送给工具智能体。
- `Tool Agents -> Observations Agent`：工具智能体收集信息，并将新发现发送给观察智能体。
- `Observations Agent -> Knowledge Gap Agent`：观察智能体分析新发现，并将思考结果和研究策略反馈给知识差距智能体，形成一个循环。
- `Observations Agent -> Writer Agent`：最终，观察智能体将信息传递给写作智能体。

## 仓库语境与术语解释
- **IterativeResearcher**: README 中提到，`IterativeResearcher` 运行一个连续的循环，对一个主题或子主题进行研究，并起草一份报告。
- **Knowledge Gap Agent**: 分析当前研究状态并识别知识差距。
- **Tool Agents**: 专门用于执行特定研究操作的智能体，可以扩展以添加自定义工具。README 中列举了 Web Search Agent 和 Website Crawler Agent。
- **Web Search**: README 中提到，默认使用 [Serper](https://www.serper.dev) 来运行 Google 搜索，需要设置 `SERPER_API_KEY` 环境变量。
- **Crawler**: 用于抓取网站信息。

## 可作为 QA Ground Truth 的高信息密度摘要
该图描述了 `IterativeResearcher` 的流程，从用户输入开始，知识差距智能体识别知识空白，工具选择智能体选择合适的工具，工具智能体收集信息，观察智能体分析信息并调整研究策略，最终由写作智能体生成报告。整个过程是一个闭环反馈系统，通过不断迭代，逐步深入地研究目标主题。其中，知识差距智能体、工具选择智能体和观察智能体是核心中间节点。
