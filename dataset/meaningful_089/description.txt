## 图类型与用途
该图是一个流程图，描述了用户在系统中进行签到和完成任务的流程。它展示了签到和任务两个模块的交互，以及用户如何通过签到和完成任务获得奖励。

## 图的整体布局
该图采用从上到下的布局。整体上分为“签到与任务系统”和“任务模块”两个子图，流程从用户触发签到或浏览任务列表开始，最终更新用户数据或提示签到成功。

## 分组/子图/阶段说明
图中包含两个子图：
- **签到与任务系统**：描述用户签到的完整流程，包括判断是否已签到、记录签到信息、判断是否满足连续签到条件、发放奖励、更新用户数据和签到日历。
- **任务模块**：描述用户浏览任务、领取任务、跟踪任务进度、完成任务并获得奖励的流程。

## 节点逐项说明
- **用户触发签到**：用户发起签到操作的入口。
- **今日是否已签到？**：判断用户今天是否已经签到。
- **中断：已签到**：如果用户已签到，则流程结束。
- **记录签到信息**：记录用户的签到信息。
- **是否满足连续签到条件？**：判断用户是否满足连续签到的条件。
- **发放连续签到奖励**：如果满足连续签到条件，则发放奖励。
- **无需发放奖励**：如果不满足连续签到条件，则不发放奖励。
- **更新用户数据**：更新用户的相关数据，例如签到次数、奖励等。
- **更新签到日历**：更新签到日历，显示用户的签到记录。
- **提示签到成功**：提示用户签到成功。
- **用户浏览任务列表**：用户查看可领取的任务列表。
- **是否有可领取任务？**：判断是否有可领取的任务。
- **展示可领取任务**：展示可供用户领取的任务。
- **展示已完成/不可领取任务**：展示用户已完成或不可领取的任务。
- **用户领取任务**：用户选择并领取任务。
- **记录任务领取信息**：记录用户领取的任务信息。
- **开始跟踪任务进度**：开始跟踪用户完成任务的进度。
- **任务完成？**：判断用户是否已完成任务。
- **发放任务奖励**：如果任务完成，则发放奖励。
- **继续跟踪任务进度**：如果任务未完成，则继续跟踪进度。

## 连线、分支与汇聚关系
- A -> B：用户触发签到后，进入是否已签到的判断。
- B -- 是 --> C：如果已签到，则中断流程。
- B -- 否 --> D：如果未签到，则记录签到信息。
- D -> E：记录签到信息后，进入是否满足连续签到条件的判断。
- E -- 是 --> F：如果满足连续签到条件，则发放连续签到奖励。
- E -- 否 --> G：如果不满足连续签到条件，则无需发放奖励。
- F -> H：发放连续签到奖励后，更新用户数据。
- G -> H：无需发放奖励后，更新用户数据。
- H -> I：更新用户数据后，更新签到日历。
- I -> J：更新签到日历后，提示签到成功。
- J -> K：签到成功后，用户可以浏览任务列表。
- K -> L：用户浏览任务列表后，进入是否有可领取任务的判断。
- L -- 是 --> M：如果有可领取任务，则展示可领取任务。
- L -- 否 --> N：如果没有可领取任务，则展示已完成/不可领取任务。
- M -> O：展示可领取任务后，用户可以领取任务。
- O -> P：用户领取任务后，记录任务领取信息。
- P -> Q：记录任务领取信息后，开始跟踪任务进度。
- Q -> R：开始跟踪任务进度后，进入任务是否完成的判断。
- R -- 是 --> S：如果任务完成，则发放任务奖励。
- R -- 否 --> T：如果任务未完成，则继续跟踪任务进度。
- S -> U：发放任务奖励后，更新用户数据。
- T -> Q：继续跟踪任务进度后，回到跟踪任务进度的步骤。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **签到**：用户每天登录系统进行的一种行为，通常可以获得奖励。
- **任务**：系统提供给用户完成的指定目标，完成任务后可以获得奖励。
- **连续签到**：用户连续多天进行签到。
- **奖励**：用户通过签到或完成任务获得的虚拟货币、道具或其他形式的激励。
- **用户数据**：用户的个人信息、签到记录、任务完成情况、奖励等数据的集合。
- **签到日历**：用于展示用户签到记录的日历。

## 可作为 QA Ground Truth 的高信息密度摘要
用户触发签到，系统判断是否已签到，若已签到则流程结束，否则记录签到信息，并判断是否满足连续签到条件，满足则发放连续签到奖励，否则无需发放奖励，最终更新用户数据和签到日历，并提示签到成功。签到成功后，用户可以浏览任务列表，系统判断是否有可领取任务，有则展示可领取任务，用户领取任务后，系统记录任务领取信息并开始跟踪任务进度，判断任务是否完成，完成则发放任务奖励，否则继续跟踪任务进度，最终更新用户数据。
