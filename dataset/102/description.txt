## Edges, Branches & Convergence
- `Directory Scanner --> Markdown Parser`: Scans the directory and passes the files to the Markdown Parser.
- `Markdown Parser --> Mermaid Extractor`: Parses the Markdown and passes it to the Mermaid Extractor.
- `Mermaid Extractor --> Syntax Validator`: Extracts Mermaid diagrams and passes them to the Syntax Validator.
- `Syntax Validator --> Valid?`: Passes the extracted Mermaid diagram to the validation check.
- `Valid? -- Yes --> Skip Block`: If the syntax is valid, skip the block.
- `Valid? -- No --> AI Fixer`: If the syntax is invalid, attempt to fix it with the AI Fixer.
- `AI Fixer --> Re-validate`: Passes the potentially fixed syntax to be re-validated.
- `Re-validate --> Fixed?`: Passes the re-validated syntax to the fixed check.
- `Fixed? -- Yes --> Update Content`: If the syntax is fixed, update the content.
- `Fixed? -- No --> Log Error`: If the syntax is not fixed, log an error.
- `Skip Block --> Next Block`: Proceeds to the next block after skipping.
- `Update Content --> Next Block`: Proceeds to the next block after updating the content.
- `Log Error --> Next Block`: Proceeds to the next block after logging an error.
- `Next Block --> More Blocks?`: Checks if there are more blocks to process.
- `More Blocks? -- Yes --> Syntax Validator`: If there are more blocks, loop back to the Syntax Validator.
- `More Blocks? -- No --> Save File`: If there are no more blocks, save the file.
- `Syntax Validator -- Yes --> Save File`: If the syntax is valid, save the file.
