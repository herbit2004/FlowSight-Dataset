## Repository Context & Terminology
- **rpm-ostree**: A hybrid image/package system. It combines the advantages of both image-based and package-based systems.
- **ostree**: A system for managing bootable, immutable, versioned file system trees.
- **bootc**: A tool for creating bootable container images.
- **libdnf**: The DNF (Dandified YUM) package management library.
- **libsolv**: A dependency solver library used by DNF.
- **librepo**: A library for downloading RPM repository metadata and packages.
- **librpm**: A library for installing and managing RPM packages.
