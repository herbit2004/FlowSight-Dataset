## Edges, Branches & Convergence
- `A --> B`: The user's search query is passed to the query enrichment stage.
- `B -- Add Synonyms --> C`: Synonyms are added to the query and passed to the semantic search engine.
- `B -- Correct Spelling --> C`: Spelling errors are corrected in the query and passed to the semantic search engine.
- `C --> D`: The semantic search engine returns a set of candidate products.
- `D --> E`: The candidate products are passed to the personalization filter.
- `E -- User History Match --> F`: If there is a match in user history, the ranker model is used.
- `E -- No History --> G`: If there is no user history, the popularity bias strategy is used.
- `F --> H`: The ranker model generates product recommendations.
- `G --> H`: The popularity bias strategy generates product recommendations.
- `F, G --> H`: Paths from the Ranker Model and Popularity Bias converge at the Product Recommendations node.
- `H --> I`: The product recommendations are displayed to the user.

## Repository Context & Terminology
- **User Search Query**: The text input provided by the user to initiate a product search.
- **Query Enrichment**: The process of improving the search query by adding synonyms, correcting spelling, and other techniques to broaden or refine the search.
- **Semantic Search Engine**: A search engine that understands the meaning and context of the search query to provide more relevant results.
- **Candidate Products**: A set of products that are initially considered as potential matches for the user's query.
- **Personalization Filter**: A process that filters and ranks candidate products based on user-specific data, such as past purchases, browsing history, and preferences.
- **Ranker Model**: A machine learning model that ranks products based on their relevance to the user and their likelihood of being purchased.
- **Popularity Bias**: A strategy that promotes popular or frequently purchased products, especially when user-specific data is limited.
- **Product Recommendations**: A curated list of products presented to the user, intended to be relevant and appealing based on their search query and profile.
