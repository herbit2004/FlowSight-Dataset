## Repository Context & Terminology
- **Box Node**: A fundamental element in the layout tree, representing a rectangular area on the screen.
- **Formatting Context**: A set of rules that govern the layout of a box and its descendants. Different formatting contexts (Block, Inline, Flex, Grid, Table, Multi-column) define different layout models.
- **Block Formatting Context (BFC)**: A formatting context where boxes are laid out one after another, vertically. Floats and margins are significant in BFC.
- **Inline Formatting Context (IFC)**: A formatting context where boxes are laid out horizontally. Line boxes are used to contain inline-level elements.
- **Flex Formatting Context**: A formatting context that uses the flexbox layout model for flexible and responsive layouts.
- **Grid Formatting Context**: A formatting context that uses the grid layout model for two-dimensional layouts.
- **Table Formatting Context**: A formatting context that uses the table layout model for tabular data.
- **Multi-column Context**: A formatting context that divides content into multiple columns.
