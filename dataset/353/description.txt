## Repository Context & Terminology
- **gltf**: GL Transmission Format, a standard file format for 3D scenes and models.
- **PBR (Physically Based Rendering)**: A rendering technique that simulates the interaction of light with surfaces in a physically plausible way.
- **Surface Shader**: A program that calculates the color of a surface based on its material properties, lighting conditions, and viewing angle.
- **Material**: A set of properties that define how a surface reflects and interacts with light.
- **Color3**: A data type representing a color with three components (red, green, blue).
