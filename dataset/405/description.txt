## Repository Context & Terminology
- **HDL (Hardware Description Language)**: A specialized computer language used to describe the structure and behavior of digital circuits and systems. Common examples include VHDL and Verilog.
- **Flip-Flop**: A basic building block of digital electronics, a flip-flop is a circuit that has two stable states and can store one bit of information.
- **BRAM (Block RAM) Tiles**: On-chip memory blocks available in Field-Programmable Gate Arrays (FPGAs). They provide fast and efficient data storage.
- **Register**: A storage location within a digital circuit used to hold data or instructions.
- **Pre-Fix**: Refers to the state of the HDL design before the application of a specific fix or optimization.
- **Post-Fix**: Refers to the state of the HDL design after the application of a specific fix or optimization.
