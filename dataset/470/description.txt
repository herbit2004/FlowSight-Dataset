## Repository Context & Terminology
- **GUARDRAIL**: A component that can be deployed in various ways (sidecar, gateway, embedded) to provide security and policy enforcement.
- **Sidecar**: A deployment pattern where a utility component (GUARDRAIL in this case) is deployed alongside the main application container in the same pod.
- **Control Plane**: A set of components (Policy Server, Identity Service, Audit Collector) that manage and control the behavior of the system.
- **MCP (Mesh Configuration Protocol)**: A protocol used for configuring and managing service meshes.
- **Client Pod**: A pod containing a client application and its associated sidecars.
- **Server Pod**: A pod containing a server application and its associated sidecars.

The Service Mesh Model leverages the sidecar pattern, where GUARDRAIL is deployed alongside application containers to intercept and manage traffic, enforcing policies defined in the Control Plane. The diagram highlights the flexibility of GUARDRAIL in adapting to different architectural needs, from a centralized gateway to distributed sidecars or direct embedding.
