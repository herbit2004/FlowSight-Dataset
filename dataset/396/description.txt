## 图类型与用途
这是一个架构图，展示了 MemCP 服务器与 Claude Code 以及其他组件之间的交互关系。它在仓库中的作用是说明 MemCP 如何为 Claude Code 提供持久化的外部记忆，从而避免上下文丢失，如 README 所述。

## 图的整体布局
图整体采用从上到下的布局。顶部是 Claude Code 和 Hooks，中间是 MemCP Server 和 Sub-Agents，底部是 Memory、MAGMA Graph、Search 和 Context Store 等组件。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可以分为三个阶段：与 Claude Code 的交互、MemCP Server 的核心处理、以及底层数据存储与子代理处理。

## 节点逐项说明
- **CC (Claude Code)**：指的是 Claude 的代码执行环境，是需要持久化记忆的主体。
- **S (MemCP Server/FastMCP)**：MemCP 服务器的核心组件，负责接收来自 Claude Code 和 Sub-Agents 的请求，并与 Memory、MAGMA Graph、Search 和 Context Store 进行交互。FastMCP 可能是指该服务器的一个快速版本或实现。`server.py` 定义了 MCP tool endpoints，如 `memcp_remember` 和 `memcp_recall`。
- **M (Memory/24 tools)**：MemCP 服务器的内存模块，包含 24 个工具，用于管理和操作存储在其中的信息。README 中列出了部分工具，如 `memcp_ping`、`memcp_remember`、`memcp_recall` 等。
- **G (MAGMA Graph/SQLite)**：一个基于 SQLite 数据库的图数据库，用于存储知识图谱，包含语义 (Semantic)、时间 (Temporal)、因果 (Causal) 和实体 (Entity) 四种类型的边。`graph.db` 文件存储知识图谱。
- **SR (Search/5 tiers)**：搜索模块，提供五种不同层级的搜索功能，用于在存储的知识中查找相关信息。README 中提到 5 层搜索包括 keyword, BM25, fuzzy, semantic, hybrid。
- **C (Context Store/Filesystem)**：上下文存储模块，使用文件系统存储上下文信息。
- **SA (Sub-Agents)**：子代理，用于辅助 MemCP 服务器进行分析、映射和合成等任务。
- **A1 (Analyzer)**：分析器，用于分析输入的信息。
- **A2 (Mapper x N)**：映射器，可能有多个实例 (N 个)，用于将输入的信息映射到知识图谱中。
- **A3 (Synthesizer)**：合成器，用于将从知识图谱中检索到的信息合成为 Claude Code 可以理解的形式。
- **H (Hooks)**：钩子，用于在 Claude Code 执行 `/compact` 操作之前和之后执行特定的操作。
- **E1 (Semantic)**：MAGMA Graph 的语义边类型。
- **E2 (Temporal)**：MAGMA Graph 的时间边类型。
- **E3 (Causal)**：MAGMA Graph 的因果边类型。
- **E4 (Entity)**：MAGMA Graph 的实体边类型。

## 连线、分支与汇聚关系
- `CC -> S`：Claude Code 通过 MCP 协议与 MemCP 服务器进行通信。
- `S -> M`：MemCP 服务器与 Memory 模块进行交互。
- `S -> G`：MemCP 服务器与 MAGMA Graph 模块进行交互。
- `S -> SR`：MemCP 服务器与 Search 模块进行交互。
- `S -> C`：MemCP 服务器与 Context Store 模块进行交互。
- `G -> E1`：MAGMA Graph 包含语义边。
- `G -> E2`：MAGMA Graph 包含时间边。
- `G -> E3`：MAGMA Graph 包含因果边。
- `G -> E4`：MAGMA Graph 包含实体边。
- `SA -> S`：Sub-Agents 通过 MCP 协议与 MemCP 服务器进行通信。
- `SA -> A1`：Sub-Agents 包含 Analyzer 组件。
- `SA -> A2`：Sub-Agents 包含 Mapper 组件。
- `SA -> A3`：Sub-Agents 包含 Synthesizer 组件。
- `H -> CC`：Hooks 在 Claude Code 执行 `/compact` 操作之前执行 PreCompact 操作，并在之后发送 Reminders。

## 仓库语境与术语解释
- **MemCP**：Persistent Memory MCP Server for Claude Code，旨在解决 Claude Code 在 `/compact` 操作后丢失上下文的问题。
- **MCP Protocol**：MemCP 使用的通信协议，`server.py` 定义了 MCP tool endpoints。
- **MAGMA Graph**：一个基于 SQLite 的知识图谱，用于存储和连接 insights，包含语义、时间、因果和实体四种类型的边。
- **Sub-Agents**：用于辅助 MemCP 服务器进行分析、映射和合成等任务的子代理，实现了 RLM Map-Reduce 架构。
- **Hooks**：用于在 Claude Code 执行 `/compact` 操作前后执行特定操作的机制，例如自动保存和提醒。
- **Context Store**：用于存储大型内容（如文件和对话历史）的模块，允许检查、切片和分块，而无需加载到 prompt 中。
- **RLM framework**：Recursive Language Model 框架，MemCP 实现了该框架，内容存储在磁盘上，Claude 决定加载哪些内容。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 MemCP 的架构，Claude Code 通过 MCP 协议与 MemCP Server 交互，MemCP Server 负责与 Memory、MAGMA Graph、Search 和 Context Store 等组件交互，实现数据的存储、检索和管理。Sub-Agents 辅助 MemCP Server 进行分析、映射和合成等任务。Hooks 用于在 Claude Code 执行 `/compact` 操作前后执行特定操作，保证上下文的持久化。MAGMA Graph 使用 SQLite 存储知识图谱，包含四种类型的边：语义、时间、因果和实体。该架构旨在为 Claude Code 提供持久化的外部记忆，解决上下文丢失的问题。`server.py` 定义了 MCP tool endpoints，`graph.db` 文件存储知识图谱。
