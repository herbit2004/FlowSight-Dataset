## High-Density QA Ground Truth Summary
The architecture begins with the Frontend UI built using React and TypeScript, which communicates with the Backend API via HTTP/WS. The Backend API, implemented in Go with GraphQL, then branches out to several key components. It sends SQL queries to the Vector Store (PostgreSQL + pgvector), events to the Task Queue for asynchronous processing, and telemetry data to OpenTelemetry. The Task Queue triggers the AI Agents, which then interacts with Security Tools via commands, queries the Vector Store for information, and accesses the Knowledge Graph via Graphiti. Graphiti stores graph data in Neo4j. OpenTelemetry routes metrics to VictoriaMetrics, traces to Jaeger, and logs to Loki, which are then queried by Grafana for monitoring. The Backend API also sends analytics data to Langfuse, which stores data in ClickHouse, caches data in Redis, and stores files in MinIO. The Vector Store (PostgreSQL + pgvector) serves as a central data repository for both the Backend API and AI Agents, enabling efficient data retrieval and processing.
