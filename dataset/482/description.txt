## 图类型与用途
这是一个流程图，描述了 GroqTales 平台如何从用户输入提示（Prompt）开始，经过后端处理、AI 生成，最终铸造为 NFT 的完整流程。它在仓库中用于展示整个平台架构和数据流，帮助理解各个组件之间的交互。

## 图的整体布局
图采用从上到下的布局。顶部是用户界面，中间是后端 API 和 AI 引擎，底部是数据存储和区块链相关组件。整体流程从用户界面开始，数据经过一系列处理后，最终到达区块链。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可以分为三个阶段：用户输入与请求处理、AI 故事生成、数据存储与 NFT 铸造。

## 节点逐项说明
- **User Interface - Next.js**：用户界面，使用 Next.js 构建。用户在此输入带有 70 多个参数的提示（Prompt），作为整个流程的起点。根据 `README.md` 和 `app/create/ai-story/page.tsx`，用户可以在此自定义故事的各个方面。
- **Backend API - Node.js**：后端 API，使用 Node.js 构建。它负责处理用户请求、与 Groq AI LPU Engine 交互、管理元数据、上传数据到 IPFS，以及触发 NFT 铸造。
- **Groq AI LPU Engine**：Groq 提供的 AI 推理引擎。它接收来自后端 API 的推理请求，并生成结构化的 JSON 故事。
- **Supabase PostgreSQL**：Supabase 提供的 PostgreSQL 数据库。用于存储故事的元数据，例如作者、标题、描述等。
- **Story/Image Data**：存储故事和图像数据的地方，使用 IPFS (InterPlanetary File System) 进行分布式存储。
- **Monad Testnet Blockchain**：Monad 测试网区块链。用于铸造和管理故事 NFT。
- **Smart Contracts - Solidity**：智能合约，使用 Solidity 编写。定义了 NFT 的逻辑和规则，例如所有权、交易等。

## 连线、分支与汇聚关系
- `A -> B`：用户通过用户界面 (A) 输入带有 70 多个参数的提示 (Prompt)，这些提示被发送到后端 API (B)。
- `B -> C`：后端 API (B) 将推理请求发送到 Groq AI LPU Engine (C)。
- `C -> B`：Groq AI LPU Engine (C) 生成结构化的 JSON 故事，并将其返回给后端 API (B)，形成汇聚关系。
- `B -> D`：后端 API (B) 将故事的元数据存储到 Supabase PostgreSQL 数据库 (D) 中。
- `B -> E`：后端 API (B) 将故事和图像数据上传到 IPFS (E) 进行存储。
- `A -> F`：用户通过用户界面 (A) 触发 NFT 铸造，这会与 Monad 测试网区块链 (F) 交互。
- `F --- G`：Monad 测试网区块链 (F) 使用智能合约 (G) 来管理 NFT 的铸造和所有权。

## 仓库语境与术语解释
- **Next.js**：一个 React 框架，用于构建用户界面。
- **Node.js**：一个 JavaScript 运行时环境，用于构建后端 API。
- **Groq AI LPU Engine**：一个 AI 推理引擎，用于生成故事内容。`README.md` 提到 Groq AI 用于生成沉浸式叙事或漫画风格的故事。
- **Supabase**：一个开源的 Firebase 替代品，提供 PostgreSQL 数据库服务。
- **IPFS (InterPlanetary File System)**：一个分布式存储系统，用于存储故事和图像数据。
- **Monad Blockchain**：一个区块链平台，用于铸造和管理故事 NFT。`README.md` 提到 GroqTales 允许用户在 Monad 区块链上铸造和交易 AI 生成的故事 NFT。
- **Solidity**：一种用于编写智能合约的编程语言。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 GroqTales 平台的核心流程：用户通过 Next.js 用户界面输入包含 70 多个参数的提示，后端 Node.js API 将请求发送到 Groq AI LPU Engine 生成结构化故事。故事元数据存储在 Supabase PostgreSQL 数据库中，故事和图像数据上传到 IPFS。用户可以通过用户界面在 Monad Testnet Blockchain 上铸造 NFT，由 Solidity 智能合约管理。整个流程的关键环节包括用户输入、AI 生成、数据存储和 NFT 铸造。
