## Repository Context & Terminology
- **GPT (Generative Pre-trained Transformer)**: A type of neural network architecture based on the Transformer model, pre-trained on a large corpus of text data and fine-tuned for specific tasks.
- **Tokenizer**: A process that converts raw text into a sequence of tokens, which are then used as input to the model.
- **Token Embedding**: A vector representation of each token in the vocabulary.
- **Position Embedding**: A vector representation of the position of each token in the sequence.
- **RMSNorm**: Root Mean Square Layer Normalization.
- **Multi-Head Attention**: A mechanism that allows the model to attend to different parts of the input sequence when computing the output.
- **MLP (Multilayer Perceptron)**: A feedforward neural network.
- **ReLU (Rectified Linear Unit)**: An activation function.
- **Adam Optimizer**: An optimization algorithm used to update the model parameters during training.
