## Repository Context & Terminology
- **feature/PT-xxx**: A branch dedicated to a specific feature or task, likely following a naming convention where "PT" could stand for "Project Task" and "xxx" is a unique identifier.
- **release/***: A branch created for the purpose of preparing and deploying a new release. The asterisk suggests a naming pattern, such as "release/1.2.3".
- **master**: The main branch of the repository, representing the stable, production-ready codebase.
- **Tag**: A specific point in the repository's history that is marked with a name, typically used to identify releases.
- **Testnet**: A test network that mirrors the main network but uses simulated or low-value assets, allowing developers to test changes without risking real funds or data.
- **Mainnet**: The primary, production-ready blockchain network where real transactions occur.
- **Semantic Versioning**: A versioning scheme that uses a three-part number (MAJOR.MINOR.PATCH) to indicate the type of changes included in a release.
