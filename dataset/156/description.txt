## Repository Context & Terminology
- **Terraform**: An infrastructure-as-code tool used to define and provision infrastructure.
- **AWS**: Amazon Web Services, a cloud computing platform.
- **Load Balancer**: Distributes incoming network traffic across multiple servers to ensure no single server is overwhelmed.
- **Listener**: Checks for connection requests from clients, using the protocol and port that you configure.
- **Target Group**: A group of targets (instances, IP addresses, Lambda functions) that receive traffic from a load balancer.
- **EC2 Instance**: A virtual server in AWS's Elastic Compute Cloud (EC2) for running applications.
- **Security Group**: A virtual firewall that controls the traffic allowed in and out of EC2 instances.
- **Subnet**: A range of IP addresses in a VPC that enables you to isolate different EC2 resources.
- **VPC**: A virtual private cloud, a logically isolated section of the AWS cloud where you can launch AWS resources in a defined virtual network.
- **S3 Bucket**: A storage service in AWS for storing objects.
- **S3 Bucket Policy**: A resource-based policy that grants specified AWS accounts or AWS services access to the bucket and the objects in it.
- **RDS**: Relational Database Service, a distributed relational database service by Amazon Web Services (AWS).
