## 连线、分支与汇聚关系
- `aws_lb.web --> aws_security_group.web`：负载均衡器与 Web 服务器安全组关联。
- `aws_lb.web --> aws_subnet.public`：负载均衡器部署在公共子网中。
- `aws_lb_listener.web --> aws_lb.web`：负载均衡器的监听器指向负载均衡器本身。
- `aws_lb_listener.web --> aws_lb_target_group.web`：负载均衡器的监听器指向负载均衡器的目标组。
- `aws_lb_target_group.web --> aws_vpc.main`：负载均衡器的目标组与 VPC 关联。
- `aws_lb_target_group_attachment.web --> aws_instance.web_server`：目标组附件与 Web 服务器实例关联。
- `aws_lb_target_group_attachment.web --> aws_lb_target_group.web`：目标组附件与目标组关联。
- `aws_s3_bucket_policy.logs_policy --> aws_s3_bucket.logs`：日志存储桶策略应用于日志存储桶。
- `aws_s3_bucket_policy.test_policy --> aws_s3_bucket.test`：测试存储桶策略应用于测试存储桶。
- `aws_security_group.db --> aws_security_group.web`：数据库安全组允许来自 Web 服务器安全组的流量。
- `aws_security_group.web --> aws_vpc.main`：Web 服务器安全组与 VPC 关联。
- `aws_subnet.private --> aws_vpc.main`：私有子网与 VPC 关联。
- `aws_subnet.public --> aws_vpc.main`：公共子网与 VPC 关联。

## 仓库语境与术语解释
- **Terraform**：一种基础设施即代码 (IaC) 工具，用于定义和配置基础设施。Terramaid 的目标是解析 Terraform 配置并生成可视化图表。
- **AWS**：Amazon Web Services，亚马逊提供的云计算服务。图中展示的资源均为 AWS 资源。
- **S3 Bucket**：AWS Simple Storage Service (S3) 提供的存储桶，用于存储对象。
- **Security Group**：AWS 提供的虚拟防火墙，用于控制进出 EC2 实例的流量。
- **VPC**：AWS Virtual Private Cloud，在 AWS 云中隔离出的私有网络。
- **Load Balancer (LB)**：AWS 负载均衡器，用于在多个 EC2 实例之间分配流量。
- **Terramaid**：一个实用程序，用于从 Terraform 配置创建 Mermaid 图表。根据 README，它可以增强文档，简化审查流程，并促进团队成员之间更好的协作。
