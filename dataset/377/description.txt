## 图类型与用途
这是一个架构图，展示了一个 AI 安全系统的四层架构，用于威胁检测和响应。它在仓库中的作用是展示系统的整体设计，从威胁数据摄取到自动化响应。

## 图的整体布局
图整体采用从上到下的布局。顶部是威胁面数据摄取层，中间是 AI 安全核心层和已部署的模型层，底部是自动化响应层。

## 分组/子图/阶段说明
图中包含四个子图，分别代表四个层级：
- **INGEST ("🌐 THREAT SURFACE — Layer 1")**：威胁面，第一层，负责收集各种潜在的威胁数据源。
- **CORE ("🤖 AI SECURITY CORE — Layer 2")**：AI 安全核心，第二层，负责处理和分析摄取的数据，提取特征并进行异常检测。
- **MODELS ("⚡ DEPLOYED MODELS — Layer 3")**：已部署的模型，第三层，基于 AI 安全核心的分析结果，提供具体的威胁检测功能。
- **RESPONSE ("✅ AUTOMATED RESPONSE — Layer 4")**：自动化响应，第四层，根据检测结果自动采取相应的安全措施。

## 节点逐项说明
- **A ("🔴 Network Traffic")**：网络流量数据，作为威胁数据源之一。
- **B ("📦 Code Repos")**：代码仓库数据，作为威胁数据源之一。
- **C ("🔗 URL Requests")**：URL 请求数据，作为威胁数据源之一。
- **D ("📋 System Logs")**：系统日志数据，作为威胁数据源之一。
- **E ("🧠 Deep Learning Engine")**：深度学习引擎，使用 LSTM、CNN、Transformers 等模型进行序列建模和时间模式识别。
- **F ("🔍 Anomaly Detection")**：异常检测模块，使用 Isolation Forest、AutoEncoder 等算法进行无监督的异常识别。
- **G ("📊 Feature Engineering")**：特征工程模块，使用 NLP、图分析等技术进行语义提取和降维。
- **H ("🛡️ Zero-Day Detector")**：零日漏洞检测器，准确率 98.2%，延迟小于 50ms。根据 README，该检测器使用深度神经网络检测实时网络流量中的新型威胁。
- **I ("🎣 Phishing Classifier")**：钓鱼分类器，用于 URL 和邮件的实时检测。
- **J ("📈 APT Detector")**：APT（高级持续性威胁）检测器，基于行为分析，正在积极开发中。
- **K ("🔐 Smart Contract Auditor")**：智能合约审计器，用于区块链安全。
- **L ("⚡ Real-Time Alerts")**：实时警报。
- **M ("📊 Threat Intelligence Reports")**：威胁情报报告。
- **N ("🔒 Auto Block & Quarantine")**：自动阻止和隔离。
- **O ("🧾 Audit Trail & Forensics")**：审计跟踪和取证。

## 连线、分支与汇聚关系
- `A -> CORE`：网络流量数据输入到 AI 安全核心层。
- `B -> CORE`：代码仓库数据输入到 AI 安全核心层。
- `C -> CORE`：URL 请求数据输入到 AI 安全核心层。
- `D -> CORE`：系统日志数据输入到 AI 安全核心层。
- `E <--> F`：深度学习引擎和异常检测模块之间存在相互反馈。
- `F <--> G`：异常检测模块和特征工程模块之间存在特征向量的交换。
- `G -> E`：特征工程模块将 enriched embeddings 输入到深度学习引擎。
- `CORE -> H`：AI 安全核心层的分析结果输入到零日漏洞检测器。
- `CORE -> I`：AI 安全核心层的分析结果输入到钓鱼分类器。
- `CORE -> J`：AI 安全核心层的分析结果输入到 APT 检测器。
- `CORE -> K`：AI 安全核心层的分析结果输入到智能合约审计器。
- `H -> L`：零日漏洞检测器的检测结果触发实时警报。
- `H -> M`：零日漏洞检测器的检测结果生成威胁情报报告。
- `H -> N`：零日漏洞检测器的检测结果触发自动阻止和隔离。
- `H -> O`：零日漏洞检测器的检测结果用于审计跟踪和取证。
- `I -> L`：钓鱼分类器的检测结果触发实时警报。
- `I -> M`：钓鱼分类器的检测结果生成威胁情报报告。
- `I -> N`：钓鱼分类器的检测结果触发自动阻止和隔离。
- `I -> O`：钓鱼分类器的检测结果用于审计跟踪和取证。
- `J -> L`：APT 检测器的检测结果触发实时警报。
- `J -> M`：APT 检测器的检测结果生成威胁情报报告。
- `J -> N`：APT 检测器的检测结果触发自动阻止和隔离。
- `J -> O`：APT 检测器的检测结果用于审计跟踪和取证。
- `K -> L`：智能合约审计器的检测结果触发实时警报。
- `K -> M`：智能合约审计器的检测结果生成威胁情报报告。
- `K -> N`：智能合约审计器的检测结果触发自动阻止和隔离。
- `K -> O`：智能合约审计器的检测结果用于审计跟踪和取证。
- `H, I, J, K -> L, M, N, O`：形成汇聚关系，多个检测器的结果都可能触发相同的响应措施。

## 仓库语境与术语解释
- **Zero-Day Detector**：根据 README，该项目旨在检测在防病毒软件签名编写之前的新型威胁。
- **LSTM, CNN, Transformers**：深度学习引擎中使用的模型，用于序列建模和时间模式识别。
- **Isolation Forest, AutoEncoder**：异常检测模块中使用的算法，用于无监督的异常识别。
- **NLP, Graph Analysis**：特征工程模块中使用的技术，用于语义提取和降维。
- **APT (Advanced Persistent Threat)**：高级持续性威胁，一种复杂的攻击类型。
- **MITRE ATT&CK**：如果代码中存在相关映射，则说明该系统可以自动进行威胁分类。
- **Auto firewall rule push**：根据 README 中 Zero-Day AI Threat Detector 项目的描述，检测到高置信度的威胁后可以自动推送防火墙规则。
