## High-Density QA Ground Truth Summary
The process begins with the user typing a prompt within the Claude Code environment, followed by pressing Enter to submit it. This action triggers the UserPromptSubmit hook, which then passes the prompt to the Vibe-log CLI. The CLI then checks if the prompt initiates a new chat. If it's not a new chat (No branch), the previous conversation context is included; otherwise (Yes branch), the prompt is analyzed standalone. Both paths converge at the Claude SDK, which analyzes the prompt quality, potentially influenced by personalities from the Infuse Coach such as "Gordon" (tough love), "Vibe-log" (encouraging), or a custom style. The SDK generates a score and suggestion, which are then saved to the `~/.vibe-log/analysis` file. The status bar displays the analysis result, including a score (e.g., 85/100) and feedback (e.g., "Gordon says: Add more context chef!"). This feedback loop aims to guide the user towards crafting better prompts, ultimately leading to improved results. The Claude Code SDK is central to this analysis, providing the tools to assess and enhance prompt quality based on contextual information and potentially infused coaching styles.
