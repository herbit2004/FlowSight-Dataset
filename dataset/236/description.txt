## Diagram Type & Purpose

It compares three distinct flows: one using ChatGPT/Claude, one using a local LLM setup, and one using Gemini. The diagram serves to visualize the number of LLM calls required by each approach and the steps involved.

## Overall Layout
The diagram is laid out from left to right (LR). It consists of three subgraphs, each representing a different workflow. Each subgraph starts with a "Video" node and ends with a "Done" node.

## Repository Context & Terminology
- **LLM (Large Language Model)**: A type of artificial intelligence model that uses deep learning techniques to understand and generate human language.
- **ChatGPT/Claude**: Specific LLMs provided by OpenAI and Anthropic, respectively.
- **Gemini**: An LLM provided by Google.
- **Frames**: Still images extracted from a video.
- **Cards**: Visual summaries or highlights generated from the video content.
- **Transcription**: The process of converting audio from the video into text.
