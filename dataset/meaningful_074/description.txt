## Diagram Type & Purpose
This is a flowchart diagram illustrating the process of invoice request and issuance. It depicts the steps involved from receiving an invoice request to delivering the invoice or rejecting the request. The diagram serves as a visual representation of the invoice processing workflow, aiding in understanding and potentially optimizing the process.

## Overall Layout
The diagram has a left-to-right (LR) primary direction. It starts with an "Incoming Invoice Request" node and branches into different paths depending on validation and approval outcomes, ultimately leading to either "Invoice Delivered" or "Notify Requestor: Request Rejected".

## Edges, Branches & Convergence
- `A --> B`: Incoming invoice request is passed for validation.
- `B -- Valid --> C`: If the request is valid, a draft invoice is created.
- `B -- Invalid --> I`: If the request is invalid, the request is rejected.
- `C --> D`: The draft invoice is checked to see if approval is required.
- `D -- Yes --> E`: If approval is required, the approval workflow is initiated.
- `D -- No --> H`: If approval is not required, the invoice is finalized.
- `E --> F`: An approval task is assigned.
- `F --> G`: The approval task is checked to see if it is approved.
- `G -- Yes --> H`: If the invoice is approved, the invoice is finalized.
- `G -- No --> I`: If the invoice is not approved, the request is rejected.
- `H --> J`: The finalized invoice is used to generate an invoice document.
- `J --> K`: The invoice document is sent to the customer.
- `K --> L`: The invoice is delivered.
- `I --> M`: The requestor is notified that the request is rejected.
- Paths converge at node H (Finalize Invoice) from both the "Approval Required? -- No" branch and the "Approved? -- Yes" branch.

## Repository Context & Terminology
- **Invoice Request**: A formal request for payment for goods or services provided.
- **Validation**: The process of ensuring that the invoice request contains all the necessary and correct information.
- **Draft Invoice**: A preliminary version of the invoice, subject to review and approval.
- **Approval Workflow**: A structured process for obtaining authorization for the invoice.
- **Finalize Invoice**: The process of completing the invoice and making it ready for delivery.
- **Invoice Document**: The final, official document that is sent to the customer.
- **Requestor**: The person or entity that submitted the invoice request.
