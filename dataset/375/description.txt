## Edges, Branches & Convergence
- `A --> B`: User request is sent to the FastAPI server.
- `M --> B`: Web UI request is sent to the FastAPI server.
- `N --> B`: ComfyUI request is sent to the FastAPI server.
- `O --> B`: SD WebUI request is sent to the FastAPI server.
- `B --> C`: FastAPI server initiates authentication verification.
- `C -- 通过 (Pass) --> D`: If authentication passes, the request is routed.
- `C -- 失败 (Fail) --> E`: If authentication fails, a 401 error is returned.
- `D --> F`: Request is dispatched to the VisualGPT provider.
- `F --> G`: VisualGPT provider uses the Cloudscraper module.
- `F --> I`: VisualGPT provider uses the OSS uploader.
- `G --> H`: Cloudscraper module interacts with the VisualGPT official API.
- `I --> J`: OSS uploader uploads data to Alibaba Cloud OSS.
- `H --> K`: VisualGPT official API provides the processed result.
- `J --> K`: Alibaba Cloud OSS provides data to the processed result.
- `H, J --> K`: The outputs of the VisualGPT API and Alibaba Cloud OSS converge at the "Processed Result" node.
- `K --> L`: Processed result is returned to the user.
