## Repository Context & Terminology
- **CloudFront CDN**: A content delivery network (CDN) service from AWS that caches content at edge locations to reduce latency for users.
- **Application Load Balancer (ALB)**: An AWS load balancer that distributes incoming application traffic across multiple targets, such as EC2 instances, in multiple Availability Zones. It operates at the application layer (Layer 7).
- **API Service, User Service, Order Service**: These represent microservices within the application, each responsible for a specific domain.
- **ElastiCache Redis**: A fully managed, in-memory data store service from AWS, used for caching frequently accessed data to improve application performance.
- **RDS PostgreSQL**: A fully managed relational database service from AWS, using the PostgreSQL database engine.
- **SQS Event Queue**: A fully managed message queuing service from AWS, used for decoupling services and enabling asynchronous communication.
- **/api/*, /users/*, /orders/***: These URL paths are used by the Application Load Balancer to route requests to the appropriate service.

## High-Density QA Ground Truth Summary
The diagram illustrates a tiered application architecture, starting with the CloudFront CDN (Tier 0) which delivers content and routes HTTPS requests to the Application Load Balancer (ALB) in Tier 1. The ALB then routes requests based on their URL path: `/api/*` to the API Service, `/users/*` to the User Service, and `/orders/*` to the Order Service, all within Tier 2. The API Service interacts with both the RDS PostgreSQL database and the ElastiCache Redis instance in Tier 3. The User and Order Services also interact with the RDS PostgreSQL database. The Order Service publishes events to the SQS Event Queue, while the API Service consumes events from it. The RDS PostgreSQL database and ElastiCache Redis instance serve as the data storage and caching layers, respectively. The SQS Event Queue facilitates asynchronous communication between the API and Order services, enabling event-driven architecture. The ALB's path-based routing is a key element, directing traffic to the appropriate microservice based on the request's URL.
