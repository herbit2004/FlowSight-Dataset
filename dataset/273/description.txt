## Repository Context & Terminology
- **SvelteKit**: A full-stack web framework based on Svelte.
- **FastAPI**: A modern, high-performance web framework for building APIs with Python.
- **Redis**: An in-memory data structure store, used as a database, cache, and message broker.
- **Celery**: An asynchronous task queue or distributed task queue.
- **FFmpeg**: A free and open-source software project consisting of a large suite of libraries and programs for handling video, audio, and other multimedia files and streams.
- **NVENC**: NVIDIA Encoder, a hardware-accelerated video encoding API and SDK.
- **Pub/Sub**: Publish-subscribe pattern, a messaging pattern where senders of messages, called publishers, do not program the messages to be sent directly to specific receivers, called subscribers, but instead categorize published messages into classes without knowledge of which subscribers, if any, there may be.
