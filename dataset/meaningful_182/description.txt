## Repository Context & Terminology
- **Referral Code**: A unique code assigned to a user that can be shared with others to invite them to join the platform.
- **Referral Link**: A unique URL assigned to a user that can be shared with others to invite them to join the platform.
- **Referral Attribution**: The process of identifying and tracking which referrer is responsible for a new user signup.
- **Engagement Campaign**: A marketing campaign designed to increase user engagement with the platform.
- **A/B Testing**: A method of comparing two versions of a marketing campaign to determine which one performs better.
- **Personalized Email**: An email that is tailored to the individual recipient.
- **Push Notification**: A message that is sent to a user's mobile device.

## High-Density QA Ground Truth Summary
The user referral and growth system begins with a 'New User Signup', followed by an 'Eligibility Check'. If the user is eligible, a 'Referral Code' is generated and stored. If not eligible, a 'Standard Welcome' is shown, which later triggers an engagement campaign. The referral code is then displayed as a link, and when a 'Referral Link' is shared and clicked, the system tracks 'Referral Attribution'. A key branch occurs: if the clicking user is an 'Existing User', a specific referral reward is applied; otherwise, a 'New User Signup - Referred' process begins, attributing the referral to the referrer and applying a new user referral reward. Both reward paths, along with a 'No Attribution' path (if the referral link is not clicked), converge at 'Update Referral Stats'. This triggers an 'Engagement Campaign', which undergoes 'A/B Test Variant' testing, branching into 'Send Personalized Email' or 'Push Notification'. Engagement is monitored for both email and push notifications, and the results feed into 'Analyze Campaign Performance'. Finally, the system concludes by 'Adjusting Targeting/Messaging' based on the analyzed campaign performance, optimizing the user acquisition and retention strategy. The referral code and link are crucial components for tracking and rewarding successful referrals, driving growth within the platform.
