## Edges, Branches & Convergence
- `A --> B`: Data flows from data intake to schema validation.
- `B -- Valid Schema --> C`: If the schema is valid, the data is routed based on its source type.
- `C -- Type A: Raw Log --> D`: Raw logs of type A are sent to the log parser.
- `C -- Type B: Sensor Data --> E`: Sensor data of type B is sent to the sensor normalizer.
- `D --> F`: Parsed logs are sent for Geo-IP lookup.
- `E --> F`: Normalized sensor data is sent for Geo-IP lookup.
- `F --> G`: Data with Geo-IP information is sent for customer profile enrichment.
- `G --> H`: Enriched data is evaluated for aggregation needs.
- `H -- Yes --> I`: If aggregation is needed, the data is aggregated into sessions.
- `H -- No --> J`: If aggregation is not needed, the data is written to the enriched data sink.
- `I --> J`: Aggregated data is written to the enriched data sink.
- `J --> K`: Data in the enriched data sink is evaluated for publishing to the data lake.
- `K -- Yes --> L`: If publishing to the data lake is needed, the data is published.
- `K -- No --> M`: If publishing to the data lake is not needed, the pipeline ends successfully.
- `L --> M`: Data published to the data lake results in successful pipeline completion.
- `B -- Invalid Schema --> N`: If the schema is invalid, the pipeline fails with a schema error.
- `C -- Unknown Source --> O`: If the data source is unknown, the pipeline fails with an unsupported source error.
- `N --> P`: Schema errors trigger error reporting.
- `O --> P`: Unsupported source errors trigger error reporting.
- `P --> M`: Error reporting leads to the end of the pipeline.

## Repository Context & Terminology
- **Data Intake**: The process of receiving and ingesting raw data into the pipeline.
- **Schema Validation**: The process of verifying that the incoming data conforms to a predefined schema.
- **Routing Logic**: The logic used to determine the appropriate processing path for data based on its source type.
- **Log Parser**: A component that parses raw log data into a structured format.
- **Sensor Normalizer**: A component that normalizes sensor data to a consistent scale or format.
- **Geo-IP Lookup**: A process of determining the geographical location of an IP address.
- **Customer Profile Enrichment**: The process of adding customer profile information to the data.
- **Data Lake**: A centralized repository for storing large volumes of structured and unstructured data.
