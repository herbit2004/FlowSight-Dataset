## 图类型与用途
这是一个架构图，描述了 Sehat Saathi 项目的前端和后端技术栈及其依赖关系。该图在 README.md 中，用于展示项目的系统设计和技术架构概览。

## 图的整体布局
图整体采用从左到右的布局，分为前端和后端两大部分。前端和后端分别位于图的左右两侧，各自依赖的技术栈位于中间层，最终都汇聚到用户界面和 API 服务器。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可分为前端、后端、用户界面和 API 服务器四个阶段。

## 节点逐项说明
- **Frontend**：代表整个前端部分，是前端技术栈的起点。
- **React**：一个流行的 JavaScript 库，用于构建用户界面。该项目使用 React 构建 UI/UX Layer，如 README.md 所示。
- **TypeScript**：一种 JavaScript 的超集，增加了静态类型检查。
- **Vite**：一个快速的前端构建工具。该项目使用 Vite 进行 Optimized Bundling，如 README.md 所示。
- **Tailwind CSS**：一个实用至上的 CSS 框架。
- **Shadcn/ui**：一个基于 Radix UI 和 Tailwind CSS 的可重用组件库。
- **Lucide React**：一组美观的开源图标。
- **TanStack Query**：一个强大的数据获取、缓存和状态管理库。
- **React Router**：React 的标准路由库。
- **Leaflet**：一个用于交互式地图的 JavaScript 库。
- **Recharts**：一个基于 React 的可组合图表库。
- **Backend**：代表整个后端部分，是后端技术栈的起点。
- **Node.js**：一个基于 Chrome V8 引擎的 JavaScript 运行时环境。
- **Express**：一个流行的 Node.js Web 应用框架。
- **MongoDB**：一个 NoSQL 数据库。
- **Socket.io**：一个用于实时、双向通信的库。
- **JWT**：一种用于安全地传输信息的标准。
- **User Interface**：代表最终呈现给用户的界面。
- **API Server**：代表后端提供的 API 服务。

## 仓库语境与术语解释
- **Frontend**：前端代码主要位于 `src/` 目录下，使用 React 和 TypeScript 构建。
- **Backend**：后端代码位于 `sehat-sakshi-backend/src/` 目录下，使用 Node.js 和 Express 构建。
- **React**：一个用于构建用户界面的 JavaScript 库，在 `package.json` 中被列为依赖项。
- **Vite**：一个前端构建工具，用于快速打包和构建前端代码，相关配置位于 `vite.config.ts`。
- **Tailwind CSS**：一个 CSS 框架，用于快速构建美观的用户界面，相关配置位于 `tailwind.config.ts`。
- **MongoDB**：一个 NoSQL 数据库，用于存储后端数据。
- **API Server**：后端提供的 API 服务，用于与前端进行数据交互。
- **User Interface**：最终呈现给用户的界面，由前端的各种库和框架共同构建。

## 可作为 QA Ground Truth 的高信息密度摘要
该架构图展示了 Sehat Saathi 项目的前端和后端技术栈。前端使用 React、TypeScript、Vite、Tailwind CSS 等技术构建用户界面，后端使用 Node.js、Express、MongoDB 等技术提供 API 服务。前端的各种库和框架最终都服务于用户界面的呈现，而后端的各种技术则用于构建和维护 API 服务器。该图体现了前端和后端之间的依赖关系，以及它们如何共同构建整个应用。前端从 Frontend 节点出发，后端从 Backend 节点出发，最终分别汇聚到 User Interface 和 API Server 节点。
