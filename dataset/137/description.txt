## 仓库语境与术语解释
- **godepgraph**：一个用于生成 Go 包依赖关系图的程序。
- **Go 标准库**：Go 语言自带的一系列常用包，例如 `flag`、`fmt`、`os` 等。
- **$GOROOT**：Go 语言的安装目录，标准库位于该目录下。
- **Mermaid**：一种使用文本描述图表的语法，用于生成流程图、时序图等。`godepgraph` 支持以 Mermaid 格式输出依赖关系图，如 README 所示。
- **flag -nostdlib**：`godepgraph` 的一个命令行参数，用于忽略 Go 标准库的依赖。
- **go/build**: Go 语言提供的用于构建 Go 包的工具集合。
