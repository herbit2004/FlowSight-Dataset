## Diagram Type & Purpose
This is a flowchart diagram illustrating a security scanning process. It outlines the steps involved in scanning user requests, selecting code files, analyzing them for secrets, code patterns, and dependencies, leveraging AI for deeper analysis, and finally generating a security report. The diagram serves as a high-level overview of the security analysis pipeline.

## Overall Layout
The diagram's primary direction is top-down (TD). It starts with "User Requests Scan" at the top and flows down through various stages of analysis, culminating in "Generate Security Report" at the bottom. The diagram includes two subgraphs: "Pattern Engine (Fast)" and "AI Engine (Deep)".

## Subgraphs / Stages
- **Pattern Engine (Fast)**: This subgraph represents a fast pattern-matching engine that quickly scans code for secrets, code patterns, and dependencies.
- **AI Engine (Deep)**: This subgraph represents a deep analysis engine that uses AI (specifically Gemini 3) to perform context-aware analysis and identify AI findings.

## High-Density QA Ground Truth Summary
The security scanning process begins with "User Requests Scan," which feeds into "Select Code Files," determining the scope of the analysis. The selected files are then processed by the "Pattern Engine (Fast)" subgraph, starting with "Fetch Content." This subgraph branches into three parallel analysis paths: "Detect Secrets," "Code Patterns," and "Check Dependencies." Simultaneously, "High Risk Files" identified during content fetching are sent to the "AI Engine (Deep)" subgraph for "Gemini 3 Analysis," resulting in "AI Findings." The AI Engine performs context-aware analysis, providing deeper insights. All findings from the "Pattern Engine (Fast)" and "AI Engine (Deep)" converge at the "Deduplicate & Aggregate" node, ensuring that only unique and relevant issues are considered. Finally, the aggregated results are used to "Generate Security Report," providing a comprehensive overview of the security vulnerabilities. The "Pattern Engine (Fast)" is designed for rapid scanning, while the "AI Engine (Deep)" leverages AI models like Gemini 3 for more sophisticated analysis of "High Risk Files," demonstrating a layered approach to security assessment.
