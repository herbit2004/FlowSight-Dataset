## 图类型与用途
该图是一个流程图，描述了使用会话协商的单点登录（Single Sign-On，SSO）过程。它展示了用户访问应用时，系统如何通过检测和验证会话，或者通过SSO认证中心进行认证，最终授权用户访问应用。

## 图的整体布局
该图从左到右布局，整体呈现单向流程。流程从用户访问应用开始，最终返回应用页面。

## 分组/子图/阶段说明
图中包含一个名为 "Single Sign-On with 会话协商" 的子图，该子图包含了整个 SSO 认证流程。

## 节点逐项说明
- **A (用户访问应用)**：用户尝试访问应用程序的起始点。
- **B (检测本地会话)**：系统检查用户是否存在本地会话。
- **C (有本地会话?)**：判断是否存在本地会话的决策点。
- **D (验证会话有效性)**：验证本地会话是否仍然有效。
- **E (会话有效?)**：判断会话是否有效的决策点。
- **F (应用授权验证)**：验证用户是否有权访问应用程序。
- **G (生成应用会话)**：为用户生成应用程序会话。
- **H (返回应用页面)**：将用户重定向到应用程序页面。
- **I (发起 SSO 认证请求)**：如果本地会话不存在或无效，则发起 SSO 认证请求。
- **J (SSO 认证中心)**：处理 SSO 认证请求的中心服务器。
- **K (创建/更新 SSO 会话)**：在 SSO 认证中心创建或更新 SSO 会话。

## 连线、分支与汇聚关系
- A -> B：用户访问应用后，系统检测本地会话。
- B -> C：检测本地会话后，判断是否存在本地会话。
- C -- 是 --> D：如果存在本地会话，则验证会话有效性。
- D -> E：验证会话有效性后，判断会话是否有效。
- E -- 是 --> F：如果会话有效，则进行应用授权验证。
- F -> G：应用授权验证通过后，生成应用会话。
- G -> H：生成应用会话后，返回应用页面。
- E -- 否 --> I：如果会话无效，则发起 SSO 认证请求。
- C -- 否 --> I：如果不存在本地会话，则发起 SSO 认证请求。
- I -> J：发起 SSO 认证请求后，请求发送到 SSO 认证中心。
- J -> K：SSO 认证中心创建或更新 SSO 会话。
- K -> F：创建/更新 SSO 会话后，进行应用授权验证。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **SSO (Single Sign-On)**：单点登录，允许用户使用一组凭据访问多个应用程序。
- **会话**：用户与应用程序或系统之间的一次交互过程，通常通过会话 ID 进行标识。
- **会话协商**：在 SSO 过程中，客户端与服务器之间就使用何种会话管理机制进行协商的过程。
- **认证**：验证用户身份的过程。
- **授权**：确定用户是否有权访问特定资源或执行特定操作的过程。

## 可作为 QA Ground Truth 的高信息密度摘要
用户访问应用后，系统首先检测本地会话。如果存在有效会话，则进行应用授权验证，生成应用会话并返回应用页面。如果本地会话不存在或无效，则发起 SSO 认证请求，由 SSO 认证中心创建或更新 SSO 会话，然后进行应用授权验证，最终生成应用会话并返回应用页面。
