## High-Density QA Ground Truth Summary
The process begins with a user query submitted via either the CLI (Typer) or the Python API. This query triggers the `build_deep_agent()` function, which orchestrates the creation of an agent runtime environment. This involves utilizing a `prompt.py` module with a default system prompt, initializing a LangChain model (potentially with a provider ID), loading MCP tools using `MCPToolLoader` (converting JSON schemas to Pydantic models and then to `BaseTool` instances), and setting up the `Agent Graph`. The `Agent Graph` interacts with the LangChain model, exchanging messages to facilitate reasoning and action. If deep agents are installed, the `DeepAgents loop` iterates through them. These tool calls are routed through `FastMCPMulti` to the appropriate MCP servers (Server A, B, or C). The servers return tool results back through `FastMCPMulti` and `_FastMCPTool` to the `Agent Graph`. Finally, the `Agent Graph` provides the final answer back to the user via the CLI or Python API, completing the cycle. The `MCPToolLoader` converts JSON schemas into Pydantic models and then into `BaseTool` instances, which are then used by the LangChain tools.
