## 图类型与用途
这是一个流程图，用于展示 GitHub 仓库 `masterfabric/one-hundered-days` 的目录结构和主要文件之间的关系。它在仓库中的作用是提供仓库内容的高层概览，帮助用户快速了解仓库的组织方式。

## 图的整体布局
图整体采用从上到下的布局。顶部是仓库根目录，中间是三个主要目录，底部是各个目录下的文件和子目录。

## 仓库语境与术语解释
- **Repository Root**: 仓库的根目录，包含所有其他目录和文件。
- **interns/**: 包含正式实习生项目的相关资源，如入职模板和工作流程标准。
- **trainee/**: 包含开放培训生项目（MasterFabric Academy）的指南和项目。
- **days/**: 包含各种技术栈（如 Flutter、Expo、DevOps 等）的每日学习路线图。
- **approved_intern+template.md**: 实习生入职模板，位于 `interns/` 目录下，用于收集实习生的基本信息和目标。
- **pr_and_commit_guide.md**: 位于 `interns/` 目录下，提供关于编写清晰的 Pull Request 和提交消息的指南，遵循 Conventional Commits 规范。
- **CONTRIBUTING.md**: 位于 `trainee/` 目录下，提供贡献指南，说明如何为 MasterFabric Academy 做出贡献。
- **LEARNING_PATHS.md**: 位于 `trainee/` 目录下，列出可用的学习路径，帮助学员选择感兴趣的技术栈。
- **finder_dev/**: 位于 `trainee/projects/` 目录下，是一个 Next.js 项目示例，用于培训。
- **MasterFabric Academy**: `README.md` 中提到，这是一个非营利开源教育计划，旨在为全球社区提供开放和可访问的软件开发培训。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 `masterfabric/one-hundered-days` 仓库的目录结构。从仓库根目录开始，主要分为 `interns/`、`trainee/` 和 `days/` 三个目录，分别对应正式实习生项目、开放培训生项目和每日学习路线图。`interns/` 目录下包含入职模板和贡献指南，`trainee/` 目录下包含学习路径和项目示例，`days/` 目录下包含各种技术栈的路线图，例如 Flutter、Expo、DevOps、NestJS、Next.js、Git 和 AI Agents。其中，`approved_intern+template.md` 是实习生入职的起点，而 `finder_dev/` 是一个 Next.js 项目示例。
