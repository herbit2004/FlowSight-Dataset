## 图类型与用途
该图是一个流程图，描述了社交裂变邀请的完整流程。它展示了用户发起邀请，到受邀用户参与，最终邀请人和受邀人获得奖励的整个过程。该流程图清晰地呈现了各个环节之间的逻辑关系和判断条件。

## 图的整体布局
该图采用从左到右的布局方式。流程从左侧的“用户发起邀请”开始，逐步向右推进，最终在右侧的“流程结束”处结束。整体上呈现出清晰的层次结构。

## 分组/子图/阶段说明
图中包含一个名为“受邀用户”的子图，该子图详细描述了受邀用户参与邀请活动的流程。主流程可以分为三个阶段：
1. 用户发起邀请并生成邀请链接/海报阶段
2. 受邀用户参与并完成注册/登录阶段
3. 奖励发放阶段

## 节点逐项说明
- **A[用户发起邀请]**：流程的起始节点，表示用户主动发起邀请活动。
- **B{判断用户是否已登录}**：判断用户是否已经登录的条件判断节点。
- **C[生成专属邀请链接/海报]**：为用户生成专属的邀请链接或海报。
- **D[跳转至登录/注册页面]**：如果用户未登录，则跳转到登录或注册页面。
- **E[用户分享邀请链接/海报]**：用户将生成的邀请链接或海报分享给其他人。
- **F{受邀用户点击链接/扫描海报}**：判断受邀用户是否点击了邀请链接或扫描了海报。
- **G{判断是否为新用户}**：判断受邀用户是否为新用户的条件判断节点。
- **H[注册/下载App 并完成引导]**：如果受邀用户是新用户，则引导其注册/下载App并完成引导。
- **I[老用户直接登录App]**：如果受邀用户是老用户，则直接登录App。
- **J[记录邀请关系]**：记录邀请人和受邀人之间的邀请关系。
- **K[发放新用户奖励]**：向新用户发放奖励。
- **L{判断邀请人是否满足活动条件}**：判断邀请人是否满足活动条件的条件判断节点。
- **M[发放邀请人奖励]**：向满足条件的邀请人发放奖励。
- **N[流程结束]**：流程的结束节点。

## 连线、分支与汇聚关系
- A -> B：用户发起邀请后，进入用户登录判断环节。
- B -- 是 --> C：如果用户已登录，则生成专属邀请链接/海报。
- B -- 否 --> D：如果用户未登录，则跳转至登录/注册页面。
- D -> C：跳转至登录/注册页面后，生成专属邀请链接/海报。
- C -> E：生成邀请链接/海报后，用户分享。
- E -> F：用户分享后，受邀用户点击链接/扫描海报。
- F -- 是 --> G：如果受邀用户点击了链接/扫描了海报，则判断是否为新用户。
- F -- 否 --> (其他流程，图中未显示)：如果受邀用户没有点击链接/扫描海报，则流程结束（图中未显示）。
- G -- 是 --> H：如果是新用户，则注册/下载App并完成引导。
- G -- 否 --> I：如果是老用户，则直接登录App。
- H -> J：注册/下载App并完成引导后，记录邀请关系。
- I -> J：老用户直接登录App后，记录邀请关系。
- J -> K：记录邀请关系后，发放新用户奖励。
- K -> L：发放新用户奖励后，判断邀请人是否满足活动条件。
- L -- 是 --> M：如果邀请人满足活动条件，则发放邀请人奖励。
- L -- 否 --> N：如果邀请人不满足活动条件，则流程结束。
- M -> N：发放邀请人奖励后，流程结束。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **社交裂变**：通过社交关系链进行传播，实现用户增长的一种营销方式。
- **邀请链接/海报**：用于邀请新用户的专属链接或海报，包含邀请人的信息。
- **新用户奖励**：为了鼓励新用户注册/下载App，而提供的一种奖励。
- **邀请人奖励**：为了鼓励老用户邀请新用户，而提供的一种奖励。
- **活动条件**：邀请人需要满足的条件，例如邀请人数达到一定数量。
- **App引导**：引导新用户熟悉App功能和使用的过程。

## 可作为 QA Ground Truth 的高信息密度摘要
用户发起邀请，系统判断用户是否登录，若未登录则跳转至登录/注册页面，登录后生成专属邀请链接/海报。用户分享邀请链接/海报，受邀用户点击链接后，系统判断是否为新用户，新用户需注册/下载App并完成引导，老用户直接登录App，之后系统记录邀请关系并给新用户发放奖励。最后，系统判断邀请人是否满足活动条件，满足则发放邀请人奖励，否则流程结束。
