## Repository Context & Terminology
- **Claude Code CLI**: The command-line interface for interacting with the Claude Code system.
- **Hook System**: A system that allows triggering actions based on specific events or conditions.

- **stdin**: Standard input, a common way to pass data to a program.
- **osascript**: A command-line tool for executing AppleScript scripts on macOS.
- **notify-send**: A command-line tool for sending desktop notifications on Linux.
- **say**: A command-line tool on macOS for text-to-speech.
- **espeak**: An open-source software speech synthesizer.
- **SAPI**: Speech API, a Microsoft API for speech recognition and text-to-speech.

## High-Density QA Ground Truth Summary
The process begins with the Claude Code CLI, which triggers the Hook System by sending JSON data. The Hook Runner, implemented in Python, receives this data and parses it, passing the parsed context to the Context Parser via stdin. The Context Parser then branches out to three different output channels: Audio Files (MP3s), Desktop Notifications (using osascript/notify-send), and Text-to-Speech (using say/espeak/SAPI). Each of these output channels generates an alert that is sent to the User Terminal. The Desktop Notifications channel utilizes `osascript` on macOS or `notify-send` on Linux to display alerts, while the Text-to-Speech channel leverages `say` on macOS, `espeak`, or the Microsoft Speech API (SAPI) to generate spoken alerts. All three output channels converge at the User Terminal, where the user receives the alerts. The Claude Code CLI acts as the initiator, while the User Terminal serves as the final destination for the alerts generated by the system.
