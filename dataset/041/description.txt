## Repository Context & Terminology
- **NestJS**: A progressive Node.js framework for building efficient, reliable and scalable server-side applications.
- **Monorepo**: A software development strategy where code for many projects is stored in the same repository.
- **package.json**: A file in the root directory of a Node.js project that contains metadata about the project, such as its name, version, and dependencies.
- **tsconfig.json**: A file that specifies the root files and the compiler options required to compile the project.
- **nest-cli.json**: A configuration file for the NestJS CLI, used for generating and managing NestJS projects.
- **.env**: A file that stores environment-specific variables for the application.
- **Socket.IO**: A library that enables real-time, bidirectional and event-based communication between web clients and servers.
