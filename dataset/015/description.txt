## 图类型与用途
这是一个架构图，展示了 QuantaLogic 生态系统的核心组件及其相互关系。它用于概览 QuantaLogic 框架的模块化设计，以及用户如何与这些模块进行交互。

## 图的整体布局
图采用从上到下的布局。顶部是用户节点，中间是 QuantaLogic 核心及其主要模式，底部是各个模式的具体实现或扩展。

## 分组/子图/阶段说明
图中包含一个名为 "QuantaLogic Ecosystem" 的子图，它将 QuantaLogic 框架的核心组件组织在一起。

## 节点逐项说明
- **Users**：代表使用 QuantaLogic 框架的最终用户。
- **quantalogic**：QuantaLogic 框架的核心，作为整个系统的入口点和协调者。
- **quantalogic_react**：QuantaLogic 的一个模式，基于 ReAct (Reason + Act) 范式，用于处理复杂的任务。README 指出它提供了超过 40 个内置工具。
- **quantalogic_codeact**：QuantaLogic 的一个模式，是 ReAct 的扩展，它使用可执行代码作为主要的行动语言，通过生成、运行和迭代 Python 代码来解决问题。
- **quantalogic_flow**：QuantaLogic 的一个模式，用于简化流程，通过 YAML 文件定义工作流。
- **quantalogic_toolbox**：QuantaLogic 的工具箱，包含各种工具和插件，用于扩展框架的功能。
- **40+ Built-in Tools**：ReAct 模式使用的工具集合，提供各种预定义的工具来辅助任务执行。
- **Python Code Execution**：CodeAct 模式的核心功能，允许 AI 代理执行生成的 Python 代码。
- **YAML Workflows**：Flow 模式使用 YAML 文件来定义和管理工作流程。
- **Plugin System**：Toolbox 提供的插件系统，允许用户自定义和扩展 QuantaLogic 的功能。

## 连线、分支与汇聚关系
- `Users -> quantalogic`：用户通过 QuantaLogic 核心与整个系统交互。
- `quantalogic -> quantalogic_react`：QuantaLogic 核心将任务分发给 ReAct 模式。
- `quantalogic -> quantalogic_codeact`：QuantaLogic 核心将任务分发给 CodeAct 模式。
- `quantalogic -> quantalogic_flow`：QuantaLogic 核心将任务分发给 Flow 模式。
- `quantalogic -> quantalogic_toolbox`：QuantaLogic 核心使用 Toolbox 提供的工具。
- `quantalogic_react -> 40+ Built-in Tools`：ReAct 模式使用内置的工具来执行行动。
- `quantalogic_codeact -> Python Code Execution`：CodeAct 模式通过执行 Python 代码来实现其功能。
- `quantalogic_flow -> YAML Workflows`：Flow 模式使用 YAML 文件来定义和执行工作流程。
- `quantalogic_toolbox -> Plugin System`：Toolbox 提供插件系统，用于扩展 QuantaLogic 的功能。

## 仓库语境与术语解释
- **QuantaLogic**：一个 Python 框架，利用大型语言模型 (LLM) 创建 AI 代理，用于编码、自动化和对话等多种应用场景。
- **ReAct**：一种 AI 代理模式，结合了推理 (Reasoning) 和行动 (Acting)，允许代理在解决问题时进行思考和采取行动。
- **CodeAct**：ReAct 的扩展，使用可执行 Python 代码作为主要的行动语言，适用于复杂的、多步骤的任务。
- **Flow**：一种 AI 代理模式，使用 YAML 文件定义结构化的工作流程，适用于自动化流程和数据管道。
- **Toolbox**：一个工具集合，用于扩展 QuantaLogic 框架的功能，可以包含内置工具和自定义插件。
- **YAML**：Flow 模式使用 YAML 文件来定义和管理工作流程。
- **Plugin System**：Toolbox 提供的插件系统，允许用户自定义和扩展 QuantaLogic 的功能。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 QuantaLogic 生态系统的架构，用户通过 QuantaLogic 核心与系统交互。QuantaLogic 提供了三种主要模式：ReAct、CodeAct 和 Flow，以及一个 Toolbox。ReAct 模式使用内置工具，CodeAct 模式执行 Python 代码，Flow 模式使用 YAML 文件定义工作流程。Toolbox 提供插件系统。整体架构旨在提供一个灵活、可扩展的 AI 代理平台，其中 ReAct 模式提供了超过 40 个内置工具。
