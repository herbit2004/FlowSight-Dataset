## 图类型与用途
这是一个流程图，描述了使用 Markdown 写作微信公众号文章的完整流程，包括图片处理模式的选择。它在仓库中的作用是展示从 Markdown 写作到最终完成微信公众号文章发布的步骤，并突出了 API 模式和 AI 模式两种图片处理方式。

## 图的整体布局
图整体采用从左到右的布局。流程从左侧的 Markdown 写作开始，经过图片处理模式选择，最终在右侧完成微信公众号文章的发布。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可以分为三个阶段：写作与图片插入、图片处理模式选择与 HTML 生成、效果预览与最终发布。

## 节点逐项说明
- **Markdown 写作**：表示用户使用 Markdown 语法进行文章内容的创作。这是流程的起点。
- **插入图片**：表示在 Markdown 文章中插入图片。
- **选择模式**：这是一个判断节点，用于选择图片处理模式，有两种选择：API 模式或 AI 模式。
- **md2wechat.cn**：表示使用 `md2wechat.cn` 提供的 API 服务进行图片处理。根据 README，使用 API 模式需要先获取 API Key。
- **Claude AI**：表示使用 Claude AI 服务进行图片处理。根据 README，AI 模式不需要 API Key，可以直接使用 Claude。
- **HTML 生成**：表示将 Markdown 内容和处理后的图片转换为 HTML 格式。
- **预览效果**：表示预览生成的 HTML 页面效果。
- **满意吗**：这是一个判断节点，用于判断预览效果是否满意。
- **上传图片**：表示将图片上传到服务器。
- **发送草稿**：表示将文章草稿发送到微信公众号平台。
- **完成**：表示整个流程完成。

## 连线、分支与汇聚关系
- `Markdown 写作 -> 插入图片`：Markdown 写作完成后，进入插入图片的环节。
- `插入图片 -> 选择模式`：插入图片后，需要选择图片处理模式。
- `选择模式 -- API --> md2wechat.cn`：选择 API 模式，进入 `md2wechat.cn` 服务。
- `选择模式 -- AI --> Claude AI`：选择 AI 模式，进入 Claude AI 服务。
- `md2wechat.cn -> HTML 生成`：API 处理完成后，生成 HTML 代码。
- `Claude AI -> HTML 生成`：AI 处理完成后，生成 HTML 代码。
- `HTML 生成 -> 预览效果`：HTML 生成后，进入预览效果的环节。
- `预览效果 -> 满意吗`：预览效果后，需要判断是否满意。
- `满意吗 -- 调整 --> 选择模式`：如果不满意，则返回到选择模式节点，重新选择图片处理模式或调整 Markdown 内容。
- `满意吗 -- OK --> 上传图片`：如果满意，则进入上传图片的环节。
- `上传图片 -> 发送草稿`：图片上传完成后，进入发送草稿的环节。
- `发送草稿 -> 完成`：发送草稿后，流程结束。

## 仓库语境与术语解释
- **Markdown**：一种轻量级标记语言，用于编写具有格式的文本。
- **md2wechat**：一个工具，用于将 Markdown 格式的文章转换为微信公众号文章的 HTML 格式。
- **API 模式**：使用 `md2wechat.cn` 提供的 API 服务进行图片处理的模式。根据 README，使用 API 模式需要先获取 API Key。
- **AI 模式**：使用 Claude AI 服务进行图片处理的模式。根据 README，AI 模式不需要 API Key，可以直接使用 Claude。
- **Claude AI**：一种人工智能服务，用于处理图片。
- **HTML**：一种用于创建网页的标准标记语言。
- **微信公众号**：一个在微信平台上发布文章的平台。
