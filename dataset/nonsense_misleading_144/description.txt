## Edges, Branches & Convergence

  `B -- Yes, Insufficient --> C`: If payment is insufficient, the order is cancelled.
  `B -- No, Sufficient --> D`: If payment is sufficient, the order is placed in a queue.
  `D --> E`: The order in the queue triggers an inventory availability check.
  `E -- No, Available --> F`: If inventory is not available, the customer is notified of a delay.
  `E -- Yes, Unavailable --> G`: If inventory is unavailable (counterfactual error), the order proceeds to picking, packing, and shipping.

  `I --> J`: After updating inventory levels, a confirmation email is sent.
  `J --> K`: After sending the confirmation email, the order is completed.
