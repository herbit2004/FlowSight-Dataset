## Repository Context & Terminology
- **TDD (Test-Driven Development)**: A software development process where tests are written before the code.
- **DDD (Domain-Driven Design)**: A software development approach focused on modeling the software to match a domain according to input from that domain's experts.
- **Red-Green-Refactor**: A cycle used in TDD: write a failing test (Red), write code to pass the test (Green), and improve the code without breaking the test (Refactor).
- **Test Coverage**: A metric that measures the percentage of code covered by tests.
