## 图类型与用途
这是一个流程图，展示了 QuantaLogic 框架的整体架构和不同模式的工作流程。它描述了用户如何通过 QuantaLogic 与不同的 AI 模式进行交互，并最终获得输出结果。该图在 README 中用于概括 QuantaLogic 的核心功能和组件。

## 图的整体布局
图采用从上到下的布局。用户作为流程的起点位于顶部，QuantaLogic 框架作为核心处理中心位于中间，不同的 AI 模式分支从 QuantaLogic 延伸出来，最终汇聚到输出结果，并返回给用户。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为四个阶段：用户输入、模式选择与分发、AI 模式处理、结果输出与反馈。

## 节点逐项说明
- **User**：代表使用 QuantaLogic 框架的用户，是整个流程的起点。
- **QuantaLogic**：代表 QuantaLogic 框架本身，是整个流程的核心入口，负责接收用户输入并分发到不同的模式。
- **Pure ReAct**：代表 QuantaLogic 的 ReAct (Reason + Act) 模式，用于处理复杂的任务，通过推理和行动来解决问题。根据 README，ReAct 模式让 agents *reason* (think step-by-step) and *act* (use tools or code) in a loop。
- **CodeAct**：代表 QuantaLogic 的 CodeAct 模式，是 ReAct 的扩展，它使用可执行代码作为主要行动语言，通过生成、运行和迭代 Python 代码来解决问题。根据 README，CodeAct is ideal for complex, multi-step tasks, advanced automation, and scenarios where precise, verifiable actions are needed.
- **Flow: Automate**：代表 QuantaLogic 的 Flow 模式，用于自动化工作流程。
- **Chat: Converse**：代表 QuantaLogic 的 Chat 模式，用于自然语言对话，并能利用工具来增强对话能力。
- **LLM + Tools**：代表 Pure ReAct 模式的核心组成部分，包括大型语言模型 (LLM) 和一系列工具，用于推理和执行行动。
- **LLM + Code Actions**：代表 CodeAct 模式的核心组成部分，包括大型语言模型 (LLM) 和代码行动，用于生成、运行和迭代代码。
- **Nodes + Engine**：代表 Flow 模式的核心组成部分，包括节点和引擎，用于定义和执行自动化流程。
- **Persona + Tools**：代表 Chat 模式的核心组成部分，包括角色设定 (Persona) 和一系列工具，用于进行自然语言对话。
- **Output**：代表 QuantaLogic 框架最终产生的输出结果。

## 连线、分支与汇聚关系
- `User -> QuantaLogic`：用户通过输入与 QuantaLogic 框架进行交互。
- `QuantaLogic -> Pure ReAct`：QuantaLogic 将请求分发到 Pure ReAct 模式。
- `QuantaLogic -> CodeAct`：QuantaLogic 将请求分发到 CodeAct 模式。
- `QuantaLogic -> Flow: Automate`：QuantaLogic 将请求分发到 Flow 模式。
- `QuantaLogic -> Chat: Converse`：QuantaLogic 将请求分发到 Chat 模式。
- `Pure ReAct -> LLM + Tools`：Pure ReAct 模式使用 LLM + Tools 进行推理和行动。
- `CodeAct -> LLM + Code Actions`：CodeAct 模式使用 LLM + Code Actions 生成、运行和迭代代码。
- `Flow: Automate -> Nodes + Engine`：Flow 模式使用 Nodes + Engine 定义和执行自动化流程。
- `Chat: Converse -> Persona + Tools`：Chat 模式使用 Persona + Tools 进行自然语言对话。
- `LLM + Tools -> Output`：LLM + Tools 的处理结果输出到 Output。
- `LLM + Code Actions -> Output`：LLM + Code Actions 的处理结果输出到 Output。
- `Nodes + Engine -> Output`：Nodes + Engine 的处理结果输出到 Output。
- `Persona + Tools -> Output`：Persona + Tools 的处理结果输出到 Output。
- `LLM + Tools, LLM + Code Actions, Nodes + Engine, Persona + Tools -> Output`：形成汇聚关系。
- `Output -> User`：输出返回给用户，形成一个完整的交互闭环。

## 仓库语境与术语解释
- **QuantaLogic**：一个 Python 框架，利用 LLM 创建 AI agents，提供 ReAct、Flow 和 Chat 模式。
- **ReAct**：一种 AI 范式，让 agents 在推理和行动的循环中解决问题。
- **CodeAct**：ReAct 的扩展，使用可执行 Python 代码作为主要行动语言。
- **Flow**：用于构建结构化工作流程的引擎，支持 YAML 和 Python API。
- **LLM (Large Language Model)**：支持 OpenAI, Anthropic, DeepSeek 等模型，通过 LiteLLM 集成。
- **Tool**：用于扩展 Agent 能力的组件，例如代码执行、网页搜索、文件管理等。
- **Persona**：在 Chat 模式中使用的角色设定，用于进行自然语言对话。
