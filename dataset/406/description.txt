It depicts the data flow through the SSB extraction process and compares the resource impact of using different FIFO sizes (2 entries vs. 16 entries) in terms of BRAM (Block RAM) usage and flip-flop count. This diagram serves as a high-level overview of the system's architecture and performance trade-offs.

## Repository Context & Terminology
- **SSB (Synchronisation Signal Block)**: A signal used for synchronization purposes in communication systems.
- **FIFO (First-In, First-Out)**: A type of buffer where the first element added is the first one removed.
- **BRAM (Block RAM)**: A type of memory block available in FPGAs (Field-Programmable Gate Arrays).
- **Flip-Flop**: A basic building block of digital circuits used for storing one bit of data.
- **BRAM Tiles**: Physical units of BRAM memory available in an FPGA.
- **Resource Utilization**: The amount of hardware resources (e.g., flip-flops, BRAM tiles) used by a design.
