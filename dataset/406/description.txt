## 图类型与用途
这是一个流程图，用于展示SSB信号提取系统的架构，以及FIFO大小对BRAM映射和资源利用率的影响。它旨在说明FIFO大小是影响BRAM推断成功与否的关键因素，并展示了不同配置下的资源使用情况。

## 图的整体布局
图整体采用从左到右和从上到下的混合布局。左侧是FIFO大小的影响，中间是SSB信号提取系统的流程，下方展示了资源使用的影响。

## 分组/子图/阶段说明
图中包含三个子图：
- **SSB Signal Extraction System**：展示了SSB信号提取系统的完整流程，从输入信号到输出信号。
- **FIFO Size Impact**：展示了不同FIFO大小（2 entries 和 16 entries）对BRAM映射的影响。
- **Resource Impact**：展示了BRAM映射成功或失败对资源利用率的影响。

## 节点逐项说明
- **Input Signal (IN)**：输入信号，是SSB信号提取系统的起点。
- **Peak Detection (PEAK)**：峰值检测模块，用于检测输入信号中的峰值。
- **Event Processing (EVENT)**：事件处理模块，处理检测到的峰值事件。
- **Peak FIFO (FIFO)**：峰值FIFO（先进先出）队列，用于存储检测到的峰值事件。根据 README 和代码文件（如 `HDL_v1/extractSSBsig_hdl.m`），FIFO 大小是影响 BRAM 推断的关键因素。
- **Circular Buffer (BUFFER)**：循环缓冲区，用于存储信号数据。
- **SSB Extraction (EXTRACT)**：SSB信号提取模块，从循环缓冲区中提取SSB信号。
- **Output Signal (OUT)**：输出信号，是SSB信号提取系统的终点。
- **FIFO: 2 entries (FIFO2)**：表示FIFO大小为2个条目。
- **FIFO: 16 entries (FIFO16)**：表示FIFO大小为16个条目。
- **✅ BRAM Success (BRAM_SUCCESS)**：表示BRAM映射成功。
- **❌ BRAM Failure (BRAM_FAIL)**：表示BRAM映射失败。
- **~900 Flip-Flops, BRAM Tiles Used (EFFICIENT)**：表示使用约900个触发器，并成功使用了BRAM Tile，资源利用率高。
- **67,389+ Flip-Flops, No BRAM Tiles (INEFFICIENT)**：表示使用超过67,389个触发器，但没有使用BRAM Tile，资源利用率低。

## 连线、分支与汇聚关系
- `IN -> PEAK`：输入信号进入峰值检测模块。
- `PEAK -> EVENT`：峰值检测后进行事件处理。
- `EVENT -> FIFO`：事件处理后数据进入峰值FIFO。
- `FIFO -> BUFFER`：峰值FIFO的数据进入循环缓冲区。
- `BUFFER -> EXTRACT`：循环缓冲区的数据用于SSB信号提取。
- `EXTRACT -> OUT`：提取后的SSB信号作为输出信号。
- `FIFO2 -> BRAM_SUCCESS`：FIFO大小为2时，BRAM映射成功。
- `FIFO16 -> BRAM_FAIL`：FIFO大小为16时，BRAM映射失败。
- `BRAM_SUCCESS -> EFFICIENT`：BRAM映射成功导致高效的资源利用。
- `BRAM_FAIL -> INEFFICIENT`：BRAM映射失败导致低效的资源利用。

## 仓库语境与术语解释
- **SSB (Synchronization Signal Block)**：5G NR中的同步信号块，该仓库旨在提取该信号。
- **BRAM (Block RAM)**：FPGA中的块RAM资源，用于存储数据。
- **FIFO (First-In, First-Out)**：先进先出队列，用于数据缓冲。
- **Flip-Flops**：触发器，用于存储二进制数据，是FPGA中的基本逻辑单元。
- **MATLAB HDL Coder**：MATLAB的工具箱，用于从MATLAB代码生成HDL代码。README 指出 FIFO size 直接影响 BRAM mapping 的成功率。
- **Xilinx Vivado**：Xilinx公司的FPGA开发工具，用于综合、实现和验证FPGA设计。
- `extractSSBsig_hdl.m`：MATLAB函数，实现了SSB信号提取的HDL兼容版本，代码文件（如 `HDL_v1/extractSSBsig_hdl.m`）中定义了 FIFO 的大小。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了SSB信号提取系统的架构以及FIFO大小对BRAM映射的影响。信号从输入开始，经过峰值检测、事件处理、峰值FIFO、循环缓冲区和SSB提取，最终输出。FIFO大小是影响BRAM映射的关键因素：较小的FIFO（如2 entries）导致BRAM映射成功和高效的资源利用，而较大的FIFO（如16 entries）导致BRAM映射失败和低效的资源利用。该研究的目的是优化MATLAB HDL Coder生成的HDL代码，以实现更高效的FPGA资源利用。
