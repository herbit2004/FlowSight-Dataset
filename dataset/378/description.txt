## Repository Context & Terminology
- **Raw Data Ingestion**: The initial process of collecting and importing data from various sources into the system for further processing.
- **Normalise & Clean**: Data preprocessing steps to standardize the data format, handle missing values, and remove noise or inconsistencies.
- **Feature Extraction**: The process of selecting and transforming relevant features from the raw data to improve model performance.
- **Time-Window Slicing**: Dividing the data into time-based segments or windows to capture temporal patterns and trends.
- **Model Training**: The process of training a machine learning model using historical data to learn patterns and relationships.
- **Evaluation & Tuning**: Assessing the model's performance on unseen data and adjusting its parameters to optimize accuracy and generalization.
- **Real-Time Inference**: Applying the trained model to new, incoming data to make predictions or detect anomalies in real-time.
- **Threat Alert + Block**: Triggering alerts and taking actions to block or mitigate potential threats based on the model's predictions.
