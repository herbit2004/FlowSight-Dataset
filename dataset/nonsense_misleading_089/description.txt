## Edges, Branches & Convergence
- `User Submits Order --> Payment Received?`: The order submission triggers the payment verification process.
- `Payment Received? -- No --> Send Payment Reminder`: If payment is not received, a payment reminder is sent.
- `Send Payment Reminder --> User Submits Order`: After sending the payment reminder, the process loops back to the "User Submits Order" node.
- `Payment Received? -- Yes --> Inventory Check`: If payment is received, an inventory check is performed.
- `Inventory Check -- Available --> Fulfill Order`: If the inventory is available, the order is fulfilled.
- `Inventory Check -- Unavailable --> Notify Backorder`: If the inventory is unavailable, the user is notified about the backorder.
- `Notify Backorder --> Order Refunded`: Upon backorder notification, the order is refunded.
- `Order Refunded --> Inventory Check`: After refunding the order, the process loops back to the "Inventory Check" node.
- `Fulfill Order --> Shipping Label Generated?`: After fulfilling the order, the system checks if a shipping label has been generated.
- `Shipping Label Generated? -- Yes --> Ship Order`: If the shipping label is generated, the order is shipped.
- `Shipping Label Generated? -- No --> Close Order`: If the shipping label is not generated, the order is closed.
- `Ship Order --> Order Delivered`: After shipping the order, it is delivered.
- `Close Order --> Order Delivered`: After closing the order, the flow goes to "Order Delivered".
- `Order Delivered --> Send Confirmation Email`: After the order is delivered, a confirmation email is sent.
- `Send Confirmation Email --> Archive Order Data`: After sending the confirmation email, the order data is archived.
- `Archive Order Data --> End`: After archiving the order data, the process ends.
