## Edges, Branches & Convergence
- `UM --> API`: User message is sent to the RESTful APIs.
- `API --> RME`: RESTful APIs trigger a message event.
- `RME --> BP`: Message event triggers backend processing.
- `BP --> Auth`: Backend processing leads to user authentication check.
- `Auth -- Yes --> LMDB`: If the user is authenticated, load conversation history from MongoDB.
- `Auth -- No --> LBrowser`: If the user is not authenticated, load conversation history from local browser storage.
- `LMDB --> Prep`: Conversation history from MongoDB is used to prepare the AI agent input.
- `LBrowser --> Prep`: Conversation history from local browser storage is used to prepare the AI agent input.
- `Prep --> AInput`: Prepared input is fed to the AI Agent Input.
- `AInput --> Orchestration`: AI Agent Input goes to Agent Tool Orchestration.
- `Orchestration --> UsePinecone`: Agent Tool Orchestration triggers a check to use data from Pinecone.
- `UsePinecone -- Yes --> QueryPinecone`: If data from Pinecone should be used, query vectorized properties data from Pinecone.
- `UsePinecone -- No --> NoPinecone`: If data from Pinecone should not be used, proceed without RAG data from Pinecone.
- `QueryPinecone --> MOE`: Vectorized properties data from Pinecone is used in the Mixture-of-Experts API request pipeline.
- `NoPinecone --> MOE`: Proceeding without RAG data from Pinecone leads to the Mixture-of-Experts API request pipeline.
- `MOE --> Generate`: Mixture-of-Experts API request pipeline generates the final response.
- `Generate --> APIResp`: Final response is sent as an API request response.
- `APIResp --> Display`: API request response is displayed in the user interface.
- `Display --> Rate`: Displayed response prompts the user to rate the response.
- `Rate -- Thumbs Down --> Update`: If the user gives a thumbs down, update the expert weights and go through another API request.
- `Update --> MOE`: The update process loops back to the Mixture-of-Experts API request pipeline.
- `Rate -- Thumbs Up --> End`: If the user gives a thumbs up, no update is needed.

## Repository Context & Terminology
- **RESTful APIs**: Represent an architectural style for building web services. In this context, they handle incoming user messages and trigger backend processing.
- **MongoDB**: A NoSQL database used to store conversation history for authenticated users.
- **Local Browser Storage**: A mechanism for storing conversation history in the user's browser for unauthenticated users.
- **AI Agent**: A software entity that uses AI to process user messages and generate responses.
- **Pinecone**: A vector database used for storing and querying vectorized properties data.
- **RAG (Retrieval-Augmented Generation)**: A technique for improving the quality of generated text by retrieving relevant information from a knowledge base.
- **Mixture-of-Experts**: An ensemble learning technique where multiple specialized AI experts are combined to generate a final response.
