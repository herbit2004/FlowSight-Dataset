## 图类型与用途
这是一个流程图，描述了一个基于多智能体的内容创作工作室的架构，用于自动化内容创作流程。该图展示了从用户请求到最终交付完整内容包的整个过程，是理解系统工作流程的关键。

## 图的整体布局
图采用从上到下的布局。流程从顶部的用户请求开始，经过多个阶段的处理，最终在底部生成完整的内容包。

## 分组/子图/阶段说明
图中包含五个显式子图，分别代表内容创作的不同阶段：
- **Phase 1: Intake & Research**：负责解析用户简报和查找热门话题。
- **Phase 2: Initial Draft**：负责创建内容的初始草稿。
- **Phase 3: Quality Loop (Max 3 iterations)**：负责评估和改进草稿的质量，最多迭代三次。
- **Phase 4: Multi-Channel Generation (Parallel)**：负责为多个平台（博客、社交媒体、邮件）创建内容，并行执行。
- **Phase 5: Packaging**：负责将所有生成的内容组装成一个完整的内容包。

## 节点逐项说明
- **User Request**：用户发起的内容创作请求，是整个流程的起点。
- **Master Orchestrator**：主协调器，使用 gemini-2.5-flash 模型，负责接收用户请求并将其分配给内容创作协调器。
- **Content Creation Coordinator**：内容创作协调器，使用 gemini-2.5-flash 模型，负责协调和管理内容创作的各个阶段。根据 `content_creation_studio/agent.py`，它会委托 `full_content_workflow` 执行完整的流程。
- **Intake Agent**：摄取代理，负责解析用户请求的简报，提取关键信息。
- **Topic Research Agent**：主题研究代理，负责查找当前的热门话题，为内容创作提供方向。
- **Content Drafter Agent**：内容起草代理，负责根据研究结果创建内容的初始草稿。
- **Quality Checker**：质量检查器，负责评估草稿的质量，判断其得分是否达到70分以上。
- **Content Improver**：内容改进器，负责根据质量检查的结果，对草稿进行改进和优化。
- **Approved Content**：质量检查通过的内容，表示内容质量合格。
- **Blog Post Writer**：博客文章写手，负责撰写800-1200字的博客文章，并进行SEO优化。根据 `content_creation_studio/sub_agents/blog_post_writer_agent/agent.py`，该 Agent 会根据 `target_audience` 和 `tone` 生成最终的博客文章。
- **Social Media Creator**：社交媒体内容创作者，负责为LinkedIn、Twitter、Instagram等平台创建特定格式的内容。
- **Email Newsletter Writer**：电子邮件通讯写手，负责撰写引人入胜的电子邮件，并包含明确的行动号召。
- **SEO Metadata Agent**：SEO元数据代理，负责生成元标签和关键词，用于搜索引擎优化，通常包含5-10个关键词。
- **Final Packager Agent**：最终打包代理，负责将所有生成的内容（博客文章、社交媒体内容、电子邮件、SEO元数据）组装成一个完整的内容包。根据 `content_creation_studio/sub_agents/final_packager_agent/agent.py`，该 Agent 会将所有内容整合为一个包含执行摘要的综合内容包。
- **Complete Content Package**：完整的内容包，最终交付给用户。

## 连线、分支与汇聚关系
- `User Request -> Master Orchestrator`：用户请求被发送到主协调器。
- `Master Orchestrator -> Content Creation Coordinator`：主协调器将请求传递给内容创作协调器。
- `Content Creation Coordinator -> Intake Agent`：内容创作协调器启动摄取代理。
- `Intake Agent -> Topic Research Agent`：摄取代理完成后，启动主题研究代理。
- `Topic Research Agent -> Content Drafter Agent`：主题研究完成后，内容起草代理创建初始草稿。
- `Content Drafter Agent -> Quality Checker`：草稿完成后，进入质量检查阶段。
- `Quality Checker -- No --> Content Improver`：如果质量检查未通过（得分低于70），则进行内容改进。
- `Content Improver -> Quality Checker`：内容改进后，再次进行质量检查，形成循环。
- `Quality Checker -- Yes --> Approved Content`：如果质量检查通过（得分高于等于70），则内容被批准。
- `Approved Content -> Blog Post Writer`：批准的内容被发送到博客文章写手。
- `Approved Content -> Social Media Creator`：批准的内容被发送到社交媒体内容创作者。
- `Approved Content -> Email Newsletter Writer`：批准的内容被发送到电子邮件通讯写手。
- `Approved Content -> SEO Metadata Agent`：批准的内容被发送到SEO元数据代理。
- `Blog Post Writer -> Final Packager Agent`：博客文章写手完成的内容被发送到最终打包代理。
- `Social Media Creator -> Final Packager Agent`：社交媒体内容创作者完成的内容被发送到最终打包代理。
- `Email Newsletter Writer -> Final Packager Agent`：电子邮件通讯写手完成的内容被发送到最终打包代理。
- `SEO Metadata Agent -> Final Packager Agent`：SEO元数据代理完成的内容被发送到最终打包代理。
- `Blog Post Writer, Social Media Creator, Email Newsletter Writer, SEO Metadata Agent -> Final Packager Agent`：多个内容生成器汇聚到最终打包代理，形成汇聚关系。
- `Final Packager Agent -> Complete Content Package`：最终打包代理将所有内容组装成完整的内容包并交付给用户。

## 仓库语境与术语解释
- **Gemini models**：该项目使用 Google 的 Gemini 模型来驱动智能代理。README 表明该项目基于 Gemini 模型。
- **Agent Engine**：该项目部署在 Google Cloud Platform 上，使用 Agent Engine 进行可扩展的 AI 代理编排。README 表明该项目使用 Agent Engine。
- **ADK (Agent Development Kit)**：该项目使用 Google 的 Agent Development Kit 来构建和部署 AI 代理。README 表明该项目使用 ADK。
- **Intake Agent**：负责解析用户请求的简报，提取关键信息。根据 `content_creation_studio/agent.py`，它是 `full_content_workflow` 的一部分。
- **SEO Metadata Agent**：负责生成元标签和关键词，用于搜索引擎优化。根据 `content_creation_studio/agent.py`，它是 `parallel_content_creation` 的一部分。
- **Final Packager Agent**：负责将所有生成的内容组装成一个完整的内容包。根据 `content_creation_studio/agent.py`，它是 `full_content_workflow` 的最后一步。
- **LoopAgent**：`content_creation_studio/agent.py` 中定义的一个类，用于创建循环代理，例如质量改进循环。
- **ParallelAgent**：`content_creation_studio/agent.py` 中定义的一个类，用于创建并行代理，例如多渠道内容创建。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了内容创作工作室的完整流程，从用户发起请求开始，经过主协调器和内容创作协调器的协调，进入摄取和研究阶段，然后创建初始草稿。质量检查环节通过循环迭代改进内容，最终生成博客文章、社交媒体内容、电子邮件和SEO元数据。所有内容由最终打包代理组装成完整的内容包，交付给用户。其中，gemini-2.5-flash 模型被用于多个 Agent，Agent Engine 被用于部署。
