## Repository Context & Terminology
- **Sensor Logs**: Data generated by sensors, typically time-series data.
- **Data Validation**: The process of ensuring that data meets certain quality criteria and is free from errors.
- **Timestamp Indexing**: Indexing data based on timestamps to enable efficient time-based queries.
- **Data Transformation**: The process of converting data from one format or structure to another.
- **Hot Tier Storage**: A storage tier that provides fast access to frequently used data, often using in-memory caching.
- **Cold Tier Storage**: A storage tier that provides lower-cost storage for infrequently accessed data, typically using object storage.
- **Parquet**: A columnar storage format optimized for efficient data retrieval and analytics.
- **Object Storage**: A storage architecture that manages data as objects, often used for large-scale, unstructured data.
- **Data Lifecycle Management**: The process of managing the lifecycle of data, from creation to deletion or archival.
- **Glacier Storage**: A low-cost, long-term storage service for infrequently accessed data.

Finally, the merged results are returned to the user via `Return Results to User`.
