## Repository Context & Terminology
- **Syscall**: A system call is a request made by a user-level program to the operating system kernel.
- **Virtual File System (VFS)**: An abstraction layer that allows applications to access different file systems in a uniform way.
- **Driver**: A software component that enables the operating system to interact with hardware devices.
- **mount**: The process of making a file system accessible to the operating system.
- **map**: In the context of memory management, mapping refers to associating a virtual address space with physical memory.
- **exec/exit**: System calls related to program execution (exec) and termination (exit).
