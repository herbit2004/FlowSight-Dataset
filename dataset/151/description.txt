## 图类型与用途
这是一个流程图，描述了 Zeal 8-bit OS 中用户程序与操作系统内核的交互方式，以及内核内部各模块之间的关系。该图旨在展示用户程序如何通过系统调用访问硬件资源，并说明 VFS 的架构。

## 图的整体布局
图采用从上到下的布局。顶部是用户程序，通过系统调用与内核交互，内核再通过不同的模块管理硬件资源。底部是硬件层。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可分为用户程序层、系统调用分发层、资源管理层和硬件层四个阶段。

## 节点逐项说明
- **User program**：用户程序，运行在用户空间，是整个流程的起点。
- **Syscall dispatcher**：系统调用分发器，负责接收用户程序的系统调用请求，并将其路由到相应的内核模块。
- **Time & Date module**：时间和日期模块，提供获取系统时间和日期的功能。
- **Disk module**：磁盘模块，负责管理磁盘设备。
- **Virtual File System**：虚拟文件系统，提供统一的文件访问接口。根据 `docs/details/vfs.md`，VFS 位于用户程序和内核之间，决定是调用驱动程序还是文件系统。
- **File System**：文件系统，负责管理磁盘上的文件组织结构。
- **Driver implementation: video, keyboard, serial, etc...**：驱动程序实现，包括视频、键盘、串口等硬件设备的驱动。
- **Hardware**：硬件，代表实际的硬件设备，是整个流程的终点。
- **Memory module**：内存模块，负责管理内存资源。
- **Loader module**：加载器模块，负责加载和执行用户程序。

## 连线、分支与汇聚关系
- `User program -- syscall/rst 8 --> Syscall dispatcher`：用户程序通过系统调用 (syscall) 或复位指令 (rst 8) 向系统调用分发器发出请求。
- `Syscall dispatcher -- getdate/time --> Time & Date module`：系统调用分发器调用时间模块来获取时间和日期。
- `Syscall dispatcher -- mount --> Disk module`：系统调用分发器调用磁盘模块来挂载磁盘。
- `Syscall dispatcher --> Virtual File System`：系统调用分发器将文件相关的请求传递给虚拟文件系统。
- `Syscall dispatcher -- map --> Memory module`：系统调用分发器调用内存模块来管理内存。
- `Syscall dispatcher -- exec/exit --> Loader module`：系统调用分发器调用加载器模块来执行或退出程序。
- `Virtual File System --> Disk module & Driver implementation: video, keyboard, serial, etc...`：虚拟文件系统将文件操作请求传递给磁盘模块和驱动程序。
- `Disk module <--> File System`：磁盘模块与文件系统模块之间进行双向通信，实现磁盘数据的读写，形成汇聚关系。
- `File System --> Driver implementation: video, keyboard, serial, etc...`：文件系统模块通过驱动程序访问底层硬件。
- `Driver implementation: video, keyboard, serial, etc... --> Hardware`：驱动程序直接与硬件进行交互。

## 仓库语境与术语解释
- **Syscall**：系统调用，用户程序请求操作系统服务的接口。根据 `docs/details/syscalls.md`，系统依赖 syscalls 在用户程序和内核之间执行请求。
- **VFS (Virtual File System)**：虚拟文件系统，提供统一的文件访问接口，隔离用户程序和底层文件系统及驱动程序。
- **Driver**：驱动程序，用于控制硬件设备。根据 `docs/details/drivers.md`，驱动程序包含 init、read、write、open、close、seek 和 ioctl 等例程。
- **Disk module**：磁盘模块，负责管理磁盘设备。根据 `docs/details/vfs.md`，Zeal 8-bit OS 支持最多 26 个磁盘，用字母 A 到 Z 表示。
- **File System**：文件系统，负责管理磁盘上的文件组织结构。`docs/details/vfs.md` 提到 rawtable 和 ZealFS 是已实现的文件系统。
- **Loader module**: 加载器模块，负责加载和执行用户程序。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 Zeal 8-bit OS 中用户程序与内核的交互流程。用户程序通过 syscall/rst 8 指令向 Syscall dispatcher 发出请求，Syscall dispatcher 将请求分发到 Time & Date module、Disk module、Virtual File System、Memory module 和 Loader module 等模块。Virtual File System 进一步与 Disk module、File System 和 Driver implementation 交互，最终 Driver implementation 与 Hardware 进行交互。其中，VFS 负责决定是调用驱动程序还是文件系统，而 syscall 是用户程序与内核交互的关键接口。
