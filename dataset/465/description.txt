## Repository Context & Terminology
- **Frontend**: The user interface of the application, typically built with technologies like React, Vue, or Angular.
- **Backend**: The server-side logic of the application, responsible for handling requests, processing data, and interacting with databases and external services.
- **API Endpoint**: A specific URL that the backend exposes for clients to interact with.
- **Pinecone Index**: A vector database used for similarity search and retrieval.
- **Neo4j Aura**: A graph database as a service, used for storing and querying relationships between data.
- **MongoDB Atlas**: A cloud-based NoSQL database service.
- **Redis Cache**: An in-memory data store used for caching frequently accessed data.
