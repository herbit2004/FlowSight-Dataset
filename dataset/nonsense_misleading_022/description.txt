## Edges, Branches & Convergence
- `A --> B`: Flow from receiving the customer order to checking the inventory.
- `B -- Yes --> C`: If the inventory check is successful (items are in stock), generate a picking list.
- `B -- No --> H`: If the inventory check fails (items are out of stock), send an 'Out of Stock' notification.
- `C --> D`: Flow from generating the picking list to checking if payment has been received.
- `D -- Yes --> E`: If payment has been received, package the items.
- `D -- No --> I`: If payment has not been received, cancel the order.
- `E --> F`: Flow from packaging the items to checking if a shipping label has been created.
- `F -- Yes --> G`: If a shipping label has been created, arrange shipment.
- `F -- No --> K`: If a shipping label has not been created, generate a shipping label.
- `G --> J`: Flow from arranging shipment to delivering the order.
- `H --> J`: Flow from sending 'Out of Stock' notification to delivering the order.
- `I --> A`: Flow from canceling the order back to receiving a customer order (loop).
- `K --> L`: Flow from generating a shipping label to sending a shipment confirmation.
- `L --> J`: Flow from sending a shipment confirmation to delivering the order.
