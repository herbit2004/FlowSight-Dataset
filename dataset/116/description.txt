## Repository Context & Terminology
- **HelixToolkit**: A collection of components which make it easy to display and interact with 3D geometry inside .NET applications.
- **WPF (Windows Presentation Foundation)**: A UI framework for building Windows desktop applications.
- **DirectX 11**: A graphics API used for rendering 3D graphics.
- **SharpDX**: A .NET wrapper for DirectX.
- **Assimp**: A library for importing 3D models.
- **WinUI**: A user interface layer that contains modern controls and styles for Windows apps.
- **Avalonia**: A cross-platform XAML-based UI framework.
