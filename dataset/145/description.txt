## 图类型与用途
这是一个流程图，描述了本地语音助手系统的工作流程，从用户语音输入到用户听到回复的完整过程。该图在仓库中用于展示整个系统的架构和数据流。

## 图的整体布局
图采用从上到下的布局。顶部是用户语音输入，底部是用户听到回复，中间是语音识别、文本转录、对话链和语音合成等处理阶段。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可以分为三个阶段：语音输入与识别、AI 对话生成、语音合成与输出。

## 节点逐项说明
- **🎤 User Speech Input**：用户的语音输入，是整个流程的起点。
- **Speech Recognition<br/>OpenAI Whisper**：语音识别模块，使用 OpenAI 的 Whisper 模型将语音转换为文本。根据 README，Whisper 模型经过大量数据集训练，能够处理多种语言和方言。
- **📝 Text Transcription**：文本转录，是语音识别模块的输出，代表语音识别后的文本内容。
- **Conversational Chain<br/>Langchain + Ollama<br/>Gemma3 / Llama-4 / Other LLMs**：对话链，使用 Langchain 框架和 Ollama 运行本地大语言模型（LLM），例如 Gemma3、Llama-4 或其他 LLM，负责理解用户输入并生成回复。根据 README，Ollama 用于离线运行和部署 LLM。
- **🤖 Generated Response**：生成的回复，是对话链的输出，代表 LLM 生成的文本回复。
- **Speech Synthesizer<br/>Chatterbox TTS**：语音合成器，使用 Chatterbox TTS 模型将文本回复转换为语音。根据 README，Chatterbox TTS 具有语音克隆和情感控制功能。
- **🔊 Audio Output**：语音输出，是语音合成器的输出，代表合成的语音内容。
- **👤 User Hears Response**：用户听到回复，是整个流程的终点，表示用户接收到系统的语音回复。

## 连线、分支与汇聚关系
- `🎤 User Speech Input -> Speech Recognition<br/>OpenAI Whisper`：用户的语音输入进入语音识别模块。
- `Speech Recognition<br/>OpenAI Whisper -> 📝 Text Transcription`：语音识别模块将语音转换为文本转录。
- `📝 Text Transcription -> Conversational Chain<br/>Langchain + Ollama<br/>Gemma3 / Llama-4 / Other LLMs`：文本转录被传递给对话链。
- `Conversational Chain<br/>Langchain + Ollama<br/>Gemma3 / Llama-4 / Other LLMs -> 🤖 Generated Response`：对话链使用 LLM 生成回复。
- `🤖 Generated Response -> Speech Synthesizer<br/>Chatterbox TTS`：生成的回复进入语音合成器。
- `Speech Synthesizer<br/>Chatterbox TTS -> 🔊 Audio Output`：语音合成器将文本回复转换为语音输出。
- `🔊 Audio Output -> 👤 User Hears Response`：用户最终听到语音输出。

## 仓库语境与术语解释
- **OpenAI Whisper**: 用于语音转文本的工具，README 中提到它在各种语言和方言上都表现出色。
- **Langchain**: 用于与 LLM 交互的框架，`app.py` 中使用了 Langchain 的 `ChatPromptTemplate` 和 `RunnableWithMessageHistory`。
- **Ollama**: 用于本地运行 LLM 的工具，README 推荐使用 Ollama 运行 Llama-2 或其他模型。
- **Chatterbox TTS**: 用于文本转语音的工具，README 提到它具有语音克隆和情感控制功能，`tts.py` 文件中定义了 `TextToSpeechService` 类来使用 Chatterbox TTS。
- **Gemma3 / Llama-4 / Other LLMs**: 可选的大语言模型，用于生成回复。
- **`app.py`**: 包含主程序逻辑，包括语音录制、转录、对话链和语音合成。
- **`tts.py`**: 包含 `TextToSpeechService` 类，用于使用 Chatterbox TTS 进行语音合成。

## 可作为 QA Ground Truth 的高信息密度摘要
该图描述了本地语音助手系统的完整流程：用户语音输入首先通过 OpenAI Whisper 进行语音识别，转换为文本转录；然后，文本被传递给基于 Langchain 和 Ollama 的对话链，使用 Gemma3 或 Llama-4 等 LLM 生成回复；最后，生成的回复通过 Chatterbox TTS 进行语音合成，最终用户听到回复。其中，Ollama 负责本地 LLM 运行，Chatterbox TTS 提供语音克隆和情感控制功能。
