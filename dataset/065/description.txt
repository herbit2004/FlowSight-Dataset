## Repository Context & Terminology
- **Hangfire**: An open-source framework that helps you to create, process, and manage your background jobs, delayed tasks, and recurring processes in .NET applications.
- **Entity Framework Core (EF Core)**: A modern object-database mapper for .NET. It supports LINQ queries, change tracking, updates, and schema migrations.
- **Npgsql**: The .NET data provider for PostgreSQL. It allows .NET applications to connect to and interact with PostgreSQL databases.
- **Microsoft.Extensions.***: A set of .NET libraries providing fundamental services such as logging, configuration, dependency injection, and caching.
- **Dapper**: A simple and fast object mapper for .NET, often used for data access.
- **JSON (JavaScript Object Notation)**: A lightweight data-interchange format.
- **Dependency Injection (DI)**: A design pattern that allows decoupling of components by providing dependencies to them instead of having them create dependencies themselves.
