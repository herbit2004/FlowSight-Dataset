## Repository Context & Terminology
- **FSM (Finite State Machine)**: A computational model consisting of a finite number of states, transitions between those states, and actions.
- **activeState**: The current state of the FSM.
- **OnExitRequest()**: A method called on the active state when a transition away from that state is requested.
- **fsm.StateCanExit()**: A method called to determine if the FSM can exit the current state.
- **OnLogic / an event**: Represents the conditions or triggers that initiate the delayed state change.
