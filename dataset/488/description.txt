## Diagram Type & Purpose
This is a flowchart diagram illustrating a software development workflow, from initial user story to production deployment. It outlines the stages, tasks, and reviews involved in taking a feature from conception to release. The diagram serves as a visual representation of the development process, aiding in project management and team coordination.

## Overall Layout
The diagram is laid out in a top-down (TD) direction. It follows a hierarchical structure, starting with a user story and branching out into sub-issues, tasks, and reviews, before converging towards an integration branch and finally, production deployment. The start node is "User Story," and the end node is "Production Deploy."

## Subgraphs / Stages
No explicit subgraphs; logically divided into 6 stages: User Story & Specification, Epic Creation, Sub-Issue Decomposition, Task Assignment & Implementation, Review & Validation, and Integration & Deployment.

## Repository Context & Terminology
- **User Story**: A high-level description of a software feature from the end-user's perspective.
- **BDD (Behavior-Driven Development)**: A software development process based on defining the expected behavior of the system.
- **Epic**: A large user story that can be broken down into smaller tasks.
- **Pull Request (PR)**: A request to merge code changes from a branch into another.
- **Integration Branch**: A branch where all developed features are integrated and tested together.
- **Production Deploy**: The process of deploying the integrated and tested code to the live production environment.
- **Agent**: In this context, the agent refers to the role or team responsible for a particular task.
