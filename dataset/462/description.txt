## 图类型与用途
这是一个流程图，用于指导开发者在 Unity 中使用 DxMessaging 时，根据消息发送的需求选择合适的消息类型。它帮助开发者确定应该使用 `UNTARGETED`、`TARGETED` 还是 `BROADCAST` 消息。

## 图的整体布局
图整体采用从上到下的布局。顶部是流程的起点，中间是两个或三个决策点，底部是三个结果节点。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可分为三个阶段：消息需求判断、发送者判断、接收者/行为判断。

## 节点逐项说明
- **Start (I need to send a message)**：流程的起点，表示开发者需要发送消息。
- **Q1 (Does it matter WHO sent it?)**：第一个决策点，询问是否关心消息的发送者。
- **Q2 (Does it matter WHO receives it?)**：第二个决策点，询问是否关心消息的接收者。只有在不关心发送者的情况下才会进入此决策点。
- **Q3 (Am I commanding someone to act?)**：第三个决策点，询问是否正在命令某人采取行动。只有在关心发送者的情况下才会进入此决策点。
- **Untargeted (Use UNTARGETED Global announcement)**：结果节点，表示使用 `UNTARGETED` 类型的全局广播消息。适用于不关心发送者和接收者的情况。根据 README 和 `docs/concepts/message-types.md`，`UNTARGETED` 消息用于全局通知，任何监听者都可以订阅。
- **Targeted (Use TARGETED Directed command)**：结果节点，表示使用 `TARGETED` 类型的定向命令消息。适用于关心接收者，或者关心发送者且正在命令某人采取行动的情况。根据 README 和 `docs/concepts/message-types.md`，`TARGETED` 消息用于向特定实体发送命令或事件。
- **Broadcast (Use BROADCAST Observable fact)**：结果节点，表示使用 `BROADCAST` 类型的可观察事实消息。适用于关心发送者但不命令某人采取行动的情况。根据 README 和 `docs/concepts/message-types.md`，`BROADCAST` 消息用于从特定源发出事件，供任何监听者观察。

## 连线、分支与汇聚关系
- `Start -> Q1`：流程从起点开始，进入第一个决策点。
- `Q1 -- No --> Q2`：如果不关心消息的发送者，则进入第二个决策点。
- `Q1 -- Yes --> Q3`：如果关心消息的发送者，则进入第三个决策点。
- `Q2 -- No --> Untargeted`：如果不关心消息的接收者，则使用 `UNTARGETED` 消息。
- `Q2 -- Yes --> Targeted`：如果关心消息的接收者，则使用 `TARGETED` 消息。
- `Q3 -- Yes --> Targeted`：如果正在命令某人采取行动，则使用 `TARGETED` 消息。
- `Q3 -- No --> Broadcast`：如果不是在命令某人采取行动，则使用 `BROADCAST` 消息。
- `Q2 -- Yes --> Targeted` 和 `Q3 -- Yes --> Targeted` 形成汇聚关系。

## 仓库语境与术语解释
- **DxMessaging**：一个类型安全的消息系统，用于替换 C# 事件、UnityEvents 和全局静态事件总线。
- **UNTARGETED**：全局广播消息，用于发送全局通知，如游戏暂停或设置更改。对应 `DxUntargetedMessageAttribute`，参见 `Runtime/Core/Attributes/DxUntargetedMessageAttribute.cs`。
- **TARGETED**：定向命令消息，用于向特定实体发送命令，如治疗玩家或打开门。对应 `DxTargetedMessageAttribute`，参见 `Runtime/Core/Attributes/DxTargetedMessageAttribute.cs`。
- **BROADCAST**：可观察事实消息，用于从特定源发出事件，如敌人死亡或拾取物品。对应 `DxBroadcastMessageAttribute`，参见 `Runtime/Core/Attributes/DxBroadcastMessageAttribute.cs`。
- **MessageBus**：消息总线，用于处理消息的注册和分发。参见 `Runtime/Core/MessageBus/IMessageBus.cs`。
- **InstanceId**：用于标识消息的目标对象，例如 GameObject 或 Component。
- **MessageAwareComponent**：Unity 组件，用于自动管理消息的订阅和取消订阅。

## 可作为 QA Ground Truth 的高信息密度摘要
该流程图从“需要发送消息”开始，首先判断是否关心消息的发送者，如果不关心，则判断是否关心消息的接收者，从而选择 `UNTARGETED` 或 `TARGETED` 消息类型；如果关心消息的发送者，则判断是否正在命令某人采取行动，从而选择 `TARGETED` 或 `BROADCAST` 消息类型。`UNTARGETED` 消息用于全局通知，`TARGETED` 消息用于向特定实体发送命令，`BROADCAST` 消息用于从特定源发出事件。该图旨在帮助开发者根据消息发送的需求选择合适的 DxMessaging 消息类型。
