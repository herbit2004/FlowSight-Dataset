## 图类型与用途
该图是一个流程图，描述了合同从起草到归档的完整审核和签署流程。图中展示了合同在不同部门和环节之间的流转，以及审核不通过时返回修改的路径。

## 图的整体布局
图的布局是从上到下，整体呈现一个循环流程。流程从发起方起草合同开始，最终到合同归档结束。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可分为以下阶段：
1. 合同起草阶段
2. 内部审核阶段（合同审核、法务部合同审查）
3. 外部审核阶段（对方审核）
4. 合同签署阶段
5. 合同归档阶段

## 节点逐项说明
- **A[发起方: 起草合同]**: 合同流程的起始节点，由发起方负责起草合同。
- **B{合同审核}**: 对合同进行初步审核的环节，判断合同是否符合基本要求。
- **C[法务部: 合同审查]**: 由法务部门对合同进行法律层面的审查。
- **D{对方审核}**: 将合同发送给对方进行审核的环节。
- **E[签约方: 合同签署]**: 合同审核通过后，由签约方进行合同签署。
- **F[合同归档]**: 合同签署完成后，进行合同归档。

## 连线、分支与汇聚关系
- A -> B: 发起方起草合同后，进入合同审核环节。
- B -- 通过 --> C: 合同审核通过后，进入法务部合同审查环节。
- B -- 驳回 --> A: 合同审核不通过，返回发起方重新起草合同。
- C -- 通过 --> D: 法务部合同审查通过后，进入对方审核环节。
- C -- 驳回 --> A: 法务部合同审查不通过，返回发起方重新起草合同。
- D -- 通过 --> E: 对方审核通过后，进入合同签署环节。
- D -- 驳回 --> A: 对方审核不通过，返回发起方重新起草合同。
- E -> F: 合同签署完成后，进入合同归档环节。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **合同**：一种具有法律约束力的协议，用于明确各方权利和义务。
- **审核**：对合同内容进行检查和评估，确保其符合相关规定和要求。
- **法务部**：负责法律事务的部门，对合同进行法律层面的审查。
- **签约方**：参与合同签署的各方。
- **归档**：将合同进行整理和保存，以便日后查阅和使用。

## 可作为 QA Ground Truth 的高信息密度摘要
合同流程从发起方起草合同开始，经过合同审核，若通过则进入法务部合同审查；若未通过，则返回发起方。法务部审查通过后，进入对方审核，不通过则返回发起方。对方审核通过后，进入合同签署环节，最终完成合同归档。整个流程中，任何审核环节的驳回都会导致合同返回发起方重新起草。
