## Edges, Branches & Convergence
- `Start --> Entry`: User query is passed for initial processing.
- `Entry --> ChunkEngine`: Processed user message is chunked and embedded.
- `ChunkEngine --> ParallelStart`: Chunked input triggers the launch of parallel tasks.
- `ParallelStart --> Scribe`: Task 1: Fire-and-Forget triggers the Scribe Agent.
- `Scribe --> UserProfile`: Scribe Agent updates the User Profile JSON.
- `ParallelStart --> FactScrubber`: Task 2: Async triggers the FactScrubber.
- `FactScrubber --> FactStore`: FactScrubber extracts key-value pairs and stores them in Fact Store SQL.
- `ParallelStart --> Crawler`: Task 3: Retrieval triggers the LatticeCrawler.
- `Crawler --> Candidates`: LatticeCrawler retrieves raw candidates.
- `Candidates --> Governor`: Raw candidates are passed to the Governor for routing and filtering.
- `ParallelStart --> Governor`: Task 4: Main Logic triggers the Governor.
- `Governor --> ValidatedMems`: Key 2: Context Filter filters the memories.
- `Governor --> Decision`: Routing Logic triggers the Routing Decision.
- `Decision -- Active Topic --> ResumeBlock`: If the topic is active, resume the bridge block.
- `Decision -- New Topic --> CreateBlock`: If the topic is new, create a bridge block.
- `ResumeBlock --> Hydrator`: Resume bridge block is passed to the ContextHydrator.
- `CreateBlock --> Hydrator`: Create bridge block is passed to the ContextHydrator.
- `ValidatedMems --> Hydrator`: Truly Relevant Memories are passed to the ContextHydrator.
- `FactStore --> Hydrator`: Fact Store SQL data is passed to the ContextHydrator.
- `UserProfile --> Hydrator`: User Profile JSON data is passed to the ContextHydrator.
- `Hydrator --> FinalPrompt`: ContextHydrator creates the final LLM prompt.
- `FinalPrompt --> MainLLM`: Final LLM prompt is passed to the Response Generation.
- `MainLLM --> End`: Response Generation completes and the process ends.

- **LatticeCrawler**: A component responsible for crawling and retrieving information from various sources.
- **Governor**: A component that acts as a router and filter, deciding which information is relevant and how to route the process.
- **FactScrubber**: A component that extracts key-value pairs from the context.
- **Scribe Agent**: A component responsible for updating the user profile.
- **ContextHydrator**: A component that combines various pieces of information to create a comprehensive context for the LLM.
- **LLM (Large Language Model)**: A powerful language model used for generating responses.
