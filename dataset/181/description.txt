## Repository Context & Terminology
- **Frontend**: The client-side part of the application, typically built with React.
- **Backend**: The server-side part of the application, typically built with Django.
- **React**: A JavaScript library for building user interfaces.
- **Django**: A high-level Python web framework that encourages rapid development and clean, pragmatic design.
- **Django Rest Framework**: A powerful and flexible toolkit for building Web APIs.
- **REST API**: An architectural style for designing networked applications.
- **Models**: Data structures that define the data stored in the application. In Django, models are Python classes that inherit from `django.db.models.Model`.
- **Views**: Functions or classes that handle HTTP requests and return HTTP responses. In Django, views retrieve data from models and render templates.
- **Templates**: Files that contain the HTML structure of the web pages. Django templates allow embedding dynamic content using template tags and variables.
- **API Key**: A secret key used to authenticate requests to the API.
