## 图类型与用途
这是一个架构图，展示了 Django、React 和 TypeScript 项目的前后端架构关系。它在仓库中用于概览整个项目的技术栈和模块间的交互方式。

## 图的整体布局
图采用从上到下的布局，顶部是前端和后端的高层抽象，中间是具体的技术栈和组件，底部是数据和 API 相关的节点。整体呈现一种分层结构，从宏观到微观地展示了应用架构。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为前端、后端和共享资源三个部分。前端部分主要涉及 React 和环境变量，后端部分涉及 Django 和 Django Rest Framework，共享资源部分包括 API Client、REST API、Models 和 Templates。

## 节点逐项说明
- **Frontend**：代表整个前端应用，使用 React 构建用户界面。
- **React**：前端框架，负责用户界面和交互。README 提到项目使用 React 18。
- **Env. variables**：存储前端需要的配置信息，例如 API 密钥。
- **Backend**：代表整个后端应用，使用 Django 处理业务逻辑。
- **Django**：后端框架，负责处理业务逻辑、数据存储和 API。README 提到项目使用 Django 5。
- **Django Rest Framework**：Django 的一个扩展，用于构建 RESTful API。
- **Views**：Django 视图，处理 HTTP 请求并返回响应。
- **Templates**：Django 模板，用于生成 HTML 页面。
- **Models**：Django 模型，定义数据结构和数据库交互。
- **API Client**：前端用于与后端 API 交互的客户端。
- **Root Container**：React 应用的根容器，是所有 React 组件的父组件。
- **API Key**：用于身份验证的 API 密钥。
- **Publications**：代表存储在数据库中的出版物数据。`backend/models/publications.py` 定义了 Publication 模型。
- **REST API**：后端提供的 RESTful API 接口。

## 连线、分支与汇聚关系
- `Frontend --> React & Env. variables`：前端依赖于 React 框架和环境变量。
- `Backend --> Django & Django Rest Framework`：后端依赖于 Django 框架和 Django Rest Framework。
- `Django --> Views & Templates & Models`：Django 框架包含视图、模板和模型。
- `Views --> Templates`：视图负责渲染模板。
- `React --> API Client & Root Container`：React 应用使用 API 客户端和根容器。
- `Models --> API Key & Publications`：模型定义了 API 密钥和出版物数据的结构。
- `Root Container -- Mounts on same file from Django templates --> Templates`：React 根容器挂载在 Django 模板中的同一个文件中，实现前后端集成。
- `Env. variables -.-> API Key & API Client`：环境变量为 API 密钥和 API 客户端提供配置信息。
- `Django Rest Framework -- Provides a REST endpoint to manipulate data from models --> REST API`：Django Rest Framework 提供 REST API 接口来操作模型中的数据。
- `REST API --> Publications`：REST API 用于访问和操作出版物数据。
- `API Client -- Consumes API Key to authenticate with backend --> REST API`：API 客户端使用 API 密钥向后端 REST API 进行身份验证。

## 仓库语境与术语解释
- **Frontend**: 指的是使用 React 构建的前端部分，负责用户界面和交互。
- **Backend**: 指的是使用 Django 构建的后端部分，负责处理业务逻辑、数据存储和 API。
- **React**: 一个流行的 JavaScript 库，用于构建用户界面。该项目使用 React 18。
- **Django**: 一个高级 Python Web 框架，用于快速开发 Web 应用。该项目使用 Django 5。
- **Django Rest Framework**: 一个强大的工具包，用于构建 Web API。
- **Publications**: 指的是存储在数据库中的出版物数据，`backend/models/publications.py` 定义了 Publication 模型。
- **API Key**: 用于身份验证的 API 密钥，用于前端与后端进行安全通信。
- **Env. variables**: 环境变量，用于存储配置信息，例如 API 密钥。`frontend/.env.example` 提供了一个示例。

## 可作为 QA Ground Truth 的高信息密度摘要
该架构图展示了一个 Django + React 前后端分离的应用架构。前端使用 React 和环境变量，后端使用 Django 和 Django Rest Framework。前端通过 API Client 和 Root Container 与后端交互，后端通过 Views, Templates 和 Models 处理请求。Django Rest Framework 提供了 REST API 接口来操作 Publications 数据，前端通过 API Key 进行身份验证。整体架构清晰地展示了前后端之间的依赖关系和数据流向，其中 API Key 和 Publications 是两个关键的数据节点。
