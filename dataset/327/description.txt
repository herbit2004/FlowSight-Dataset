## Diagram Type & Purpose
This is an architecture diagram illustrating the high-level components and data flow within a software system. It depicts the interaction between UI elements, renderer processes, IPC communication, main process services, and external services. The diagram serves as a visual representation of the system's architecture, aiding in understanding the relationships and dependencies between different modules.

## Repository Context & Terminology
- **LSP (Language Server Protocol)**: A protocol used between a code editor or IDE and a language server that provides language-specific features like autocomplete, go to definition, find all references, etc.
- **MCP**: visible in diagram; no further repository context available.
- **LanceDB**: visible in diagram; no further repository context available.
- **LLM (Large Language Model)**: A large neural network trained on a massive amount of text data, capable of generating human-like text, translating languages, and answering questions.
- **IPC (Inter-Process Communication)**: Mechanisms that allow different processes to communicate with each other.
- **Web Workers**: A simple means for web content to run scripts in background threads. This allows you to perform processing tasks without interrupting the user interface.
- **Renderer Process**: In Electron, the renderer process is responsible for rendering the user interface of the application.
