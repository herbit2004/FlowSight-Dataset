## 图类型与用途
这是一个架构图，展示了 AutoMem 系统的核心组件和服务之间的数据流。AutoMem 是一个为 AI 助手设计的长期记忆系统，该图旨在说明 AutoMem 如何存储、回忆和关联记忆。

## 图的整体布局
图采用从上到下的布局。顶部是 AI Client，中间是 AutoMem Service Flask，底部是 Dual Storage Layer。数据流从客户端开始，经过服务层，最终到达存储层。

## 分组/子图/阶段说明
图中包含两个子图：
- **AutoMem Service Flask**：表示 AutoMem 的核心服务，包含 REST API、Background Enrichment Pipeline、Consolidation Engine 和 Automated Backups 等组件。
- **Dual Storage Layer**：表示双重存储结构，包含 FalkorDB (Graph Database) 和 Qdrant (Vector Database)。

## 节点逐项说明
- **AI Client**：代表使用 AutoMem 服务的 AI 助手或其他客户端应用。
- **REST API**：提供 RESTful API 接口，用于处理记忆的存储、回忆和关联等生命周期管理。
- **Background Enrichment Pipeline**：后台富化管道，负责从原始数据中提取更多信息，并将其添加到记忆中。根据 README，该 Pipeline 运行实体提取、自动标签、摘要、时间链接、语义邻居和模式检测。
- **Consolidation Engine**：巩固引擎，负责整理和优化存储的记忆，可能包括删除冗余信息或合并相关记忆。
- **Automated Backups**：自动备份组件，可选，用于定期备份存储的数据。
- **FalkorDB**：图数据库，用于存储记忆之间的关系和模式。根据 README，FalkorDB 用于存储规范记录、关系和巩固信息。
- **Qdrant**：向量数据库，用于存储记忆的语义向量，支持语义搜索。根据 README，Qdrant 用于语义回忆和相似性搜索。

## 连线、分支与汇聚关系
- `AI Client -> API`：AI 客户端通过 REST API 与 AutoMem 服务交互，进行记忆的存储、回忆和关联操作。
- `API -> FalkorDB`：API 将数据写入图数据库 FalkorDB。
- `API -> Qdrant`：API 将数据写入向量数据库 Qdrant。
- `Enrichment -> FalkorDB`：富化管道将提取的信息写入 FalkorDB，包括 11 种边类型和模式节点。
- `Enrichment -> Qdrant`：富化管道将提取的信息写入 Qdrant，用于语义搜索，存储 3072 维向量。
- `Consolidation -> FalkorDB`：巩固引擎对 FalkorDB 中的数据进行整理和优化。
- `Consolidation -> Qdrant`：巩固引擎对 Qdrant 中的数据进行整理和优化。
- `Backups -.-> FalkorDB`：备份组件可选地备份 FalkorDB 中的数据。
- `Backups -.-> Qdrant`：备份组件可选地备份 Qdrant 中的数据。

## 仓库语境与术语解释
- **AutoMem**：一个为 AI 助手设计的长期记忆系统，旨在让 AI 助手能够记住、连接和发展他们的理解。
- **FalkorDB**：图数据库，用于存储记忆之间的关系和模式，支持关系建模。
- **Qdrant**：向量数据库，用于存储记忆的语义向量，支持语义搜索。
- **Dual Storage Layer**：AutoMem 结合了 FalkorDB 和 Qdrant 两种存储系统，利用图数据库的关系建模能力和向量数据库的语义搜索能力。
- **Enrichment Pipeline**：在后台自动增强每个记忆，包括实体提取、自动标签、摘要、时间链接、语义邻居和模式检测。
- **Consolidation Engine**：使用神经科学启发的巩固周期来保持记忆的相关性，包括衰减、创造、聚类和遗忘。
- **REST API**：AutoMem 服务的核心接口，客户端通过该 API 进行记忆的存储、回忆和关联操作。

## 可作为 QA Ground Truth 的高信息密度摘要
AutoMem 架构的核心在于通过双重存储层（FalkorDB 和 Qdrant）来增强 AI 助手的记忆能力。AI 客户端通过 REST API 与 AutoMem 服务交互，存储和检索记忆。后台富化管道不断地从原始数据中提取更多信息，并将其添加到记忆中，从而提高记忆的质量。巩固引擎负责整理和优化存储的记忆，保持记忆的有效性。可选的备份组件确保数据的安全性。
