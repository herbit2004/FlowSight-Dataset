## Diagram Type & Purpose
This is an architecture diagram depicting the high-level components and data flow within a multi-provider AI system integrated with ServiceNow. It illustrates the interaction between the frontend, authentication, backend services, a multi-provider AI layer, and ServiceNow. The diagram serves as a blueprint for understanding the system's architecture and how different components interact to deliver AI-powered services.

## Overall Layout
The diagram is laid out from top to bottom (TB). It is hierarchically structured, with distinct subgraphs representing different layers and integrations. The start nodes are "Next.js 15 App" and "API Routes", and the end nodes are "PostgreSQL" and "ServiceNow Instance".

## Subgraphs / Stages
The diagram contains the following subgraphs:
- **Frontend Layer**: Represents the user interface components built with Next.js and React.
- **Authentication Layer**: Handles user authentication using JWT middleware and session management.
- **Backend Services**: Provides API endpoints, streaming services, workflow orchestration, AI processing, and data storage.
- **Multi-Provider AI Layer**: Manages multiple AI providers and routes requests to appropriate agents.
- **ServiceNow Integration**: Integrates the system with ServiceNow through a helper application and staging tables.
