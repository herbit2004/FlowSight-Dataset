## 图类型与用途
这是一个流程图，描述了 Telegram 消息如何通过 Cloudflare Tunnel 和 Bridge Server 传递给 Claude Code，以及 Claude Code 的响应如何返回给 Telegram。该图在仓库的 README.md 文件中，用于概括 `claudecode-telegram` 项目的工作原理。

## 图的整体布局
图采用从左到右的布局。流程从 Telegram 开始，经过一系列中间组件，最终将响应返回给 Telegram。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为三个阶段：消息接收与转发、Claude Code 处理、响应发送。

## 节点逐项说明
- **A[Telegram]**: 代表 Telegram 平台，用户通过 Telegram 与机器人进行交互。
- **B[Cloudflare Tunnel]**: 代表 Cloudflare Tunnel，用于将本地的 Bridge Server 暴露到互联网，使得 Telegram 可以访问它。
- **C[Bridge Server]**: 代表桥接服务器，负责接收来自 Telegram 的 Webhook 请求，并将消息注入到 Claude Code 中。
- **D[Claude Code]**: 代表 Claude Code，是实际运行的代码生成和对话模型。
- **E[Read Transcript]**: 代表读取转录的过程，由 Stop Hook 触发，用于读取 Claude Code 的输出（对话记录）。

## 连线、分支与汇聚关系
- `A[Telegram] --> B[Cloudflare Tunnel]`：Telegram 将消息发送到 Cloudflare Tunnel。
- `B[Cloudflare Tunnel] --> C[Bridge Server]`：Cloudflare Tunnel 将消息转发到 Bridge Server。
- `C[Bridge Server] -->|tmux send-keys| D[Claude Code]`：Bridge Server 使用 `tmux send-keys` 命令将消息注入到 Claude Code 中。
- `D[Claude Code] -->|Stop Hook| E[Read Transcript]`：Claude Code 完成响应时，Stop Hook 被触发，触发 Read Transcript 过程。
- `E[Read Transcript] -->|Send Response| A[Telegram]`：Read Transcript 将响应发送回 Telegram。

## 仓库语境与术语解释
- **Telegram Bot Token**: 环境变量 `TELEGRAM_BOT_TOKEN`，用于 Telegram 机器人与 Telegram API 进行身份验证。
- **Cloudflare Tunnel**: 用于将本地服务暴露到公网，避免直接暴露端口。
- **Bridge Server**: 运行 `bridge.py` 脚本的服务器，负责接收 Telegram Webhook 并与 Claude Code 交互。
- **tmux**: 一个终端复用器，用于保持 Claude Code 持续运行，Bridge Server 通过 `tmux send-keys` 命令向 Claude Code 发送消息。
- **Stop Hook**: Claude Code 完成响应后触发的脚本，用于读取 Claude Code 的输出并发送回 Telegram。对应 `hooks/send-to-telegram.sh` 脚本。
- **Read Transcript**: 读取 Claude Code 输出的过程，从转录文件中提取 Claude Code 的响应。
- `bridge.py`: 该文件是桥接服务器的主要代码，负责接收 Telegram Webhooks，并将消息注入到 Claude Code 中。

## 可作为 QA Ground Truth 的高信息密度摘要
该图描述了 Telegram 消息通过 Cloudflare Tunnel 到 Bridge Server，再通过 `tmux send-keys` 命令注入到 Claude Code 的流程。Claude Code 响应后，Stop Hook 触发 Read Transcript 过程，最终将响应发送回 Telegram。其中，Cloudflare Tunnel 用于暴露本地服务，Bridge Server 负责消息转发，tmux 用于保持 Claude Code 运行，而 Stop Hook 和 Read Transcript 负责提取 Claude Code 的响应。
