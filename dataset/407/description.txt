## Repository Context & Terminology
- **FIFO (First-In, First-Out)**: A data structure that follows the principle of "first in, first out," where the first element added to the queue is the first one to be removed.
- **BRAM (Block RAM)**: On-chip memory blocks available in FPGAs (Field-Programmable Gate Arrays) that can be used to store data.
- **Flip-Flop (FF)**: A basic building block of digital circuits that stores one bit of information. Flip-Flops are used to implement registers and memory elements.
- **Mapping Success**: Refers to whether a FIFO can be efficiently implemented using BRAM resources.
- **Resource Usage**: The amount of hardware resources (e.g., Flip-Flops, BRAM) consumed by a particular implementation.
