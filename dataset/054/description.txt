## 图类型与用途
这是一个流程图，展示了使用 Gemini 和 Claude Code 这两种 AI 工具进行软件开发的流程，并突出了使用这些工具带来的潜在成本节约。该图在仓库中用于说明如何通过结合使用免费和付费 AI 工具来优化开发成本。

## 图的整体布局
图采用从左到右的布局。流程从项目规划开始，经过引用和代码实现，最终达到节省成本的目标。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为三个阶段：项目规划、代码实现和成本节约。

## 节点逐项说明
- **Plan with Gemini FREE**：表示使用 Gemini 进行项目规划，且该规划是免费的。根据 `advanced/tip-money-saving-strategy/guide.md`，Gemini 2.5 Pro Preview 可用于项目规划和架构设计。
- **Reference with @ tags**：表示在规划阶段，使用 `@` 标签来引用相关信息、文档或资源。`advanced/tip-money-saving-strategy/guide.md` 中提到可以使用 `@` 标签在 prompts 中引用 planning files。
- **Implement with Claude Code Pay-per-use**：表示使用 Claude Code 进行代码实现，且使用 Claude Code 是按使用量付费的。`advanced/tip-money-saving-strategy/guide.md` 说明可以使用 Claude Code extension 进行代码实现。
- **Save $240/year**：表示通过使用 Gemini 和 Claude Code 这种方式，每年可以节省 240 美元。

## 连线、分支与汇聚关系
- `Plan with Gemini FREE -> Reference with @ tags`：使用 Gemini 进行项目规划后，在规划阶段使用 `@` 标签进行引用。
- `Reference with @ tags -> Implement with Claude Code Pay-per-use`：在规划阶段完成引用后，使用 Claude Code 进行代码实现。
- `Implement with Claude Code Pay-per-use -> Save $240/year`：通过使用 Gemini 和 Claude Code，最终可以节省成本。

## 仓库语境与术语解释
- **Gemini**：指 Google 提供的 AI 模型，在此处特指 Gemini 2.5 Pro Preview，用于项目规划。
- **Claude Code**：指 Anthropic 提供的代码生成工具，在此处通过 Claude Code extension 在 Cursor IDE 中使用。
- **@ tags**：用于在 prompts 中引用 planning files，以便 Claude Code 可以参考规划内容进行代码实现。
- **Cursor IDE**：一个支持 AI 辅助开发的集成开发环境，该仓库的 README 说明了其作用。
- `advanced/tip-money-saving-strategy/guide.md`：该文件提供了在 Cursor IDE 中设置和使用 Claude Code extension 的完整指南，作为一种省钱策略。

该图展示了使用 Gemini 和 Claude Code 进行软件开发的流程。首先使用免费的 Gemini 进行项目规划，然后在规划过程中使用 `@` 标签进行引用，最后使用按需付费的 Claude Code 进行代码实现，从而节省成本。核心主线是“Gemini 规划 -> @ 标签引用 -> Claude Code 实现 -> 节省成本”，其中 `@` 标签引用是关键中间环节，`advanced/tip-money-saving-strategy/guide.md` 提供了详细的设置指南。
