## Repository Context & Terminology
- **BlueALSA**: An advanced Linux sound architecture (ALSA) Bluetooth audio backend.
- **ALSA (Advanced Linux Sound Architecture)**: A Linux kernel component providing an API for sound card drivers.
- **D-Bus**: A message bus system, a software bus for inter-process communication.
- **bluetoothd**: The Bluetooth daemon, responsible for managing Bluetooth connections.
- **bluealsad**: The BlueALSA daemon, which bridges Bluetooth audio and ALSA.
- **bluealsactl**: A control utility for BlueALSA.
- **bluealsa-aplay**: A utility for playing audio through BlueALSA.
- **ALSA libasound**: The ALSA library used for audio input/output.
