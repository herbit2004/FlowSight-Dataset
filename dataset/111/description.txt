## 图类型与用途
这是一个流程图，旨在帮助用户诊断和解决在使用 Camoufox 时遇到的网站反爬虫问题。它通过一系列的是/否问题，引导用户逐步缩小问题范围，最终找到导致反爬虫机制触发的原因。Camoufox 是一个定制的 Firefox 版本，用于网页抓取和反检测，如 README 所述。

## 图的整体布局
图整体采用从上到下的布局。流程从顶部的“Start”节点开始，通过一系列判断节点，最终到达不同的问题解决方案节点。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可分为以下几个阶段：
1. **初步诊断**：判断是否是官方 Firefox 就存在问题。
2. **Camoufox 基础配置测试**：测试干净的 Camoufox 版本在 headless 模式下是否被标记。
3. **高级配置与调试**：涉及 `config.patch`、`privacy.resistFingerprinting`、FPP 等配置的调整。
4. **Playwright 相关问题排查**：如果使用了 Playwright，则排查相关补丁的影响。
5. **最终手段**：反混淆 JavaScript 代码，或逐个删除 `camoufox.cfg` 中的选项。

## 节点逐项说明
- **A (Start)**：流程的起点。
- **B (Does website flag in the official Firefox?)**：网站是否在官方 Firefox 浏览器中就被标记为爬虫？
- **C (Likely bad IP/rate-limiting. If the website fails on both headless and headful mode on the official Firefox distribution, the issue is not with the browser.)**：如果官方 Firefox 也被标记，很可能是 IP 地址问题或频率限制，问题不在浏览器本身。
- **D ("Run make ff-dbg(1) and build(2) a clean distribution of Firefox. Does the website flag in Firefox **headless** mode(4)?")**：使用 `make ff-dbg` 构建一个干净的 Firefox 版本，并在无头模式下运行。网站是否被标记？`make ff-dbg` 是 Makefile 中定义的一个目标，用于构建带有调试符号的 Firefox 版本。
- **E ("Does the website flag in headful mode(3) AND headless mode(4)?")**：网站是否在有头模式和无头模式下都被标记？
- **F ("Open the developer UI(5), apply config.patch, then rebuild(2). Does the website still flag(3)?")**：打开开发者 UI，应用 `config.patch`，然后重新构建。网站是否仍然被标记？`config.patch` 可能是用于修改 Firefox 默认配置的补丁文件，图中可见，但仓库上下文未进一步说明。
- **G ("Enable privacy.resistFingerprinting in the config(6). Does the website still flag(3)?")**：在配置中启用 `privacy.resistFingerprinting`。网站是否仍然被标记？`privacy.resistFingerprinting` 是 Firefox 的一个隐私设置，用于抵抗指纹识别，图中可见，但仓库上下文未进一步说明。
- **H ("In the config(6), enable FPP and start omitting overrides until you find the one that fixed the leak.")**：在配置中启用 FPP (Fingerprint Protection)，并逐步删除覆盖设置，直到找到修复泄漏的设置。FPP 指纹保护，图中可见，但仓库上下文未进一步说明。
- **I (If you get to this point, you may need to deobfuscate the Javascript behind the website to identify what it's testing.)**：如果到了这一步，可能需要反混淆网站的 JavaScript 代码，以确定它正在测试什么。
- **J ("Omit options from camoufox.cfg(6) and rerun(3) until you find the one causing the leak.")**：从 `camoufox.cfg` 中删除选项，并重新运行，直到找到导致泄漏的选项。`camoufox.cfg` 可能是 Camoufox 的配置文件，用于定制浏览器行为。
- **K ("Open the developer UI, apply the playwright bootstrap patch, then rebuild. Does it still flag?")**：打开开发者 UI，应用 Playwright 引导补丁，然后重新构建。网站是否仍然被标记？
- **L (The issue has nothing to do with Playwright. Apply the rest of the Camoufox patches one by one until the one causing the leak is found.)**：问题与 Playwright 无关，逐个应用剩余的 Camoufox 补丁，直到找到导致泄漏的补丁。
- **M (Juggler needs to be debugged to locate the leak.)**：需要调试 Juggler 以定位泄漏。Juggler 是 Camoufox 的一个组件，可能用于处理浏览器指纹或网络请求。

## 连线、分支与汇聚关系
- `A -> B`：流程从起点开始，进入第一个判断节点。
- `B -- Yes --> C`：如果网站在官方 Firefox 中就被标记，则问题很可能是 IP 地址或频率限制。
- `B -- No --> D`：如果网站在官方 Firefox 中没有被标记，则进入 Camoufox 基础配置测试阶段。
- `D -- Yes --> E`：如果网站在 headless 模式下被标记，则进入下一个判断节点。
- `D -- No --> F`：如果网站在 headless 模式下没有被标记，则进入 `config.patch` 相关测试。
- `E -- No --> G`：如果网站只在 headless 模式下被标记，则启用 `privacy.resistFingerprinting`。
- `E -- Yes --> C`：如果网站在有头和无头模式下都被标记，则问题很可能是 IP 地址或频率限制，形成汇聚关系。
- `G -- No --> H`：如果启用 `privacy.resistFingerprinting` 后问题解决，则启用 FPP 并逐步删除覆盖设置。
- `G -- Yes --> I`：如果启用 `privacy.resistFingerprinting` 后问题仍然存在，则可能需要反混淆 JavaScript 代码。
- `F -- Yes --> K`：如果应用 `config.patch` 后问题仍然存在，则进入 Playwright 相关问题排查。
- `F -- No --> J`：如果应用 `config.patch` 后问题解决，则逐个删除 `camoufox.cfg` 中的选项。
- `K -- No --> M`：如果应用 Playwright 引导补丁后问题解决，则需要调试 Juggler。
- `K -- Yes --> L`：如果应用 Playwright 引导补丁后问题仍然存在，则问题与 Playwright 无关，逐个应用剩余的 Camoufox 补丁。
- `M --> I`：调试 Juggler 后，如果问题仍然存在，则可能需要反混淆 JavaScript 代码，形成汇聚关系。

## 仓库语境与术语解释
- **Camoufox**：一个定制的 Firefox 版本，用于网页抓取和反检测，旨在避免被网站的反爬虫机制检测到，如 README 所述。
- **headless mode**：无头模式，指在没有图形用户界面的情况下运行浏览器。
- **config.patch**：用于修改 Firefox 默认配置的补丁文件，图中可见，但仓库上下文未进一步说明。
- **privacy.resistFingerprinting**：Firefox 的一个隐私设置，用于抵抗指纹识别，图中可见，但仓库上下文未进一步说明。
- **FPP (Fingerprint Protection)**：指纹保护，图中可见，但仓库上下文未进一步说明。
- **camoufox.cfg**：Camoufox 的配置文件，用于定制浏览器行为。
- **Juggler**：Camoufox 的一个组件，可能用于处理浏览器指纹或网络请求。`additions/juggler/` 目录下包含 Juggler 相关的代码文件。
- **Makefile**：用于自动化构建过程，包含 `make ff-dbg` 等目标，用于构建不同版本的 Camoufox。
