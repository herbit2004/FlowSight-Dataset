## Edges, Branches & Convergence
- `Start --> Init`: Starts the process and initializes context.
- `Init --> CheckBudget`: Checks if the token budget has been exceeded.
- `CheckBudget -- Yes --> BeastMode`: If the token budget is exceeded, enter Beast Mode.
- `CheckBudget -- No --> GetQuestion`: If the token budget is not exceeded, get the current question.
- `GetQuestion --> GenPrompt`: Generates a prompt.
- `GenPrompt --> ModelGen`: Generates a response using Gemini.
- `ModelGen --> ActionCheck`: Checks the action type.
- `ActionCheck -- answer --> AnswerCheck`: If the action type is 'answer', check if it's the original question.
- `ActionCheck -- reflect --> ProcessQuestions`: If the action type is 'reflect', process new sub-questions.
- `ActionCheck -- search --> SearchQuery`: If the action type is 'search', execute a search query.
- `ActionCheck -- visit --> VisitURLs`: If the action type is 'visit', visit URLs.
- `AnswerCheck -- Yes --> EvalAnswer`: If it's the original question, evaluate the answer.
- `AnswerCheck -- No --> StoreKnowledge`: If it's not the original question, store as intermediate knowledge.
- `EvalAnswer --> IsGoodAnswer`: Checks if the answer is definitive.
- `IsGoodAnswer -- Yes --> HasRefs`: If the answer is definitive, check for references.
- `IsGoodAnswer -- No --> StoreBad`: If the answer is not definitive, store the bad attempt and reset context.
- `HasRefs -- Yes --> End`: If there are references, the process ends.
- `HasRefs -- No --> GetQuestion`: If there are no references, get the current question.
- `ProcessQuestions --> DedupQuestions`: Processes new sub-questions and checks for unique questions.
- `DedupQuestions -- Yes --> AddGaps`: If there are new unique questions, add them to the gaps queue.
- `DedupQuestions -- No --> DisableReflect`: If there are no new unique questions, disable reflection for the next step.
- `SearchQuery --> NewURLs`: Executes a search query and checks if new URLs were found.
- `NewURLs -- Yes --> StoreURLs`: If new URLs were found, store them for future visits.
- `NewURLs -- No --> DisableSearch`: If no new URLs were found, disable search for the next step.
- `VisitURLs --> NewContent`: Visits URLs and checks if new content was found.
- `NewContent -- Yes --> StoreContent`: If new content was found, store it as knowledge.
- `NewContent -- No --> DisableVisit`: If no new content was found, disable visiting for the next step.
- `StoreBad --> GetQuestion`: After storing a bad attempt, get the current question.
- `StoreKnowledge --> GetQuestion`: After storing intermediate knowledge, get the current question.
- `AddGaps --> GetQuestion`: After adding to the gaps queue, get the current question.
- `DisableReflect --> GetQuestion`: After disabling reflection, get the current question.
- `StoreURLs --> GetQuestion`: After storing URLs, get the current question.
- `DisableSearch --> GetQuestion`: After disabling search, get the current question.
- `StoreContent --> GetQuestion`: After storing content, get the current question.
- `DisableVisit --> GetQuestion`: After disabling visiting, get the current question.
- `BeastMode --> FinalAnswer`: Enters Beast Mode and generates the final answer.
- `FinalAnswer --> End`: Generates the final answer and ends the process.

## Repository Context & Terminology

- **Gaps Queue**: A queue of questions or information gaps that need to be addressed.
- **Beast Mode**: A special mode, likely for handling difficult or complex questions, potentially involving more aggressive search or reasoning strategies.
