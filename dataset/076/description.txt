## 图类型与用途
这是一个系统架构图，展示了 5G NR SSB 信号扫描器（5G-Scanner）的整体架构，包括 Web 界面层、核心应用层、数据存储层、硬件层和射频与网络层。该图在仓库中用于概括系统的模块组成和数据流向。

## 图的整体布局
图整体采用从上到下的布局。顶部是 Web 界面层，中间是核心应用层和硬件层，底部是射频与网络层，数据存储层位于中间偏右位置。

## 分组/子图/阶段说明
图中包含五个子图，分别代表系统的五个主要层级：
- **🌐 Web Interface Layer**：Web 界面层，负责用户交互和数据展示。
- **⚙️ Core Application Layer**：核心应用层，负责配置管理、GSCN 计算和 USRP 控制。
- **💾 Data Storage Layer**：数据存储层，负责存储系统配置、扫描结果和信号数据。
- **🔧 Hardware Layer**：硬件层，包含 FPGA 比特流、RFNoC 模块和 USRP X310 硬件设备。
- **📡 RF & Network Layer**：射频与网络层，包含天线、SSB 信号和 gNodeB 基站。

## 节点逐项说明
- **📱 Web UI (HTML/CSS/JavaScript)**：Web 用户界面，使用 HTML/CSS/JavaScript 构建，负责用户交互和数据展示。
- **🔌 REST API (Flask Backend)**：REST 应用程序编程接口，使用 Flask 后端构建，提供 Web UI 与核心应用层之间的数据交换接口。
- **📋 Config Manager (config.py)**：配置管理器，对应 `config.py` 文件，负责加载和管理系统配置。
- **📊 GSCN Calculator (gscn_calculator.py)**：GSCN 计算器，对应 `gscn_calculator.py` 文件，根据 3GPP 标准计算 GSCN 频率。
- **🎛️ USRP Controller (usrp_controller.py)**：USRP 控制器，对应 `usrp_controller.py` 文件，负责控制 USRP X310 硬件设备。
- **📄 config.json (Settings)**：配置文件，存储系统设置。
- **📈 detected_frequencies.json (Scan Results)**：扫描结果，存储扫描到的频率信息。
- **📁 \*.dat files (Signal Data)**：信号数据，存储捕获的原始信号数据。
- **💻 FPGA Bitstream (Custom Processing)**：FPGA 比特流，用于自定义处理的 FPGA 配置。
- **🔍 RFNoC Blocks (SSB Detection)**：RFNoC 模块，用于 SSB 检测。
- **📡 USRP X310 (SDR Platform)**：NI USRP X310 软件定义无线电平台，负责信号的接收和发送。
- **📶 Antenna (5G NR Bands)**：天线，用于接收 5G NR 频段的信号。
- **📊 SSB Signals (n1/n3/n77/n78/n79)**：5G NR 同步信号块，包括 n1, n3, n77, n78, n79 等频段。
- **🏢 gNodeB (Base Station)**：5G 基站。

## 连线、分支与汇聚关系
- `UI <--> API`：Web UI 通过 REST API 与 Core Application Layer 进行通信。
- `API -.-> CFG`：API 将配置信息传递给 Config Manager。
- `CFG <--> CALC`：Config Manager 与 GSCN Calculator 相互交互。
- `CALC <--> CTRL`：GSCN Calculator 将计算结果传递给 USRP Controller。
- `CTRL -.-> FREQ`：USRP Controller 将扫描结果存储到 detected_frequencies.json。
- `CTRL -.-> FILES`：USRP Controller 将捕获的数据存储到 *.dat 文件。
- `CTRL --> RFNOC`：USRP Controller 发送命令给 RFNoC Blocks。
- `FPGA --> RFNOC`：FPGA Bitstream 配置 RFNoC Blocks。
- `RFNOC --> X310`：RFNoC Blocks 控制 USRP X310。
- `X310 --> RF`：USRP X310 与 RF & Network Layer 进行通信。
- `ANT <--> SSB`：天线接收 SSB 信号。
- `SSB <--> GNB`：SSB 信号与 gNodeB 基站进行通信。

## 仓库语境与术语解释
- **5G NR SSB (Synchronization Signal Blocks)**：5G 新空口同步信号块，用于设备初始接入网络。
- **NI USRP X310**：美国国家仪器公司的软件无线电平台，用于信号的接收和发送。README 提到它是该项目使用的硬件平台。
- **config.py**：Python 文件，负责加载和管理系统配置。README 中提到它是模块化架构的关键组件。
- **gscn_calculator.py**：Python 文件，负责根据 3GPP 标准计算 GSCN 频率。README 中提到它是模块化架构的关键组件。
- **usrp_controller.py**：Python 文件，负责控制 USRP X310 硬件设备。README 中提到它是模块化架构的关键组件。
- **config.json**：JSON 文件，存储系统设置，例如 USRP 可执行文件路径、数据目录和扫描参数。
- **RFNoC (Radio Frequency Network on Chip)**：Ettus Research 公司的技术，用于在 USRP 设备上实现自定义信号处理。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 5G-Scanner 系统的整体架构，从 Web UI 发起请求，通过 REST API 传递到核心应用层。核心应用层包含 Config Manager、GSCN Calculator 和 USRP Controller，分别负责配置管理、频率计算和设备控制。USRP Controller 通过 Hardware Layer 的 RFNoC Blocks 控制 USRP X310 硬件，接收 Antenna 捕获的 SSB 信号，并将扫描结果和信号数据存储到 Data Storage Layer。该架构的关键组件包括 USRP X310 硬件平台和 config.py、gscn_calculator.py、usrp_controller.py 等模块化 Python 文件。
