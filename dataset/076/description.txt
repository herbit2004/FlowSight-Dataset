## Repository Context & Terminology
- **5G NR**: 5G New Radio, the global standard for the fifth generation of wireless communications.
- **USRP (Universal Software Radio Peripheral)**: A software-defined radio platform used for signal processing and communication experiments.
- **RFNoC (RF Network on Chip)**: A framework for implementing signal processing functions on FPGAs in USRP devices.
- **SSB (Single Sideband)**: A type of amplitude modulation where one sideband is suppressed, reducing bandwidth and power consumption.
- **gNodeB**: The base station in a 5G NR network.
- **config.py**: Python file responsible for managing and loading configuration parameters for the application.
- **gscn_calculator.py**: Python file containing the logic for calculating the Global Synchronization Channel Number (GSCN).
- **usrp_controller.py**: Python file responsible for controlling the USRP device, handling data capture, and sending commands.
