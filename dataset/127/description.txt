## 图类型与用途
这是一个流程图，展示了 CodeGPT 如何与 Google 的 Gemini API 和 VertexAI Gemini 服务交互，以提供代码补全或代码审查摘要功能。该图在 README.md 中作为架构示例，用于解释 CodeGPT 如何利用 Google 的 AI 模型。

## 图的整体布局
图采用从上到下的布局。顶部是用户，中间是 CodeGPT 及其 Gemini Provider 组件，底部是 Google 及其 Gemini API 和 VertexAI Gemini 服务。

## 分组/子图/阶段说明
图中包含两个子图：
- **CodeGPT**：代表 CodeGPT 应用程序本身，作为用户与 Google 服务之间的桥梁。
- **Google**：代表 Google 提供的 Gemini API 和 VertexAI Gemini 服务。

## 节点逐项说明
- **User**：代表使用 CodeGPT 的用户，是整个流程的起点。
- **Gemini Provider**：CodeGPT 内部的组件，负责处理用户请求，并根据配置选择与 Gemini API 或 VertexAI Gemini 服务进行通信。在 `cmd/provider.go` 中，`NewGemini` 函数负责创建 Gemini 客户端。
- **Gemini API**：Google 提供的 Gemini API 服务，用于生成文本。
- **VertexAI Gemini**：Google 提供的 VertexAI 平台上的 Gemini 服务，同样用于生成文本。
- **Completion / GetSummaryPrefix**：用户向 CodeGPT 发送的请求类型，可以是代码补全或获取摘要前缀。
- **BackendGeminiAPI**：GeminiClient 根据配置选择使用 Gemini API 时发送的请求。
- **BackendVertexAI**：GeminiClient 根据配置选择使用 VertexAI Gemini 时发送的请求。
- **Response (text, usage)**：Gemini API 或 VertexAI Gemini 返回给 GeminiClient 的响应，包含生成的文本和使用情况信息。

## 连线、分支与汇聚关系
- `User -- Completion / GetSummaryPrefix --> Gemini Provider`：用户向 CodeGPT 发送代码补全或获取摘要前缀的请求。
- `Gemini Provider -- BackendGeminiAPI --> Gemini API`：GeminiClient 根据配置选择使用 Gemini API，并向其发送请求。
- `Gemini API -- Response (text, usage) --> Gemini Provider`：Gemini API 将生成的文本和使用情况信息作为响应返回给 GeminiClient。
- `Gemini Provider -- BackendVertexAI --> VertexAI Gemini`：GeminiClient 根据配置选择使用 VertexAI Gemini，并向其发送请求。
- `VertexAI Gemini -- Response (text, usage) --> Gemini Provider`：VertexAI Gemini 将生成的文本和使用情况信息作为响应返回给 GeminiClient。
- `Gemini Provider --> User`：GeminiClient 将从 Gemini API 或 VertexAI Gemini 获得的响应（文本和使用情况）返回给用户。

## 仓库语境与术语解释
- **CodeGPT**：一个 CLI 工具，用于生成 git commit messages 或提供代码审查摘要。
- **Gemini API / VertexAI Gemini**：Google 提供的两种不同的 Gemini 服务，CodeGPT 可以配置使用其中一种。
- **Gemini Provider**：CodeGPT 内部用于与 Gemini API 或 VertexAI Gemini 服务交互的组件。`provider/gemini/gemini.go` 文件定义了 Gemini 客户端的结构和方法。
- **Completion / GetSummaryPrefix**：CodeGPT 提供的两种主要功能，分别用于代码补全和生成代码审查摘要。
- **API Key Helper**：用于动态获取 API 密钥的机制，可以从密码管理器或密钥服务中获取。README.md 中有关于 API Key Helper 的详细配置说明。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 CodeGPT 如何通过 Gemini Provider 组件与 Google 的 Gemini API 或 VertexAI Gemini 服务交互，从而为用户提供代码补全或代码审查摘要的功能。用户发起请求后，Gemini Provider 根据配置选择合适的 Google 服务，并将请求转发给该服务。Google 服务生成文本后，将结果返回给 Gemini Provider，最终 Gemini Provider 将结果呈现给用户。该流程的关键分支在于 Gemini Provider 如何选择使用 Gemini API 还是 VertexAI Gemini，这取决于用户的配置。
