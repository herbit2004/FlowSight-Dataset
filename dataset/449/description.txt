## Repository Context & Terminology
- **SSRF (Server-Side Request Forgery)**: A security vulnerability where an attacker can induce the server to make HTTP requests to arbitrary domains. The Scanner Pipeline aims to mitigate this.
- **Blocklist**: A list of prohibited items (e.g., URLs, domains, IP addresses) used to prevent access to malicious or undesirable content.
- **Rate Limit**: A mechanism to control the number of requests a user or client can make within a given time frame, preventing abuse and ensuring fair resource allocation.
- **DLP (Data Loss Prevention)**: A set of technologies and processes used to prevent sensitive data from leaving the organization's control.
- **Env Leak**: The unintentional exposure of environment variables, which may contain sensitive information such as API keys or database credentials.
- **Entropy**: A measure of randomness or unpredictability in data, used to detect potentially malicious or obfuscated content.
- **Privileged Zone**: A network segment or environment with stricter security controls and limited access, typically housing sensitive resources and applications.
- **Firewall Zone**: A network segment protected by a firewall, controlling network traffic and enforcing security policies.
