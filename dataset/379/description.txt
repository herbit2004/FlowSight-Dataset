## Repository Context & Terminology
- **TCP/UDP/ICMP**: Common network protocols used for communication over the internet. TCP provides reliable, connection-oriented communication, UDP provides connectionless communication, and ICMP is used for network diagnostics and error reporting.
- **Scapy**: A Python-based interactive packet manipulation program & library. It is able to forge or decode packets of a wide number of protocols, send them on the wire, capture them, match requests and replies, and much more.
- **Wireshark**: A network protocol analyzer that captures and analyzes network traffic.
- **LSTM (Long Short-Term Memory)**: A type of recurrent neural network (RNN) architecture well-suited for processing sequential data, such as network traffic flows.
- **Isolation Forest**: An unsupervised machine learning algorithm for anomaly detection that isolates anomalies by randomly partitioning the data.
- **AutoEncoder**: A type of neural network used for unsupervised learning, typically for dimensionality reduction or anomaly detection. It learns to encode and decode data, and anomalies are identified based on high reconstruction errors.
- **MITRE ATT&CK**: A knowledge base of adversary tactics and techniques based on real-world observations. It is used to understand and classify cyberattacks.
- **SIEM (Security Information and Event Management)**: A system that collects and analyzes security logs and events from various sources to detect and respond to threats.
- **SOAR (Security Orchestration, Automation and Response)**: A platform that automates security tasks and workflows to improve incident response efficiency.

## High-Density QA Ground Truth Summary
The system begins with live network traffic, encompassing TCP, UDP, and ICMP streams. This traffic is captured using tools like Scapy and Wireshark. The captured packets undergo feature extraction, where characteristics such as packet size distribution, flow duration and timing, protocol anomalies, and behavioral signatures are identified. These extracted features are then fed into three machine learning models: an LSTM classifier (configured with 128 input units, 64 bidirectional units, and a dropout of 0.2), an Isolation Forest model (contamination of 0.01 and 200 estimators), and an AutoEncoder for reconstruction error scoring. The outputs of these models are combined using an ensemble voting mechanism, employing weighted majority voting and confidence scoring. If the resulting ensemble score exceeds 0.85, the traffic is classified as a threat, triggering actions such as automatically blocking the traffic via firewall rule push, generating a threat report with IOC extraction, and dispatching alerts to a SIEM system, SOAR platform, and via email. Conversely, if the ensemble score is below 0.15, the traffic is deemed clean, logged, and archived. The MITRE ATT&CK framework is used to map detected threats to specific adversary tactics and techniques, providing a structured understanding of the attack.
