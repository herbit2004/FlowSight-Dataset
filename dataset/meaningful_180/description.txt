## 图类型与用途
该图是一个流程图，描述了仓库管理中的入库和出库两个主要流程。它展示了从接收请求到流程结束的各个步骤，包括库存检查、质检、补货、拣货等。该图可以帮助理解仓库操作的整体逻辑和关键环节。

## 图的整体布局
该图采用从上到下的布局方式。整体上分为入库流程和出库流程两个子图，分别位于图的左右两侧。两个流程都以接收请求开始，最终汇聚到流程结束节点。

## 分组/子图/阶段说明
图中包含两个显式子图：
- **入库流程**：描述了从接收到入库请求到更新库存信息的整个过程。
- **出库流程**：描述了从接收到出库请求到通知物流的整个过程。

## 节点逐项说明
- **A[接收到入库请求]**：接收到需要将货物存入仓库的请求。
- **B{检查库存状态}**：检查当前仓库中该货物的库存量。
- **C[启动补货流程]**：当库存低于阈值时，启动补货流程以增加库存。
- **D[分配入库库位]**：为即将入库的货物分配一个合适的存储位置。
- **E[执行质检]**：对入库货物进行质量检查，确保符合标准。
- **F[搬运至指定库位]**：将质检合格的货物搬运到之前分配的库位。
- **G[隔离并通知质检部门]**：将质检不合格的货物隔离，并通知相关部门处理。
- **H[更新库存信息]**：在货物成功入库后，更新仓库的库存记录。
- **I[接收到出库请求]**：接收到需要将货物从仓库中取出的请求。
- **J[检查库存]**：检查当前仓库中该货物的库存量是否满足出库需求。
- **K[拣货]**：从仓库中取出所需数量的货物。
- **L[通知缺货]**：如果库存不足，则通知相关人员缺货情况。
- **M[复核]**：对拣货结果进行复核，确保数量和种类正确。
- **N[包装]**：对货物进行包装，以便运输。
- **O[生成出库单]**：生成出库单据，记录出库信息。
- **P[通知物流]**：通知物流部门进行货物运输。
- **Q((流程结束))**：入库或出库流程的最终结束点。

## 连线、分支与汇聚关系
- A -> B：接收到入库请求后，检查库存状态。
- B -- 库存小于阈值 --> C：如果库存小于阈值，则启动补货流程。
- B -- 库存充足 --> D：如果库存充足，则分配入库库位。
- C -> D：补货流程完成后，分配入库库位。
- D -> E：分配入库库位后，执行质检。
- E -- 质检通过 --> F：质检通过后，搬运至指定库位。
- E -- 质检不通过 --> G：质检不通过后，隔离并通知质检部门。
- F -> H：搬运至指定库位后，更新库存信息。
- I -> J：接收到出库请求后，检查库存。
- J -- 库存充足 --> K：如果库存充足，则拣货。
- J -- 库存不足 --> L：如果库存不足，则通知缺货。
- K -> M：拣货后，进行复核。
- M -> N：复核后，进行包装。
- N -> O：包装后，生成出库单。
- O -> P：生成出库单后，通知物流。
- H -> Q：更新库存信息后，流程结束。
- P -> Q：通知物流后，流程结束。
- L -> Q：通知缺货后，流程结束。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **入库请求**：将货物存入仓库的申请。
- **出库请求**：将货物从仓库取出的申请。
- **库存阈值**：库存量的最低标准，低于该值需要补货。
- **质检**：对货物进行质量检查的过程。
- **库位**：仓库中用于存放货物的具体位置。
- **拣货**：从仓库中取出所需货物的过程。
- **复核**：对拣货结果进行核对，确保准确无误。

## 可作为 QA Ground Truth 的高信息密度摘要
入库流程从接收到入库请求开始，检查库存状态，若库存小于阈值则启动补货流程，然后分配入库库位，执行质检。质检通过则搬运至指定库位并更新库存信息，质检不通过则隔离并通知质检部门，最终流程结束。出库流程从接收到出库请求开始，检查库存，若库存充足则拣货、复核、包装、生成出库单并通知物流，若库存不足则通知缺货，最终流程结束。
