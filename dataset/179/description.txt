## 图类型与用途
这是一个流程图，描述了 Solana Copy Trading Bot 如何针对 PumpFun 和 PumpSwap 交易进行复制时，进行价格校正和盈利计算，最终做出正确的卖出决策。该图重点展示了如何使用新的参数替代旧参数，以进行更准确的计算。

## 图的整体布局
图整体采用从上到下的布局。顶部是交易解析的起始节点，中间是交易类型判断和价格校正阶段，底部是盈亏计算和卖出决策。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可以分为三个阶段：交易解析与类型判断、价格校正、盈亏计算与决策。

- **Transaction Parsing**：交易解析，负责解析从目标交易中获取到的原始交易数据。
- **Transaction Type**：交易类型，判断解析后的交易是买入还是卖出。
- **PumpFun Buy**：PumpFun 买入交易，处理 PumpFun 上的买入交易。
- **PumpFun Sell**：PumpFun 卖出交易，处理 PumpFun 上的卖出交易。
- **PumpSwap Buy**：PumpSwap 买入交易，处理 PumpSwap 上的买入交易。
- **PumpSwap Sell**：PumpSwap 卖出交易，处理 PumpSwap 上的卖出交易。
- **❌ OLD: virtual_sol / virtual_token ✅ NEW: sol_amount / token_amount**：PumpFun 买入价格校正，使用新的 `sol_amount / token_amount` 参数替代旧的 `virtual_sol / virtual_token` 参数。
- **❌ OLD: virtual_sol / virtual_token ✅ NEW: sol_amount / token_amount**：PumpFun 卖出价格校正，使用新的 `sol_amount / token_amount` 参数替代旧的 `virtual_sol / virtual_token` 参数。
- **❌ OLD: quote_reserve / base_reserve ✅ NEW: quote_amount_out / base_amount_in**：PumpSwap 买入价格校正，使用新的 `quote_amount_out / base_amount_in` 参数替代旧的 `quote_reserve / base_reserve` 参数。
- **❌ OLD: quote_reserve / base_reserve ✅ NEW: quote_amount_out / base_amount_in**：PumpSwap 卖出价格校正，使用新的 `quote_amount_out / base_amount_in` 参数替代旧的 `quote_reserve / base_reserve` 参数。
- **Correct Buy Price**：校正后的买入价格，经过参数校正后得到的准确买入价格。
- **Correct Sell Price**：校正后的卖出价格，经过参数校正后得到的准确卖出价格。
- **Accurate PnL Calculation**：准确的盈亏计算。
- **Proper Selling Decisions**：正确的卖出决策。

## 连线、分支与汇聚关系
- `Transaction Parsing -> Transaction Type`：解析交易后判断交易类型。
- `Transaction Type -- Buy Transaction --> PumpFun Buy`：如果是 PumpFun 买入交易，则进入 PumpFun 买入处理流程。
- `Transaction Type -- Sell Transaction --> PumpFun Sell`：如果是 PumpFun 卖出交易，则进入 PumpFun 卖出处理流程。
- `Transaction Type -- Buy Transaction --> PumpSwap Buy`：如果是 PumpSwap 买入交易，则进入 PumpSwap 买入处理流程。
- `Transaction Type -- Sell Transaction --> PumpSwap Sell`：如果是 PumpSwap 卖出交易，则进入 PumpSwap 卖出处理流程。
- `PumpFun Buy -> ❌ OLD: virtual_sol / virtual_token ✅ NEW: sol_amount / token_amount`：PumpFun 买入交易进行价格校正。
- `PumpFun Sell -> ❌ OLD: virtual_sol / virtual_token ✅ NEW: sol_amount / token_amount`：PumpFun 卖出交易进行价格校正。
- `PumpSwap Buy -> ❌ OLD: quote_reserve / base_reserve ✅ NEW: quote_amount_out / base_amount_in`：PumpSwap 买入交易进行价格校正。
- `PumpSwap Sell -> ❌ OLD: quote_reserve / base_reserve ✅ NEW: quote_amount_out / base_amount_in`：PumpSwap 卖出交易进行价格校正。
- `❌ OLD: virtual_sol / virtual_token ✅ NEW: sol_amount / token_amount -> Correct Buy Price`：PumpFun 买入价格校正后得到校正后的买入价格。
- `❌ OLD: virtual_sol / virtual_token ✅ NEW: sol_amount / token_amount -> Correct Sell Price`：PumpFun 卖出价格校正后得到校正后的卖出价格。
- `❌ OLD: quote_reserve / base_reserve ✅ NEW: quote_amount_out / base_amount_in -> Correct Buy Price`：PumpSwap 买入价格校正后得到校正后的买入价格。
- `❌ OLD: quote_reserve / base_reserve ✅ NEW: quote_amount_out / base_amount_in -> Correct Sell Price`：PumpSwap 卖出价格校正后得到校正后的卖出价格。
- `Correct Buy Price -> Accurate PnL Calculation`：校正后的买入价格用于盈亏计算。
- `Correct Sell Price -> Accurate PnL Calculation`：校正后的卖出价格用于盈亏计算，形成汇聚关系。
- `Accurate PnL Calculation -> Proper Selling Decisions`：根据盈亏计算结果做出卖出决策。

## 仓库语境与术语解释
- **PumpFun & PumpSwap**：根据 README，PumpFun 和 PumpSwap 是 Solana 上的去中心化交易所 (DEX)。`src/dex/mod.rs` 中也定义了 `pump_fun` 模块。
- **virtual_sol / virtual_token, quote_reserve / base_reserve, sol_amount / token_amount, quote_amount_out / base_amount_in**：这些是用于计算价格的参数，图中表明新版本使用了更准确的参数。
- **PnL Calculation**：盈亏计算，用于评估交易的盈利情况。
- **Transaction Parsing**：交易解析，用于从原始交易数据中提取关键信息。
- **Copy Trading**：根据 README，该 Bot 用于复制其他交易者的交易。
- **Jito**：README 提到 "Use nozomi, zeroslot, bloxroute, jito..."，`src/services/jito.rs` 提供了与 Jito 相关的服务，用于加速交易确认。
- **Slippage**: `src/engine/sniper.rs` 和 `src/engine/swap.rs` 中，`slippage` 作为参数传递给 `pump_swap` 函数，表示滑点容忍度。
