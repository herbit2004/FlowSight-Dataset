## 连线、分支与汇聚关系
- 用户浏览器 -> CDN 节点：用户发起请求到达 CDN 节点。
- CDN 节点 -- 命中缓存 --> 返回内容给用户：CDN 节点命中缓存，直接返回内容。
- CDN 节点 -- 未命中缓存 --> 边缘节点回源判定：CDN 节点未命中缓存，进行回源判定。
- 边缘节点回源判定 -- 动态内容/特殊策略 --> 动态回源集群：动态内容或特殊策略，回源到动态回源集群。
- 边缘节点回源判定 -- 静态内容 --> 静态存储：静态内容，回源到静态存储。
- 动态回源集群 -> 源站反向代理：动态回源集群将请求转发到源站反向代理。
- 源站反向代理 -> 源站服务器：源站反向代理将请求转发到源站服务器。
- 源站服务器 -> 生成/获取动态内容：源站服务器生成或获取动态内容。
- 生成/获取动态内容 -> 源站反向代理：动态内容返回给源站反向代理。
- 源站反向代理 -> CDN 节点：源站反向代理将内容返回给 CDN 节点。
- 静态存储 -> 对象存储OSS：静态存储使用对象存储服务。
- 对象存储OSS -> CDN 节点：对象存储将内容返回给 CDN 节点。
- CDN 节点 -> 更新 CDN 缓存：CDN 节点更新缓存。
- 更新 CDN 缓存 -> 返回内容给用户：更新后的内容返回给用户。
- 返回内容给用户 -> 用户接收内容：用户接收内容。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **CDN (内容分发网络)**：一种分布式网络架构，通过将内容缓存到离用户更近的节点，加速内容传输。
- **回源**：当 CDN 节点未命中缓存时，从源站服务器获取内容的过程。
- **动态内容**：每次请求返回的内容可能不同的内容，例如新闻、股票信息等。
- **静态内容**：每次请求返回的内容都相同的内容，例如图片、CSS 文件等。
- **源站**：存储原始内容的服务器。
- **反向代理**：位于服务器之前的代理服务器，用于负载均衡、安全防护等。
- **对象存储**：一种用于存储非结构化数据的存储服务，例如图片、视频等。

## 可作为 QA Ground Truth 的高信息密度摘要
用户通过浏览器发起请求，请求首先到达 CDN 节点。如果 CDN 节点命中缓存，则直接返回内容给用户；否则，边缘节点进行回源判定。对于动态内容或特殊策略，请求被转发到动态回源集群，经过源站反向代理到达源站服务器，生成或获取动态内容后，依次返回到源站反向代理和 CDN 节点。对于静态内容，请求被转发到静态存储，通过对象存储OSS 返回到 CDN 节点。CDN 节点更新缓存后，最终将内容返回给用户。
