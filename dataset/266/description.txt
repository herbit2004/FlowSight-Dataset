## Repository Context & Terminology
- **Compiler**: A program that translates source code written in a high-level programming language into a lower-level language (e.g., assembly language or machine code).
- **Parser**: A component of a compiler that transforms source code into an intermediate representation, such as an abstract syntax tree (AST).
- **Analyzer**: A component of a compiler that performs semantic analysis on the intermediate representation to check for errors and gather information for code generation.
- **Backend**: A component of a compiler that generates machine code or another low-level representation from the intermediate representation.
- **Machine Code**: The lowest-level representation of a program, consisting of instructions that can be directly executed by a computer's central processing unit (CPU).
- **WebAssembly (wasm)**: A binary instruction format for a stack-based virtual machine. WASM is designed as a portable target for compilation of high-level languages like C/C++/Rust, enabling deployment on the web for client-side and server-side applications.
- **Go Compiler**: A compiler specifically designed to compile Go programming language code into executable binaries or other intermediate representations.
