## 节点逐项说明
- **发布请求**：发起环境发布的请求。
- **环境预检**：检查环境资源是否满足发布要求。
- **暂停发布**：当环境资源被占用时，暂停发布流程。
- **环境锁定**：锁定环境，防止其他发布操作干扰。
- **配置校验**：验证发布配置是否正确。
- **回滚锁定**：当配置错误、Schema不兼容或服务异常时，回滚环境锁定。
- **数据库Schema检查**：检查数据库Schema是否兼容。
- **依赖服务健康检查**：检查依赖服务的健康状态。
- **代码包部署**：将代码包部署到目标环境。
- **金丝雀发布?**：判断是否进行金丝雀发布。
- **金丝雀环境部署**：将代码包部署到金丝雀环境。
- **全量环境部署**：将代码包部署到所有环境。
- **金丝雀验证**：验证金丝雀环境的运行状态。
- **冒烟测试**：对全量环境进行冒烟测试。
- **回滚金丝雀**：当金丝雀验证失败时，回滚金丝雀环境。
- **流量切换**：将流量切换到新发布的版本。
- **停止发布**：当冒烟测试失败或回滚金丝雀时，停止发布流程。
- **发布完成**：发布流程成功完成。
- **解锁环境**：解锁环境，允许其他发布操作。
- **发布结果通知**：发送发布结果通知。

## 连线、分支与汇聚关系
- 发布请求 -> 环境预检：发起发布请求后，进行环境预检。
- 环境预检 -- 资源占用? --> 暂停发布：如果资源被占用，则暂停发布。
- 环境预检 -- 资源空闲 --> 环境锁定：如果资源空闲，则锁定环境。
- 环境锁定 -> 配置校验：环境锁定后，进行配置校验。
- 配置校验 -- 配置错误? --> 回滚锁定：如果配置错误，则回滚锁定。
- 配置校验 -- 配置正确 --> 数据库Schema检查：如果配置正确，则进行数据库Schema检查。
- 数据库Schema检查 -- Schema不兼容? --> 回滚锁定：如果Schema不兼容，则回滚锁定。
- 数据库Schema检查 -- Schema兼容 --> 依赖服务健康检查：如果Schema兼容，则进行依赖服务健康检查。
- 依赖服务健康检查 -- 服务异常? --> 回滚锁定：如果服务异常，则回滚锁定。
- 依赖服务健康检查 -- 服务正常 --> 代码包部署：如果服务正常，则进行代码包部署。
- 代码包部署 -> 金丝雀发布?：代码包部署后，判断是否进行金丝雀发布。
- 金丝雀发布? -- 是 --> 金丝雀环境部署：如果是金丝雀发布，则部署到金丝雀环境。
- 金丝雀发布? -- 否 --> 全量环境部署：如果不是金丝雀发布，则部署到全量环境。
- 金丝雀环境部署 -> 金丝雀验证：金丝雀环境部署后，进行金丝雀验证。
- 全量环境部署 -> 冒烟测试：全量环境部署后，进行冒烟测试。
- 金丝雀验证 -- 验证失败? --> 回滚金丝雀：如果金丝雀验证失败，则回滚金丝雀。
- 金丝雀验证 -- 验证成功 --> 流量切换：如果金丝雀验证成功，则进行流量切换。
- 冒烟测试 -- 测试失败? --> 停止发布：如果冒烟测试失败，则停止发布。
- 冒烟测试 -- 测试成功 --> 发布完成：如果冒烟测试成功，则发布完成。
- 流量切换 -> 发布完成：流量切换后，发布完成。
- 回滚金丝雀 -> 停止发布：回滚金丝雀后，停止发布。
- 回滚锁定 -> 停止发布：回滚锁定后，停止发布。
- 停止发布 -> 解锁环境：停止发布后，解锁环境。
- 发布完成 -> 解锁环境：发布完成后，解锁环境。
- 解锁环境 -> 发布结果通知：解锁环境后，发送发布结果通知。
- 发布结果通知 -> 发布完成：发布结果通知后，流程结束。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **环境**：指软件或应用程序运行的服务器、网络和其他基础设施。
- **Schema**：数据库的结构定义，包括表、字段、索引等。
- **金丝雀发布**：一种灰度发布策略，将新版本发布到一小部分用户，验证其稳定性和性能后再全量发布。
- **冒烟测试**：一种快速验证软件基本功能的测试方法。
- **回滚**：将系统恢复到之前的状态。
- **流量切换**：将用户流量从旧版本切换到新版本。

## 可作为 QA Ground Truth 的高信息密度摘要
发布流程从“发布请求”开始，首先进行“环境预检”，若资源占用则“暂停发布”，否则“环境锁定”。随后进行“配置校验”，若配置错误则“回滚锁定”，否则进行“数据库Schema检查”，若Schema不兼容则“回滚锁定”，否则进行“依赖服务健康检查”，若服务异常则“回滚锁定”，否则进行“代码包部署”。之后判断是否“金丝雀发布”，若是则进行“金丝雀环境部署”和“金丝雀验证”，验证失败则“回滚金丝雀”，否则“流量切换”；若否，则进行“全量环境部署”和“冒烟测试”，测试失败则“停止发布”，否则“发布完成”。“回滚锁定”、“回滚金丝雀”和“停止发布”都会进入“解锁环境”流程，最终“发布结果通知”并“发布完成”。
