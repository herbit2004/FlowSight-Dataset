## 图类型与用途
这是一个流程图，用于描述用户在账户系统中注册、登录以及访问受保护资源的流程。该图展示了用户认证的不同方式，以及认证成功或失败后的处理流程。它清晰地呈现了用户与系统之间的交互过程。

## 图的整体布局
该图采用从上到下的布局方式。流程从用户发起注册/登录开始，经过认证流程，最终到用户访问受保护资源。整个流程呈现出清晰的层次结构。

## 分组/子图/阶段说明
图中存在一个名为“账户系统”的子图，包含了用户注册和登录的完整流程。在账户系统之外，还有用户访问受保护资源和服务器验证令牌两个阶段。

## 节点逐项说明
- **A[用户发起注册/登录]**: 用户开始注册或登录流程的起始节点。
- **B{认证方式选择}**: 用户选择不同的认证方式，例如邮箱注册、手机号注册或账户密码登录。
- **C[验证邮箱有效性]**: 验证用户提供的邮箱地址是否有效。
- **D[验证手机号有效性]**: 验证用户提供的手机号码是否有效。
- **E[校验用户名密码]**: 校验用户输入的用户名和密码是否匹配。
- **F[创建新用户账户]**: 创建新的用户账户。
- **G{密码是否正确}**: 判断用户输入的密码是否正确。
- **H[生成会话令牌]**: 认证成功后，生成用于后续访问的会话令牌。
- **I[返回认证失败]**: 认证失败后，返回认证失败信息。
- **J[返回会话令牌]**: 将生成的会话令牌返回给客户端。
- **K[客户端存储令牌]**: 客户端存储会话令牌，以便后续访问。
- **L[用户访问受保护资源]**: 用户尝试访问需要认证的资源。
- **M[服务端验证令牌]**: 服务端验证客户端提供的会话令牌是否有效。

## 连线、分支与汇聚关系
- A -> B：用户发起注册/登录后，进入认证方式选择。
- B -- 邮箱注册 --> C：选择邮箱注册方式后，验证邮箱有效性。
- B -- 手机号注册 --> D：选择手机号注册方式后，验证手机号有效性。
- B -- 账户密码登录 --> E：选择账户密码登录方式后，校验用户名密码。
- C -> F：邮箱验证通过后，创建新用户账户。
- D -> F：手机号验证通过后，创建新用户账户。
- E -> G：校验用户名密码后，判断密码是否正确。
- G -- 是 --> H：密码正确，生成会话令牌。
- G -- 否 --> I：密码错误，返回认证失败。
- F -> H：创建新用户账户后，生成会话令牌。
- H -> J：生成会话令牌后，返回会话令牌。
- I -> A：认证失败后，返回到用户发起注册/登录。
- J -> K：返回会话令牌后，客户端存储令牌。
- K -> L：客户端存储令牌后，用户访问受保护资源。
- L -> M：用户访问受保护资源时，服务端验证令牌。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **会话令牌**：一种用于验证用户身份的凭证，在用户登录后生成，用于后续访问受保护资源。
- **认证**：验证用户身份的过程，确认用户是否是其声称的身份。
- **客户端**：通常指用户的浏览器或应用程序，用于与服务端进行交互。
- **服务端**：提供服务的服务器，负责处理用户请求和验证用户身份。
- **受保护资源**：需要用户认证才能访问的资源。
- **用户名密码**：用户在注册时设置的用于登录的凭证。

## 可作为 QA Ground Truth 的高信息密度摘要
用户发起注册/登录，选择认证方式，包括邮箱注册、手机号注册或账户密码登录。邮箱注册需验证邮箱有效性，手机号注册需验证手机号有效性，账户密码登录需校验用户名密码。邮箱或手机号验证通过后，创建新用户账户。密码校验正确后，生成会话令牌。认证失败则返回认证失败。生成会话令牌后返回会话令牌，客户端存储令牌。最后，用户访问受保护资源，服务端验证令牌。
