- `User Request: Text/Images/Documents --> Intelligent Router`: The user request is passed to the intelligent router.
- `Intelligent Router -- Intent Classification --> LangGraph Orchestrator`: The intelligent router classifies the intent and passes the request to the LangGraph orchestrator.
- `LangGraph Orchestrator --> Specialized Agents - XML Tag Output`: The LangGraph orchestrator routes the request to the specialized agents based on intent.
