## Repository Context & Terminology
- **Working Copy**: A local copy of the codebase where developers make changes.
- **Local Environment**: The development environment on a developer's machine.
- **Integration**: The process of merging code changes into a shared codebase.
- **Integration Environment**: A testing environment where code changes are integrated and tested together.
- **Pull Request**: A request to merge code changes from a branch into another branch.
- **Code Review**: The process of reviewing code changes before they are merged.
- **Mainstream**: The main branch of the codebase.
- **Unit Testing**: Testing individual units or components of the code.
- **Automated Functional Testing**: Automated testing of the functionality of the code.
- **Manual Functional Testing**: Manual testing of the functionality of the code.
