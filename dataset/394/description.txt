## Repository Context & Terminology
- **Range Query**: A query that asks for information about a contiguous subsequence of elements within a larger sequence.
- **Prefix Sum**: A data structure that stores the cumulative sum of elements up to each index in an array. It allows for O(1) query time for range sums but does not support updates.
- **Sparse Table**: A data structure that precomputes range minimum/maximum queries for all possible ranges of size 2^k. It allows for O(1) query time but does not support updates.
- **Fenwick Tree**: A data structure that efficiently supports both range queries and updates in O(log N) time.
- **Segment Tree**: A tree-based data structure that allows for efficient range queries and updates in O(log N) time. It is more versatile than Fenwick Tree and can handle more complex queries.
- **O(N)**: Big O notation representing linear time complexity, where the time taken increases linearly with the input size N.
- **O(log N)**: Big O notation representing logarithmic time complexity, where the time taken increases logarithmically with the input size N.
- **O(N log N)**: Big O notation representing time complexity that is a product of linear and logarithmic factors.
