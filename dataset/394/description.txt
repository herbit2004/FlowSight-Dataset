## 图类型与用途
这是一个流程图，用于展示在解决范围查询问题时，如何根据需求选择合适的数据结构。它在仓库中的作用是提供一个决策树，帮助用户选择合适的数据结构。

## 图的整体布局
图整体采用从上到下的布局。顶部是两种基础数据结构，中间是条件判断，底部是最终选择的数据结构。

## 分组/子图/阶段说明
图中包含一个名为 "Range Query Structures" 的子图，该子图包含了解决范围查询问题的一系列数据结构。

## 节点逐项说明
- **Prefix Sum**：一种简单的数据结构，用于快速计算数组中某个范围内的元素之和。构建时间复杂度 O(N)，查询时间复杂度 O(1)，不支持更新操作。
- **Sparse Table**：另一种用于范围查询的数据结构，适用于静态数组。构建时间复杂度 O(N log N)，查询时间复杂度 O(1)，不支持更新操作。
- **Fenwick Tree**：一种更高级的数据结构，用于高效地计算前缀和以及更新数组中的元素。构建时间复杂度 O(N)，查询时间复杂度 O(log N)，更新时间复杂度 O(log N)。
- **Segment Tree**：一种非常灵活的数据结构，可以用于解决各种范围查询问题。构建时间复杂度 O(N)，查询时间复杂度 O(log N)，更新时间复杂度 O(log N)，并且比其他数据结构更加通用。

## 连线、分支与汇聚关系
- `Prefix Sum -- if updates needed --> Fenwick Tree`：如果需要对数组进行更新操作，那么前缀和就不再适用，需要考虑使用树状数组。
- `Sparse Table -- if updates needed --> Segment Tree`：如果需要对数组进行更新操作，那么稀疏表也不再适用，需要考虑使用线段树。
- `Fenwick Tree -- if complex queries --> Segment Tree`：如果需要执行更复杂的范围查询操作，那么树状数组可能不够灵活，需要考虑使用线段树。

## 仓库语境与术语解释
- **Range Query Structures**：解决在给定数据范围内查找特定信息的问题，例如求和、求最大值、最小值等。
- **Prefix Sum**：如 `Basics/Prefix Sum.cpp` 所示，该方法通过预先计算数组的前缀和，从而实现 O(1) 时间复杂度的范围查询。
- **Fenwick Tree**：也称为 Binary Indexed Tree (BIT)，如 `Data Structures/BIT.cpp` 所示，它可以在 O(log N) 时间内进行更新和查询操作。
- **Segment Tree**：如 `Data Structures/Segment Tree.cpp` 所示，它是一种树形数据结构，用于存储数组的区间信息，并支持高效的范围查询和更新操作。
- **Sparse Table**：如 `Data Structures/Sparse Table.cpp` 所示，它适用于静态数组的范围查询，通过预处理可以在 O(1) 时间内回答查询。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了范围查询数据结构的选择流程。如果不需要更新，可以选择 Prefix Sum 或 Sparse Table；如果需要更新，则选择 Fenwick Tree 或 Segment Tree。Fenwick Tree 在更新和简单查询方面更高效，而 Segment Tree 则更通用，可以处理复杂的查询操作。该图的核心决策点在于是否需要更新操作以及查询的复杂度。
