## Edges, Branches & Convergence
- `Web Browser --> React Frontend Static Files`: The user interacts with the web browser, which sends HTTPS requests to the React frontend.
- `React Frontend Static Files --> FastAPI Backend API Server`: The React frontend sends API requests to the FastAPI backend via the `/api/*` endpoint.
- `FastAPI Backend API Server --> Master Orchestrator Agent`: The FastAPI backend communicates with the Master Orchestrator Agent via RemoteRunner.
- `Master Orchestrator Agent --> Content Creation Coordinator`: The Master Orchestrator Agent triggers the Content Creation Coordinator.
- `Master Orchestrator Agent --> Content Analyzer Agent`: The Master Orchestrator Agent triggers the Content Analyzer Agent.
- `Content Creation Coordinator --> Google Gemini 2.5 Flash via Vertex AI`: The Content Creation Coordinator makes API calls to the Google Gemini 2.5 Flash model.
- `Content Analyzer Agent --> Google Gemini 2.5 Flash via Vertex AI`: The Content Analyzer Agent makes API calls to the Google Gemini 2.5 Flash model.
- `FastAPI Backend API Server -.logs.-> Cloud Logging & Monitoring`: The FastAPI backend sends logs to Cloud Logging & Monitoring.
- `Artifact Registry Docker Images -.deploys.-> FastAPI Backend API Server`: Docker images from the Artifact Registry are deployed to the FastAPI backend.
- `Content Creation Coordinator -.stores.-> Cloud Storage Staging Bucket`: The Content Creation Coordinator stores data in the Cloud Storage Staging Bucket.

## High-Density QA Ground Truth Summary
The process begins with a user interacting with the **Web Browser**, which sends an HTTPS request to the **React Frontend Static Files** hosted within the **Google Cloud Run Combined Service**. The frontend, built using Vite and React 18, then communicates with the **FastAPI Backend API Server** via the `/api/*` endpoint. The backend, implemented in Python 3.11 with Uvicorn, deploys from **Artifact Registry Docker Images**. The backend then triggers the **Master Orchestrator Agent** within the **Vertex AI Agent Engine** using RemoteRunner. The Master Orchestrator Agent, version gemini-2.5-flash, then initiates both the **Content Creation Coordinator** and the **Content Analyzer Agent**, also version gemini-2.5-flash. The Content Creation Coordinator stores data in the **Cloud Storage Staging Bucket**. Both the Content Creation Coordinator and Content Analyzer Agent make API calls to the **Google Gemini 2.5 Flash via Vertex AI** model. Logs from the FastAPI backend are sent to **Cloud Logging & Monitoring**. The agents leverage the Gemini 2.5 Flash model via Vertex AI to perform content creation and analysis tasks.
