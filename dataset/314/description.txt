## Repository Context & Terminology
- **ROS (Robot Operating System)**: A flexible framework for writing robot software. It is a collection of tools, libraries, and conventions that aim to simplify the task of creating complex and robust robot behavior across a wide variety of robotic platforms.
- **Node**: In ROS, a node is an executable that performs a specific task. Nodes communicate with each other via topics, services, and actions.
- **Topic**: A named bus over which nodes exchange messages. Topics have anonymous publish/subscribe semantics, which decouples the production of information from its consumption.
- **sensor_msgs/PointCloud2**: A standard ROS message type for representing point cloud data. It includes information such as the 3D coordinates of points, color, and intensity.
- **visualization_msgs/MarkerArray**: A standard ROS message type for sending multiple visualization markers at once. It is often used to display shapes, text, and other visual elements in a 3D environment.
- **urban_road_filt**: The name of the ROS node responsible for filtering and segmenting road-related features from point cloud data in an urban environment.
