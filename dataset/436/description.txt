## Repository Context & Terminology
- **Control Plane**: The set of components that manage and control the data plane.
- **Target Namespace**: The Kubernetes namespace where the application services are deployed.
- **Kubernetes API Server**: The central management component of a Kubernetes cluster.
- **Redis**: An open source (BSD licensed), in-memory data structure store, used as a database, cache and message broker.
- **Jaeger**: An open source, end-to-end distributed tracing system.
- **Envoy Sidecar**: A proxy that runs alongside each service instance, providing traffic management, security, and observability features.
- **JDBC**: Java Database Connectivity, an API for connecting to databases.
