## 图类型与用途
该图是一个流程图，描述了从订单到生产，再到质检和最终质量分析的完整流程。它展示了产品生产和质量控制的各个环节，以及数据流向和决策过程。该图可以用于理解生产流程和质量控制的关键步骤。

## 图的整体布局
该图采用从上到下的布局，分为“订单与生产”、“质检流程”和“数据与报告”三个主要层次。流程从“订单系统”开始，最终到“质量分析”结束。

## 分组/子图/阶段说明
图中包含三个子图：
- **订单与生产**：描述了从订单系统到产出批次的生产过程。
- **质检流程**：详细描述了从质检请求到不合格品处理或良品入库的质检过程，包括初检、抽检、复检、返工等环节。
- **数据与报告**：描述了良品数据和不良品数据汇总到质检报告，并进行质量分析的过程。

## 节点逐项说明
- **A 订单系统**：接收订单的系统。
- **B 生产计划**：根据订单制定生产计划。
- **C 生产线**：执行生产计划的生产线。
- **D 产出批次**：生产线产出的产品批次。
- **E 质检请求**：对产出批次发起质检请求。
- **F 初检：外观、尺寸**：对产品进行外观和尺寸的初步检查。
- **G 是否抽检**：判断是否需要进行抽样检查。
- **I 抽样**：进行抽样操作。
- **K 抽样送检**：将抽样送去进行检验。
- **L 复检：性能测试**：对抽样进行性能测试的复检。
- **J 良品入库**：合格产品进入仓库。
- **H 不合格品处理**：对不合格产品进行处理。
- **M 扩大抽检范围**：如果复检不合格，则扩大抽检范围。
- **N 深度分析**：对不合格原因进行深度分析。
- **O 问题定位**：定位导致不合格的问题。
- **P 是否可修复**：判断产品是否可以修复。
- **Q 返工修复**：对产品进行返工修复。
- **R 修复后复检**：对修复后的产品进行复检。
- **S 良品数据**：关于合格产品的数据。
- **T 不良品数据**：关于不合格产品的数据。
- **U 质检报告**：汇总的质检报告。
- **V 质量分析**：对质检报告进行质量分析。

## 连线、分支与汇聚关系
- A -> B：订单系统产生生产计划。
- B -> C：生产计划指导生产线。
- C -> D：生产线产出批次。
- D -> E：产出批次触发质检请求。
- E -> F：质检请求进入初检环节。
- F -- 合格 --> G：初检合格，判断是否抽检。
- F -- 不合格 --> H：初检不合格，进行不合格品处理。
- G -- 是 --> I：需要抽检，进行抽样。
- G -- 否 --> J：不需要抽检，直接良品入库。
- I -> K：抽样后送检。
- K -> L：抽样送检后进行复检。
- L -- 合格 --> J：复检合格，良品入库。
- L -- 不合格 --> M：复检不合格，扩大抽检范围。
- M -> N：扩大抽检范围后进行深度分析。
- N -> O：深度分析后进行问题定位。
- O -> P：问题定位后判断是否可修复。
- P -- 是 --> Q：可以修复，进行返工修复。
- P -- 否 --> H：不可修复，进行不合格品处理。
- Q -> R：返工修复后进行复检。
- R -- 合格 --> J：修复后复检合格，良品入库。
- R -- 不合格 --> H：修复后复检不合格，进行不合格品处理。
- J -> S：良品入库产生良品数据。
- H -> T：不合格品处理产生不良品数据。
- S & T -> U：良品数据和不良品数据汇总生成质检报告。
- U -> V：质检报告用于质量分析。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **订单系统**：接收和管理客户订单的系统。
- **生产计划**：根据订单需求制定的生产安排。
- **质检**：质量检验，用于评估产品是否符合标准。
- **抽检**：随机抽取部分产品进行检验。
- **复检**：对初检或抽检结果有疑问的产品进行再次检验。
- **返工修复**：对不合格产品进行修复，使其达到合格标准。
- **良品入库**：合格产品进入仓库存储。
- **不合格品处理**：对不合格产品进行报废、降级等处理。

## 可作为 QA Ground Truth 的高信息密度摘要
流程从订单系统开始，生成生产计划，指导生产线产出批次。批次进入质检流程，首先进行初检，合格则判断是否抽检，不合格则进行不合格品处理。若抽检，则进行抽样送检和复检，合格则良品入库，不合格则扩大抽检范围，进行深度分析和问题定位，判断是否可修复，可修复则返工修复后复检，不可修复则进行不合格品处理。最终，良品和不良品数据汇总生成质检报告，用于质量分析。
