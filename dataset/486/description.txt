## Repository Context & Terminology
- **Epic**: A large body of work that can be broken down into smaller tasks (called stories or sub-issues).
- **Sub-Issue**: A smaller, more manageable task that contributes to the completion of an epic.
- **Agent Orchestration**: The automated coordination of tasks, potentially involving CI/CD pipelines or other automation tools.
- **Pull Request (PR)**: A request to merge code changes from a branch into another branch, typically the main branch.
- **Review**: The process of examining code changes in a pull request to ensure quality and correctness.
- **Merge**: The act of integrating code changes from a branch into another branch.
