## Edges, Branches & Convergence
- `Init --> Config`: The index.ts file triggers the configuration loading process.
- `Config --> Transport`: The configuration loader determines the transport type.
- `Transport -- stdio --> StdioTransport`: If the transport type is stdio, use Stdio Transport.
- `Transport -- sse --> SSETransport`: If the transport type is sse, use SSE Transport.
- `StdioTransport --> Server`: Stdio Transport connects to the MCP Server.
- `SSETransport --> Server`: SSE Transport connects to the MCP Server.
- `Server --> ToolReg`: The MCP Server uses the Tool Registry.
- `ToolReg --> InitEmbed`: The Tool Registry triggers the initialization of embeddings.
- `InitEmbed --> Ready`: After initializing embeddings, the server is ready.
- `Req --> SessionMgr`: A client request is passed to the Session Manager.
- `SessionMgr --> Router`: The Session Manager passes the request to the Hybrid Router.
- `Router --> Semantic`: The Hybrid Router routes the request to the Semantic Matcher.
- `Router --> Sequential`: The Hybrid Router routes the request to Sequential Thinking.
- `Semantic -- High Confidence --> Execute`: If the Semantic Matcher has high confidence, execute the tool.
- `Sequential -- Fallback --> Execute`: If Sequential Thinking is used as a fallback, execute the tool.
- `Execute --> JobMgr`: Tool Execution triggers the Job Manager.
- `JobMgr --> Response`: The Job Manager sends the response.
- `Execute --> Research`: Tool Execution can trigger the Research Tool.
- `Execute --> TaskMgr`: Tool Execution can trigger the Vibe Task Manager.
- `Execute --> CodeMap`: Tool Execution can trigger the Code Map Tool.
- `Execute --> FullStack`: Tool Execution can trigger the Fullstack Generator.
- `Execute --> PRDGen`: Tool Execution can trigger the PRD Generator.
- `Execute --> UserStories`: Tool Execution can trigger the User Stories Generator.
- `Execute --> TaskList`: Tool Execution can trigger the Task List Generator.
- `Execute --> Rules`: Tool Execution can trigger the Rules Generator.
- `Execute --> Workflow`: Tool Execution can trigger the Workflow Runner.
- `JobMgr --> AsyncJobs`: The Job Manager triggers Async Job Processing.
- `Execute --> FileOps`: Tool Execution can trigger File Operations.
- `Execute --> LLMHelper`: Tool Execution can trigger LLM Integration.
- `Execute --> ErrorHandler`: Tool Execution can trigger Error Handling.
- `Execute --> StateManager`: Tool Execution can trigger Session State management.
- `Config --> LLMConfig`: The Configuration Loader loads the LLM Config Mapping.
- `Config --> MCPConfig`: The Configuration Loader loads the MCP Tool Config.
- `Config --> EnvVars`: The Configuration Loader loads the Environment Variables.
- `FileOps --> SecurityBoundary`: File Operations interact with Security Boundaries.
- `SecurityBoundary --> ReadOps`: Security Boundaries control Read Operations.

- `Execute, JobMgr`: Tool Execution and Job Manager converge on Response to Client.
