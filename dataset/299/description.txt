## 图类型与用途
这是一个流程图，展示了 Java 项目如何通过 Ollama4j 库与 Ollama Server 交互，并利用 Ollama Server 管理的语言模型。该图在仓库中用于概括 Ollama4j 库的架构和使用方式。

## 图的整体布局
图采用从左到右的布局。左侧是用户的 Java 环境，右侧是 Ollama Server 的设置。流程从用户的 Java 项目开始，通过 Ollama4j 与 Ollama Server 通信，最终访问 Models。

## 分组/子图/阶段说明
图中包含两个子图：
- **Your Java Environment**：表示用户的 Java 项目及其使用的 Ollama4j 库。
- **Ollama Setup**：表示 Ollama Server 及其管理的 Models。

## 节点逐项说明
- **Ollama4j**：Ollama4j 是一个 Java 库，作为 Ollama Server 的包装器/绑定。根据 README，Ollama4j 简化了 Java 应用与 Ollama Server 的集成过程。
- **Ollama Server**：Ollama Server 是一个用于运行和管理大型语言模型的服务。
- **Models**：Models 指的是 Ollama Server 管理的各种大型语言模型。
- **Your Java Project**：Your Java Project 代表用户自己的 Java 项目，该项目需要使用 Ollama Server 提供的功能。

## 连线、分支与汇聚关系
- `Your Java Project -> Ollama4j`：用户的 Java 项目使用 Ollama4j 库。
- `Ollama4j -> Ollama Server`：Ollama4j 库与 Ollama Server 进行通信。
- `Ollama Server -> Models`：Ollama Server 管理着各种大型语言模型。

## 仓库语境与术语解释
- **Ollama4j**：根据 README，Ollama4j 是一个 Java 库，旨在简化 Java 应用程序与 Ollama Server 的集成。
- **Ollama Server**：Ollama Server 是一个用于运行和管理大型语言模型的服务。
- **Models**：指的是由 Ollama Server 管理的各种大型语言模型。
- **pom.xml**：Maven 项目的配置文件，用于管理项目依赖，包括 Ollama4j 自身的依赖。
- **OllamaChatMessage**：`src/main/java/io/github/ollama4j/models/chat/OllamaChatMessage.java` 定义了聊天消息的结构，包括角色和内容。
- **OllamaChatRequest**：`src/main/java/io/github/ollama4j/models/chat/OllamaChatRequest.java` 定义了与 Ollama Server 交互的聊天请求。
- **OllamaGenerateRequest**：`src/main/java/io/github/ollama4j/models/generate/OllamaGenerateRequest.java` 定义了与 Ollama Server 交互的生成请求。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 Ollama4j 如何作为 Java 项目与 Ollama Server 之间的桥梁。用户的 Java 项目通过 Ollama4j 库与 Ollama Server 通信，Ollama Server 负责管理和运行各种大型语言模型。核心流程是“Java 项目 -> Ollama4j -> Ollama Server -> Models”，Ollama4j 简化了 Java 应用与 Ollama Server 的集成过程，使得用户可以通过 Java 代码间接使用 Ollama Server 上的模型。
