## Repository Context & Terminology
- **NestJS Monorepo**: A repository structure where multiple applications and libraries are managed within a single repository.
- **Apps Directory**: Contains independent services, each potentially a separate deployable unit.
- **Libs Directory**: Contains shared libraries that can be used by multiple applications within the monorepo.
- **API Server (api-server)**: A service that exposes a REST API, typically running on port 3001. It includes validation and Swagger documentation for API endpoints.
- **Worker (worker)**: A background service that performs tasks such as cron jobs and queue processing. It does not have an HTTP server.
- **Websocket Service (websocket-service)**: A service that provides real-time communication using WebSockets and Socket.IO, running on port 3002.
- **Admin Panel (admin)**: An application that provides an administrative interface, typically running on port 3003.
- **Database Abstraction (db/)**: A library that provides an abstraction layer for interacting with different databases (MongoDB, PostgreSQL, MySQL), allowing for easy switching between them via environment variables.
- **Configuration (configuration/)**: A library that manages environment-specific configurations, providing type-safe validation and centralized settings.
- **Common (common/)**: A library containing reusable utilities, such as logging, error handling, and filters.
- **Security (security/)**: A library providing security middleware, including Helmet, rate limiting, compression, and logging.
- **Swagger (swagger/)**: A library for generating and serving Swagger API documentation, including an interactive UI.
