## Repository Context & Terminology
- **Archival**: The process of moving data to long-term storage for preservation.
- **Cleanup**: The process of removing or purging old or unnecessary data.
- **Retention Period**: The duration for which data must be kept before it can be archived or deleted.
- **Cold Storage**: A storage solution for infrequently accessed data, typically with lower cost and slower access times.
- **Audit Logs**: Records of system events and user activities, used for security and compliance purposes.
- **Inactive User Account**: A user account that has not been used for a specified period of time.
- **Metadata**: Data about data, providing information about the characteristics and context of the data.

## High-Density QA Ground Truth Summary
The Archival & Cleanup Job Scheduler starts by checking the job schedule to determine whether to initiate daily, weekly, or monthly scans. The daily scan focuses on the file system and database, branching based on whether the file age exceeds the retention period. If it does, the file is moved to cold storage, its metadata is updated with an archived timestamp, and an archival report is generated. Otherwise, it's logged that the file is within retention, and an archival report is generated. The weekly scan examines audit logs and permissions, branching based on whether the log data age exceeds 90 days. If so, the log data is purged, and an audit log purge report is generated. Otherwise, the log data is maintained, and an audit log purge report is generated. The monthly scan focuses on inactive user accounts, branching based on whether the user last logged in more than a year ago. If so, the user account is disabled, and a further check determines if the account has been disabled for more than 6 months. If yes, the account is deleted; otherwise, the disabled account is maintained, and an alert is sent. If the user logged in within the last year, it's logged that the user is actively using the account. After generating the archival, audit log purge, or user deletion reports, they are emailed, and the process ends with the "End: Report Sent" node.
