## 仓库语境与术语解释
- **Chisel**：一个 .NET 工具，用于从项目中移除不需要的依赖项，特别是那些与云身份验证相关的依赖项，例如 Azure SDK。
- **Microsoft.Data.SqlClient**：Microsoft SQL Server 的 .NET 数据提供程序。根据 README，即使在本地使用 SQL Server 时，它也可能依赖于 Azure SDK。
- **Azure SDK**：用于访问 Azure 服务的 .NET 库集合。Chisel 可以用来移除 `Microsoft.Data.SqlClient` 对 Azure SDK 的不必要依赖。
- **packages.lock.json**：一个文件，用于记录项目中所有依赖项的版本信息。Chisel 使用此文件来分析依赖关系。
- **IntermediateOutputPath**：MSBuild 属性，指定中间输出文件的路径，Chisel 生成的依赖关系图会保存在此目录下。
- **ChiselGraphName**：MSBuild 属性，指定 Chisel 生成的依赖关系图的文件名。如果文件名以 `.mmd` 或 `.mermaid` 结尾，则生成 Mermaid 格式的图，否则生成 Graphviz 格式的图。
- **ChiselPackage**：MSBuild item，用于指定要从项目中移除的 NuGet 包。
