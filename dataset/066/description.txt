## Repository Context & Terminology
- **Microsoft.Data.SqlClient**: The ADO.NET data provider for SQL Server. It allows .NET applications to connect to and interact with SQL Server databases.
- **Azure.Core**: Provides shared primitives, abstractions, and helpers for modern Azure SDK client libraries.
- **Azure.Identity**: Provides authentication support for Azure services.
- **Microsoft.Extensions.***: A set of .NET libraries providing common services such as logging, configuration, dependency injection, and caching.
- **Microsoft.IdentityModel.***: A set of .NET libraries for handling identity and security tokens, including JWT (JSON Web Tokens).
- **System.Text.Json**: A .NET library for serializing to and deserializing from JSON.
- **System.Configuration.ConfigurationManager**: Provides access to configuration files for .NET applications.
