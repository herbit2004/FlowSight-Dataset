## Repository Context & Terminology
- **Frontend**: The user interface of the application, typically built with technologies like React, Angular, or Vue.js.
- **Backend**: The server-side logic of the application, responsible for handling requests, processing data, and interacting with databases and services.
- **API Endpoint**: A specific URL that the backend exposes for clients to interact with. Examples include `/api/chat`, `/api/properties`, and `/api/graph/similar/:zpid`.
- **Pinecone Index**: A vector database used for storing and querying high-dimensional vectors, often used in recommendation systems and similarity searches.
- **Neo4j Aura**: A graph database as a service, used for storing and querying relationships between data points.
- **MongoDB Atlas**: A cloud-based NoSQL database service.
- **Ingestion**: The process of loading and transforming data into a format suitable for storage and analysis.
