## Edges, Branches & Convergence
- `A --> B`: Data flows from Data Sources to Airbyte ETL for ingestion.
- `B --> C`: Data flows from Airbyte ETL to Dremio Lakehouse for storage.
- `C --> D`: Data flows from Dremio Lakehouse to dbt Transformations for data processing.
- `D --> E`: Transformed data flows from dbt Transformations to Apache Superset for visualization.
- `E --> F`: Business Insights are generated from Apache Superset.
- `C --> G`: Data flows from Dremio Lakehouse to Vector DB Milvus for vector embedding storage.
- `D --> G`: Data flows from dbt Transformations to Vector DB Milvus for vector embedding storage.
- `I --> H`: The Local LLM Ollama provides the language model for the RAG System.
- `G --> H`: Vector embeddings are retrieved from Vector DB Milvus and fed into the RAG System.
- `G & I --> H`: Data from Milvus and Ollama converge at the RAG System.
- `H --> J`: The RAG System feeds data to the AI Chat UI.
- `J --> K`: AI-Powered Insights are generated from the AI Chat UI.

## Repository Context & Terminology
- **Airbyte ETL**: A data integration platform that helps move data from different sources to data warehouses, data lakes, and databases.
- **Dremio Lakehouse**: A data lakehouse platform that provides SQL access to data stored in data lakes.
- **dbt (data build tool)**: A command-line tool that enables data analysts and engineers to transform data in their data warehouses more effectively.
- **Apache Superset**: A modern data exploration and visualization platform.
- **Vector DB Milvus**: An open-source vector database built to manage embedding vectors generated by machine learning models and neural networks.
- **Local LLM Ollama**: Ollama is a tool that allows you to run large language models locally.
- **RAG (Retrieval-Augmented Generation) System**: An AI framework that combines the power of pre-trained language models with information retrieval techniques to generate more accurate and contextually relevant responses.
