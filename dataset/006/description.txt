## Repository Context & Terminology
- **.beads/beads.jsonl**: This file stores issue data in JSONL format. It serves as the primary data source for the analysis.
- **JSONL**: JSON Lines format, a text format where each line is a valid JSON value.
- **PageRank, Betweenness, HITS**: These are graph metrics used to analyze the importance and relationships of nodes in the issue graph.
- **Bubble Tea**: A Go framework for building terminal-based user interfaces.
- **TUI**: Textual User Interface, a user interface rendered in a terminal.
- **--robot-insights**: Command-line flag to output JSON data for AI agents.
- **--export-md**: Command-line flag to export a Markdown report.

## High-Density QA Ground Truth Summary
The diagram illustrates a data analysis pipeline that begins with the `.beads/beads.jsonl` file, a JSONL issue store within the Data Layer. This data is loaded by the Loader within the Analysis Engine, which then passes it to the Graph Builder. The Graph Builder constructs a graph representation of the issue data, which is then used to calculate various metrics, including PageRank, Betweenness, and HITS. From the 9 Metrics node, the data branches out in three directions. First, it's outputted as `--robot-insights` JSON for AI Agents and as an `--export-md` Markdown Report. Second, the metrics data feeds into the Bubble Tea Model within the TUI Layer. The Bubble Tea Model then drives four different TUI views: List View, Graph View, Tree View, and Insights Dashboard. The Bubble Tea framework is used to create the TUI, allowing users to interact with and visualize the analysis results directly in the terminal. The JSONL format is used for storing issue data, and graph metrics like PageRank are used to analyze the relationships between issues.
