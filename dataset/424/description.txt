## 图类型与用途
这是一个分层架构图，描述了“程序员计算器”应用程序的内部结构和数据流。它展示了用户界面、事件处理、核心处理引擎以及验证和实用工具层之间的交互，用于概括应用程序的架构设计。

## 图的整体布局
图采用从上到下的分层布局。顶部是用户界面层，中间是事件分发层和核心处理引擎，底部是验证与实用工具层。数据流从用户界面开始，经过各层处理，最终返回用户界面。

## 分组/子图/阶段说明
图中有四个显式子图，分别代表四个主要层：
- **UI (用户界面层)**：负责用户交互，接收输入并显示结果。
- **EVENT (事件分发层)**：负责处理用户输入和输出，将输入传递给核心处理引擎，并将结果返回给用户界面。
- **CORE (核心处理引擎)**：负责执行数字转换、算术运算和有符号数处理。
- **UTIL (验证 & 实用工具层)**：负责验证用户输入、解析数字和处理错误。

## 节点逐项说明
- **Calculator GUI Application**：用户与计算器交互的图形界面，位于UI层。
- **Input Handler**：接收来自GUI的用户输入，并将其传递给核心处理引擎，位于EVENT层。
- **Output Handler**：接收来自核心处理引擎的计算结果，并将其格式化后显示在GUI上，位于EVENT层。
- **Conversion Engine**：负责在二进制、八进制、十进制和十六进制之间进行数字转换，位于CORE层。
- **Arithmetic Engine**：负责执行各种进制下的加、减、乘、除运算，位于CORE层。
- **Signed Number Engine**：负责处理有符号数，包括 1 的补码和 2 的补码的计算，位于CORE层。
- **Input Validator**：负责验证用户输入的有效性，确保输入符合特定进制的规则，位于UTIL层。
- **Number Parser**：负责将用户输入的字符串解析为数字，以便进行计算，位于UTIL层。
- **Error Handler**：负责处理程序运行过程中出现的错误，并向用户提供错误信息，位于UTIL层。

## 连线、分支与汇聚关系
- `GUI -> INPUT`：GUI将用户输入传递给Input Handler。
- `GUI -> OUTPUT`：GUI接收Output Handler的输出结果。
- `INPUT -> CONV`：Input Handler将输入传递给Conversion Engine。
- `INPUT -> ARITH`：Input Handler将输入传递给Arithmetic Engine。
- `INPUT -> SIGNED`：Input Handler将输入传递给Signed Number Engine。
- `CONV -> VALID`：Conversion Engine将数据传递给Input Validator进行验证。
- `ARITH -> PARSER`：Arithmetic Engine将数据传递给Number Parser进行解析。
- `SIGNED -> ERROR`：Signed Number Engine将数据传递给Error Handler进行错误处理。
- `CONV -> OUTPUT`：Conversion Engine将处理结果传递给Output Handler。
- `ARITH -> OUTPUT`：Arithmetic Engine将处理结果传递给Output Handler。
- `SIGNED -> OUTPUT`：Signed Number Engine将处理结果传递给Output Handler。
- `CONV, ARITH, SIGNED -> OUTPUT`：Conversion Engine、Arithmetic Engine 和 Signed Number Engine 的结果都汇聚到 Output Handler。

## 仓库语境与术语解释
- **GUI (Graphical User Interface)**：图形用户界面，是用户与程序交互的界面。
- **Conversion Engine**：根据 README，该引擎支持二进制、八进制、十进制和十六进制之间的转换。
- **Arithmetic Engine**：根据 README，该引擎支持加、减、乘、除运算，且适用于所有进制。
- **Signed Number Engine**：根据 README，该引擎支持 1 的补码和 2 的补码的计算。
- **Input Validator**：用于验证用户输入的有效性，例如确保输入的字符符合当前进制的规则。
- **Number Parser**：将用户输入的字符串解析为数字，以便进行后续的计算。
- **Error Handler**：处理程序运行过程中出现的错误，并向用户提供错误信息。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了程序员计算器的分层架构，用户通过 Calculator GUI Application 输入数据，经过 Input Handler 分发给 Conversion Engine、Arithmetic Engine 和 Signed Number Engine 进行处理，处理后的数据分别经过 Input Validator、Number Parser 和 Error Handler 进行验证、解析和错误处理，最终由 Output Handler 将结果返回给 Calculator GUI Application。核心处理引擎包括进制转换、算术运算和有符号数处理，整体架构体现了分层设计的思想。
