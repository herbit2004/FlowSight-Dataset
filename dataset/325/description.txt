## 图类型与用途
这是一个流程图/架构图，展示了 LLM-TradeBot 的对抗决策框架 (ADF) 的整体架构和交易流程。该图在仓库中用于概括核心交易逻辑，包括数据收集、量化分析、预测、对抗、反思、决策、风险审计和执行等多个环节，以及各个环节中智能体的角色和数据流向。

## 图的整体布局
图整体采用从上到下的布局，从数据收集层开始，经过多个分析和决策层，最终到达执行层。每个层级都包含不同的智能体和数据处理环节，数据自上而下流动。

## 分组/子图/阶段说明
图中包含 8 个显式子图，分别代表不同的处理层级：
- **1️⃣ Data Collection Layer (数据收集层)**：负责从市场收集原始数据。
- **2️⃣ Quant Analysis Layer (量化分析层)**：利用市场快照数据进行量化分析，生成量化信号。
- **3️⃣ Prediction Layer (预测层)**：利用市场快照数据进行价格预测，生成价格上涨概率预测。
- **4️⃣ Bull/Bear Adversarial Layer (多头/空头对抗层)**：从多头和空头角度分析市场，生成多头和空头视角分析结果。
- **5️⃣ Reflection Layer (反思层)**：分析交易历史，提取模式和建议。
- **6️⃣ Decision Layer (决策层)**：整合量化信号、预测结果、多头/空头视角分析结果和反思洞察，做出交易决策。
- **7️⃣ Risk Audit Layer (风险审计层)**：对交易决策进行风险审计，生成风险等级和防护措施。
- **8️⃣ Execution Layer (执行层)**：执行交易决策，完成交易。

## 节点逐项说明
- **🕵️ DataSyncAgent (The Oracle)**：数据同步代理，负责从市场收集原始数据。根据 `src/agents/data_sync_agent.py`，该 Agent 异步并发请求多周期 K 线数据，并进行时间对齐验证。
- **MarketSnapshot 5m/15m/1h K-lines**：市场快照，包含不同时间粒度的 K 线数据（5 分钟、15 分钟、1 小时）。
- **👨‍🔬 QuantAnalystAgent (The Strategist)**：量化分析代理，利用市场快照数据进行量化分析。根据 `src/agents/quant_analyst_agent.py`，该 Agent 提供情绪分析和 OI 燃料验证。
- **📈 TrendSubAgent**：趋势子代理，分析市场趋势。
- **📊 OscillatorSubAgent**：震荡指标子代理，分析市场震荡指标。
- **💹 SentimentSubAgent**：情绪子代理，分析市场情绪。
- **Quant Signals**：量化信号，由趋势、震荡指标和情绪分析生成。
- **🔮 PredictAgent (The Prophet)**：预测代理，利用市场快照数据进行价格预测。根据 `src/agents/predict_agent.py`，该 Agent 输出未来价格上涨概率。
- **LightGBM Model Auto-Train 2h**：LightGBM 模型，用于价格预测，每 2 小时自动训练。
- **P_Up Prediction**：价格上涨概率预测。
- **🐂 Bull Agent (The Optimist)**：多头代理，从多头角度分析市场。
- **🐻 Bear Agent (The Pessimist)**：空头代理，从空头角度分析市场。
- **Bull Perspective**：多头视角分析结果。
- **Bear Perspective**：空头视角分析结果。
- **📜 Trade History Last 10 Trades**：交易历史，记录最近 10 笔交易。
- **🧠 ReflectionAgent (The Philosopher)**：反思代理，分析交易历史，提取模式和建议。
- **Reflection Insights Patterns & Recommendations**：反思洞察，包括交易模式和建议。
- **⚖️ DecisionCoreAgent (The Critic)**：决策核心代理，整合量化信号、预测结果、多头/空头视角分析结果和反思洞察，做出交易决策。根据 `src/agents/decision_core_agent.py`，该 Agent 使用加权投票机制和动态权重调整。
- **RegimeDetector**：用于检测市场状态。
- **PositionAnalyzer**：用于分析当前仓位。
- **VoteResult Action + Confidence**：投票结果，包括交易动作和置信度。
- **🛡️ RiskAuditAgent (The Guardian)**：风险审计代理，对交易决策进行风险审计。根据 `src/agents/risk_audit_agent.py`，该 Agent 自动修正止损方向，进行资金预演，并拥有一票否决权。
- **AuditResult Risk Level + Guard**：审计结果，包括风险等级和防护措施。
- **🚀 ExecutionEngine (The Executor)**：执行引擎，执行交易决策。根据 `src/execution/engine.py`，该模块负责执行交易操作。

## 连线、分支与汇聚关系
- `DataSyncAgent (The Oracle) -> MarketSnapshot 5m/15m/1h K-lines`：数据同步代理将收集到的市场数据存储为市场快照。
- `MarketSnapshot 5m/15m/1h K-lines -> QuantAnalystAgent (The Strategist)`：市场快照数据被传递给量化分析代理进行分析。
- `QuantAnalystAgent (The Strategist) -> TrendSubAgent`：量化分析代理将任务分发给趋势子代理。
- `QuantAnalystAgent (The Strategist) -> OscillatorSubAgent`：量化分析代理将任务分发给震荡指标子代理。
- `QuantAnalystAgent (The Strategist) -> SentimentSubAgent`：量化分析代理将任务分发给情绪子代理。
- `TrendSubAgent & OscillatorSubAgent & SentimentSubAgent -> Quant Signals`：趋势、震荡指标和情绪分析结果汇聚形成量化信号，形成汇聚关系。
- `MarketSnapshot 5m/15m/1h K-lines -> PredictAgent (The Prophet)`：市场快照数据被传递给预测代理进行价格预测。
- `PredictAgent (The Prophet) -> LightGBM Model Auto-Train 2h`：预测代理使用 LightGBM 模型进行预测。
- `LightGBM Model Auto-Train 2h -> P_Up Prediction`：LightGBM 模型输出价格上涨概率预测。
- `MarketSnapshot 5m/15m/1h K-lines -> Bull Agent (The Optimist)`：市场快照数据被传递给多头代理进行分析。
- `MarketSnapshot 5m/15m/1h K-lines -> Bear Agent (The Pessimist)`：市场快照数据被传递给空头代理进行分析。
- `Bull Agent (The Optimist) -> Bull Perspective`：多头代理输出多头视角分析结果。
- `Bear Agent (The Pessimist) -> Bear Perspective`：空头代理输出空头视角分析结果。
- `Quant Signals & P_Up Prediction & Bull Perspective & Bear Perspective & Reflection Insights Patterns & Recommendations -> DecisionCoreAgent (The Critic)`：量化信号、预测结果、多头/空头视角分析结果和反思洞察汇聚到决策核心代理，形成汇聚关系。
- `DecisionCoreAgent (The Critic) -> RegimeDetector`：决策核心代理使用市场状态检测器。
- `DecisionCoreAgent (The Critic) -> PositionAnalyzer`：决策核心代理使用仓位分析器。
- `RegimeDetector & PositionAnalyzer -> VoteResult Action + Confidence`：市场状态检测和仓位分析结果汇聚形成投票结果，形成汇聚关系。
- `VoteResult Action + Confidence -> RiskAuditAgent (The Guardian)`：投票结果被传递给风险审计代理进行审计。
- `RiskAuditAgent (The Guardian) -> AuditResult Risk Level + Guard`：风险审计代理输出审计结果，包括风险等级和防护措施。
- `AuditResult Risk Level + Guard -> ExecutionEngine (The Executor)`：审计结果被传递给执行引擎执行交易。
- `ExecutionEngine (The Executor) -.-> Trade History Last 10 Trades`：执行引擎完成交易后，更新交易历史。
- `Trade History Last 10 Trades -> ReflectionAgent (The Philosopher)`：交易历史被传递给反思代理进行分析。
- `ReflectionAgent (The Philosopher) -> Reflection Insights Patterns & Recommendations`：反思代理输出反思洞察，包括交易模式和建议。

## 仓库语境与术语解释
- **Adversarial Decision Framework (ADF)**：对抗决策框架，是 LLM-TradeBot 的核心架构，通过多智能体协作和对抗，实现高胜率和低回撤的自动化期货交易。
- **DataSyncAgent (The Oracle)**：数据同步代理，负责从 Binance 交易所获取 K 线数据，并进行数据清洗和对齐，确保数据质量。
- **QuantAnalystAgent (The Strategist)**：量化分析代理，负责对市场数据进行量化分析，生成技术指标和量化信号，为决策提供依据。
- **PredictAgent (The Prophet)**：预测代理，使用机器学习模型预测未来价格走势，为决策提供参考。
- **DecisionCoreAgent (The Critic)**：决策核心代理，整合各个智能体的分析结果，做出最终交易决策。
- **RiskAuditAgent (The Guardian)**：风险审计代理，负责对交易决策进行风险评估和控制，确保交易安全。
- **ExecutionEngine (The Executor)**：执行引擎，负责执行交易指令，完成交易操作。
- **LightGBM Model**：一种梯度提升决策树算法，用于价格预测。
