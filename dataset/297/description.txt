## Repository Context & Terminology
- **WebSocket**: A communication protocol that provides full-duplex communication channels over a single TCP connection. It's used for real-time data transfer between the client and the server.
- **SDK (Software Development Kit)**: A set of software development tools that allows the creation of applications for a certain software package, software framework, hardware platform, computer system, video game console, operating system, or similar platform.
- **JSONL**: A format where each line is a separate JSON object. It's often used for storing logs and data.
- **Session**: Represents a user's interaction with the application over a period of time. It includes data such as user options, messages, and state.
- **Interface**: A contract that defines the methods and properties that a class must implement. In this case, `IClaudeAgentSDKClient` is an interface that defines the methods for interacting with the Claude Agent SDK.
- **Implementation**: A concrete class that implements an interface. `SimpleClaudeAgentSDKClient` is a simple implementation of the `IClaudeAgentSDKClient` interface.
