## Diagram Type & Purpose
This is a flowchart diagram illustrating the workflow of a task management system involving a user, an agent team, a shared task board, and a team mailbox. The diagram depicts how tasks are created, assigned, worked on, and how communication flows between the different actors in the system. It serves as a visual representation of the task management process.

## Overall Layout
The diagram's primary direction is top-down (TD). It presents a hierarchical structure with the User at the top, followed by the Agent Team, Shared Task Board, and Team Mailbox. The User node serves as the start node, and the User node also serves as the end node.

- **Shared Task Board**: A central repository for managing tasks and their status.
- **Team Mailbox**: A communication channel for sharing status updates and broadcasts within the team.
- **Lead Agent (orchestrator)**: The agent responsible for task creation, assignment, and overall workflow management.
