## Repository Context & Terminology
- **StackQL**: A query tool that allows users to query cloud infrastructure using SQL.
- **ProviderDefs**: Definitions that allow StackQL to interact with different cloud providers.
- **Cloud Provider API**: The API provided by cloud service providers (e.g., AWS, Azure, GCP) for managing their services.
- **`stackql exec`**: StackQL command to execute a SQL query.
- **`stackql shell`**: StackQL command to start an interactive shell.
- **`stackql srv`**: StackQL command to start a server.
