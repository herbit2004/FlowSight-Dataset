## Edges, Branches & Convergence
- `DataClient --> Auth`: Data client sends MCP requests to the Data Plane Authentication component.
- `MgmtClient --> Auth2`: Management client sends API calls to the Control Plane Authentication component.
- `Auth --> Routing`: Data Plane Authentication forwards requests to Adapter Routing.
- `Auth --> ToolRouting`: Data Plane Authentication forwards requests to Tool Router Gateway.
- `Auth2 --> AdapterMgmt`: Control Plane Authentication forwards requests to Adapter Management.
- `Auth2 --> ToolMgmt`: Control Plane Authentication forwards requests to Tool Management.
- `AdapterMgmt & ToolMgmt --> DeploymentMgmt`: Adapter and Tool Management both send requests to the Deployment Manager (convergence).
- `AdapterMgmt & ToolMgmt --> MetadataMgmt`: Adapter and Tool Management both send requests to the Metadata Manager (convergence).
- `Routing -.-> MCPServers`: Adapter Routing establishes session affinity with MCP Servers.
- `ToolRouting -.-> ToolRouters`: Tool Router Gateway establishes session affinity with Tool Gateway Routers.
- `ToolRouters ==> ToolServers`: Tool Gateway Routers perform dynamic routing to Registered Tool Servers.
- `DeploymentMgmt --> Cluster`: Deployment Manager deploys and monitors the Kubernetes Cluster.
- `MetadataMgmt <--> Metadata`: Metadata Manager reads and writes to the Metadata Store.

## Repository Context & Terminology
- **MCP (Management Control Plane)**: A system for managing and controlling various aspects of a software deployment, including adapters, tools, and metadata.
- **Data Plane**: The part of the system that handles the actual data processing and routing.
- **Control Plane**: The part of the system that manages the configuration and control of the data plane.
- **RBAC (Role-Based Access Control)**: A method of regulating access to computer or network resources based on the roles of individual users within an organization.
- **CRUD (Create, Read, Update, Delete)**: The four basic operations performed on persistent storage.
- **Session Affinity**: A mechanism to ensure that requests from the same client are always routed to the same server instance.
- **Dynamic Routing**: A routing technique where the routing path is determined dynamically based on network conditions.
