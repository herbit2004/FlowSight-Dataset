## Repository Context & Terminology
- **Netlink**: A Linux kernel interface used for communication between kernel and userspace processes.
- **Genetlink**: A generic netlink family that simplifies the creation of new netlink families.
- **Conntrack**: Connection tracking, a kernel feature that tracks network connections.
- **Nflog**: Netfilter log, a kernel feature that logs network packets.
- **Nfqueue**: Netfilter queue, a kernel feature that queues network packets for userspace processing.
- **Nftables**: A modern packet filtering framework in the Linux kernel.
- **Rtnetlink**: A netlink family used for routing and link management.
- **Devlink**: A netlink family used for device management.
