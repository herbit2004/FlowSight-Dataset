## Repository Context & Terminology
- **autoqa CLI**: The command-line interface for the `autoqa` tool, providing various commands for test plan generation, exploration, and execution.
- **autoqa.config.json**: A JSON file that stores configuration settings for the `autoqa` tool, allowing users to customize its behavior.
- **Playwright Engine**: A Node library to automate Chromium, Firefox and WebKit with a single API. Playwright is built to enable cross-browser web automation that is ever-green, capable, reliable and fast.
- **Markdown Specs**: Markdown files containing specifications for test cases, used as input for test plan generation.
- **test-plan.json**: A JSON file containing the generated test plan, which can be used for automated testing.
- **Exploration Artifacts**: A collection of data generated during the exploration process, including the navigation graph, element inventory, and exploration transcript.
- **Navigation Graph**: A graph representing the navigation paths explored during the exploration process.
- **Element Inventory**: A list of elements identified on the web pages during the exploration process.

## High-Density QA Ground Truth Summary
The `autoqa CLI` serves as the entry point, branching into `Plan Commands`, `Run Command`, and `Init Command`. The `Plan Commands` further diverge into `explore`, `generate`, and `explore + generate`, determining the test plan creation method. `explore` initiates `Configuration Loading` from `autoqa.config.json`, `CLI Options`, and `Default Values`, which then leads to `Browser Creation` using the `Playwright Engine`. This results in the `Explore Agent` utilizing `Planning Tools` to produce `Exploration Artifacts` such as the `Navigation Graph`, `Element Inventory`, and `Exploration Transcript`. Alternatively, `generate` uses a `Plan Agent` to perform `Test Plan Generation`, creating `Markdown Specs` that are converted into `*.md Test Files` and a `test-plan.json` file. The `Configuration Loading` stage is crucial as it determines the settings for the subsequent exploration and generation processes. The final outputs are the `Exploration Artifacts` and the `*.md Test Files` along with `test-plan.json`, representing the results of the exploration and test plan generation processes, respectively. The `Playwright Engine` is a key dependency for browser automation during exploration.
