## Repository Context & Terminology
- **Entry Layer**: The initial layer that receives requests from external sources like web interfaces, IM tools, or APIs.
- **Feature Layer**: The layer responsible for providing various features such as chat, coding, feed, and knowledge management.
- **Agent Layer**: The layer containing different agents like Wegent Chat, Claude Code, Agno, and Dify, which perform specific tasks.
- **Execution Environment**: The environment where the agents are executed, which can be an agent sandbox, a cloud device, or a local device.
