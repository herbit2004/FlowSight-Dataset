- `Rule Set Lookup -- Rule Set A --> Rule Evaluation: A`: The system selects Rule Set A for evaluation.

- `Rule Evaluation: A -- Matched Rule --> Action Orchestration`: If Rule Set A matches, the system proceeds to action orchestration.
