## Repository Context & Terminology
- **OfficeIMO**: A .NET library for creating and manipulating Office Open XML documents (e.g., .docx files) programmatically.
- **OfficeIMO.Word**: The core module within OfficeIMO that provides functionalities for working with Word documents.
- **Extensions**: Additional modules that extend the capabilities of OfficeIMO.Word to support different file formats or functionalities.
- **AngleSharp**: A cross-platform HTML parsing library written in C#. It's often used for extracting data from HTML documents or manipulating them.
- **QuestPDF**: An open-source, modern .NET library for PDF document generation. It offers a fluent API for creating complex layouts and documents.
- **SkiaSharp**: A .NET binding for the Skia graphics library. It provides a powerful and cross-platform API for 2D graphics rendering.
- **Markdown**: A lightweight markup language with plain text formatting syntax. It is often used for creating formatted text using a text editor.
