## Repository Context & Terminology
- **Vite**: A build tool that aims to provide a faster and leaner development experience for modern web projects.
- **Tailwind CSS**: A utility-first CSS framework for rapidly building custom designs.
- **Capacitor**: An open-source native runtime for building web apps that run on iOS, Android, and the web.
- **Cloudflare R2**: A distributed object storage service that offers high performance and low cost.
- **Cloudflare D1**: A serverless SQL database built on Cloudflare's global network.
- **Cloudflare KV**: A key-value storage service optimized for edge delivery.
- **API Gateway**: A service that acts as a single entry point for all API requests, providing routing, authentication, and other functionalities.
- **APIKeyPool**: A mechanism for managing and rotating API keys to prevent abuse and ensure security.

## High-Density QA Ground Truth Summary
The system architecture begins with the client layer, utilizing Vite, Tailwind, and Capacitor for UI development. Client-side processing handles tasks like parsing document formats (PPTX, PDF, DOCX, XLSX) and managing local storage via IndexedDB and localStorage. The client communicates with the backend through the API Gateway, which routes requests to specific handlers: Auth Handler, Chat Handler, API Handler, and Share Handler. The Auth Handler authenticates requests, potentially accessing Cloudflare D1 SQLite Database and utilizing Cloudflare KV Session Cache. The API Handler interacts with external services like Gemini API, Brave Search API, GNews API, and pollinations.ai, and also accesses Cloudflare KV for guest usage and proxy caching. Both Chat Handler and API Handler rely on an APIKeyPool for managing API keys, which is part of the Enterprise API Management. The APIKeyPool is followed by a Health Check, Circuit Breaker, Retry Manager, and a 4-Tier Degradation strategy to ensure resilience. The client can directly access Cloudflare R2 Object Storage for storing avatars and files. The backend components are hosted on Cloudflare Pages.
