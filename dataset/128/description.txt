## 图类型与用途
这是一个流程图，描述了 MultiAgentPPT 项目中多智能体协同生成 PPT 幻灯片的核心流程。该图展示了从用户输入研究内容到最终生成 PPT 的架构和步骤，用于概括多智能体生成 PPT 的整体流程。

## 图的整体布局
图整体采用从上到下的布局。顶部是用户输入和初步处理阶段，中间是并行研究和内容合并阶段，底部是幻灯片生成和质量检查阶段。

## 分组/子图/阶段说明
图中包含一个名为 "Loop PPT Agent" 的子图，用于描述幻灯片生成过程的循环机制。除此之外，逻辑上可以分为以下几个阶段：
- **大纲生成阶段**：包括用户输入、调用 Outline Agent、MCP 检索资料和生成大纲。
- **大纲确认与拆分阶段**：用户确认大纲后，大纲被拆分成更小的、更易于处理的主题或章节。
- **并行研究阶段**：多个 Research Agent 并行处理拆分后的大纲内容，并使用 RAG 技术检索相关信息。
- **内容合并阶段**：汇总智能体将多个 Research Agent 的调研结果合并，生成 PPT 的内容。
- **幻灯片生成与检查阶段**：循环生成每一页幻灯片，并进行质量检查。

## 节点逐项说明
- **用户输入研究内容**：流程的起点，用户提供希望生成 PPT 的主题或内容。
- **调用 Outline Agent**：根据用户输入，调用大纲生成智能体，负责生成 PPT 的初步内容大纲。
- **MCP 检索资料**：MCP (可能是指某种检索机制或组件) 用于检索与主题相关的资料，为生成大纲提供信息支持。
- **生成大纲**：Outline Agent 基于检索到的资料，生成初步的 PPT 大纲。
- **用户确认大纲**：用户审核生成的大纲，确认是否符合预期。这是一个决策节点，如果大纲不满意，可能需要返回修改。
- **发送大纲给 PPT 生成 Agent**：用户确认大纲后，将其发送给负责生成 PPT 内容的智能体。
- **Split Outline Agent 拆分大纲**：将大纲拆分成更小的、更易于处理的主题或章节。
- **Parallel Agent 并行处理**：启动多个智能体并行处理拆分后的大纲内容，提高效率。
- **Research Agent 1/2/3**：多个研究智能体，每个智能体负责对一个或多个主题进行深入调研和信息收集。
- **自动知识库检索 RAG**：每个 Research Agent 使用 RAG (Retrieval-Augmented Generation) 技术，从自动知识库中检索相关信息，为内容生成提供支持。
- **SummaryAgent合并结果**：汇总智能体，将多个 Research Agent 的调研结果合并，生成 PPT 的内容。
- **Loop PPT Agent 生成幻灯片页**：进入一个循环，用于生成每一页幻灯片。
- **Write PPT Agent 生成每页幻灯片**：负责生成单页幻灯片的内容，包括文字、图片等。
- **Check PPT Agent 检查每页内容质量，最多重试 3 次**：检查幻灯片的内容质量，如果质量不达标，则返回 Write PPT Agent 重新生成，最多重试 3 次。

## 连线、分支与汇聚关系
- `用户输入研究内容 -> 调用 Outline Agent`：用户输入研究内容后，调用 Outline Agent。
- `调用 Outline Agent -> MCP 检索资料`：调用 Outline Agent 后，进行 MCP 检索资料。
- `MCP 检索资料 -> 生成大纲`：MCP 检索资料后，生成大纲。
- `生成大纲 -> 用户确认大纲`：生成大纲后，用户确认大纲。
- `用户确认大纲 -> 发送大纲给 PPT 生成 Agent`：用户确认大纲后，发送大纲给 PPT 生成 Agent。
- `发送大纲给 PPT 生成 Agent -> Split Outline Agent 拆分大纲`：发送大纲给 PPT 生成 Agent 后，Split Outline Agent 拆分大纲。
- `Split Outline Agent 拆分大纲 -> Parallel Agent 并行处理`：Split Outline Agent 拆分大纲后，Parallel Agent 并行处理。
- `Parallel Agent 并行处理 -> Research Agent 1/2/3`：Parallel Agent 并行处理后，分别启动 Research Agent 1/2/3。
- `Research Agent 1/2/3 -> 自动知识库检索 RAG`：每个 Research Agent 使用 RAG 技术，从自动知识库中检索相关信息。
- `自动知识库检索 RAG -> SummaryAgent合并结果`：多个 Research Agent 的调研结果汇聚到 SummaryAgent合并结果，形成汇聚关系。
- `SummaryAgent合并结果 -> Loop PPT Agent 生成幻灯片页`：SummaryAgent合并结果后，进入 Loop PPT Agent 生成幻灯片页。
- `Loop PPT Agent 生成幻灯片页 -> Write PPT Agent 生成每页幻灯片`：进入 Loop PPT Agent 后，Write PPT Agent 生成每页幻灯片。
- `Write PPT Agent 生成每页幻灯片 -> Check PPT Agent 检查每页内容质量，最多重试 3 次`：Write PPT Agent 生成每页幻灯片后，Check PPT Agent 检查每页内容质量。
- `Check PPT Agent 检查每页内容质量，最多重试 3 次 -> Write PPT Agent 生成每页幻灯片`：如果幻灯片内容质量不达标，则返回 Write PPT Agent 重新生成，形成循环。

## 仓库语境与术语解释
- **MultiAgentPPT**：一个基于 A2A + MCP + ADK 的多智能体系统，支持流式并发生成高质量 (可在线编辑）PPT 内容。
- **Outline Agent**：根据用户需求生成初步内容大纲。
- **MCP (Multi-Channel Processing)**：可能指某种检索机制或组件，用于检索与主题相关的资料。在 `backend/slide_outline/README.md` 中提到需要启动 MCP 工具。
- **RAG (Retrieval-Augmented Generation)**：一种结合检索和生成的技术，用于从知识库中检索相关信息，为内容生成提供支持。
- **Split Outline Agent**：将大纲内容细分为多个主题。
- **Research Agent**：多个智能体分别对每个主题进行深入调研。
- **Summary Agent**：将调研结果汇总生成 PPT 内容。
- **Loop PPT Agent**：使用循环 Agent 生成每一页 PPT，代替一次性生成全部内容，方便生成更多页数，避免 LLM 的 token 输出限制。
- **A2A (Agent-to-Agent)**：一种智能体之间的通信协议或框架，用于实现多智能体协同工作。
- **ADK (Agent Development Kit)**：一种用于开发和部署智能体的工具包。

## 可作为 QA Ground Truth 的高信息密度摘要
该流程图描述了 MultiAgentPPT 项目中多智能体协同生成 PPT 的核心流程。从用户输入研究内容开始，系统调用 Outline Agent 生成初步大纲，并使用 MCP 检索相关资料。用户确认大纲后，Split Outline Agent 将大纲拆分成多个主题，多个 Research Agent 并行处理这些主题，并使用 RAG 技术检索信息。Summary Agent 合并研究结果，然后 Loop PPT Agent 循环生成每一页幻灯片，并由 Check PPT Agent 检查质量。该流程的关键环节包括大纲生成、并行研究和幻灯片生成与检查，最终生成完整的 PPT 演示文稿。
