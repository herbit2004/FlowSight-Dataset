## Edges, Branches & Convergence
- `A --> B`: User input triggers the Outline Agent.
- `B --> C`: Outline Agent uses MCP to retrieve materials.
- `C --> D`: MCP materials are used to generate an outline.
- `D --> E`: The generated outline is presented to the user for confirmation.
- `E --> F`: If the user confirms the outline, it is sent to the PPT Generation Agent.
- `F --> G`: The PPT Generation Agent splits the outline.
- `G --> H`: The split outline is processed in parallel.
- `H --> I1`, `H --> I2`, `H --> I3`: The parallel agent distributes tasks to Research Agents 1, 2, and 3.
- `I1 --> RAG1`, `I2 --> RAG2`, `I3 --> RAG3`: Each Research Agent performs RAG.
- `RAG1 --> J`, `RAG2 --> J`, `RAG3 --> J`: Results from the RAG processes converge at the Summary Agent.
- `J --> L`: The Summary Agent's combined results are used by the Loop PPT Agent.
- `L --> L1`: The Loop PPT Agent triggers the Write PPT Agent.
- `L1 --> L2`: The Write PPT Agent passes the generated slide to the Check PPT Agent.
- `L2 --> L1`: If the Check PPT Agent finds issues, it loops back to the Write PPT Agent for a retry (up to 3 times).

- **MCP**: Likely stands for Master Control Program, responsible for retrieving relevant materials.
- **PPT Generation Agent**: An agent responsible for generating the PPT presentation based on the outline.

- **Parallel Agent**: An agent that processes the split outline in parallel using multiple research agents.
- **Research Agent**: An agent responsible for researching and gathering information for the presentation.
- **RAG (Retrieval-Augmented Generation)**: A technique used by the research agents to retrieve information from a knowledge base and generate content.
- **SummaryAgent**: An agent that combines the results from the research agents.
- **Loop PPT Agent**: An agent that loops through the process of generating PPT slides.
- **Write PPT Agent**: An agent that generates each slide of the PPT presentation.
- **Check PPT Agent**: An agent that checks the content quality of each slide.

## High-Density QA Ground Truth Summary
The process begins with the user providing research content, which is then fed into the Outline Agent. The Outline Agent uses MCP to retrieve relevant materials and generates an outline. The user confirms this outline, which is then sent to the PPT Generation Agent. The PPT Generation Agent splits the outline using the Split Outline Agent, enabling parallel processing by multiple Research Agents. These Research Agents (1, 2, and 3) each perform Retrieval-Augmented Generation (RAG) to gather information. The results from the RAG processes converge at the SummaryAgent, which combines the findings. The combined results are then used by the Loop PPT Agent to generate the PPT slides. Inside the Loop PPT Agent subgraph, the Write PPT Agent generates each slide, which is then passed to the Check PPT Agent for quality assessment. If the Check PPT Agent identifies issues, it loops back to the Write PPT Agent for a retry, with a maximum of 3 retries. The process continues until all slides are generated and checked. The final output is a PPT presentation. The use of RAG highlights the system's ability to leverage existing knowledge bases for content generation, improving the quality and relevance of the presentation.
