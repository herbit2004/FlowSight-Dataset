## Repository Context & Terminology
- **.Net Self-Hosting**: Refers to the capability of a .NET application to host its own runtime environment, rather than relying on an external web server like IIS.
- **Redis/MemoryCache**: These are caching technologies used to improve application performance by storing frequently accessed data in memory.
- **DTO (Data Transfer Object)**: A design pattern used to transfer data between application layers, often used to encapsulate data for transport.
- **NuGet Packages**: Packages of reusable .NET code that can be easily added to a project.
- **HTTP Pipeline Filters**: Components that intercept and process HTTP requests and responses, used for tasks like authentication, authorization, and logging.
- **CRUD Operations**: Create, Read, Update, and Delete operations, which are fundamental data manipulation operations in applications.
