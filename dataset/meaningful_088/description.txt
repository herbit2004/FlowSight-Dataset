It depicts the flow of events from sending a referral invitation to applying a reward to the referrer's account, including handling declined invitations and user inactivity. The diagram serves as a visual representation of the referral program's logic and helps in understanding the user journey and potential intervention points.

## Edges, Branches & Convergence
- `A --> B`: A referral invitation is sent.
- `B -- Yes --> C`: The user accepts the invitation.
- `B -- No --> D`: The user declines the invitation.
- `C --> E`: The new user onboarding process is complete.
- `E -- Yes --> F`: The new user makes an initial purchase.
- `E -- No --> G`: The new user does not make an initial purchase.
- `G --> H`: A discount is offered to the user.
- `H -- Yes --> I`: The user uses the discount.
- `H -- No --> J`: The user does not use the discount.
- `I --> F`: The new user makes a purchase.
- `F --> K`: A referral reward is triggered.
- `K --> L`: The referrer reward is calculated.
- `D --> M`: The declined invitation is tracked.
- `M --> N`: The reason for declining the invitation is analyzed.

- `O --> P`: A re-engagement campaign is considered.
- `F` converges from `E -- Yes --> F` and `I --> F`.

## Repository Context & Terminology
- **Referral Invitation**: An invitation sent to a potential new user by an existing user.
- **New User Onboarding**: The process of guiding a new user through the initial setup and usage of a product or service.
- **Initial Purchase**: The first purchase made by a new user.
- **Nudge**: A subtle prompt or reminder to encourage a specific action.
- **Discount**: A reduction in the price of a product or service.
- **User Inactivity**: A period of time during which a user does not engage with a product or service.
- **Re-engagement Campaign**: A marketing effort to encourage inactive users to return to a product or service.

## High-Density QA Ground Truth Summary
The flowchart begins with "Referral Invitation Sent," which leads to the decision "User Accepts Invite?". If the user accepts ("Yes" branch), the flow proceeds to "New User Onboarding" and then to the decision "Initial Purchase?". If the user declines ("No" branch), the flow goes to "Track Declined Invitation," followed by "Analyze Declined Invitation Reason" and "Improve Referral Messaging." If the user makes an initial purchase, "Referral Reward Triggered" is activated, leading to "Referrer Reward Calculation" and finally "Apply Reward to Referrer Account." If no initial purchase is made, a "Nudge: Offer Discount" is presented, followed by the decision "Discount Used?". If the discount is used ("Yes" branch), a "New User Purchase" occurs, triggering the referral reward. If the discount is not used ("No" branch), "Track User Inactivity" is initiated, leading to "Consider Re-engagement Campaign" and "Re-engagement Email Sent." The "Referral Reward Triggered" node is a convergence point, reached either directly after an initial purchase or after a purchase using a discount. The referral program aims to incentivize existing users to invite new users, rewarding them upon successful conversion and purchase.
