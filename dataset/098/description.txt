## 图类型与用途
这是一个架构图，展示了 GNN (GeneralizedNotationNotation) 项目的组织结构，将项目划分为源代码、文档和输出三个主要部分，并展示它们之间的依赖关系。该图在 README 中用于概括项目架构。

## 图的整体布局
图采用从左到右的布局，将项目架构分为三个主要部分：源代码、文档和输出。信息流从左侧的文档和中间的源代码流向右侧的输出。

## 分组/子图/阶段说明
图中包含三个子图，分别代表项目的三个主要组成部分：
- **📁 Source Code (src/)**：包含项目源代码的目录，是 GNN 项目的核心组成部分。
- **📚 Documentation (doc/)**：包含项目文档的目录，为项目提供支持和指导。
- **🎯 Outputs (output/)**：包含项目输出的目录，展示了 GNN 项目的最终成果。

## 节点逐项说明
- **⚙️ Pipeline Scripts 0_template.py → 24_intelligent_analysis.py**：包含一系列流水线脚本，用于数据处理和分析。
- **🧠 Core Modules gnn/, render/, llm/**：包含 `gnn/`, `render/`, `llm/` 等核心模块，实现 GNN 的核心功能，例如 GNN 语言的解析、渲染和 LLM 集成。
- **🔧 Utilities utils/, pipeline/**：包含 `utils/` 和 `pipeline/` 等工具模块，提供辅助功能和流水线管理。
- **🧪 Testing tests/**：包含 `tests/` 目录，用于存放单元测试和集成测试。
- **📖 Core Docs gnn/, syntax, examples**：包含关于 `gnn/` 模块、GNN 语法和示例的核心文档。
- **🎯 Specialized pymdp/, rxinfer/, mcp/**：包含针对特定框架（如 `pymdp/`, `rxinfer/`, `mcp/`）的专业文档。
- **🧩 Applications cognitive_phenomena/**：包含关于 `cognitive_phenomena/` 等应用场景的文档。
- **📊 Reports Type checking, analysis**：包含类型检查和分析报告。
- **🎨 Visualizations Graphs, matrices**：包含生成的图表和矩阵等可视化结果。
- **💻 Generated Code PyMDP, RxInfer, PyTorch, NumPyro**：包含生成的针对 PyMDP, RxInfer, PyTorch, NumPyro 等框架的代码。
- **🌐 Static Site HTML summaries**：包含 HTML 格式的摘要信息，用于静态站点展示。

## 连线、分支与汇聚关系
- `Pipeline Scripts -> Reports`：流水线脚本的执行结果生成报告。
- `Core Modules -> Visualizations`：核心模块的功能生成可视化结果。
- `Core Modules -> Generated Code`：核心模块的功能生成特定框架的代码。
- `Core Docs -> Pipeline Scripts`：核心文档为流水线脚本的编写提供指导。
- `Specialized -> Core Modules`：专业文档指导核心模块的开发，使其能够支持特定的框架。
- `Applications -> Core Modules`：应用场景的需求驱动核心模块的开发。

## 仓库语境与术语解释
- **GNN (Generalized Notation Notation)**：一种基于文本的语言，用于标准化 Active Inference 生成模型的表示和通信。
- **Active Inference**：一种认知科学理论，认为生物体通过最小化自由能来行动和感知。
- **Pipeline Scripts**：一系列 Python 脚本，从 `0_template.py` 到 `24_intelligent_analysis.py`，用于执行 GNN 项目的各个阶段。
- **Core Modules**：实现 GNN 核心功能的模块，包括 `gnn/` (GNN 语言解析), `render/` (代码生成), `llm/` (LLM 集成)。
- **PyMDP, RxInfer, PyTorch, NumPyro**：GNN 项目支持的用于生成模型的框架。
- **cognitive_phenomena**：GNN 项目的应用场景，例如认知现象建模。
- **Reports**：包含类型检查和分析报告，用于验证 GNN 模型的正确性。
