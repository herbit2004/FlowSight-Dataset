## Edges, Branches & Convergence
- `Portal --> SWA_Angular`: A request from the portal website is routed to the Angular static web application.
- `SWA_Angular -- "portal.contoso.com/api/**" --> APIM`: The Angular application sends API requests to the API Management gateway.
- `APIM -- "portal.contoso.com/api/**" --> Functions`: The API Management gateway routes requests to Azure Functions.
- `Blog -- "blog.contoso.com" --> ACA_Next`: A request from the blog website is routed to the Next.js application.
- `ACA_Next -. "Strapi API" .-> ACA_Strapi`: The Next.js application communicates with the Strapi CMS via its API.
- `CMS -- "cms.contoso.com" --> ACA_Strapi`: A request from the CMS website is routed to the Strapi CMS application.
- `ACA_Strapi -- "read/write" ----> DB_PostresSQL`: Strapi reads and writes data to the PostgreSQL database.
- `DB_PostresSQL -- "read only" --> Functions`: Azure Functions reads data from the PostgreSQL database.
- `ACA_Strapi -- "upload" --> Storage`: Strapi uploads files to Azure Blob Storage.
- `API --> APIM`: A request from the API is routed to the API Management gateway.
- `APIM -- "api.contoso.com" --> Functions`: The API Management gateway routes requests to Azure Functions.
- `Functions <-- "read/write" --> DB_Mongo`: Azure Functions reads and writes data to the MongoDB database.
- `Stripe ---> APIM`: A request from Stripe is routed to the API Management gateway.
- `APIM -- "stripe.contoso.com" --> ACA_Stripe`: The API Management gateway routes requests to the Stripe service within Azure Container Apps.
- `ACA_Stripe <-. "validate payment (through APIM)" .-> Functions`: The Stripe service triggers payment validation through Azure Functions.

## Repository Context & Terminology
- **Azure Container Apps**: A serverless container execution environment that enables running microservices and containerized applications without managing infrastructure.
- **Azure API Management (APIM)**: A fully managed service that enables developers to publish, secure, transform, analyze, and monetize APIs.
- **Azure Functions**: A serverless compute service that enables you to run code on-demand without having to explicitly provision or manage infrastructure.
- **Azure Blob Storage**: A massively scalable and secure object storage for any type of unstructured data—images, videos, audio, documents, and more—easily and cost-effectively.
- **Next.js**: An open-source React front-end development web framework that enables functionalities such as server-side rendering and static website generation.
- **Strapi**: An open-source headless CMS that allows developers to build customizable APIs.
- **Angular**: A platform and framework for building single-page client applications using HTML, CSS and TypeScript.

## High-Density QA Ground Truth Summary
The architecture diagram begins with external requests originating from the "Internet" subgraph, specifically from `https://portal.contoso.com`, `https://blog.contoso.com`, `https://cms.contoso.com`, `https://stripe.contoso.com`, and `https://api.contoso.com`. The "Stripe" service triggers payment validation through "Azure Functions". The diagram highlights the central role of "Azure API Management" in routing and securing API requests within the Contoso ecosystem, and the use of "Azure Container Apps" for hosting containerized applications like "Next.js" and "Strapi".
