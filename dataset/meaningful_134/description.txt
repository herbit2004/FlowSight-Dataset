## Edges, Branches & Convergence
- `A --> B`: Data flows from data ingestion to data validation and cleaning.
- `B -- Valid Data --> C`: Valid data flows from data validation to feature engineering.
- `B -- Invalid Data --> E`: Invalid data flows from data validation to data anomaly logging.
- `C --> D`: Engineered features flow from feature engineering to model training.
- `D --> F`: Trained model flows from model training to model evaluation.
- `F -- Pass Metrics Threshold --> G`: If the model evaluation metrics pass the threshold, the model flows to model serialization.
- `F -- Fail Metrics Threshold --> H`: If the model evaluation metrics fail the threshold, the process flows to retraining with modified parameters.
- `H --> D`: Retrained model flows back to model training.
- `G --> I`: Serialized model flows from model serialization to model registry.
- `I --> J`: Model artifacts flow from model registry to A/B testing service.
- `J --> K`: Real-time inference request is sent to the A/B testing service.
- `K -- Group A --> L`: Inference request is routed to Model Instance A (Latest Stable) for Group A.
- `K -- Group B --> M`: Inference request is routed to Model Instance B (Canary Release) for Group B.
- `L --> N`: Prediction response is generated by Model Instance A.
- `M --> N`: Prediction response is generated by Model Instance B.
- `L and M converge at N`: Prediction responses from both model instances converge at the prediction response node.
- `N --> O`: Prediction response flows to performance monitoring.
- `O --> P`: Performance monitoring data flows to Data Dog Alerts.

## Repository Context & Terminology
- **Data Ingestion**: The process of acquiring and importing data from various sources into a system for processing and analysis.
- **Data Validation**: The process of ensuring that data meets predefined quality standards and constraints.
- **Feature Engineering**: The process of selecting, transforming, and creating features from raw data to improve the performance of machine learning models.
- **Gradient Boosted Trees**: A machine learning algorithm that combines multiple decision trees to create a strong predictive model.
- **Model Evaluation**: The process of assessing the performance of a trained machine learning model using various metrics.
- **Model Serialization**: The process of converting a trained machine learning model into a format that can be stored and loaded later.
- **Model Registry**: A centralized repository for storing and managing trained machine learning models and their associated metadata.
- **A/B Testing**: A method of comparing two versions of a system or product to determine which one performs better.
- **Canary Release**: A deployment strategy where a new version of a system is rolled out to a small subset of users before being released to the entire user base.
- **Data Dog**: A monitoring and analytics platform for cloud-scale applications.
