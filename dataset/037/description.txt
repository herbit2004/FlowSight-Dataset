## 图类型与用途
这是一个架构图，展示了 Secure Enterprise OS 的整体架构，该系统被设计成一个具有类似生物大脑、记忆、神经系统和身体的结构，用于 AI 辅助的 1C 企业开发。该图在仓库中用于概览系统的主要组件及其相互关系。

## 图的整体布局
图整体采用从上到下的布局。顶部是用户界面，中间是神经系统和 AI 核心，底部是认知记忆和系统服务。

## 分组/子图/阶段说明
图中包含四个子图，分别代表系统的不同功能模块：
- **Brain ("🧠 The Brain (AI Core)")**：代表 AI 系统的核心大脑部分，负责决策、规划和执行。
- **Memory ("🐘 Cognitive Memory")**：代表 AI 系统的认知记忆，用于存储和检索信息。
- **Nervous ("📡 Nervous System")**：代表 AI 系统的神经系统，负责组件之间的通信。
- **Body ("🛠️ The Body (Services)")**：代表 AI 系统的身体，负责与外部世界交互并执行任务。
- **Users ("👥 User Interfaces")**：代表用户界面，用于与 AI 系统进行交互。

## 节点逐项说明
- **Unified Portal**：统一的用户门户，提供访问 AI 系统功能的入口。
- **VS Code / EDT (MCP)**：使用 VS Code 或 EDT (MCP) 作为集成开发环境，用于开发和调试 AI 系统。根据 README，EDT 指的是 1C:EDT，是 1C 平台的开发环境。
- **NATS JetStream**：使用 NATS JetStream 消息队列系统实现异步通信和事件驱动架构。README 中提到 NATS 用于实现毫秒级的异步反应。
- **LangGraph Orchestrator**：是整个 AI 系统的编排器，使用 LangGraph 框架，负责协调各个节点的工作流程。
- **Planner Node**：负责根据目标和当前状态制定行动计划。
- **Executor Node**：负责执行 Planner 节点制定的计划。
- **Reflector Node**：负责反思执行结果，评估计划的有效性，并为未来的计划提供反馈。
- **Postgres 17**：使用 Postgres 数据库存储结构化数据。
- **pgvector**：Postgres 的向量扩展，用于存储和检索向量嵌入，支持语义搜索和相似度匹配。
- **Neo4j - Code Graph**：使用 Neo4j 图数据库存储代码图，用于理解代码之间的依赖关系和影响。README 中提到该图用于映射 1C 元数据的依赖关系。
- **Git Automation**：负责 Git 仓库的自动化操作，例如代码提交、分支管理等。
- **Docker Control**：负责 Docker 容器的管理和控制，例如容器的创建、启动、停止等。
- **1C Integration (OData/RAS)**：负责与 1C 企业管理平台的集成，通过 OData 和 RAS 协议进行数据交换和功能调用。
- **Security Monitor**：使用 Wazuh 进行安全监控，检测潜在的安全威胁。

## 连线、分支与汇聚关系
- `Users <--> NATS`：用户界面通过 NATS 消息队列与系统进行交互。
- `NATS <--> Orchestrator`：NATS 消息队列将用户请求传递给 Orchestrator，并将 Orchestrator 的响应传递给用户界面。
- `Orchestrator <--> Memory`：Orchestrator 与 Memory 组件进行数据交互，例如从 Memory 中检索信息或将信息存储到 Memory 中。
- `Orchestrator <--> Body`：Orchestrator 与 Body 组件进行交互。
- `Body --> NATS`：Body 组件的输出通过 NATS 发送。

## 仓库语境与术语解释
- **LangGraph**：一种用于编排 LLM 任务的框架，用于构建 stateful、cyclic 的 Agent。
- **NATS JetStream**：一个消息队列系统，用于实现异步通信和事件驱动架构，替代了之前的 RabbitMQ。
- **Postgres 17 + pgvector**：用于存储 AI 系统的认知记忆，包括向量、图和历史记录。
- **Neo4j - Code Graph**：用于存储 1C 代码的知识图谱，帮助 AI 理解代码的依赖关系。
- **OData/RAS**：用于与 1C 企业管理平台进行数据交换和功能调用的协议。
- **Wazuh**：一个安全监控工具，用于检测潜在的安全威胁。
- **MCP (Meta-Configuration Protocol)**：用于连接 IDE (如 VS Code, Cursor) 和 1C:Enterprise 平台的协议。

## 可作为 QA Ground Truth 的高信息密度摘要
该架构图展示了 Secure Enterprise OS 的核心组件。用户通过 Unified Portal 或 VS Code/EDT 与系统交互，请求通过 NATS JetStream 消息队列传递给 LangGraph Orchestrator。Orchestrator 与 Cognitive Memory (Postgres 17 + pgvector, Neo4j) 和 Body (Git Automation, Docker Control, 1C Integration, Security Monitor) 进行交互，Body 组件的输出最终通过 NATS 返回。该架构的核心是使用 LangGraph 编排 AI 任务，并利用 NATS 实现异步通信，同时集成了 1C 平台和安全监控。
