## Repository Context & Terminology
- **CSI (Channel State Information)**: Information about the communication channel, often used in wireless communication for signal processing and analysis.
- **ESP32**: A low-cost, low-power system-on-a-chip (SoC) series with Wi-Fi and Bluetooth capabilities.
- **Nexmon**: A firmware patching framework for Broadcom/Cypress Wi-Fi chips, often used for monitor mode and frame injection.
- **UDP (User Datagram Protocol)**: A connectionless protocol used for transmitting data packets over a network.
- **PCap (Packet Capture)**: A file format for storing captured network packets.
- **YAML (YAML Ain't Markup Language)**: A human-readable data serialization format often used for configuration files.
- **Three.js**: A JavaScript library for creating and displaying animated 3D computer graphics in a web browser.
- **ReID (Person Re-Identification)**: The task of identifying the same person across different images or videos.
