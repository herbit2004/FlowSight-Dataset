## Repository Context & Terminology
- **Arc**: Stands for "Atomically Reference Counted". It's a type in Rust that provides shared ownership of a value. Multiple `Arc` instances can point to the same data, and the data is deallocated when the last `Arc` pointing to it is dropped.
- **RwLock**: Stands for "Read-Write Lock". It's a synchronization primitive that allows multiple readers or a single writer to access a shared resource concurrently.
- **HashMap**: A data structure that stores key-value pairs, allowing for efficient retrieval of values based on their keys.
- **dyn Tool**: Represents a dynamic trait object for the `Tool` trait. This allows the registry to hold different types of tools that implement the `Tool` trait.
