## Edges, Branches & Convergence
- `Start --> Run init.py`: Starts the initialization process.
- `Run init.py --> Feed BOOTSTRAP_MISSION.md or SETUP_MISSION.md`: Feeds the system with mission or setup information.
- `Feed BOOTSTRAP_MISSION.md or SETUP_MISSION.md --> Edit AGENTS.md`: Edits the agent configuration.
- `Edit AGENTS.md --> Trigger: spec-writer.skill`: Triggers the specification writing process.
- `Trigger: spec-writer.skill --> Artifact: PRD.md`: Generates the Product Requirements Document.
- `Artifact: PRD.md --> Human Approve?`: Requires human approval for the PRD.
- `Human Approve? -- No --> Trigger: spec-writer.skill`: If not approved, returns to the specification writing process.
- `Human Approve? -- Yes --> Trigger: arch-design.skill`: If approved, proceeds to the architectural design phase.
- `Trigger: arch-design.skill --> Artifact: PLAN.md + C4`: Generates the architectural plan.
- `Artifact: PLAN.md + C4 --> Human Approve?`: Requires human approval for the architectural plan.
- `Human Approve? -- No --> Trigger: arch-design.skill`: If not approved, returns to the architectural design process.
- `Human Approve? -- Yes --> Trigger: Decompose project/TASKS.md`: If approved, proceeds to task decomposition.
- `Trigger: Decompose project/TASKS.md --> Tasks Remaining?`: Checks if there are any remaining tasks.
- `Tasks Remaining? -- Yes --> Pick Task`: If tasks remain, picks a task.
- `Pick Task --> Trigger: tdd-cycle.skill`: Triggers the TDD cycle for the selected task.
- `Trigger: tdd-cycle.skill --> Test Fails`: Checks if the tests fail.
- `Test Fails --> Implement Pass`: Implements the code to pass the tests.
- `Implement Pass --> Refactor`: Refactors the code.
- `Refactor --> Audit Log`: Logs the audit information.
- `Audit Log --> Tasks Remaining?`: Returns to check for remaining tasks.
- `Tasks Remaining? -- No --> Trigger: integrity-check.skill`: If no tasks remain, proceeds to integrity check.
- `Trigger: integrity-check.skill --> Trigger: security-audit.skill`: Triggers the security audit.
- `Trigger: security-audit.skill --> Human Review?`: Requires human review.
- `Human Review? -- No --> Fix Issues`: If not approved, fixes the issues.
- `Fix Issues --> Trigger: integrity-check.skill`: Returns to the integrity check.
- `Human Review? -- Yes --> Deploy`: If approved, deploys the software.
- `Deploy --> Done`: Completes the process.
