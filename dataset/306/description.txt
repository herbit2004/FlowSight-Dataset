## Diagram Type & Purpose
This is an architecture diagram illustrating the relationships between different contexts within a Role-Based Access Control (RBAC) system. It depicts the flow of assignments and associations between users, roles, permissions, and menus, managed by the RBAC domain service. The diagram provides a high-level overview of the system's structure and how different components interact to manage access control.

## Overall Layout
The diagram is laid out from top to bottom (TB). It shows a hierarchical structure with the RBAC Context at the top, followed by User, Role, Menu, and Permission Contexts. The RBAC Domain Service acts as the central component, connecting to the User, Role, and Permission contexts.

## Subgraphs / Stages
The diagram contains explicit subgraphs representing different contexts: RBAC Context, User Context, Role Context, Menu Context, and Permission Context.

## Repository Context & Terminology
- **RBAC (Role-Based Access Control)**: A security mechanism that restricts system access to authorized users based on their roles.
- **Aggregate Root**: A concept from Domain-Driven Design (DDD) representing a cluster of associated objects that are treated as a single unit for data changes.
- **Gateway**: An interface that provides a simplified way to access underlying resources or services.
- **Domain Service**: A service that encapsulates domain-specific logic not naturally belonging to an entity or value object.
- **Context**: A boundary within which a particular model is applicable.

## High-Density QA Ground Truth Summary
The diagram begins with the RBAC Domain Service, which is the central component for managing access control. The RBAC Domain Service interacts directly with the User, Role, and Permission contexts. A user, represented by the User Aggregate Root, is assigned to a role, represented by the Role Aggregate Root. This assignment is depicted by a dashed arrow labeled "Assign." The Role Aggregate Root is then associated with both Permission and Menu contexts, indicated by dashed arrows labeled "Associate." The Permission Context contains the Permission Aggregate Root and Permission Gateway, while the Menu Context contains the Menu Aggregate Root and Menu Gateway. These associations define the permissions and menus accessible to users assigned to specific roles. The RBAC Domain Service manages these relationships, ensuring that users have appropriate access based on their assigned roles and the associated permissions and menus. The diagram ends with the Permission and Menu contexts, representing the final level of access control.
