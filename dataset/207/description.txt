## 图类型与用途
这是一个流程图，描述了多智能体系统（MAS）如何对输入的思想进行顺序思考。该图展示了从接收输入到生成统一响应的完整流程，用于概括 MAS 的核心处理逻辑。

## 图的整体布局
图采用从上到下的布局。顶部是输入节点，随后是分析、策略选择和多智能体处理阶段，底部是最终的输出节点。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可以分为四个阶段：输入与复杂度分析、策略选择、多智能体并行处理、最终合成与响应。

## 节点逐项说明
- **A[Input Thought]**：表示系统接收到的初始输入，即需要进行分析和处理的原始想法或问题。
- **B[AI Complexity Analyzer]**：负责分析输入思想的复杂度，例如涉及的概念数量、逻辑深度等。根据 `src/mcp_server_mas_sequential_thinking/routing/ai_complexity_analyzer.py`，该模块使用 AI 智能体来评估 thought 的复杂性。
- **C[Complexity Metadata Stored]**：存储复杂度分析器生成的元数据，这些元数据用于后续步骤的决策，例如选择合适的策略或调整智能体的行为。
- **D[Fixed Strategy: full_exploration]**：代表系统采用的固定策略，这里是“完全探索”，意味着系统会尽可能全面地分析和处理输入思想的各个方面。根据 README 和 `src/mcp_server_mas_sequential_thinking/routing/multi_thinking_router.py`，当前系统强制使用 `full_exploration` 策略。
- **E[Step 1: Initial Synthesis]**：对输入思想进行初步的整合和提炼，为后续的专业智能体分析做准备。
- **F[Step 2: Parallel Specialist Agents]**：多个专业的 AI 智能体并行工作，分别从不同的角度或领域对输入思想进行分析和处理。根据 README，这些智能体包括 Factual Agent、Emotional Agent、Critical Agent、Optimistic Agent、Creative Agent 和 Synthesis Agent。
- **G[Step 3: Final Synthesis]**：将各个专业智能体的分析结果进行整合，形成一个更全面、更深入的理解。根据 README，Synthesis Agent 负责整合所有视角，生成连贯的响应。
- **H[Unified Response]**：系统最终生成的输出，是对输入思想经过多智能体协同分析后的综合性回答或解决方案。

## 连线、分支与汇聚关系
- `A -> B`：输入思想传递给 AI 复杂度分析器。
- `B -> C`：复杂度分析器将分析结果（复杂度元数据）存储起来。
- `C -> D`：存储的复杂度元数据引导固定策略的执行。
- `D -> E`：固定策略启动顺序思考过程，首先进行初始合成。
- `E -> F`：初始合成的结果被传递给并行专业智能体。
- `F -> G`：并行专业智能体的分析结果被传递给最终合成步骤。
- `G -> H`：最终合成将所有结果整合，生成统一响应。

## 仓库语境与术语解释
- **Multi-Agent System (MAS)**：一个由多个智能体组成的系统，这些智能体协同工作以解决复杂问题。该项目使用 MAS 实现顺序思考过程。
- **Agno**：用于构建多智能体系统的框架。该项目使用 Agno 框架来实现 MAS。
- **MCP server**：一个后台服务，扩展 LLM 客户端的功能。该项目是一个 MCP server，为 LLM 客户端提供顺序思考能力。
- **full_exploration**：一种固定的处理策略，确保所有请求都经过相同的多步骤路径。
- **AI Complexity Analyzer**：一个 AI 驱动的模块，用于评估输入思想的复杂性。它分析语义深度、哲学含义和概念复杂性。
- **Thinking Agents**：系统中使用的专业 AI 智能体，包括 Factual Agent、Emotional Agent、Critical Agent、Optimistic Agent、Creative Agent 和 Synthesis Agent。

## 可作为 QA Ground Truth 的高信息密度摘要
该图描述了一个基于多智能体系统的顺序思考流程。流程从接收“Input Thought”开始，通过“AI Complexity Analyzer”分析其复杂度，然后采用固定的“full_exploration”策略。接下来，系统通过“Step 1: Initial Synthesis”、“Step 2: Parallel Specialist Agents”和“Step 3: Final Synthesis”进行多智能体并行处理和结果整合，最终生成“Unified Response”。其中，AI 复杂度分析和多智能体并行处理是关键环节。该流程体现了从输入到最终响应的完整处理过程，并强调了多智能体协同工作的重要性。
