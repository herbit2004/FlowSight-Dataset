## 图类型与用途
这是一个流程图，描述了 `json-render` 框架如何将用户提示转换为用户界面。它展示了从用户输入到最终渲染输出的核心流程，用于概括框架的工作原理。

## 图的整体布局
图采用从左到右的布局。流程从用户提示开始，经过 AI 处理和渲染，最终输出用户界面。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为三个阶段：用户输入、AI 处理与 JSON 规范生成、用户界面渲染。

## 节点逐项说明
- **User Prompt**：用户提供的自然语言提示，用于描述期望生成的用户界面。
- **AI + Catalog**：核心处理单元，包含人工智能模型和组件目录（Catalog）。AI 模型根据用户提示，并参考组件目录中的可用组件，生成 JSON 规范。根据 README，组件目录定义了 AI 可以使用的组件，起到了约束作用。
- **JSON Spec**：AI 生成的 JSON 格式的界面描述，包含了界面组件的结构、属性和数据。
- **Renderer**：渲染器，负责将 JSON 规范转换为实际的用户界面，例如 React 组件、Vue 组件等。
- **[guardrailed]**：表示 AI 的行为受到组件目录的约束，只能使用目录中定义的组件，确保输出的安全性和可控性。
- **[predictable]**：表示 JSON 规范的输出是可预测的，符合预定义的 schema，保证输出的结构和数据类型符合预期。
- **[streamed]**：表示渲染过程是流式的，可以逐步渲染界面，提高响应速度和用户体验。

## 连线、分支与汇聚关系
- `User Prompt -> AI + Catalog`：用户提示被发送到 AI + 组件目录进行处理。
- `AI + Catalog -> JSON Spec`：AI + 组件目录根据用户提示和组件目录生成 JSON 规范。
- `JSON Spec -> Renderer`：JSON 规范被传递给渲染器进行渲染。
- `AI + Catalog -.- [guardrailed]`：AI + 组件目录受到 "guardrailed" 的约束。
- `JSON Spec -.- [predictable]`：JSON 规范是 "predictable" 的。
- `Renderer -.- [streamed]`：渲染器的渲染过程是 "streamed" 的。

## 仓库语境与术语解释
- **Generative UI**：README 中提到，`json-render` 是一个 Generative UI 框架，AI 根据自然语言提示生成界面，并受限于预定义的组件。
- **Catalog**：组件目录，定义了 AI 可以使用的组件，确保生成的用户界面安全可控。README 中展示了如何使用 `defineCatalog` 定义组件目录。
- **JSON Spec**：AI 生成的 JSON 格式的界面描述，包含了界面组件的结构、属性和数据。
- **Renderer**：将 JSON 规范转换为实际用户界面的渲染器。README 中展示了 React 的渲染器示例。
- **guardrailed**：AI 只能使用组件目录中的组件，受到约束。
- **predictable**：JSON 输出匹配预定义的 schema。
- **streamed**：渲染过程是流式的，可以逐步渲染界面。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 `json-render` 框架的核心流程：用户通过 User Prompt 提供自然语言提示，AI + Catalog 根据提示和预定义的组件目录生成 JSON Spec，最后 Renderer 将 JSON Spec 渲染成用户界面。AI 的行为受到组件目录 "guardrailed" 的约束，JSON Spec 的输出是 "predictable" 的，渲染过程是 "streamed" 的。该流程体现了 `json-render` 框架通过组件目录约束 AI 行为，保证输出安全性和可控性的特点。
