## Repository Context & Terminology
- **SMS, Email, Webhook, API**: These represent common methods for external systems to interact with the described system, triggering actions or providing data.
- **Cron**: A time-based job scheduler in Unix-like computer operating systems. It enables users to schedule jobs (commands or shell scripts) to run automatically at a specific time, date, or interval.
- **Durable Queue**: A message queue that persists messages to disk or another durable storage mechanism. This ensures that messages are not lost if the system crashes or restarts.
- **Headless Browser**: A browser that runs without a graphical user interface. It is often used for automated testing and web scraping.
- **Webhooks**: Automated HTTP callbacks triggered by events in one system and sent to another.
- **HTTP**: Hypertext Transfer Protocol, the foundation of data communication on the World Wide Web.
