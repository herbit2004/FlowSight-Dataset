## 图类型与用途
这是一个流程图，展示了 ArsMedicaTech 平台中 LLM 层如何与外部知识源交互，以响应用户的查询或提示。它描述了用户查询如何通过提示路由引擎、决策树工具、RAG 模块以及外部知识源（NCBI、clinicaltrials.gov、medlineplus.gov）最终到达 LLM 核心引擎，并生成答案返回给用户。

## 图的整体布局
图整体采用从上到下的布局。顶部是用户输入节点，中间是 LLM 层，底部是外部知识源。数据流从用户查询开始，经过 LLM 层的处理和外部知识源的检索，最终由 LLM 生成答案返回给用户。

## 分组/子图/阶段说明
图中包含两个子图：
- **LLM Layer**：包含 LLM 核心引擎、提示路由引擎、决策树工具和 RAG 模块，负责处理用户输入和生成答案。
- **External Knowledge Sources**：包含 NCBI、clinicaltrials.gov 和 medlineplus.gov，提供外部知识检索能力。

## 节点逐项说明
- **USER (User Prompt or Query)**：代表用户输入的原始问题或请求，是整个流程的起点。
- **PROMPT (Prompt Router / Engine)**：负责接收用户输入，并根据输入的内容和类型，将其路由到不同的处理模块。
- **DECISION_TREE (Decision Tree Tool)**：一个基于规则的决策引擎，用于根据用户提示的特定特征，执行确定性的逻辑判断。
- **RAG (RAG / Vector Search (SurrealDB))**：代表检索增强生成（Retrieval-Augmented Generation）模块，它使用向量搜索技术（此处使用 SurrealDB）在结构化记录中查找相关信息。README 提到计划使用 SurrealDB 实现 RAG。
- **LLM (LLM Core Engine)**：代表平台的核心大型语言模型，负责生成最终的答案或响应。
- **NCBI (Search NCBI)**：代表与美国国家生物技术信息中心（NCBI）数据库的集成，用于搜索生物医学文献。
- **CLINICAL (Search clinicaltrials.gov)**：代表与 clinicaltrials.gov 网站的集成，用于搜索临床试验信息。
- **MEDLINE (Search medlineplus.gov)**：代表与 medlineplus.gov 网站的集成，用于搜索面向患者的医疗信息。

## 连线、分支与汇聚关系
- `USER -> PROMPT`：用户输入的问题或查询首先被发送到提示路由/引擎。
- `PROMPT -> DECISION_TREE`：提示路由引擎根据确定性逻辑将部分请求发送到决策树工具。
- `PROMPT -> NCBI`：提示路由引擎将部分请求发送到 NCBI 进行文献搜索。
- `PROMPT -> CLINICAL`：提示路由引擎将部分请求发送到 clinicaltrials.gov 进行临床试验信息搜索。
- `PROMPT -> MEDLINE`：提示路由引擎将部分请求发送到 medlineplus.gov 进行患者信息搜索。
- `PROMPT -> RAG`：提示路由引擎将部分请求发送到 RAG 模块进行结构化记录搜索。
- `DECISION_TREE -> LLM`：决策树工具的输出被发送到 LLM。
- `NCBI -> LLM`：从 NCBI 检索到的信息被发送到 LLM。
- `CLINICAL -> LLM`：从 clinicaltrials.gov 检索到的信息被发送到 LLM。
- `MEDLINE -> LLM`：从 medlineplus.gov 检索到的信息被发送到 LLM。
- `RAG -> LLM`：从 RAG 模块检索到的信息被发送到 LLM。
- `DECISION_TREE, NCBI, CLINICAL, MEDLINE, RAG -> LLM`：多个知识来源的信息汇聚到 LLM。
- `LLM -> USER`：LLM 基于所有输入的信息生成最终答案，并将其返回给用户。

## 仓库语境与术语解释
- **LLM (Large Language Model)**：大型语言模型，是 ArsMedicaTech 平台的核心组件，用于生成答案和响应。README 提到计划集成 OpenAI-compatible LLMs。
- **RAG (Retrieval-Augmented Generation)**：检索增强生成，一种利用外部知识库来增强 LLM 生成能力的技术。README 提到计划使用 SurrealDB 实现 RAG。
- **SurrealDB**：一个多模型数据库，支持图、关系、文档、键值和全文搜索等多种数据模型。README 提到 SurrealDB 被用作 ArsMedicaTech 平台的数据库。
- **NCBI (National Center for Biotechnology Information)**：美国国家生物技术信息中心，提供生物医学文献数据库。
- **clinicaltrials.gov**：一个提供临床试验信息的网站。
- **medlineplus.gov**：一个提供面向患者的医疗信息的网站。
- **Prompt Engineering**: README 中提到，近期的 AI 集成计划包括 prompt engineering 支持。
- **Decision Tree**: README 中提到，近期的 AI 集成计划包括构建 decision tree 集成，用于确定性的 AI 推理。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 ArsMedicaTech 平台如何利用 LLM 和外部知识源响应用户查询。用户查询首先被发送到 Prompt Router，然后根据查询类型分发到 Decision Tree Tool、RAG 模块以及 NCBI、clinicaltrials.gov 和 medlineplus.gov 等外部知识源进行检索。检索到的信息与 Decision Tree 的输出一起汇聚到 LLM Core Engine，最终生成答案返回给用户。其中，RAG 模块使用 SurrealDB 进行向量搜索，LLM 的集成是平台 AI 能力的核心。
