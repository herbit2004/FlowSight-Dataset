## Repository Context & Terminology
- **Raw CSV Dataset**: The initial data source, typically containing structured data in comma-separated values format.
- **Feature Engineering**: The process of transforming raw data into features that better represent the underlying problem to the predictive models, resulting in improved model accuracy.
- **Supervised Models**: Machine learning models trained on labeled data, where the algorithm learns a mapping from input features to output labels.
- **Clustering Models**: Machine learning models that group similar data points together based on inherent patterns in the data.
- **Model Artifacts**: The serialized representation of trained machine learning models, including weights, biases, and other parameters.
- **Metrics Report**: A report containing various metrics used to evaluate the performance of machine learning models, such as accuracy, precision, recall, and F1-score.
- **FastAPI**: A modern, high-performance web framework for building APIs with Python.
- **Flask**: A lightweight web framework for Python, often used for building web applications and APIs.
- **Next.js**: A React framework for building web applications with server-side rendering and static site generation capabilities.
