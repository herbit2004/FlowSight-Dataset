## 分组/子图/阶段说明
图中包含四个子图，分别代表特征工程的四个阶段：
- **数据准备**：对原始数据进行清洗、转换和标准化。
- **特征选择**：从已有的特征中选择最相关的特征。
- **特征衍生**：通过组合、多项式等方式创建新的特征。
- **特征验证**：使用模型评估特征集的性能，并决定是否发布或回溯。

## 节点逐项说明
- **A (原始数据源)**：表示未经处理的原始数据。
- **B (特征提取)**：从原始数据中提取有用的特征。
- **C (缺失值处理)**：处理数据中的缺失值，例如填充或删除。
- **D (异常值检测)**：检测数据中的异常值。
- **E (数据标准化)**：将数据缩放到一个标准范围内，例如使用 Z-score 或 MinMax。
- **F (数据转换)**：对数据进行转换，例如对数转换。
- **G (特征评估)**：评估特征的质量和相关性。
- **H (特征重要性排序)**：根据特征的重要性对特征进行排序。
- **I (选择 Top-N 特征)**：选择最重要的前 N 个特征。
- **J (特征组合)**：将不同的特征组合在一起，创建新的特征。
- **K (多项式特征)**：创建多项式特征，例如平方项或交叉项。
- **L (特征交叉)**：将不同的特征进行交叉组合。
- **M (模型训练)**：使用特征集训练机器学习模型。
- **N (性能评估)**：评估模型的性能。
- **O (特征集发布)**：如果模型性能合格，则发布特征集。
- **P (回溯分析)**：如果模型性能不合格，则进行回溯分析，找出问题所在。

## 连线、分支与汇聚关系
- A -> B：从原始数据源提取特征。
- B -> C：对提取的特征进行缺失值处理。
- C -> D：对处理后的数据进行异常值检测。
- D -> E：对检测后的数据进行数据标准化。
- E -> F：对标准化后的数据进行数据转换。
- F -> G：对转换后的特征进行评估。
- G -> H：对评估后的特征进行重要性排序。
- H -> I：选择 Top-N 个特征。
- I -> J：对选择的特征进行组合。
- J -> K：创建多项式特征。
- K -> L：进行特征交叉。
- L -> M：使用特征集训练模型。
- M -> N：评估模型性能。
- N -- 合格 --> O：如果性能合格，则发布特征集。
- N -- 不合格 --> P：如果性能不合格，则进行回溯分析。
- P -> G：回溯分析后，重新进行特征评估。
