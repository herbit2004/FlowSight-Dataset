## Repository Context & Terminology
- **IndexedDB**: A NoSQL database built into web browsers for client-side storage.
- **Appwrite**: An open-source backend-as-a-service platform that provides a cloud database and other backend functionalities.
- **Real-time Events**: Events triggered by changes in the database, enabling real-time updates across connected clients.
- **WebSocket**: A communication protocol that provides full-duplex communication channels over a single TCP connection, enabling real-time data transfer.
- **Client Layer**: The part of the application that runs on the user's device, handling user interactions and local data storage.
- **Sync Layer**: The part of the application responsible for synchronizing data between the client and the cloud database.
- **Multi-Device**: Refers to the application's ability to synchronize data and provide a consistent experience across multiple devices or browser tabs.
