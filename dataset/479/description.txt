## High-Density QA Ground Truth Summary
The process begins with COBOL files, located in the `source/` directory and having `.cbl` or `.cpy` extensions, which are fed into the Regex/Syntax Parsing stage for deep SQL/Variable extraction. The parsed data is then passed to the AI Agents framework, which triggers four agents: CobolAnalyzerAgent, BusinessLogicExtractor, Java/C# Converter, and DependencyMapper. The CobolAnalyzerAgent and BusinessLogicExtractor output data to the SQLite database (`Data/migration.db`), storing run metadata, file content, raw AI analysis, and generated code. The Java/C# Converter outputs both to the SQLite database and generates Java/C# code located in `output/java` or `output/csharp`. The DependencyMapper outputs data to the Neo4j database (`bolt://localhost:7687`), storing dependencies, relationship graph, and impact analysis data. Finally, both the SQLite and Neo4j databases provide data to the Web Portal & MCP Server running at `localhost:5028`. The final outputs are the generated Java/C# code and the Web Portal, which leverages the data stored in SQLite and Neo4j. The AI Agents framework uses AI to perform tasks such as analyzing COBOL code and extracting business logic.
