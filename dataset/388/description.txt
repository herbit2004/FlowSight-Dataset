- **访问驾驶舱 (Access Cockpit)**: The initial access point to the image generation application. This could be a web page, a command-line interface, or another entry point.
- **输入提示词 (Enter Prompt)**: The user's textual input that guides the image generation process. This is a crucial element in text-to-image models.
- **快速生成 (Quick Generation)**: A mode that uses default parameters for faster image generation, potentially sacrificing some customization or quality.
- **高级设置 (Advanced Settings)**: A mode that allows users to fine-tune various parameters, offering more control over the image generation process.
- **服务端轮询 (Server-Side Polling)**: A technique where the server periodically checks for updates or completion of the image generation task.
- **客户端轮询 (Client-Side Polling)**: A technique where the client (e.g., a web browser) periodically sends requests to the server to check for updates or completion of the image generation task.
