## 图类型与用途
这是一个流程图，描述用户如何通过 Z-Image Turbo 2API 生成图像的流程。该图展示了从访问驾驶舱、输入提示词，到选择生成模式、最终下载或分享图像的完整用户交互过程。

## 图的整体布局
图采用从上到下的布局。流程从顶部的“访问驾驶舱”开始，经过一系列选择和处理步骤，最终到达底部的“下载/分享”节点。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为四个阶段：
1. **提示词输入与模式选择**：用户访问驾驶舱并输入提示词，选择快速生成或高级设置。
2. **任务提交**：将图像生成任务提交给后端服务。
3. **生成模式选择与轮询**：选择服务端或客户端轮询模式，并根据生成状态进行处理。
4. **结果展示与分享**：展示生成的图像或错误信息，并提供下载/分享选项。

## 节点逐项说明
- **A (访问驾驶舱)**：用户访问 Z-Image Turbo 2API 的用户界面或入口点。根据 README，驾驶舱是内置的 HTML5 控制面板，既是 API 也是创作工具。
- **B (输入提示词)**：用户输入用于生成图像的文本描述，即 Prompt。
- **C (选择操作模式)**：用户选择生成图像的方式，是快速生成（默认参数）还是高级设置（自定义参数）。
- **D (快速生成 默认参数)**：使用默认参数快速生成图像。
- **E (高级设置 自定义参数)**：用户可以自定义图像生成的各种参数。
- **F (提交任务)**：将图像生成任务提交给后端服务。
- **G (生成模式选择)**：选择图像生成的轮询模式，服务端或客户端。
- **H (服务端轮询 自动等待)**：服务端自动轮询生成状态，用户无需手动刷新。
- **I (客户端轮询 实时进度)**：客户端（浏览器）轮询生成状态，并显示实时进度条。
- **J (返回最终图像)**：服务端轮询完成后，返回最终生成的图像。
- **K (显示进度条)**：客户端轮询时，显示图像生成进度条。
- **L (轮询查询状态)**：客户端向服务端轮询查询图像生成状态。
- **M (生成状态)**：判断图像生成的状态，是完成、失败还是处理中。
- **N (展示图像)**：图像生成完成后，在界面上展示生成的图像。
- **O (显示错误)**：图像生成失败时，显示错误信息。
- **P (下载/分享)**：用户可以下载或分享生成的图像。

## 连线、分支与汇聚关系
- `A -> B`：用户访问驾驶舱后，输入提示词。
- `B -> C`：输入提示词后，选择操作模式。
- `C -> D`：选择快速生成模式。
- `C -> E`：选择高级设置模式。
- `D -> F`：快速生成模式提交任务。
- `E -> F`：高级设置模式提交任务。
- `F -> G`：提交任务后，选择生成模式。
- `G -> H`：选择服务端轮询模式。
- `G -> I`：选择客户端轮询模式。
- `H -> J`：服务端轮询完成后，返回最终图像。
- `I -> K`：客户端轮询时，显示进度条。
- `K -> L`：显示进度条后，轮询查询生成状态。
- `L -> M`：轮询查询状态后，判断生成状态。
- `M -- 完成 --> N`：生成完成后，展示图像。
- `M -- 失败 --> O`：生成失败后，显示错误。
- `M -- 处理中 --> L`：生成处理中，继续轮询查询状态。
- `J -> P`：返回最终图像后，可以下载/分享。
- `N -> P`：展示图像后，可以下载/分享，形成汇聚关系。

## 仓库语境与术语解释
- **Z-Image Turbo 2API**：一个运行在 Cloudflare Workers 上的轻量级中间件，充当智能协议转换器。
- **驾驶舱**：内置的 HTML5 控制面板，既是 API 也是创作工具，用户可以通过它与服务进行交互。
- **Cloudflare Workers**：一个边缘计算平台，Z-Image Turbo 2API 运行在其上，利用其免费额度实现零成本部署。
- **轮询模式**：包括服务端轮询和客户端轮询，用于获取图像生成的状态。README 提到优化的轮询机制，支持 Server-Sent Events (SSE) 实时进度反馈。
- **API_MASTER_KEY**：一个环境变量，用于设置 API 的专属密钥，提供访问认证。
- **/v1/images/generations**：生成图像的 API 端点，模拟 OpenAI 格式。
- **/v1/chat/completions**：聊天式图像生成的 API 端点，模拟 OpenAI 格式。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 Z-Image Turbo 2API 的用户交互流程。用户首先访问驾驶舱并输入提示词，然后选择快速生成或高级设置，提交任务后选择服务端或客户端轮询模式。服务端轮询自动等待并返回最终图像，客户端轮询则显示实时进度条并查询生成状态。最终，生成的图像或错误信息会展示给用户，并提供下载/分享选项。该流程从“访问驾驶舱”开始，到“下载/分享”结束，其中生成模式选择和轮询是关键中间环节。
