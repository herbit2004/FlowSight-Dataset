## 图类型与用途
这是一个架构图，展示了5G NR SSB信号扫描器的系统架构，包括用户界面层、应用层、硬件层和数据层。该图用于概括系统的组件及其相互关系，帮助理解系统的工作原理和数据流向。

## 图的整体布局
图整体采用从左到右的层次布局。最左侧是用户界面层，中间是应用层，右侧上方是数据层，右侧下方是硬件层。

## 分组/子图/阶段说明
图中显式地分为四个层级：用户界面层、应用层、硬件层和数据层。

## 节点逐项说明
- **HTML (index.html)**：用户界面的主要入口，包含1120+行代码，负责呈现信息和接收用户输入。根据 `templates/index.html`，该文件是 Flask 应用的模板文件。
- **JS (JavaScript)**：负责用户界面的实时更新，提供动态交互体验。
- **CSS (Bootstrap CSS)**：使用Bootstrap框架提供的CSS样式，实现响应式设计，使界面在不同设备上都能良好显示。
- **FLASK (app.py)**：使用Flask框架构建的REST API，包含605行代码，是应用的核心逻辑处理中心，负责接收用户请求、协调各个模块、处理数据并返回结果。根据 `app.py`，该文件是 Flask 应用的主文件，处理 API 请求和管理扫描过程。
- **CONFIG_MGR (config.py)**：配置管理器，包含135行代码，负责读取和管理系统的配置信息。根据 `config.py`，该模块负责加载和保存配置信息，包括 USRP 设置、路径设置和扫描设置。
- **GSCN_CALC (gscn_calculator.py)**：GSCN频率计算器，包含176行代码，用于根据3GPP标准计算5G NR的GSCN频率。根据 `gscn_calculator.py`，该模块包含 GSCN 到频率的转换函数和 5G NR 频段信息。
- **USRP_CTRL (usrp_controller.py)**：USRP控制器，包含301行代码，负责控制USRP X310硬件，包括频率设置、信号采集等。根据 `usrp_controller.py`，该模块负责与 USRP 设备通信，构建命令并管理进程。
- **EXEC (init_ssb_block)**：RFNoC应用，用于初始化SSB块，是运行在FPGA上的应用程序。
- **FPGA_BIN (FPGA Bitstream)**：FPGA比特流文件，包含自定义的处理逻辑，用于加速信号处理。
- **X310 (USRP X310)**：USRP X310软件无线电硬件，负责实际的射频信号接收和发送。README 表明该硬件是 NI USRP X310 Software Defined Radio platform。
- **CONFIG_JSON (config.json)**：JSON格式的配置文件，存储系统的各种配置参数。根据 `config.json`，该文件存储了 USRP 设置、路径设置和扫描设置等配置信息。
- **FREQ_JSON (detected_frequencies.json)**：JSON格式的文件，存储检测到的频率信息。根据 `app.py`，该文件用于持久化存储检测到的频率信息。
- **SIGNAL_DATA (*.dat files)**：存储采集到的信号数据，以.dat文件格式保存。

## 连线、分支与汇聚关系
- `HTML <--> JS`：HTML页面和JavaScript代码相互交互，JavaScript负责更新HTML页面上的内容。
- `JS <--> FLASK`：JavaScript通过REST API与Flask应用进行通信，发送请求并接收数据。
- `FLASK --> CONFIG_MGR`：Flask应用使用配置管理器读取配置信息。
- `FLASK --> GSCN_CALC`：Flask应用使用GSCN计算器计算频率。
- `FLASK --> USRP_CTRL`：Flask应用使用USRP控制器控制硬件。
- `CONFIG_MGR <--> CONFIG_JSON`：配置管理器读取和写入JSON配置文件。
- `USRP_CTRL --> EXEC`：USRP控制器执行RFNoC应用。
- `USRP_CTRL <--> FREQ_JSON`：USRP控制器与存储检测到的频率信息的JSON文件交互。
- `USRP_CTRL --> SIGNAL_DATA`：USRP控制器将采集到的信号数据存储到.dat文件中。
- `EXEC --> FPGA_BIN`：RFNoC应用使用FPGA比特流文件。
- `FPGA_BIN --> X310`：FPGA比特流文件配置USRP X310硬件。

## 仓库语境与术语解释
- **5G NR SSB (Synchronization Signal Blocks)**：5G NR 同步信号块，是该扫描器检测的目标信号。
- **USRP X310**：NI USRP X310 软件无线电硬件平台，用于接收和发送射频信号。
- **GSCN (Global Synchronization Channel Number)**：全局同步信道号，用于标识 5G NR 频率。
- **RFNoC (Radio Frequency Network on Chip)**：一种用于在 FPGA 上实现无线电功能的架构。
- **Flask**：一个使用 Python 编写的 Web 应用框架，用于构建 REST API。`app.py` 是 Flask 应用的主文件。
- **config.json**：JSON 格式的配置文件，存储系统的各种配置参数，如 USRP 设置、路径设置和扫描设置。
- **init_ssb_block**：RFNoC 应用，用于初始化 SSB 块，是运行在 FPGA 上的应用程序。

## 可作为 QA Ground Truth 的高信息密度摘要
该架构图展示了 5G NR SSB 信号扫描器的整体架构。用户通过 HTML 界面与 JavaScript 交互，向 Flask 应用发送请求。Flask 应用使用 `config.py` 管理配置，调用 `gscn_calculator.py` 计算频率，并使用 `usrp_controller.py` 控制 USRP X310 硬件，执行 `init_ssb_block` 应用。检测到的频率信息存储在 `detected_frequencies.json` 中，采集到的信号数据存储为 `.dat` 文件。核心流程是“用户界面 -> Flask 应用 -> 配置管理/频率计算/硬件控制 -> 数据存储”，其中 USRP X310 硬件和配置文件是关键组成部分。
