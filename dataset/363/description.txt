## Repository Context & Terminology
- **Highway DSL**: A Domain Specific Language for defining workflows.
- **WorkflowBuilder**: A component that provides a fluent API for constructing workflows.
- **Fluent API**: A design pattern that allows for method chaining to create a readable and expressive syntax.
- **Core Operators**: Fundamental operations like Task, Condition, Parallel, etc., used to build workflow logic.
- **Scheduling**: Mechanisms to trigger workflow execution based on time or events.
- **Events**: A system for emitting and reacting to events within a workflow.
- **Error Handling**: Strategies for managing errors during workflow execution, such as retry policies and circuit breakers.
- **Runtime Integration**: Support for executing workflows in various runtime environments like Airflow and Temporal.
