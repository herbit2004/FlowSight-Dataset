## 图类型与用途
这是一个架构图，展示了 Highway DSL v2.1.2 (LTS Stable) 的架构和主要功能模块。它用于概览 Highway DSL 的核心组件，以及它如何生成不同的输出格式并与不同的运行时环境集成。

## 图的整体布局
图采用从上到下的层次布局。顶部是 `WorkflowBuilder`，作为配置入口，向下分别连接到 `Core Operators`、`Scheduling`、`Events` 和 `Error Handling` 四个主要模块。右侧是 `Output Formats` 和 `Runtime Integration`，展示了 DSL 的输出能力和集成环境。

## 分组/子图/阶段说明
图中包含三个显式子图：
- **Highway DSL v2.1.2 (LTS Stable)**：表示 Highway DSL 的核心模块，包含 `WorkflowBuilder`、`Core Operators`、`Scheduling`、`Events` 和 `Error Handling`。
- **Output Formats**：展示了 Highway DSL 支持的输出格式，包括 YAML 和 JSON。
- **Runtime Integration**：展示了 Highway DSL 可以集成的运行时环境，包括 Absurd Runtime、Airflow、Temporal 和 Custom Engines。

## 节点逐项说明
- **WorkflowBuilder Fluent API**：构建工作流的入口点，提供流畅的 API 来定义工作流。根据 README，`WorkflowBuilder` 提供了一个强大且直观的接口，用于以编程方式定义工作流。
- **Core Operators**：构成工作流的基本构建块，包含 Task、Condition、Parallel、ForEach、While、Wait、Switch、Join 和 Reflexive 等操作符。
    - **Task**：执行具体任务的操作符。
    - **Condition**：基于条件判断的操作符。
    - **Parallel**：并行执行多个分支的操作符。
    - **ForEach**：循环执行操作符。
    - **While**：当条件为真时循环执行操作符。
    - **Wait**：等待特定事件或时间的操作符。
    - **Switch**：基于不同的条件执行不同的分支的操作符。
    - **Join**：显式协调多个分支的操作符，类似于 Temporal 的 Join。README 提到 JoinOperator 用于显式协调，替代了基于 TriggerRule 的连接方式。
    - **Reflexive**：自反操作符，可能用于循环或递归。README 提到 Reflexive Operator 实现了 Reflexive Loop 模式。
- **Scheduling**：用于定义工作流的调度方式，包含 Cron Schedules、Start Date、Catchup 和 Tags。
    - **Cron Schedules**：使用 Cron 表达式进行调度。
    - **Start Date**：指定工作流的开始日期。
    - **Catchup**：处理错过的调度执行。
    - **Tags**：用于标记和组织工作流。
- **Events**：用于处理事件，包含 EmitEvent 和 WaitForEvent。
    - **EmitEvent**：发出事件。
    - **WaitForEvent**：等待事件。
- **Error Handling**：用于处理错误，包含 RetryPolicy、TimeoutPolicy、Callbacks 和 CircuitBreaker。
    - **RetryPolicy**：定义重试策略。
    - **TimeoutPolicy**：定义超时策略。
    - **Callbacks**：定义回调函数。
    - **CircuitBreaker**：熔断器模式，防止级联故障。README 提到 Per-Activity Circuit Breaker 用于防止级联故障。
- **YAML**：YAML 格式的配置文件。
- **JSON**：JSON 格式的配置文件。
- **Absurd Runtime**：一个特定的运行时环境。
- **Airflow**：Apache Airflow，一个流行的工作流管理平台。
- **Temporal**：Temporal.io，一个持久化工作流引擎。
- **Custom Engines**：自定义的运行时引擎。

## 仓库语境与术语解释
- **Highway DSL**：一个 Python 领域特定语言，用于定义生产级工作流，具有 Temporal 风格的协调模式。
- **WorkflowBuilder**：一个用于构建工作流的 Fluent API。根据 README，它提供了一个强大且直观的接口，用于以编程方式定义工作流。
- **Core Operators**：构成工作流的基本构建块，例如 Task, Condition, Parallel 等。
- **Scheduling**：用于定义工作流的调度方式，例如 Cron Schedules, Start Date 等。
- **Events**：用于处理事件，例如 EmitEvent, WaitForEvent。
- **Error Handling**：用于处理错误，例如 RetryPolicy, TimeoutPolicy, Callbacks, CircuitBreaker。
- **Temporal**：一个持久化工作流引擎，Highway DSL 提供了与其类似的 Join 机制。
- **Airflow**：一个流行的工作流管理平台，Highway DSL 旨在提供 Airflow-parity 的功能。
