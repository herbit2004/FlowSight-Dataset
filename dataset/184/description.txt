## 图类型与用途
这是一个流程图，描述了 TrainPPTAgent 系统中用户、前端、后端以及各个服务之间的交互和数据流动，展示了 PPT 生成过程的架构。该图在 README.md 中被用作展示系统架构的示意。

## 图的整体布局
图采用从上到下的布局。顶部是用户，中间是前端界面和后端 API，底部是大纲服务和 PPT 生成服务，以及它们调用的搜索服务和知识库。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可以分为四个阶段：用户交互、大纲生成、PPT 内容生成、结果展示。

## 节点逐项说明
- **U (用户)**：表示使用 TrainPPTAgent 系统的用户，是整个流程的起点和终点。
- **FE (前端界面)**：用户与系统交互的界面，负责接收用户输入的主题，展示生成的 PPT。前端使用 Vue.js + Vite + TypeScript 技术栈，具体信息可参考 README.md。
- **API (后端 API)**：后端的核心服务，负责接收前端请求，协调各个服务，并将结果返回给前端。后端基于 Python (FastAPI) 构建，具体信息可参考 README.md。
- **Outline (大纲服务)**：负责根据用户输入的主题生成 PPT 大纲。对应后端代码中的 `backend/simpleOutline` 模块，具体实现见 `backend/simpleOutline/agent.py`。
- **WebSearch1 (Web 搜索)**：大纲服务调用，用于从网络上搜索相关信息，辅助生成大纲。
- **PPTGen (PPT生成服务：内部循环和检查Json格式)**：负责根据大纲生成 PPT 的具体内容，包含内部循环和 JSON 格式检查。对应后端代码中的 `backend/slide_agent` 模块，具体实现见 `backend/slide_agent/slide_agent/agent.py`。
- **WebSearch2 (Web 搜索)**：PPT 生成服务调用，用于从网络上搜索相关信息，辅助生成 PPT 内容。
- **ImgSearch (配图搜索)**：PPT 生成服务调用，用于搜索与 PPT 内容相关的图片。
- **DBSearch (知识库)**：PPT 生成服务调用，用于搜索用户上传的知识库文件。对应后端代码中的 `backend/personaldb` 模块，用于解析各种格式的文件，具体实现见 `backend/personaldb/main.py`。

## 连线、分支与汇聚关系
- `U -> FE`：用户与前端界面交互。
- `FE -- 输入主题 --> API`：用户通过前端界面输入主题，发送给后端 API。
- `API -- 调用大纲服务 --> Outline`：后端 API 调用大纲服务生成 PPT 大纲。
- `Outline -- 调用 Web搜索 --> WebSearch1`：大纲服务在生成大纲的过程中，会调用 Web 搜索服务获取网络信息。
- `Outline --> API`：大纲服务将生成的大纲返回给后端 API。
- `FE -- 确认大纲 --> API`：前端界面接收到大纲后，用户可以确认大纲，并将确认的大纲发送给后端 API。
- `API --> PPTGen`：后端 API 调用 PPT 生成服务生成 PPT 内容。
- `PPTGen -- 调用 Web搜索 --> WebSearch2`：PPT 生成服务在生成 PPT 内容的过程中，会调用 Web 搜索服务获取相关信息。
- `PPTGen -- 调用 配图搜索 --> ImgSearch`：PPT 生成服务在生成 PPT 内容的过程中，会调用配图搜索服务获取相关信息。
- `PPTGen -- 调用 搜索上传文件 --> DBSearch`：PPT 生成服务在生成 PPT 内容的过程中，会调用知识库服务获取相关信息。
- `PPTGen --> API`：PPT 生成服务将生成的 PPT 内容返回给后端 API。
- `FE -- 渲染展示 PPT --> U`：前端界面接收到 PPT 内容后，渲染并展示给用户。

## 仓库语境与术语解释
- **TrainPPTAgent**：一款基于 AI 的智能演示文稿生成工具，用户只需输入主题，系统即可自动生成 PPT 大纲与逐页内容。
- **前后端分离架构**：前端使用 Vue.js + Vite + TypeScript，后端基于 Python (FastAPI)，架构清晰、可扩展性强。
- **大纲服务 (backend/simpleOutline)**：负责根据用户输入的主题生成 PPT 大纲，具体实现见 `backend/simpleOutline/agent.py`。
- **PPT 生成服务 (backend/slide_agent)**：负责根据大纲生成 PPT 的具体内容，具体实现见 `backend/slide_agent/slide_agent/agent.py`。
- **知识库 (backend/personaldb)**：用于搜索用户上传的知识库文件，解析各种格式的文件，具体实现见 `backend/personaldb/main.py`。
- **LLM (Large Language Model)**：大语言模型，用于大纲与内容生成。
- **GRPO (Generative Pre-trained Reinforcement Optimization)**：强化学习方法，用于优化 PPT Agent 的生成效果。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 TrainPPTAgent 的整体架构和数据流。用户通过前端界面输入主题，系统首先调用大纲服务生成 PPT 大纲，大纲服务会调用 Web 搜索服务获取网络信息。用户确认大纲后，系统调用 PPT 生成服务生成 PPT 内容，PPT 生成服务会调用 Web 搜索服务、配图搜索服务和知识库服务获取相关信息。最后，前端界面渲染并展示 PPT 给用户。核心流程是“用户输入 -> 大纲生成 -> 内容生成 -> 结果展示”，其中大纲服务、PPT 生成服务和知识库是关键模块。
