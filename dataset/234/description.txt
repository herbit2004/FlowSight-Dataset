## Repository Context & Terminology
- **Worker Bees**: A set of processes or agents that perform specific tasks within the system. These tasks are often triggered by external events or user interactions.
- **Judge**: A component responsible for evaluating criteria and principles, potentially for decision-making or policy enforcement within the system.
- **Queen Bee**: A central component that manages system state, communication, and coordination between different parts of the system.
- **Event Bus**: A messaging system that allows different components to communicate with each other without being directly coupled.
- **Credential Store**: A secure storage location for sensitive information such as passwords, API keys, or other credentials.
- **Shared Memory**: A region of memory that can be accessed by multiple processes, allowing them to share data and communicate with each other.
- **Codebase**: The source code of the system, which can be modified to change the behavior of the worker bees.
