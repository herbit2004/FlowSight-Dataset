- **DocFX**: A documentation generator for .NET.
- **SvelteKit**: A framework for building web applications with Svelte.
- **Azure SQL**: A managed SQL Server database service in Azure.
- **Cosmos DB**: A globally distributed, multi-model database service in Azure.
- **Blob Storage**: A service for storing unstructured data in Azure.
- **Azure OpenAI**: A service providing access to OpenAI models in Azure.
- **Managed Identities**: A feature of Azure Active Directory that provides an identity for applications to use when connecting to resources that support Azure AD authentication.

## High-Density QA Ground Truth Summary
The architecture begins with Azure Front Door, acting as the entry point for all incoming traffic. Front Door then routes traffic to different websites and APIs based on the requested domain: arolariu.ro (Next.js), api.arolariu.ro (.NET), docs.arolariu.ro (DocFX), and cv.arolariu.ro (SvelteKit). The .NET API interacts with various data storage services, including Azure SQL, Cosmos DB, Blob Storage, and Azure OpenAI, and retrieves secrets from Key Vault. The Next.js website retrieves configuration settings from App Configuration. Both the website and the API send telemetry data to Azure Application Insights for monitoring. Managed Identities are used to authenticate both the website and the API. The DNS Zone manages the domain name resolution for arolariu.ro. Log Analytics and Grafana are used for observability, providing insights into the system's performance and health. The system is deployed within an Azure Subscription located in the swedencentral region.
