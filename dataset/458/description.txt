## 图类型与用途
这是一个流程图，描述了 Claude AI 技能系统中多智能体协作的技能调用流程。它展示了用户调用技能时，如何通过多个智能体并行工作，从不同维度分析问题，最终整合结果并输出。该图在仓库中用于说明 agent teams 的工作方式，尤其是在需要多维度分析的场景下。

## 图的整体布局
图采用从上到下的布局。顶部是用户发起的技能调用，中间是协调器和多个智能体并行分析的阶段，底部是结果整合与输出。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可以分为三个阶段：技能调用与任务准备、多智能体并行分析、结果整合与输出。

## 节点逐项说明
- **User["/skill invoked"]**：表示用户通过某种方式（例如斜杠命令）触发了一个技能调用请求。
- **Coord1["COORDINATOR\nGathers input, prepares agent prompts"]**：第一个协调器，负责收集用户输入，并根据不同的智能体（Agent）的需求，准备相应的提示词（prompts）。
- **A1["Agent 1 · Sonnet\nDimension A\ne.g. Technical"]**：第一个智能体，使用 Sonnet 模型，负责分析维度 A，例如技术维度。
- **A2["Agent 2 · Sonnet\nDimension B\ne.g. Cost"]**：第二个智能体，使用 Sonnet 模型，负责分析维度 B，例如成本维度。
- **AN["Agent N · Sonnet\nDimension N\ne.g. Risk"]**：第 N 个智能体，使用 Sonnet 模型，负责分析维度 N，例如风险维度。这里的 N 代表可以有多个智能体并行工作。
- **Coord2["COORDINATOR\nSynthesises all agent results\ninto unified output"]**：第二个协调器，负责将所有智能体（A1, A2, ..., AN）的分析结果进行整合，生成统一的输出。

## 连线、分支与汇聚关系
- `User -> Coord1`：用户发起技能调用请求，请求到达第一个协调器。
- `Coord1 -> A1`：第一个协调器将任务分发给第一个智能体。
- `Coord1 -> A2`：第一个协调器将任务分发给第二个智能体。
- `Coord1 -> AN`：第一个协调器将任务分发给第 N 个智能体。
- `A1 -> Coord2`：第一个智能体完成分析后，将结果发送给第二个协调器。
- `A2 -> Coord2`：第二个智能体完成分析后，将结果发送给第二个协调器。
- `AN -> Coord2`：第 N 个智能体完成分析后，将结果发送给第二个协调器。多个智能体的结果汇聚到第二个协调器，形成汇聚关系。

## 仓库语境与术语解释
- **Agent Teams**：根据 `README.md` 和 `docs/agent-teams-guide.md`，agent teams 是指通过 Claude Code 的 Task tool 启动的并行子智能体组，用于更快、更彻底地执行任务。
- **Sonnet**：图中智能体使用的模型，根据 `agents/meta-agent.md`，Sonnet 适用于研究和文档处理等任务，提供平衡的推理能力。
- **COORDINATOR**：协调器，负责任务分发和结果整合。在 `docs/agent-teams-guide.md` 中，协调器负责收集所有智能体的结果，综合成统一的输出，并解决冲突。
- **/skill invoked**：用户通过斜杠命令等方式触发 Claude Code skills。`README.md` 说明 skills 可以通过将 `.md` 文件放入 `.claude/skills/` 目录来创建。
- **Dimension A / Dimension B / Dimension N**：代表不同的分析维度，例如技术、成本、风险等。在 `skills/architecture/impact-analysis.md` 中，展示了使用四个并行 agent 分析技术、组织、财务和风险维度。
- **Task tool**：根据 `docs/agent-teams-guide.md`，Task tool 是 Claude Code 中用于启动多个子智能体的工具，每个子智能体都在自己的上下文中独立运行。
- **Prompts**：协调器为每个智能体准备的提示词，用于指导智能体完成特定维度的分析任务。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 Claude AI 技能系统中多智能体协作的工作流程。用户通过 `/skill invoked` 触发技能，第一个协调器（Coord1）收集输入并为每个智能体准备 prompts，然后多个智能体（Agent 1, Agent 2, Agent N）并行分析不同维度（如技术、成本、风险），最后第二个协调器（Coord2）整合所有智能体的结果并输出。该流程体现了 agent teams 的核心思想，即通过并行处理提高分析效率和全面性，其中 Sonnet 模型常被用于此类任务。
