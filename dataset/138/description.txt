## Repository Context & Terminology
- **errcheck**: A tool for statically checking for unchecked errors in Go programs.
- **go/analysis**: The `go/analysis` package provides a framework for building static analysis tools for Go code.
- **go/packages**: The `go/packages` package provides functionality for loading and querying Go packages, used by many Go tools.
- **gcexportdata**: Refers to the data format used by the Go compiler to export information about packages.
- **gcimporter**: The `gcimporter` is responsible for importing packages from gcexportdata.
- **internal packages**: Packages under the `internal` directory are not part of the public API and can change without notice.
- **typesinternal**: Internal package for handling Go types.
- **event**: Internal package for event handling.
