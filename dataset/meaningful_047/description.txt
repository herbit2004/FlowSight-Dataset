## 图类型与用途
这是一个流程图，描述了数据脱敏和加密的流程。该流程从原始数据源开始，根据数据类型和规则进行脱敏和加密处理，最终存储到目标数据存储中。该图展示了敏感数据和非敏感数据的不同处理路径。

## 图的整体布局
该图采用从上到下的布局。整体上分为数据识别、脱敏/加密处理、存储三个层次。流程从“原始数据源”开始，到“目标数据存储”结束。

## 分组/子图/阶段说明
图中没有显式子图，但逻辑上可分为以下阶段：
1. 数据识别阶段：包括“原始数据源”和“数据类型识别”。
2. 脱敏/加密处理阶段：包括“脱敏规则引擎”、“规则匹配”、“脱敏处理函数”、“加密算法选择”、“数据加密”、“密钥管理服务”、“密钥获取成功”、“加密数据存储”、“告警”。
3. 数据存储阶段：包括“直接写入目标”和“目标数据存储”。

## 节点逐项说明
- **原始数据源**：数据的最初来源。
- **数据类型识别**：识别数据是否包含敏感信息。
- **脱敏规则引擎**：根据预定义的规则对敏感数据进行脱敏处理。
- **规则匹配**：判断数据是否匹配脱敏规则。
- **脱敏处理函数**：执行具体的脱敏操作。
- **加密算法选择**：选择合适的加密算法对数据进行加密。
- **数据加密**：使用选定的加密算法对数据进行加密。
- **密钥管理服务**：负责密钥的生成、存储和管理。
- **密钥获取成功**：表示成功从密钥管理服务获取到密钥。
- **加密数据存储**：存储加密后的数据。
- **告警**：当密钥获取失败时，发出告警信息。
- **直接写入目标**：对于非敏感数据，直接写入目标存储。
- **目标数据存储**：最终存储数据的地点。

## 连线、分支与汇聚关系
- 原始数据源 -> 数据类型识别：数据进入类型识别阶段。
- 数据类型识别 -- 敏感数据 --> 脱敏规则引擎：如果数据是敏感数据，则进入脱敏规则引擎。
- 数据类型识别 -- 非敏感数据 --> 直接写入目标：如果数据是非敏感数据，则直接写入目标存储。
- 脱敏规则引擎 -> 规则匹配：进入规则匹配阶段。
- 规则匹配 -- 匹配成功 --> 脱敏处理函数：如果匹配成功，则进入脱敏处理函数。
- 规则匹配 -- 匹配失败 --> 直接写入目标：如果匹配失败，则直接写入目标存储。
- 脱敏处理函数 -> 加密算法选择：选择加密算法。
- 加密算法选择 -> 数据加密：进行数据加密。
- 数据加密 -> 密钥管理服务：请求密钥管理服务。
- 密钥管理服务 -> 密钥获取成功：判断密钥是否获取成功。
- 密钥获取成功 -- YES --> 加密数据存储：如果密钥获取成功，则存储加密数据。
- 密钥获取成功 -- NO --> 告警：如果密钥获取失败，则发出告警。
- 加密数据存储 -> 直接写入目标：加密后的数据进入直接写入目标阶段。
- 告警 -> 直接写入目标：告警后进入直接写入目标阶段。
- 直接写入目标 -> 目标数据存储：数据最终存储到目标数据存储。

## 仓库语境与术语解释
本图为合成数据，无真实仓库。
- **脱敏**：移除或隐藏数据中的敏感信息，以保护隐私。
- **加密**：使用算法将数据转换为不可读的形式，以防止未经授权的访问。
- **密钥**：用于加密和解密数据的秘密值。
- **密钥管理服务**：负责密钥的生成、存储、分发和轮换的系统。
- **告警**：当系统出现异常或错误时发出的通知。
- **敏感数据**：包含个人身份信息、财务信息等需要保护的数据。
- **非敏感数据**：不需要特殊保护的数据。

## 可作为 QA Ground Truth 的高信息密度摘要
数据脱敏流程从原始数据源开始，首先进行数据类型识别，判断是否为敏感数据。如果是敏感数据，则进入脱敏规则引擎进行规则匹配。匹配成功后，执行脱敏处理函数，然后选择加密算法进行数据加密。加密过程中需要从密钥管理服务获取密钥，如果密钥获取成功，则将加密数据存储，否则发出告警。非敏感数据和脱敏后的数据都会直接写入目标，最终存储到目标数据存储中。
