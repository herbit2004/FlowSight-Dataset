- `A --> B`: Starts the schema translation process and moves to input schema validation.
- `B -- Valid --> C`: If the input schema is valid, proceed to create a jq filter query for each key.
- `B -- Invalid --> D`: If the input schema is invalid, throw a runtime error.
- `C --> E`: After creating the jq filter query, compile and test it.
- `E -- Success --> F`: If the jq filter compilation and testing is successful, proceed to validate the JSON.
- `E -- Fail --> G`: If the jq filter compilation and testing fails, retry creating the jq filter.

- `G -- Fail n times --> H`: If retrying the jq filter creation fails multiple times, throw a runtime error.

- `J -- Fail n times --> K`: If retrying the JSON validation fails multiple times, throw a runtime error.
