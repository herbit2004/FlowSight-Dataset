## Repository Context & Terminology
- **Liquid Haskell**: A refinement type checker for Haskell. It uses SMT solvers to automatically verify program correctness.
- **LHAssumptions**: Assumptions about the types and properties of external functions or modules used by the code being verified.
- **.hi file**: Haskell interface file, which contains type signatures and other information about a Haskell module.
- **CoreBinds**: Core bindings are the essential bindings extracted from the Haskell code, representing the core logic of the program.
- **liquid-fixpoint**: An SMT solver used by Liquid Haskell to discharge verification conditions.
