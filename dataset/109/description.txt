## Repository Context & Terminology
- **tsParticles**: A lightweight TypeScript library for creating particles.
- **Bundle**: A pre-configured set of modules and plugins for specific use cases.
- **Engine**: The core component responsible for managing particles and their behavior.
- **Movers**: Components that define how particles move.
- **Shapes**: Components that define the visual appearance of particles.
- **Updaters**: Components that modify particle properties over time.
- **Plugins**: Optional modules that extend the functionality of `tsParticles`.

## High-Density QA Ground Truth Summary
The diagram begins with the `tsParticles Engine`, the core of the library, which initializes the `tsParticles Basic` bundle. The `tsParticles Basic` bundle provides fundamental functionalities like basic movers (`Base`), a circle shape (`Circle`), and updaters for color, opacity, out modes, and size. From `tsParticles Basic`, the diagram branches out to several other bundles: `tsParticles Confetti`, `tsParticles Slim`, and `tsParticles Fireworks`. `tsParticles Confetti` adds confetti-related plugins and shapes. `tsParticles Slim` introduces interactions and additional shapes and updaters. `tsParticles Fireworks` focuses on fireworks effects. The `tsParticles Slim` bundle then extends to the `tsParticles` (full) bundle, which includes more interactions, plugins, shapes, and updaters. Finally, the `tsParticles` bundle extends to `tsParticles All`, the complete bundle, incorporating all features, compatibility modules like `tsParticles Particles.js Compatibility`, effects, interactions, paths, and plugins. The `tsParticles All` bundle also uses `Simplex Noise Lib` and `Perlin Noise Lib` for path generation. The diagram illustrates the modular and extensible nature of the `tsParticles` library, allowing developers to choose the appropriate bundle based on their specific requirements.
