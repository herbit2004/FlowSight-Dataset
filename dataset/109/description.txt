## 图类型与用途
这是一个流程图，展示了 `tsParticles` 库的模块化架构，以及不同 bundle 之间的依赖关系和包含的组件。该图旨在概括 `tsParticles` 库的整体架构和模块组成，方便开发者理解和使用。

## 图的整体布局
图采用从上到下的布局。顶部是核心模块，中间是不同的 bundle 及其包含的组件，底部是 `tsParticles All` 包及其依赖。

## 分组/子图/阶段说明
图中包含多个 subgraph，分别代表不同的模块和 bundle：
- **Core**：核心模块，包含 `tsParticles Engine`，`Perlin Noise Lib`，`Simplex Noise Lib` 和 `tsParticles Configs`。
- **tsParticles Basic**：基础包，包含 `Movers`，`Shapes` 和 `Updaters`。
- **tsParticles Confetti**：彩纸包，包含 `Plugins`，`Shapes` 和 `Updaters`。
- **tsParticles Slim**：精简包，包含 `Interactions`，`Plugins`，`Shapes` 和 `Updaters`。
- **tsParticles Fireworks**：烟花包，包含 `Effects`，`Plugins` 和 `Updaters`。
- **tsParticles**：完整包，包含 `Interactions`，`Plugins`，`Shapes` 和 `Updaters`。
- **tsParticles All**：所有包，包含 `tsParticles Particles.js Compatibility`，`Effects`，`Interactions`，`Paths`，`Plugins`，`Shapes` 和 `Updaters`。

## 节点逐项说明
- **tsParticles Engine**：粒子引擎，是 `tsParticles` 的核心组件。仓库语境：负责管理和控制粒子效果的创建、更新和销毁，定义在 `engine/src/Core/Engine.ts` 中。
- **Perlin Noise Lib**：柏林噪声库，用于生成随机的噪声效果。
- **Simplex Noise Lib**：单纯形噪声库，也是用于生成随机噪声效果。
- **tsParticles Configs**：粒子配置，用于配置粒子效果的各种参数。
- **Movers**：移动器，控制粒子的移动方式。
  - **Base**：基础移动器。
- **Shapes**：形状，定义粒子的形状。
  - **Circle**：圆形。
- **Updaters**：更新器，用于更新粒子的属性。
  - **Color**：颜色更新器。
  - **Opacity**：透明度更新器。
  - **Out Modes**：超出边界模式更新器。
  - **Size**：大小更新器。
- **Plugins**：插件，扩展 `tsParticles` 的功能。
  - **plugin-emitters**：发射器插件。
  - **plugin-motion**：运动插件。
  - **plugin-easing-quad**：缓动插件。
  - **plugin-absorbers**：吸收器插件。
- **Interactions**：交互，定义粒子如何与其他粒子或鼠标交互。
  - **Externals**：外部交互。
    - **Attract**：吸引。
    - **Bounce**：弹跳。
    - **Bubble**：气泡。
    - **Connect**：连接。
    - **Grab**：抓取。
    - **Parallax**：视差。
    - **Pause**：暂停。
    - **Push**：推送。
    - **Remove**：移除。
    - **Repulse**：排斥。
    - **Slow**：减速。
    - **Trail**：拖尾。
    - **Particle**：粒子交互。
    - **Pop**：弹出。
  - **Particles**：粒子间交互。
    - **Attract**：吸引。
    - **Collisions**：碰撞。
    - **Links**：连接。
    - **Repulse**：排斥。
  - **Light**：光照。
- **Shapes**：形状。
  - **Cards**：卡片形状。
  - **Emoji**：表情符号形状。
  - **Heart**：心形。
  - **Image**：图像形状。
  - **Polygon**：多边形形状。
  - **Square**：正方形形状。
  - **Star**：星星形状。
  - **Line**：线条形状。
  - **Text**：文本形状。
  - **Arrow**：箭头形状。
  - **Cog**：齿轮形状。
  - **Path**：路径形状。
  - **Rounded Polygon**：圆角多边形形状。
  - **Rounded Rect**：圆角矩形形状。
  - **Spiral**：螺旋形状。
- **Updaters**：更新器。
  - **Life**：生命周期更新器。
  - **Roll**：翻滚更新器。
  - **Rotate**：旋转更新器。
  - **Tilt**：倾斜更新器。
  - **Wobble**：摆动更新器。
  - **Destroy**：销毁更新器。
  - **Stroke Color**：描边颜色更新器。
  - **Twinkle**：闪烁更新器。
  - **Gradient**：渐变更新器。
  - **Orbit**：轨道更新器。
- **Effects**：效果。
  - **Trail**：拖尾效果。
  - **Bubble**：气泡效果。
- **Emitters Shapes**：发射器形状。
  - **Square**：正方形发射器形状。
  - **Circle**：圆形发射器形状。
  - **Canvas**：画布发射器形状。
  - **Path**：路径发射器形状。
  - **Polygon**：多边形发射器形状。
- **Paths**：路径。
  - **Curl Noise**：卷曲噪声路径。
  - **Curves**：曲线路径。

## 连线、分支与汇聚关系
- `engine --> bundle-basic`：`tsParticles Engine` 是 `tsParticles Basic` 的依赖。
- `bundle-basic --> bundle-confetti`：`tsParticles Basic` 是 `tsParticles Confetti` 的依赖。
- `bundle-basic --> bundle-slim`：`tsParticles Basic` 是 `tsParticles Slim` 的依赖。
- `bundle-basic --> bundle-fireworks`：`tsParticles Basic` 是 `tsParticles Fireworks` 的依赖。
- `bundle-slim --> bundle-full`：`tsParticles Slim` 是 `tsParticles` 的依赖。
- `bundle-full --> bundle-all`：`tsParticles` 是 `tsParticles All` 的依赖。
- `simplex-noise --> path-curl-noise`：`Simplex Noise Lib` 是 `Curl Noise` 的依赖。
- `perlin-noise --> path-perlin-noise`：`Perlin Noise Lib` 是 `Perlin Noise` 的依赖。
- `simplex-noise --> path-simplex-noise`：`Simplex Noise Lib` 是 `Simplex Noise` 的依赖。

## 仓库语境与术语解释
- **tsParticles**：一个轻量级的 TypeScript 库，用于创建粒子效果。README 提到它兼容 React.js, Vue.js, Angular, Svelte, jQuery 等多种框架。
- **Bundle**：`tsParticles` 库的不同功能模块集合，例如 `tsParticles Basic`，`tsParticles Slim`，`tsParticles Confetti` 等。
- **Engine**：`tsParticles Engine` 是核心引擎，负责管理和控制粒子效果的创建、更新和销毁。定义在 `engine/src/Core/Engine.ts` 中。
- **Plugin**：用于扩展 `tsParticles` 功能的模块，例如发射器插件、运动插件等。
- **Interaction**：定义粒子如何与其他粒子或鼠标进行交互的模块，例如吸引、弹跳、连接等。
- **Shape**：定义粒子的形状，例如圆形、正方形、心形等。
- **Updater**：用于更新粒子属性的模块，例如颜色、透明度、大小等。
- **Options**：用于配置粒子效果的各种参数，定义在 `engine/src/Options/Classes/Options.ts` 中。
