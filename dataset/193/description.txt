## 图类型与用途
这是一个流程图，展示了 Agent Control Plane (ACP) 中 ManagerAgent 和 WebFetchAgent 如何协作处理任务。它描述了任务委托的架构，以及 Agent 如何利用 MCP 服务器提供的服务。

## 图的整体布局
图采用从左到右的布局。左侧是 ManagerAgent 及其管理的任务，右侧是 WebFetchAgent 及其使用的 MCP 服务器，以及被委托的任务。

## 分组/子图/阶段说明
图中包含多个子图，分别代表不同的 Agent 和 Task：
- **ManagerAgent**：代表一个管理型 Agent，负责管理和协调多个子 Agent。
- **WebFetchAgent**：代表一个 Web 数据抓取 Agent，负责从 Web 服务器获取数据。
- **ManagerTask**：由 ManagerAgent 处理的任务。
- **DelegationTask**：一个被委托的任务，可能由 ManagerAgent 委托给其他 Agent 的任务。
- **MCPServer**：MCP 服务器，提供 `fetch server` 功能，用于 Web 数据抓取。

## 节点逐项说明
- **subAgents**：ManagerAgent 管理的子 Agent 集合。
- **MCPServers**：WebFetchAgent 使用的 MCP 服务器集合。
- **fetch[fetch server]**：MCPServer 提供的具体抓取服务。
- **agentRef**：指向 ManagerAgent 的引用，表明 ManagerTask 由 ManagerAgent 处理。
- **parentTask**：DelegationTask 的父任务，即最初发起任务的 ManagerTask。
- **userMessage**：DelegationTask 中包含的用户消息，可能是任务的输入或上下文。
- **agentRef2**：指向 WebFetchAgent 的引用，表明 DelegationTask 被委托给 WebFetchAgent 处理。

## 连线、分支与汇聚关系
- `DelegationTask --> parentTask --> ManagerTask`：DelegationTask 是 parentTask 的一部分，而 parentTask 又属于 ManagerTask。
- `agentRef2 --> WebFetchAgent`：DelegationTask 通过 `agentRef2` 引用 WebFetchAgent，表明 DelegationTask 被委托给 WebFetchAgent 处理。
- `agentRef --> ManagerAgent`：ManagerTask 通过 `agentRef` 引用 ManagerAgent，表明 ManagerTask 由 ManagerAgent 管理。
- `MCPServers --> MCPServer`：MCPServers 包含多个 MCPServer 实例。

## 仓库语境与术语解释
- **Agent Control Plane (ACP)**：一个云原生编排器，用于构建在 Kubernetes 上的 AI Agent。
- **ManagerAgent**：负责总体任务的管理和协调，可以将任务委托给其他 Agent。
- **WebFetchAgent**：一种 Agent，用于从 Web 服务器获取数据，可能使用 MCP 服务器提供的抓取服务。
- **MCP (Microservice Control Plane)**：根据 README，MCP Servers 是 Agent 可以使用的 Tools 之一。
- **Task**：根据 README，Task 是 Agent + User Message + Current context window 的组合。
- **Delegation**：图中展示了一种任务委托的架构，ManagerAgent 接收 ManagerTask，然后可能将其中一部分任务（DelegationTask）委托给其他 Agent。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 ACP 中任务委托的架构。ManagerAgent 通过 `agentRef` 管理 ManagerTask，并可能将 DelegationTask 委托给 WebFetchAgent。WebFetchAgent 通过 `agentRef2` 引用 DelegationTask，并利用 MCPServers 中的 MCPServer 提供的 `fetch server` 服务来完成任务。DelegationTask 包含 `userMessage`，并通过 `parentTask` 关联到 ManagerTask，形成一种任务分解和异步执行的模式。
