## Repository Context & Terminology
- **RAG (Retrieval-Augmented Generation)**: A framework where a language model retrieves information from an external knowledge source before generating a response.
- **Vector Database**: A database that stores data as high-dimensional vectors, enabling similarity searches based on vector embeddings.
- **Graph Database**: A database that uses graph structures with nodes, edges, and properties to store and query relationships.
- **Qdrant**: A vector similarity search engine.
- **FalkorDB**: A graph database.
- **Hybrid Search**: A search strategy that combines vector-based and graph-based search methods.
- **PostgreSQL**: A relational database management system.
- **MongoDB**: A NoSQL document database.
