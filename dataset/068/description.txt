## 图类型与用途
这是一个对象依赖关系图，展示了 Azure Data Factory (ADF) 中不同组件之间的依赖关系和数据流向。该图旨在帮助理解和管理 ADF 实例中各个组件的依赖关系，尤其是在 CI/CD 过程中，确保部署顺序正确。根据 README，该仓库提供了一个 PowerShell 模块，用于简化 Azure Data Factory 的 CI/CD 流程。

## 图的整体布局
图整体采用从左到右的布局。图中存在多个起点和终点，展示了各种 ADF 组件之间的复杂连接关系。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为以下几个阶段：
1. **数据源连接阶段**：涉及 Linked Services，用于连接到外部数据源。
2. **数据处理阶段**：涉及 Pipelines 和 Data Flows，用于执行数据集成和转换任务。
3. **数据集定义阶段**：涉及 Datasets，用于定义数据的结构和位置。
4. **触发器启动阶段**：涉及 Triggers，用于启动 Pipelines。

## 仓库语境与术语解释
- **Azure Data Factory (ADF)**：Azure 的云数据集成服务，用于构建 ETL 和 ELT 管道。
- **Linked Service**：定义到数据源的连接信息，例如数据库连接字符串或 Blob 存储帐户密钥。
- **Integration Runtime (IR)**：在 ADF 中用于执行数据移动和转换活动的基础设施。
- **Pipeline**：ADF 中的主要工作流，包含一系列活动，用于执行数据集成任务。
- **Data Flow**：一种图形化的数据转换工具，用于构建复杂的数据转换逻辑。
- **Dataset**：对数据源中数据的引用，定义了数据的结构、位置和格式。
- **Trigger**：用于启动管道的机制，例如按计划或在事件发生时。
- **azure.datafactory.tools**：该仓库提供的 PowerShell 模块，用于简化 Azure Data Factory 的 CI/CD 流程。根据 README，该模块可以部署各种类型的 ADF 对象，并支持灵活的配置和过滤选项。
- **Get-AdfDocDiagram**：`public/Get-AdfDocDiagram.ps1` 中定义的 PowerShell 函数，用于生成 ADF 对象的 Mermaid 依赖关系图。
- **Publish-AdfV2FromJson**：`public/Publish-AdfV2FromJson.ps1` 中定义的 PowerShell 函数，用于将 ADF 对象从 JSON 文件发布到目标 ADF 服务。
