## 图类型与用途
这是一个流程图，描述了 `ghidriff` 工具如何使用 `GhidraDiffEngine` 对两个二进制文件进行差异分析，并生成多种格式的差异报告。该图在 README 中作为 `ghidriff` 工具的概览，展示了其核心工作流程。

## 图的整体布局
图采用从左到右的布局。左侧是输入节点，中间是核心组件 `GhidraDiffEngine`，右侧是输出结果。

## 分组/子图/阶段说明
图中包含一个名为 `diffs_output_dir` 的子图，用于表示差异分析结果的输出目录，其中包含 Markdown、JSON 和并排 HTML 三种格式的报告。

## 节点逐项说明
- **a (old binary - rpcrt4.dll-v1)**：代表旧版本的二进制文件，例如 `rpcrt4.dll` 的 v1 版本，作为差异分析的输入之一。
- **c (new binary - rpcrt4.dll-v2)**：代表新版本的二进制文件，例如 `rpcrt4.dll` 的 v2 版本，作为差异分析的另一个输入。
- **b [GhidraDiffEngine]**：`ghidriff` 的核心组件，即 Ghidra 差异分析引擎，负责接收两个二进制文件作为输入，并执行差异分析。根据 README，`GhidraDiffEngine` 类位于 `ghidriff/ghidra_diff_engine.py`。
- **e (Ghidra Project Files)**：代表 Ghidra 项目文件，`GhidraDiffEngine` 在进行差异分析时会使用到 Ghidra 项目文件。
- **diffs_output_dir**：代表差异分析结果输出的目录。
- **i (rpcrt4.dll-v1-v2.diff.md)**：差异分析结果的 Markdown 格式报告。
- **h (rpcrt4.dll-v1-v2.diff.json)**：差异分析结果的 JSON 格式数据。
- **j (rpcrt4.dll-v1-v2.diff.side-by-side.html)**：差异分析结果的并排 HTML 格式报告。

## 连线、分支与汇聚关系
- `a -> b`：旧版本二进制文件作为输入传递给 `GhidraDiffEngine`。
- `c -> b`：新版本二进制文件作为输入传递给 `GhidraDiffEngine`。
- `b -> e`：`GhidraDiffEngine` 使用 Ghidra 项目文件进行差异分析。
- `b -> diffs_output_dir`：`GhidraDiffEngine` 将差异分析结果输出到 `diffs_output_dir` 目录中。

## 仓库语境与术语解释
- **GhidraDiffEngine**：`ghidriff` 的核心组件，用于执行二进制文件差异分析。README 中提到它利用 Ghidra 的 ProgramAPI 和 FlatProgramAPI。
- **Ghidra Project Files**：Ghidra 用于存储项目信息的文件集合。
- **Markdown Output**：`ghidriff` 的一个重要特性是生成易于分享和发布的 Markdown 格式差异报告，方便用户进行漏洞分析、补丁分析等工作。
- **JSON Output**：差异分析结果的 JSON 格式数据，方便程序化处理。
- **Side-by-side HTML**：并排 HTML 格式的差异报告，方便人工对比分析。
- **rpcrt4.dll**：图中示例使用的 Windows 系统文件，用于演示 `ghidriff` 的差异分析能力。
- **pyghidra**：一个 Python 库，用于编排 Ghidra 的运行。`ghidriff` 使用它作为 Python 到 Java 的接口。
- **find_matches**：`GhidraDiffEngine` 类中的抽象方法，用于实现具体的差异分析算法。不同的 diff 实现（如 SimpleDiff、StructuralGraphDiff、VersionTrackingDiff）会覆盖此方法。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 `ghidriff` 工具的核心流程：旧版本二进制文件和新版本二进制文件被输入到 `GhidraDiffEngine` 中，`GhidraDiffEngine` 利用 Ghidra 项目文件进行差异分析，并将分析结果以 Markdown、JSON 和并排 HTML 三种格式输出到 `diffs_output_dir` 目录中。`GhidraDiffEngine` 是核心组件，它利用 Ghidra 的 ProgramAPI 进行差异分析，并支持多种输出格式，方便用户进行漏洞分析和补丁分析。
