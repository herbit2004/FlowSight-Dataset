## Edges, Branches & Convergence
- `User Event Stream --> Event Router`: Incoming user event data is sent to the event router.
- `Event Router -- Route Key: UserID --> User Session Aggregator`: Events with the UserID route key are sent to the user session aggregator.
- `Event Router -- Route Key: AdID --> Campaign Budget Monitor`: Events with the AdID route key are sent to the campaign budget monitor.
- `User Session Aggregator --> Session Window`: Aggregated user session data is sent to the session window.
- `Session Window -- Window Closed --> Anomaly Detector`: When the session window closes, the data is sent to the anomaly detector.
- `Anomaly Detector -- Anomaly Detected --> Alert Service`: If an anomaly is detected, an alert is sent to the alert service.
- `Anomaly Detector -- No Anomaly --> Session Store`: If no anomaly is detected, the session data is sent to the session store.
- `Campaign Budget Monitor --> Aggregated Spend`: Campaign budget data is sent to the aggregated spend.
- `Aggregated Spend --> Budget Window`: Aggregated spend data is sent to the budget window.
- `Budget Window -- Window Closed --> Budget Comparator`: When the budget window closes, the data is sent to the budget comparator.
- `Budget Comparator -- Budget Exceeded --> Campaign Pauser`: If the budget is exceeded, the campaign is paused.
- `Budget Comparator -- Budget OK --> Budget Metrics`: If the budget is OK, the budget metrics are stored.
- `Campaign Pauser --> Pause Notification`: A pause notification is sent when a campaign is paused.
- `Alert Service --> AlertService`: The Alert Service sends alerts.
- `Session Store --> Session Metrics`: Session data is used to generate session metrics.
- `Budget Metrics --> Budget Performance`: Budget metrics are used to generate budget performance data.
- `Alert Service --> Dashboard Updates`: The Alert Service sends updates to the dashboard.
- `Pause Notification --> Dashboard Updates`: Pause notifications are sent to the dashboard.
- `Session Metrics --> Dashboard Updates`: Session metrics are sent to the dashboard.
- `Budget Performance --> Dashboard Updates`: Budget performance data is sent to the dashboard.
- `Pause Notification --> AlertService`: Pause notifications are sent to the AlertService.

## Repository Context & Terminology
- **User Event Stream**: A continuous flow of data representing user actions or events within a system.
- **Event Router**: A component responsible for directing events to the appropriate processing module based on event type or attributes.
- **User Session Aggregator**: A module that groups user events into sessions based on time or activity.
- **Campaign Budget Monitor**: A component that tracks campaign spending and compares it against a predefined budget.
- **Anomaly Detector**: A module that identifies unusual patterns or deviations in user behavior or system performance.
- **Alert Service**: A service responsible for sending notifications or alerts based on detected anomalies or budget overruns.
- **Dashboard Updates**: A process that updates a dashboard with the latest data and insights.

The "Alert Service" and "Pause Notification" both send updates to the "AlertService" and "Dashboard Updates." The "Session Metrics" and "Budget Performance" also contribute to the "Dashboard Updates," providing a consolidated view of system status and performance.
