## Diagram Type & Purpose
This is a flowchart diagram. It depicts the process of scanning for 5G New Radio (NR) signals. The flowchart outlines the steps involved in selecting a 5G NR band, calculating the Global Synchronization Channel Number (GSCN) range, tuning a Universal Software Radio Peripheral (USRP) to a specific frequency, detecting Synchronization Signal Block (SSB) signals, saving detection results, updating a web user interface (UI), and determining if more frequencies need to be scanned.

## Overall Layout
The diagram's primary direction is top-down (TD). It follows a sequential flow with a loop for frequency iteration. The start node is "Start Scanning" and the end node is "Scan Complete".

## Subgraphs / Stages
The diagram contains one explicit subgraph: "Frequency Iteration". This subgraph encapsulates the steps involved in scanning a range of frequencies.

## Edges, Branches & Convergence
- `Start --> SelectBand`: Initiates the selection of a 5G NR band.
- `SelectBand --> CalcGSCN`: Triggers the calculation of the GSCN range.
- `CalcGSCN --> GetFreq`: Starts the frequency iteration loop by getting the next GSCN frequency.
- `GetFreq --> TuneUSRP`: Tunes the USRP to the retrieved frequency.
- `TuneUSRP --> Detect`: Checks for SSB signal detection.
- `Detect -- Yes --> SaveResult`: If an SSB signal is detected, the detection result is saved.
- `Detect -- No --> UpdateUI`: If no SSB signal is detected, the web UI progress is updated.
- `SaveResult --> UpdateUI`: After saving the detection result, the web UI progress is updated.
- `UpdateUI --> MoreFreq`: Checks if there are more frequencies to scan.

- `MoreFreq -- No --> Complete`: If there are no more frequencies, the scanning process is complete.
- `GetFreq --> TuneUSRP`: The "Frequency Iteration" subgraph loops back to "Get Next GSCN Frequency" to continue scanning frequencies.

## Repository Context & Terminology
- **5G NR**: 5G New Radio, the global standard for the fifth generation of wireless communications.
- **GSCN**: Global Synchronization Channel Number, a number that represents the frequency of the synchronization signal block (SSB) in 5G NR.
- **3GPP TS 38.104**: A technical specification from the 3rd Generation Partnership Project (3GPP) that defines the technical requirements for 5G NR base stations.
- **USRP**: Universal Software Radio Peripheral, a software-defined radio platform used for transmitting and receiving radio signals.
- **SSB**: Synchronization Signal Block, a set of signals used for initial cell search and synchronization in 5G NR.
- **Web UI**: Web User Interface, a graphical interface accessible through a web browser, used to monitor and control the scanning process.
