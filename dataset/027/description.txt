## 图类型与用途
这是一个架构图，展示了 Rovo Dev AI 代理的源代码结构和主要组成部分。该图用于概括 Rovo Dev 的内部架构，方便理解其功能模块及其相互关系。

## 图的整体布局
图采用从上到下的布局。顶部是 Rovo Dev Source，作为整个架构的起点，向下分别连接到 Core Modules、AI Instructions、Analytics System、User Interface 和 Command Handlers。

## 分组/子图/阶段说明
图中没有显式子图/分组，但逻辑上可以分为五个主要的功能模块：核心模块、AI 指令、分析系统、用户界面和命令处理程序。

## 节点逐项说明
- **A[Rovo Dev Source]**: 代表 Rovo Dev AI 代理的完整源代码，是整个架构的起点。
- **B[Core Modules]**: 核心模块，包含 Rovo Dev 的基础功能。
    - **B1[MCP Utils]**: 模型上下文协议 (MCP) 工具，用于与模型进行交互。根据 `lib/atlassian_cli_rovodev/src/rovodev/modules/mcp_utils.py`，该模块包含运行 MCP 服务器并处理相关错误的函数。
    - **B2[Session Management]**: 会话管理，负责处理用户会话的创建、维护和销毁。
    - **B3[Memory System]**: 内存系统，管理 Rovo Dev 运行时的内存分配和释放。
    - **B4[Tool Permissions]**: 工具权限，控制 Rovo Dev 可以使用的工具和资源的访问权限。
- **C[AI Instructions]**: AI 指令，包含 Rovo Dev 使用的各种提示词和指令集。
    - **C1[Code Review Prompts]**: 代码审查提示词，用于指导 Rovo Dev 进行代码审查。
    - **C2[Test Generation]**: 测试生成，用于生成单元测试和其他类型的测试。
    - **C3[Documentation]**: 文档生成，用于自动生成代码文档。
    - **C4[Jira Integration]**: Jira 集成，允许 Rovo Dev 与 Jira 问题跟踪系统进行交互。
- **D[Analytics System]**: 分析系统，用于收集和分析 Rovo Dev 的使用数据。
    - **D1[Usage Tracking]**: 使用情况跟踪，记录 Rovo Dev 的使用频率和方式。
    - **D2[Command Analytics]**: 命令分析，分析用户执行的命令。
    - **D3[Code Metrics]**: 代码指标，收集代码质量和复杂度的指标。
    - **D4[User Behavior]**: 用户行为，跟踪用户的交互模式。
- **E[User Interface]**: 用户界面，提供用户与 Rovo Dev 交互的接口。
    - **E1[Terminal Interface]**: 终端界面，通过命令行与用户交互。
    - **E2[Interactive Prompts]**: 交互式提示，引导用户输入和选择。
    - **E3[Session Panels]**: 会话面板，显示当前会话的状态和信息。
    - **E4[Token Display]**: Token 显示，显示使用的 Token 数量。
- **F[Command Handlers]**: 命令处理程序，负责处理用户输入的命令。
    - **F1[Auth Commands]**: 身份验证命令，处理用户身份验证。
    - **F2[Config Management]**: 配置管理，管理 Rovo Dev 的配置参数。
    - **F3[MCP Server]**: MCP 服务器，处理与 MCP 的通信。
    - **F4[Log Handling]**: 日志处理，记录 Rovo Dev 的运行日志。

## 仓库语境与术语解释
- **Rovo Dev**: Atlassian 的 AI 编码代理，该图展示了其内部架构。
- **ACLI**: 包含 Rovo Dev 源代码的二进制文件，该仓库的目标是从 `acli` 二进制文件中逆向工程提取 Rovo Dev 的源代码。
- **MCP (Model Context Protocol)**: Rovo Dev 使用的 AI 框架，用于与模型进行交互。`lib/atlassian_cli_rovodev/src/rovodev/modules/mcp_utils.py` 文件定义了与 MCP 服务器交互的实用工具。
- **AI Instructions**: 包含 Rovo Dev 使用的各种提示词和指令集，例如代码审查、测试生成和文档生成。`lib/atlassian_cli_rovodev/src/rovodev/modules/instructions/instructions.yml` 文件定义了指令的列表。
- **Analytics System**: 用于收集和分析 Rovo Dev 的使用数据，包括命令使用模式、工具执行指标和代码修改跟踪。`lib/atlassian_cli_rovodev/src/rovodev/modules/analytics/__init__.py` 文件初始化分析模块。
- **User Interface**: 提供用户与 Rovo Dev 交互的接口，包括终端界面、交互式提示和会话面板。
- **Command Handlers**: 负责处理用户输入的命令，包括身份验证、配置管理和日志处理。
