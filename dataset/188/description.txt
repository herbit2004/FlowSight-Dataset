## High-Density QA Ground Truth Summary
The flowchart begins with the Claude Code CLI, which triggers the Hook System via a PreToolUse Hook. The Hook System then passes the request to the Path Converter, followed by the Decision Engine. The Decision Engine determines whether to delegate the request. If the "Delegate?" condition is "Yes", the request is passed to the Cache Layer. The Cache Layer then forwards the request to the Gemini CLI, which interacts with the Gemini API. The Gemini API returns an Analysis to the Cache Layer, which in turn returns a Response to the Hook System. The Hook System then returns a Result back to the Claude Code CLI, completing the loop. If the Decision Engine's "Delegate?" condition is "No", the flow bypasses the Cache Layer and Gemini APIs, returning directly to the Claude Code CLI. The Cache Layer serves to store and retrieve responses, potentially improving performance and reducing API calls to the external Gemini APIs. The Hook System allows for pre- and post-processing of requests, enabling flexible integration between Claude and Gemini.
