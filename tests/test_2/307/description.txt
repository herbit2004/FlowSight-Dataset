## Repository Context & Terminology
- **Adapter Layer**: The outermost layer responsible for interacting with external systems, such as handling HTTP requests or RPC calls.
- **Application Layer**: This layer contains the application's use cases and orchestrates the interaction between domain objects and infrastructure components.
- **Domain Layer**: The core of the application, containing the business logic and domain models.
- **Infrastructure Layer**: This layer provides the technical capabilities needed by the application, such as database access, messaging, and external system integration.
- **Anti-corruption Layer**: A design pattern used to isolate the domain model from external systems or legacy code, preventing them from corrupting the domain.
- **Data Transfer Object (DTO)**: An object used to transfer data between layers or systems, often used to decouple the domain model from the presentation layer.
- **Aggregate Root**: A domain entity that acts as the entry point for accessing and manipulating a cluster of related entities and value objects.
