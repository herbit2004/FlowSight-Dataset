## Repository Context & Terminology
- **ETL (Extract, Transform, Load)**: A data integration process that involves extracting data from various sources, transforming it into a usable format, and loading it into a data warehouse or data lake.
- **Lakehouse**: A data management architecture that combines the features of a data lake and a data warehouse.
- **dbt (data build tool)**: A command-line tool that enables data analysts and engineers to transform data in their data warehouses more effectively.
- **Vector Database**: A database that stores data as high-dimensional vectors, enabling efficient similarity searches and retrieval of related information.
- **Milvus**: An open-source vector database designed for managing large-scale vector embeddings.
- **LLM (Large Language Model)**: A deep learning model trained on a massive dataset of text and code, capable of generating human-quality text, translating languages, and answering questions.
- **Ollama**: A tool that allows you to run large language models locally.
- **RAG (Retrieval-Augmented Generation)**: A technique that combines a pre-trained language model with a retrieval mechanism to generate more informative and context-aware responses.
- **Apache Superset**: An open-source data exploration and visualization platform.
