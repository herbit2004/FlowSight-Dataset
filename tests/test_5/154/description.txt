## Repository Context & Terminology
- **Character**: A virtual entity with a profile, knowledge, and backend services.
- **Knowledge/RAG**: A component that enables the character to retrieve and generate responses based on a knowledge base.
- **Backend**: A service that provides functionality for the character, such as message handling, memory management, and prompt generation.
- **Prompt**: A predefined text or instruction used to guide the character's responses.
- **Template**: A pre-formatted structure for prompts, allowing for dynamic content insertion.
- **Variables**: Placeholders within prompts that can be replaced with specific values.
- **Moderation Settings**: Configurations that control the character's behavior and prevent inappropriate responses.
