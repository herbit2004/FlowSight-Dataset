## Repository Context & Terminology
- **USRP (Universal Software Radio Peripheral)**: A software-defined radio (SDR) platform used for transmitting and receiving radio signals. The USRP X310 is a specific model.
- **FPGA (Field-Programmable Gate Array)**: An integrated circuit that can be reconfigured after manufacturing, allowing for custom hardware acceleration.
- **RFNoC (Radio Frequency Network on Chip)**: A framework for building SDR applications on USRP devices with FPGAs.
- **SSB (Synchronization Signal Block)**: A set of signals used in 5G NR for cell search and synchronization.
- **GSCN (Global Synchronization Channel Number)**: A unique identifier for a 5G NR cell.
- **config.py**: Python file likely containing configuration parameters for the system.
- **gscn_calculator.py**: Python file likely containing the logic for calculating the GSCN.
- **usrp_controller.py**: Python file likely containing the logic for controlling the USRP device.

## High-Density QA Ground Truth Summary
The system begins with the Web Interface Layer, where a user interacts with the Web UI (HTML/CSS/JavaScript) and the REST API (Flask Backend). Configuration data flows from the REST API to the Core Application Layer's Config Manager (config.py). The Config Manager interacts with the GSCN Calculator (gscn_calculator.py) to determine the Global Synchronization Channel Number. The GSCN Calculator then communicates with the USRP Controller (usrp_controller.py) to configure the USRP device. The USRP Controller sends commands to the Hardware Layer, specifically the FPGA Bitstream for custom processing and the RFNoC Blocks for SSB Detection on the USRP X310 SDR Platform. The RF signals are received by the Antenna in the RF & Network Layer, which interacts with SSB Signals (n1/n3/n77/n78/n79) and the gNodeB Base Station. The USRP Controller captures data and stores scan results in `detected_frequencies.json` and raw signal data in `.dat` files within the Data Storage Layer. The `config.json` file in the Data Storage Layer holds the system's settings. The USRP, a key component, is controlled by the `usrp_controller.py` script, enabling the system to capture and process radio signals.
