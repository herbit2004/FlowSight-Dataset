## Repository Context & Terminology
- **CloudFront CDN**: A content delivery network (CDN) service that caches static and dynamic content to reduce latency and improve performance for users accessing the application from different geographic locations.
- **ALB/NLB**: Application Load Balancer (ALB) and Network Load Balancer (NLB) are AWS load balancing services that distribute incoming application traffic across multiple targets, such as EC2 instances, containers, and IP addresses. ALB operates at the application layer (HTTP/HTTPS), while NLB operates at the transport layer (TCP/UDP).
- **Auto Scaling Group**: An Auto Scaling Group (ASG) is a collection of EC2 instances that are treated as a logical grouping for the purposes of automatic scaling and management. ASGs allow you to automatically adjust the number of EC2 instances in your application based on demand or other metrics.
- **EC2 Instances**: Elastic Compute Cloud (EC2) instances are virtual servers in the cloud that provide compute capacity for running applications.
- **ECS Fargate**: Elastic Container Service (ECS) Fargate is a serverless compute engine for containers that allows you to run containers without having to manage the underlying infrastructure.
- **RDS Multi-AZ**: Relational Database Service (RDS) Multi-AZ is a deployment option for RDS databases that provides high availability and failover capabilities by automatically provisioning and maintaining a standby database instance in a different Availability Zone.
- **DynamoDB**: A fully managed NoSQL database service that provides fast and predictable performance with seamless scalability.
- **ElastiCache Redis**: A fully managed, in-memory data store service that supports the Redis data structure server. It is often used for caching to improve application performance.
- **CloudWatch Monitoring**: A monitoring and observability service that provides data and actionable insights to monitor applications, respond to performance changes, and optimize resource utilization.
- **SNS Alerts**: Simple Notification Service (SNS) is a messaging service that enables you to send notifications to subscribers based on events or triggers.
