## Repository Context & Terminology
- **Kubernetes Pod**: A Kubernetes Pod is the smallest deployable unit in Kubernetes. It is a group of one or more containers, with shared storage/network, and a specification for how to run the containers.
- **Container**: A standard unit of software that packages up code and all its dependencies so the application runs quickly and reliably from one computing environment to another.
- **Sidecar Pattern**: A design pattern where a secondary container (the sidecar) augments and supports the main application container. This is often used for cross-cutting concerns like logging, monitoring, or security.
- **localhost**: The standard hostname given to the address of the loopback network interface.
- **Shared Network Namespace**: A shared network namespace allows containers within a pod to share the same network interfaces and IP addresses.
- **Shared Volumes**: Volumes provide shared storage that can be accessed by all containers in a pod.
