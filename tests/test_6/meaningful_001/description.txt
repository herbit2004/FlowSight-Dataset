## Edges, Branches & Convergence
- `A --> B`: The order request is passed to the fraud check decision.
- `B -- Yes --> C`: If a fraud check is required, the process proceeds to the fraud detection service.
- `B -- No --> F`: If a fraud check is not required, the process skips the fraud detection and proceeds to payment authorization.
- `C --> D`: The fraud detection service provides a fraud score which is then evaluated against a threshold.
- `D -- Yes --> E`: If the fraud score is greater than the threshold, the order is rejected.
- `D -- No --> F`: If the fraud score is not greater than the threshold, the process proceeds to payment authorization.
- `F --> G`: After payment authorization, an order record is created.
- `G --> H`: After creating the order record, an order confirmation is sent.
