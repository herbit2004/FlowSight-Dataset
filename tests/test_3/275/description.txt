## Diagram Type & Purpose
This is a flowchart diagram illustrating a deep research loop. It depicts the flow of information and control between different agents involved in the research process, from initial user input to the final output generated by a writer agent. The diagram serves as a high-level overview of the research workflow.

## Overall Layout
The diagram has a left-to-right (LR) primary direction. It consists of a central subgraph representing the "Deep Research Loop," with the "User Input" node on the left and the "Writer Agent" node on the right. The flow starts at the "User Input" node and ends at the "Writer Agent" node.

## Subgraphs / Stages
The diagram contains one explicit subgraph:
- **Deep Research Loop**: This subgraph encapsulates the core iterative research process, including knowledge gap analysis, tool selection, tool execution, observation, and reflection.

- **A / User Input**: Represents the initial input provided by the user, including the query, maximum iterations, maximum time, and output instructions. visible in diagram; no further repository context available.
- **B / Knowledge Gap Agent**: Represents an agent responsible for identifying knowledge gaps based on the current state of knowledge and the research objective. visible in diagram; no further repository context available.
- **C / Tool Selector Agent**: Represents an agent that selects appropriate tools for conducting research based on the identified knowledge gaps and objective. visible in diagram; no further repository context available.
- **D / Tool Agents**: Represents a collection of agents that execute tool queries in parallel, including web search, crawler, and custom tools. visible in diagram; no further repository context available.
- **E / Observations Agent**: Represents an agent that collects and synthesizes observations from the tool agents' outputs. visible in diagram; no further repository context available.
- **F / Writer Agent**: Represents an agent that generates the final output with references based on the observations and analysis. visible in diagram; no further repository context available.

## Edges, Branches & Convergence
- `A --> B`: The user input is fed into the Knowledge Gap Agent.
- `B --> C`: The current gaps and objective are passed from the Knowledge Gap Agent to the Tool Selector Agent.
- `C --> D`: Tool queries are passed from the Tool Selector Agent to the Tool Agents.
- `D --> E`: New findings are passed from the Tool Agents to the Observations Agent.
- `E --> F`: The final output is generated by the Writer Agent based on the observations.
- `E --> B`: Thoughts on findings and research strategy are fed back from the Observations Agent to the Knowledge Gap Agent, closing the research loop.

## Repository Context & Terminology
- **Agent**: In the context of this diagram, an agent refers to an autonomous software component that performs a specific task within the research process.
- **Tool**: A tool refers to any resource or application used by the agents to gather information, such as a web search engine, a crawler, or a custom-built script.
- **Knowledge Gap**: A knowledge gap represents a deficiency in the current understanding of a particular topic, which the research process aims to address.
- **Iteration**: The research loop is iterative, meaning that it repeats until a satisfactory output is achieved or a predefined limit (max_iterations, max_time) is reached.
- **Query**: The initial question or topic that the research process aims to investigate.
- **Findings**: The information and insights gathered during the research process.
