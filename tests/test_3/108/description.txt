## Repository Context & Terminology
- **Episodic Memory**: A memory system that stores autobiographical events.
- **Working Memory**: A cognitive system with a limited capacity responsible for temporarily holding information available for processing.
- **Long-term Memory**: A memory system for storing, managing, and retrieving information over extended periods of time.
- **Vector Store**: A database that stores data as vector embeddings, enabling efficient similarity searches.
- **Knowledge Base**: A structured repository of information, facts, rules, and relationships about a specific domain.
- **Embeddings**: Numerical representations of data (text, images, etc.) that capture semantic relationships.
- **Domain Expertise**: Specialized knowledge or skill in a particular area or field.
