## Edges, Branches & Convergence
- `UM --> API`: User message is sent to RESTful APIs.
- `API --> RME`: RESTful APIs trigger a message event.
- `RME --> BP`: Message event triggers backend processing.
- `BP --> Auth`: Backend processing leads to authentication check.
- `Auth -- Yes --> LMDB`: If user is authenticated, load conversation history from MongoDB.
- `Auth -- No --> LBrowser`: If user is not authenticated, load conversation history from local browser storage.
- `LMDB --> Prep`: Conversation history from MongoDB is used to prepare AI agent input.
- `LBrowser --> Prep`: Conversation history from local browser storage is used to prepare AI agent input.
- `Prep --> AInput`: Prepared input is fed into the AI agent.
- `AInput --> Orchestration`: AI agent input leads to agent tool orchestration.
- `Orchestration --> UsePinecone`: Agent tool orchestration leads to a decision on whether to use data from Pinecone.
- `UsePinecone -- Yes --> QueryPinecone`: If data from Pinecone is to be used, query vectorized properties data from Pinecone.
- `UsePinecone -- No --> NoPinecone`: If data from Pinecone is not to be used, proceed without RAG data from Pinecone.
- `QueryPinecone --> MOE`: Vectorized properties data from Pinecone is fed into the mixture-of-experts API request pipeline.
- `NoPinecone --> MOE`: Proceeding without RAG data from Pinecone leads to the mixture-of-experts API request pipeline.
- `QueryPinecone` and `NoPinecone` converge at `MOE`.
- `MOE --> Generate`: The mixture-of-experts API request pipeline generates the final response.
- `Generate --> APIResp`: The final response is sent as an API request response.
- `APIResp --> Display`: The API request response is displayed in the user interface.
- `Display --> Rate`: The displayed response prompts the user to rate the response.
- `Rate -- Thumbs Down --> Update`: If the user gives a thumbs down, update expert weights and go through another API request.
- `Update --> MOE`: The update process loops back to the mixture-of-experts API request pipeline.
- `Rate -- Thumbs Up --> End`: If the user gives a thumbs up, no update is needed.

## Repository Context & Terminology
- **RESTful APIs**: Represent an architectural style for building web services. In this context, they handle incoming user messages.
- **MongoDB**: A NoSQL database used to store conversation history for authenticated users.
- **Pinecone**: A vector database used for storing and querying vectorized property data, enabling Retrieval-Augmented Generation (RAG).
- **RAG (Retrieval-Augmented Generation)**: A technique that enhances the AI model's knowledge by retrieving relevant information from a database (Pinecone in this case) and incorporating it into the response generation process.
- **Mixture-of-Experts (MoE)**: An ensemble learning technique where multiple specialized AI models (experts) are combined to produce a final output.
- **AI Agent**: A software entity that perceives its environment through sensors and acts upon that environment through actuators. In this context, it processes user messages and generates responses.
- **Expert Weights**: Parameters that determine the contribution of each expert in the Mixture-of-Experts model. These weights are adjusted based on user feedback.
