## Diagram Type & Purpose
This is a flowchart diagram illustrating a decision-making process within an agent-based system. The diagram outlines how a user query is processed, how the system selects a sub-workflow based on LLM reasoning, and how the final response is generated. It serves as a visual representation of the system's workflow and decision-making logic.

## Overall Layout
The diagram's layout is top-down (TD). It starts with a "User Query" node at the top and flows down through several stages, ultimately converging at the "Final Response" node at the bottom. The diagram depicts a hierarchical process with branching based on the "Sub-Workflow Selection" node.

## Subgraphs / Stages
No explicit subgraphs; logically divided into 5 stages: User Input, Agent Processing, Workflow Selection, Workflow Execution, and Response Generation.

## Edges, Branches & Convergence
- `Input --> Agent`: The user query is passed to the agent.
- `Agent --> FlowChoice`: The agent performs LLM reasoning and passes the result to the sub-workflow selection.
- `FlowChoice -- Decision A --> Flow1`: If Decision A is made, "Deterministic Workflow 1" is selected.
- `FlowChoice -- Decision B --> Flow2`: If Decision B is made, "Deterministic Workflow 2" is selected.
- `FlowChoice -- Decision C --> DirectResponse`: If Decision C is made, a response is generated directly.
- `Flow1 --> Flow1Result`: "Deterministic Workflow 1" executes, leading to a result. The edge is labeled "Step 1 → 2 → 3 → ... → 200".
- `Flow2 --> Flow2Result`: "Deterministic Workflow 2" executes, leading to a result. The edge is labeled "Step 1 → 2 → 3 → ... → 100".
- `Flow1Result --> Response`: The result of "Workflow 1" contributes to the final response.
- `Flow2Result --> Response`: The result of "Workflow 2" contributes to the final response.
- `DirectResponse --> Response`: The directly generated response becomes part of the final response.
- `Flow1Result, Flow2Result, DirectResponse --> Response`: The results from the selected workflow(s) and/or the direct response converge to form the final response.

## Repository Context & Terminology
- **AgentNode**: A component responsible for processing user queries and interacting with other parts of the system.
- **LLM Reasoning**: The process of using a Large Language Model to reason about the user query and determine the appropriate sub-workflow.
- **Deterministic Workflow**: A workflow with a predictable sequence of steps and outcomes.
- **Sub-Workflow Selection**: The process of choosing a specific workflow to execute based on the LLM's reasoning.
- **Decision A/B/C**: Represents different decision outcomes from the sub-workflow selection process. These decisions determine which path the system will take.
