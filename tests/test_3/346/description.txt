## Repository Context & Terminology

- **Mutation Testing**: A type of software testing where the source code is intentionally modified (mutated) to create "mutants." The goal is to determine if the existing test suite can detect these mutations.
- **Go Debugger**: A debugger for the Go programming language, allowing developers to step through code, inspect variables, and identify issues.
- **Pull Request (PR)**: A method of submitting code changes to a project, allowing for review and discussion before merging.
