## Edges, Branches & Convergence
- `UM --> API`: User message is sent to RESTful APIs.
- `API --> RME`: RESTful APIs trigger a receive message event.
- `RME --> BP`: Receive message event triggers backend processing.
- `BP --> Auth`: Backend processing leads to authentication check.
- `Auth -- Yes --> LMDB`: If the user is authenticated, load conversation history from MongoDB.
- `Auth -- No --> LBrowser`: If the user is not authenticated, load conversation history from local browser storage.
- `LMDB --> Prep`: Conversation history from MongoDB is used to prepare the AI agent input.
- `LBrowser --> Prep`: Conversation history from local browser storage is used to prepare the AI agent input.
- `Prep --> AInput`: Prepared input is fed to the AI agent.
- `AInput --> Orchestration`: AI agent input is used for agent tool orchestration.
- `Orchestration --> UsePinecone`: Agent tool orchestration leads to a decision on whether to use data from Pinecone.
- `UsePinecone -- Yes --> QueryPinecone`: If data from Pinecone is to be used, query vectorized properties data from Pinecone.
- `UsePinecone -- No --> NoPinecone`: If data from Pinecone is not to be used, proceed without RAG data from Pinecone.
- `QueryPinecone --> MOE`: Vectorized properties data from Pinecone is used in the mixture-of-experts API request pipeline.
- `NoPinecone --> MOE`: Proceeding without RAG data from Pinecone leads to the mixture-of-experts API request pipeline.
- `MOE --> Generate`: The mixture-of-experts API request pipeline generates the final response.
- `Generate --> APIResp`: The generated response is sent as an API request response.
- `APIResp --> Display`: The API request response is displayed in the user interface.
- `Display --> Rate`: The displayed response prompts the user to rate the response.
- `Rate -- Thumbs Down --> Update`: If the user gives a thumbs down, update expert weights and go through another API request.
- `Update --> MOE`: The updated expert weights are used in the mixture-of-experts API request pipeline, creating a feedback loop.
- `Rate -- Thumbs Up --> End`: If the user gives a thumbs up, no update is needed.

## Repository Context & Terminology
- **RESTful APIs**: Represent an architectural style for building web services. In this context, they handle incoming user messages and trigger backend processing.
- **MongoDB**: A NoSQL database used for storing conversation history when the user is authenticated.
- **Local Browser Storage**: A mechanism for storing conversation history locally in the user's browser when the user is not authenticated.
- **AI Agent**: A software entity that uses AI algorithms to process user messages and generate responses.
- **Pinecone**: A vector database used for storing and querying vectorized properties data, enabling retrieval-augmented generation (RAG).
- **RAG (Retrieval-Augmented Generation)**: A technique that combines information retrieval with text generation to improve the quality and relevance of AI-generated responses.
- **Mixture-of-Experts**: An ensemble learning technique where multiple specialized AI experts are combined to generate a final response.
- **Expert Weights**: Parameters that determine the contribution of each AI expert in the mixture-of-experts model.
