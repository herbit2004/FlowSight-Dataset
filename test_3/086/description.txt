## Edges, Branches & Convergence
- `A1 --> A2`: A code commit to the main branch triggers the GitHub Actions workflow.
- `A2 --> A3`: The GitHub Actions workflow triggers the building of a Docker image.
- `A3 --> A4`: The Docker image is tagged with the commit SHA.
- `A4 --> A5`: The Docker image is pushed to ECR.
- `A5 --> A6`: The IMAGE_URI environment variable is set.
- `A6 --> A7`: Terraform is initialized.
- `A7 --> A8`: The Terraform plan is run with the IMAGE_URI.
- `A8 --> A9`: The Terraform plan is applied.
- `A9 --> T1`: The Terraform stage is initiated after applying the Terraform plan.
- `T1 --> T2`: The Terraform backend is initialized, and variables are loaded from `variables.tf`.
- `T2 --> T3`: The `container_definitions.json.tpl` file is used.
- `T3 --> T4`: The ECS task definition is created or updated.
- `T4 --> E2`: ECS pulls the image from ECR after the task definition is updated.
- `T4 --> T5`: The ECS service is updated.
- `T5 --> T6`: Information is output from `outputs.tf`.
- `E1 --> E2`: ECR stores the Docker image, which ECS then pulls.
- `E2 --> E3`: Containers are run using the ECS task definition.
- `E3 --> E4`: The ECS service is updated with the new containers.

## Repository Context & Terminology
- **GitHub Actions**: A CI/CD platform that allows you to automate your build, test, and deployment pipeline.
- **Terraform**: An infrastructure-as-code tool that allows you to define and provision infrastructure using a declarative configuration language.
- **AWS ECS**: Amazon Elastic Container Service, a fully managed container orchestration service.
- **ECR**: Amazon Elastic Container Registry, a fully managed Docker container registry.
- **IMAGE_URI**: An environment variable that stores the URI of the Docker image in ECR.
- **variables.tf**: A Terraform file that defines the input variables for the Terraform configuration.
- **container_definitions.json.tpl**: A template file used to define the container definitions for the ECS task definition.
- **outputs.tf**: A Terraform file that defines the output values for the Terraform configuration.
