## 图类型与用途
这是一个架构图，描述了 `beads_viewer` (bv) 的数据流和组件，以及它们之间的关系。该图旨在清晰地呈现 `beads_viewer` 工具的整体架构和工作流程，帮助理解数据如何从存储层流向分析引擎，最终呈现给用户或导出为报告。

## 图的整体布局
图采用从上到下的布局，将组件分为四个主要层级：Data Layer、Analysis Engine、TUI Layer 和 Outputs。数据从顶部的 Data Layer 流向底部的 TUI Layer 和 Outputs。

## 分组/子图/阶段说明
图中包含四个显式子图：
- **📂 Data Layer**：存储 Beads issue tracker 数据的 JSONL 文件。
- **⚙️ Analysis Engine**：负责从 JSONL 文件加载数据，构建图结构，并进行各种网络指标计算。
- **🖥️ TUI Layer**：使用 Bubble Tea 框架构建的终端用户界面，用于展示 issue 数据和分析结果。
- **📤 Outputs**：将分析结果导出为 JSON 格式（供 AI 代理使用）或 Markdown 格式。

## 节点逐项说明
- **A[".beads/beads.jsonl JSONL Issue Store"]**：存储 Beads issue tracker 数据的 JSONL 文件，是所有数据的来源。
- **B["Loader"]**：负责从 JSONL 文件中加载 issue 数据。
- **C["Graph Builder"]**：根据加载的 issue 数据构建图结构，用于后续的分析。
- **D["9 Metrics PageRank · Betweenness · HITS..."]**：对图结构进行分析，计算各种网络指标，如 PageRank、Betweenness centrality 和 HITS 算法等。
- **E["Bubble Tea Model"]**：使用 Bubble Tea 框架构建的 TUI 模型，是整个界面的核心。
- **F["List View"]**：以列表形式展示 issue 数据的视图。
- **G["Graph View"]**：以图形形式展示 issue 数据的视图。
- **G2["Tree View"]**：以树形结构展示 issue 数据的视图。
- **H["Insights Dashboard"]**：展示分析引擎计算出的各种指标的仪表盘。
- **I["--robot-insights JSON for AI Agents"]**：以 JSON 格式输出分析结果，供 AI 代理使用。
- **J["--export-md Markdown Report"]**：以 Markdown 格式输出报告。

## 连线、分支与汇聚关系
- `A --> B`：Loader 从 JSONL 文件中读取 issue 数据。
- `B --> C`：Loader 将数据传递给 Graph Builder。
- `C --> D`：Graph Builder 构建图结构，并传递给 Metrics 计算模块。
- `D --> E`：Metrics 计算模块将计算结果传递给 TUI 模型。
- `D --> I`：Metrics 计算模块将计算结果输出为 JSON 格式。
- `D --> J`：Metrics 计算模块将计算结果输出为 Markdown 格式。
- `E --> F`：TUI 模型控制 List View 的显示。
- `E --> G`：TUI 模型控制 Graph View 的显示。
- `E --> G2`：TUI 模型控制 Tree View 的显示。
- `E --> H`：TUI 模型控制 Insights Dashboard 的显示。

## 仓库语境与术语解释
- **Beads**：一个 issue tracking 系统，`beads_viewer` 是为其设计的终端用户界面 (TUI) 工具。
- **.beads/beads.jsonl**：存储 issue 数据的 JSONL 文件，`beads_viewer` 从该文件读取数据。
- **Bubble Tea Model**：`beads_viewer` 使用的 TUI 框架，用于构建用户界面。
- **PageRank, Betweenness, HITS**：图分析中常用的网络指标，用于识别关键 issue 和依赖关系。
- **--robot-insights**：命令行参数，用于以 JSON 格式输出分析结果，供 AI 代理使用。
- **--export-md**：命令行参数，用于以 Markdown 格式输出报告。
- **TUI**：Terminal User Interface，即终端用户界面。`beads_viewer` 是一个 TUI 程序，可在终端中运行。

## 可作为 QA Ground Truth 的高信息密度摘要
该图展示了 `beads_viewer` 的架构，数据从 `.beads/beads.jsonl` 文件加载，经过 Loader 和 Graph Builder 处理后，计算出 PageRank、Betweenness 和 HITS 等指标。这些指标被传递给 Bubble Tea Model 构建的 TUI，以 List View、Graph View、Tree View 和 Insights Dashboard 的形式展示给用户，同时也可以通过 `--robot-insights` 和 `--export-md` 导出为 JSON 或 Markdown 格式。该架构的核心是从 issue 数据中提取有价值的图分析信息，并以多种方式呈现。
