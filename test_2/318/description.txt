## Repository Context & Terminology
- **Argo CD**: A declarative, GitOps continuous delivery tool for Kubernetes. It allows defining the desired application state in Git repositories and automatically deploying changes to Kubernetes clusters.
- **Kubernetes Cluster**: A set of node machines for running containerized applications.
- **Continuous Delivery (CD)**: A software development practice where code changes are automatically built, tested, and released to a production environment.
- **GitOps**: A declarative way of implementing continuous deployment for cloud-native applications.
- **Observability**: The ability to understand the internal state of a system based on its external outputs. This typically involves collecting and analyzing metrics, logs, and traces.
- **Dev/Stage/Prod**: Common environment names representing the development, staging, and production stages of a software release lifecycle.
