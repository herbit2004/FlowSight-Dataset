## Repository Context & Terminology
- **@trace / @trace_class**: Python decorators often used for tracing function execution, commonly found in logging or monitoring frameworks.
- **FastAPI**: A modern, fast (high-performance), web framework for building APIs with Python 3.7+ based on standard Python type hints.
- **Middleware**: Software that acts as a bridge between an operating system or database and applications, especially on a network.
- **LangChain**: A framework for developing applications powered by language models.
- **ContextVars**: Provides context-local variables, similar to thread-local storage, but works correctly with async/await code.
- **Event Bus**: A software pattern that allows components to communicate without direct dependencies, often used for logging or asynchronous tasks.
- **SSE (Server-Sent Events)**: A server push technology enabling a server to automatically send data updates to a client's web browser.
- **Mermaid.js**: A JavaScript-based diagramming and charting tool that uses Markdown-inspired text definitions to create diagrams dynamically in the browser.
