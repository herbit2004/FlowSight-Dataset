## Repository Context & Terminology
- **User Story**: A high-level description of a feature from the user's perspective.
- **BDD (Behavior-Driven Development)**: A software development process that focuses on defining the behavior of the system in terms of user stories and acceptance criteria.
- **Gherkin**: A plain-text language used to write BDD specifications.
- **Epic**: A large user story that is broken down into smaller sub-issues.
- **Sub-Issue**: A smaller task that contributes to the completion of an epic.
- **Agent Orchestration**: The automated coordination and execution of tasks by software agents.
- **Pull Request**: A request to merge code changes from a branch into the main codebase.
