## Repository Context & Terminology
- **Intent Router**: A component responsible for understanding the user's intention behind their query.
- **Planner**: A module that creates a structured plan to fulfill the user's intent, often involving multiple steps like information retrieval, reasoning, and answer generation.
- **Retrieval Planner**: A specialized planner focused on optimizing the information retrieval process.
- **FAISS (Facebook AI Similarity Search)**: A library for efficient similarity search and clustering of dense vectors. It's used for quickly finding relevant information based on vector embeddings.
- **Google CSE (Custom Search Engine)**: A programmable search engine that allows developers to create customized search experiences using Google's search infrastructure.
- **Fetch**: A general term for retrieving data from a source, often referring to making HTTP requests to web servers.
- **Guardrails**: Mechanisms to ensure the system's output is safe, ethical, and aligned with desired policies.
