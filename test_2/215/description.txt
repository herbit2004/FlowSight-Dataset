## Repository Context & Terminology
- **FiberRoot**: The root of a Fiber tree, which is a data structure used by React to manage and schedule updates to the user interface.
- **HostRoot Fiber**: The root Fiber node in a React application, representing the top-level component rendered into the DOM.
- **ReactDOMRoot**: The entry point for rendering React content into a DOM node. It provides methods for updating and unmounting the React component tree.
- **Update Queue**: A queue that stores updates to be applied to a Fiber node.
- **Event Delegation**: A technique where event listeners are attached to a parent element instead of individual child elements, improving performance.
- **Pending Lanes**: Lanes represent the priority of different updates. Pending lanes are those that have not yet been processed.
- **Ping Cache**: A cache used to store promises that are currently suspended.
